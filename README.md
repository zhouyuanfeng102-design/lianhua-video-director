# 莲华视频导演台

莲华视频导演台是 Windows PC 端的视频提示词工作台：把一句话、小说片段、场景资料和参考图整理成可编辑的结构化视频时间轴。

## 下载 Windows 便携版

**[下载最新便携版](https://github.com/zhouyuanfeng102-design/lianhua-video-director/releases/latest)**

打开下载页，在 Assets（附件）中选择 `莲华视频导演台-版本号-便携版.exe`，保存到可写入的文件夹后双击运行。适用于 Windows x64，无需安装开发环境。外部 AI 服务需在软件内填写自己的账号和 API 配置。更新前请保存项目并退出旧版，保留原有数据目录。

页面自动生成的 Source code ZIP/TAR 是开发源码；使用软件请下载便携版 EXE。

## GitHub 项目

首次创建仓库、上传源码和发布 Windows 便携版的操作见 [GitHub 发布指南](docs/github-publishing.md)。源码仓库保留程序、图标、构建配置和文档；便携版 EXE 通过 GitHub Releases 单独分发。本机交付目录、测试输出、浏览器缓存、用户数据和下载的媒体工具二进制已加入忽略规则。

从 GitHub 获取源码后，先执行 `npm ci`，再执行 `npm run desktop:dev` 启动桌面开发模式。涉及本地视频处理和 Windows 打包时，还需按 [媒体工具说明](build/media-tools/README.md) 准备 FFmpeg / FFprobe；这些二进制不包含在源码仓库中。外部 AI 服务的账号和 API 配置由使用者在软件内自行填写。

## 产品边界

本项目只负责：

- 剧情拆分、人物/场景/道具连续性整理
- 长剧情按原文进行 AI 语义分段，自定义单段秒数、连续视频段规划与逐段提示词生成；历史总稿流程继续兼容
- 长剧情视频提示词自由选择或全选、同段中英文互斥、逐段参考图设置与一键批量提交
- 一键从准确上一段的成功视频本地提取真实末帧，或配置后续段依赖；支持末帧＋自由参考图，默认人物但允许场景及其它图片，当前段中英文共用参考图
- 新制作统一使用智能导演；关系叙事/动作空间由软件按剧情自动判断，需要9张画面时将分镜图片数量设为9（现有范围1–100），生成独立图片
- 文生视频和图片/视频/音频/Clay Render 参考提示词
- 5 秒、10 秒、15 秒快捷时长，以及 1—300 秒自定义时长
- 文本模型 AI 自动决定镜头数量并生成完整逐镜方案，或按精确指定镜头数完成 AI 分镜
- 分镜时间线编辑、锁定、重写、增删、连续性检查、版本/A-B、试跑分批和 TXT/项目包清单导出
- Seedance 2.0/2.5、Kling 3.0、Vidu、Veo 3.1、Runway Gen-4、Sora 2 能力档案与目标适配稿
- NPC、场景、物品、分镜图片、历史九宫格、首尾帧、视频、音频和 Clay Render 参考资产管理

默认仍是纯提示词工作台，不会自行提交外部任务。用户可以显式启用通用视频任务 API，配置厂商提交/查询端点和字段映射后，软件可提交、轮询、下载并播放生成结果；具体合同、费用和账号限额以厂商为准。

## 启动

在 PowerShell 中执行：

```powershell
Set-Location '<项目目录>'
npm install
npm run dev
```

然后打开 `http://127.0.0.1:5173`。

桌面开发模式：

```powershell
Set-Location '<项目目录>'
npm run desktop:dev
```

启动已构建的 Electron 桌面版：

```powershell
Set-Location '<项目目录>'
npm run desktop
```

也可以直接双击目录里的 `启动莲华视频导演台.bat`；开发调试使用 `启动开发模式.bat`。

## 推荐使用流程

1. 在“剧情解析”粘贴一段话、剧情要求、小说章节，或导入 TXT/Markdown。
2. 原文过短时可点击“AI 扩写”；它会保留剧情核心和限制，补足动作、场景、因果与结果，明确要求对白时还会依据剧情扩写合适对话。
3. 点击“解析并补全”：未配置文本模型时使用本地解析，配置后会自动启用 AI 分析并补齐人物、地点和道具资料。
4. 进入“视频导演台”：短片选择“单段直出”；新长剧情选择“长剧情拆段”，确认导演参数和每段时长后，让 AI 直接理解原剧情并生成连续分段，检查并确认分段计划；总时长由每段时长 × AI 段数得出，无需先生成全片总提示词。历史总稿计划保留原流程。
5. 在“单段导演”同一页设置“节奏与分镜 / 画面与规则 / 运镜与要求”三块参数；每个视频段会单独生成从 0 秒开始的提示词，也可顺序生成所有未完成段。
6. 在资产库登记图片、视频、音频、Clay Render 与职责，并可指定首帧、尾帧或加入声音台账。
7. 生成后在“分镜时间线”编辑单镜字段，并执行连续性检查和试跑/分批计划。
8. 选择目标模型和提示词密度，生成附加适配稿；canonical 中文时间线保持不变。
9. 如需真实生成，在 API 设置显式启用视频任务 API；单段可直接提交，长剧情可在视频导演台进入“长剧情批量”，核对所选语言、逐段参考图和费用确认后一次建立批次。成功结果会下载到托管资产库。

在时间线的“本镜参考图”条带中还可以把参考图从全局绑定调整为逐镜绑定；参考图只在软件内部锚定对应角色、场景、道具和构图，最终正文始终使用 `@角色名/@主体名`。

## API 设置

“API 设置”中的文本接口使用 OpenAI Chat Completions 兼容格式，可用于：

- AI 增强剧情拆分
- 自动分镜数量评估
- 转换器 API 润色最终提示词

API 页顶部直接提供“图片 API、文本 API、视觉 API、视频任务、密码本”五个标签，默认显示图片 API；每次只展示当前面板，正常桌面窗口无需滚动页面。密码本可保存多组名称、Base URL 和 API Key，并快速填充到文本、视觉或图像接口。三类模型接口还各自支持多套自定义配置，可新建、重命名、切换、更新和删除；当前配置会在下拉列表中明确标记。

视觉接口用于参考图及旧九宫格资料读取；图像接口用于 NPC、场景、物品、独立分镜图片及既有图像任务。OpenAI 兼容、SD WebUI 与 ComfyUI 均可直接出图。ComfyUI 使用专用设置：同一图像配置可保存、命名和切换多份 API Workflow JSON，导入后会识别正负提示词节点，并在运行时注入提示词、负面词、宽高、目标宽高、尺寸、步数、CFG、采样器、调度器、Seed、SMEA 等可用占位符。带参考图时会先调用 `/upload/image` 上传真实像素，再把服务端文件名注入已连接到生成链的标准 `LoadImage` 节点；自定义加载节点可使用 `__REFERENCE_IMAGE_1__`、`__REFERENCE_IMAGE_2__` 等占位符。随后依次调用 `/prompt`、`/history/{prompt_id}` 和 `/view` 完成提交、轮询与取图。访问本机或局域网服务必须在 ComfyUI 设置中显式开启 LAN 访问；Electron 从 `/view` 下载时会继续携带配置的鉴权信息。

NovelAI 已接入原生 V4 / V4.5 出图、NAI 标签、角色 caption、负面提示词以及 ZIP / 图片二进制响应；当前不支持参考图像素，选中参考图时会在创建任务和调用模型前明确停止，不会静默忽略。ComfyUI 中用户主动勾选的主参考图要求导入的 API Workflow 已有真实图生图、IPAdapter、ControlNet 或其他参考生成链；程序不会凭空创建节点，工作流没有有效参考链时会在上传前明确停止。仅当分镜只有系统自动推断的补充参考图且当前是纯文生图工作流时，未接入的补充图片会跳过，提示词连续性事实保留并继续文生图。未启用图像 API 时，仍可在已配置文本 API 的前提下让 AI 按所选规则转换并保存提示词资产，不会用本地拼接词冒充转换结果。

Electron 桌面版的 API 密钥使用 Windows 系统加密存储，项目状态和导出包只保留空字段。浏览器开发模式使用浏览器本地存储，请勿用于真实密钥。

## 重要实现说明

- 参考图只用于后台锁定角色、场景、道具和构图；最终正文使用 `@角色名/@主体名`，不输出图片编号、资产 ID 或本地路径。
- 桌面版 `.lhvd` 是 ZIP 项目包，包含 `project.json`、完整性清单和托管媒体文件；旧版 JSON `.lhvd` 仍可导入。
- 旧格式最终提示词原样保留并标记待迁移，软件不会在启动时自动覆盖；主动重建前会先保存版本。
- 时间线始终从 `0` 秒开始覆盖到用户设置的总时长；精确镜头模式会尽量保持用户指定数量。
- 5/10/15 秒是节奏快捷预设，不会限制自定义秒数。
- 历史九宫格出图提示词和视频提示词仍分开保存，既有图片资产、枚举和导入/导出兼容保留；独立九宫格新建入口已退休，新制作使用智能导演与独立分镜图片。
