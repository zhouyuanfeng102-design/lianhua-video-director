# 批量重新生成与直接替换上段尾帧验收

仅使用独立测试数据/模拟生成接口，不执行真实收费生成，不改写用户项目。

| 场景 | 功能与可见验证 |
| --- | --- |
| 已成功批量再次生成 | 默认跳过；明确启用重新生成后确认费用，输入将再生成意图传至每一已选项，包括前端重复缓存未识别的项 |
| 旧任务状态残留 | 已成功且已有成片但旧preparing标记残留可重做；真实下载中、运行中和unknown不允许force重复提交 |
| 新一版自动尾帧链 | 同一三段链完成后重做，总6视频/4尾帧，新子任务只用新父和新帧；旧记录、资产、视频字节保持不变 |
| 现有参考图直接改尾帧 | 单槽或唯一首帧槽预选正确替换位置，确认后无需先清空；保留原图片资产与其他未替换槽 |
| 最终引用预检 | 按最终图片集合和API/Comfy槽验证；被替换旧图缺失不拦，其他缺失图仍须处理 |
| 界面 | 全选中英、手动/自动尾帧模式、替换确认、重新生成快捷操作、最终费用确认；1120×720及1280×800在100/130%字号无遮挡 |

探索：取消再生成开关恢复跳过；正在生成时重复点击不会重投；多图槽歧义不擅自替换；切换语言/计划后不串旧确认。

## 已执行记录

- 完整npm test通过。原三段完成后显式再生成第二版的真实FFmpeg集成通过：共6视频、4张真实末帧，第二版末帧为新颜色，旧任务、资产和文件校验不变；仍在运行时再次点击不创建重复任务。
- 浏览器实际按钮验证：默认成功项跳过，点击“允许重新生成已完成项”后3段可提交，均携带明确再生成授权；仍需费用确认。取消开关恢复跳过。
- 成功2项+unknown1项确认页仅计2段，unknown明确标为跳过；未绕过引擎保护。
- 已有参考图可直接预选替换并启用自动衔接，批量后续两段默认替换；未先清空任何选图，原图片资产与分镜不变。单图API模板和character用途原图也通过。
- 1120×720、1280×800及原生225%DPI桌面验证通过；替换确认及重新生成入口未越出窗口。桌面确认页真实点击复验通过。
- 无收费接口调用，无生产数据变更。新包另做隔离启动检查，旧0.5.124保留。
