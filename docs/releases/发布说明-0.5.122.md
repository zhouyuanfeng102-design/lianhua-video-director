# 莲华视频导演台 0.5.122 发布说明

## 版本定位

本版增加图像工作台普通与私密模式独立的像素选择，补齐 NovelAI / NAI 专用技术分类，并让分类预设与所选规则的提示词协议保持一致。已有剧情、图像内容规则、年龄相关规则和供应商限制不因此改写。

## 独立像素选择

- 普通与私密模式分别保存尺寸选择，支持规格默认、1X、2X以及自定义宽高/比例；切换模式、页面和重载后各自保留，不互相覆盖。“规格默认”保留原画面规格和既有行为，不代表任意接口的全局默认。
- 1X、2X只是尺寸档位，实际宽高以界面显示及后端可接受的值为准，不代表每个图像模型都支持任意高像素。
- 自定义宽高支持64–4096整数像素；不会静默取整、降档。NovelAI需64倍数、SD WebUI需8倍数，服务端还可有自身限制。四视图/四合一保留3:2布局，九宫格保留1:1，均可增加像素。
- ComfyUI 工作流必须提供受支持的宽高输入或占位符，才能应用请求尺寸；没有可覆盖入口时明确提示，不能把无效覆盖当作生效。
- 请求尺寸与可读取的实际图片尺寸分别记录、显示。服务返回较小或不同尺寸时明确提示；无法读取实际尺寸时不拿请求尺寸充当图片像素。
- 排队任务与重新生成保存原请求；即使删除原任务，新增资产仍保留请求快照，避免把后端降档后的实际尺寸当作下一次请求尺寸。桌面新增图片按独立文件保存，项目只记录引用，不把高清PNG反复塞进项目JSON。
- 不自动放大旧图片，不重跑旧任务，也不承诺增加像素就一定增加模型生成细节。

## NAI 分类预设与兼容选择

新增8个纯技术分类：

- NovelAI / NAI · 单角色参考图
- NovelAI / NAI · 多人独立角色段
- NovelAI / NAI · 角色设定图
- NovelAI / NAI · 场景环境
- NovelAI / NAI · 物品道具
- NovelAI / NAI · 分镜单帧
- NovelAI / NAI · 多人分镜绑定
- NovelAI / NAI · 九宫格视觉草稿

这些预设使用英文 NAI tags。基础画面与角色段按 `base tags | character 1 tags | character 2 tags` 组织，复用既有 V4 `char_captions`；没有出镜人物时只输出基础段。同一角色的属性留在对应角色段，不把多人的服装、动作或道具混进全局属性。

角色分段不是像素级区域控制；九宫格草稿和角色设定板只是表达布局意图，不承诺图像模型精确绘制每个区域。没有新增 ComfyUI 区域节点、蒙版或供应商端能力。

分类预设可声明输出格式。NAI、Krea/GPT自然语言和ComfyUI SD专用预设的明确冲突会被下拉过滤，自动兜底跳过不兼容项。通用预设以及未声明协议的自定义预设仍可使用，不因推荐后端不同而一律禁止手选；不会改写用户保存的规则默认。
