# 莲华视频导演台 4.5.1 发布说明

发布日期：2026-11-11（亚洲/上海）。

## 分镜改写留住原文的人和身后

分镜改写时，主体保持原文里的姓名，不改成阴唇、穴口、阴蒂或屁股。原文是他在她身后，朝向和空间就写他留在她身后，胸口对着她的背，脸对着她的背。动作先写她的头、胸、背、髋是同一个人，部位留在这个髋上，再写舔、碾或进入。他的舌留在他的嘴里。英文页用同一组句子，不把分镜标题译成对着镜头的下身特写。

程序仍只排版模型写好的字段，不另补一句。已保存的提示词和成片保持原样，重新生成该段后才会改。

## 交付

- Windows：`lianhua-video-director-4.5.1-windows-x64-portable.exe`。
- Android：`lianhua-video-director-4.5.1-android.apk`，最低 Android 8.0 / API 26。
- 4.5.0 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.5.1`。提示词规则两端共用，EXE 与 APK 一起交付。
