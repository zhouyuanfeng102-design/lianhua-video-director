# 莲华视频导演台 1.7.1 发布说明

2026-10-09

界面主题新增“经典原色”，恢复原来的多彩导航按钮和面板风格，让原有外观继续可用。

## 使用方式

未设置主题及旧配置默认采用经典原色。已经显式选择的莲华粉、湖蓝、青竹、暖砂或紫藤配色继续保留，不自动改成经典原色。

在顶部“界面与字体设置”中可选择经典原色或五种新配色；日间、夜间和跟随系统模式仍可独立选择。主题选择立即应用，并通过现有设置保存，重启后恢复。

1.7.0 的紧凑批量分段、图像任务完整提示词滚动框，以及资产库详细信息默认折叠继续保留。本次不调整生成、衔接、稿件和项目保存逻辑。

## 验证与交付

针对性主题验证通过：109 个日间元素的背景、文字和边框颜色与原 CSS 一致；经典夜间保留多彩导航，抽查的关键表面最低文字对比度为 5.82:1。六种主题切换、设置面板滚动、显式主题保存重载，以及缺失、无效和历史设置回退经典原色均通过。检查使用隔离的合成数据，没有调用真实生成接口。

`npm run pack:win` 通过，包含 TypeScript 检查、生产构建和 Windows 64 位便携 EXE 打包。本次未追加整套功能回归。`npm run deliver:1.7.1` 用于生成便携 EXE、恢复源码 ZIP、更新说明、启动脚本及 SHA-256 校验文件。历史发布说明和交付文件保留。
