# 莲华视频导演台 0.5.144 发布说明

发布日期：2026-09-22

## 版本定位

本版针对全面检查确认的5处功能问题和2处界面问题进行修复：剧情导入的迟到响应、未提交草稿关闭丢失、后台任务误干扰前台提示词生成、ComfyUI负面条件与视频输出识别，以及小窗口估时说明和侧栏名称裁切。

本次不新增人物、措辞或剧情内容的本地语义硬拦截，不删除正式项目、素材、历史任务及旧交付包；保留此前已有图片生成改动与0.5.143紧凑估时、0.5.142辅助选帧和任务提示词复制功能。

## 本版变更

- 剧情文件导入在开始时记录所属项目和输入状态；跨项目、继续编辑或连续发起导入后，旧请求的迟到结果不覆盖新内容，不清空其他项目的场景、分镜和计划。
- 剧情草稿按项目独立自动保存并恢复，正常关闭后可继续未提交的编辑。保存草稿不隐式执行“保存原文”，不改写已提交正文或清空既有派生内容；正式使用新原文仍由用户明确确认。
- 前台提示词生成身份不再绑定整个项目的更新时间，避免无关图片或视频任务状态更新导致有效返回被误丢弃；真实剧情、导演参数等输入变化及项目切换仍使过期请求失效。
- ComfyUI自动映射追踪经中间节点连接的正向和负向条件用途，负面条件不再被误识别后写入正向剧情；不通过本地内容关键词判断故事正确与否。
- ComfyUI优先识别真实视频输出，避免选中WebP等图片/动图预览而忽略已经生成的MP4。旧任务如明确误绑图片预览且仅有一个真实视频输出节点，可接收原任务成片并显示恢复原因，不重新提交生成；多个视频节点不擅自选择，明确的视频输出节点绑定继续生效。
- 小窗口估时区保留建议值、范围和“查看估时说明”入口；展开可阅读完整估时理由、当前计划状态及重新估时提示，长文本在本区滚动，不再直接隐藏说明。
- 侧栏底部采用可收缩布局，项目名缩小换行、超长名称可局部滚动或打开项目库完整查看，产品名和版本号不再被长名称挤出裁切。

## 使用与兼容

1. 请先在旧版保存或导出当前工作并完全退出，再启动`莲华视频导演台-0.5.144-便携版.exe`；不要让多个版本同时写入同一个正式数据目录。
2. 剧情输入时自动保留独立草稿；需要提交新原文时仍点击“保存原文”。草稿恢复不会自动触发解析、提示词或视频生成。
3. 已经因旧ComfyUI预览输出误选而失败的任务，可使用“恢复查询原任务”接收已有视频，不重新生成。仅有一个有效视频输出节点时才能安全恢复；链接过期或确有多个视频节点时按提示检查原任务，不自动收费重生成。
4. 长剧情规划展开规划参数后，可点击估时说明阅读全文；侧栏长名称可滚动查看，也可点击进入项目库。
5. 已保存的ComfyUI提示词映射不会被升级擅自修改。若旧工作流曾将负面节点误存为正向，可手动取消错误绑定，或在工作流管理的“API JSON”页选择“重新识别映射”，核对提示词、图片用途和自定义参数后保存；原任务的冻结工作流仍保留。

保留必要的JSON、输入类型、真实节点与文件、取消及项目归属保护。旧项目字段向后兼容，旧结果和历史成片不自动修改；0.5.143及更早的便携包、源码、校验清单与版本专属启动器继续保留。

## 验证范围

本说明描述功能和验收范围，不代表尚未执行的测试已经通过。完整自动化、真实界面、生产构建和新包启动验收以本轮实际记录为准；使用隔离项目、合成数据和模拟接口，不调用真实收费生成，不修改正式用户数据。

草稿与请求身份回归接入`test:workspace-history`，ComfyUI视频回归接入`test:comfyui`，完整信息可见性回归接入`test:styles`，并随`npm test`执行。交付前建议执行：

```powershell
npm run test:workspace-history
npm run test:comfyui
npm run test:video-generation
npm run test:styles
npm test
npm run pack:win
npm run deliver:0.5.144
```
