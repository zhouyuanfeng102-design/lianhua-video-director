# 莲华视频导演台 2.6.3 发布说明

发布日期：2026-10-18（亚洲上海）。

## 版本定位

本版修复 Seedance 在视频导演台后选参考图时，实际执行提示词同时包含“本次未提供图片、视频或音频参考素材”“全部人物、道具与场景均以文字设定为执行依据”和当前图片清单的问题，并同步本次视频规格。

旧逻辑为了保留参考段中的场景和动作事实，会把整段原文与“仅描述原稿写作时的状态”解释一起加入执行稿。这样虽列出了新图片，旧无图与仅文字执行要求仍进入视频请求。此次改为按当前素材处理过时声明，保留其中真正的剧情事实。

## 本次修复

- **参考说明与实际素材一致。** 中英文执行稿清理与本次图片或音频冲突的无素材、无图及仅文字执行声明，按当前图片顺序生成用途清单，不再附加历史素材解释段。图片与音频分别判断，未提供音频的说明不会被误当成没有图片。
- **保留原有剧情。** 参考段中的场景、人物和动作事实继续保留；对白、画面文字和引用字面量受到保护。已保存的中文、英文原稿保持不变，当前选图、调序和移除只影响本次执行稿。
- **同步本次视频规格。** 执行稿中的分辨率与画幅跟随当前请求参数，例如原稿为 2K、本次选择 720p 时，执行稿同步为 720p。时长和连续时间轴不作自动改写。
- **提交前检查明确冲突。** 最终请求对可确定的素材声明和规格矛盾给出提示并阻止带冲突提交；仍有待核对事项时，界面不显示“参考说明已同步”。

## 使用与兼容

已有项目可继续使用，不要求重新生成提示词，不新增 AI 调用。历史冻结任务保留原快照，不在升级时批量重写；原稿、任务记录和历史交付文件保留。

更新时保存项目并退出旧版，再启动新版本；保留完整的“莲华视频导演台数据”文件夹。若旧版显示保存失败，先导出当前项目备份，再退出旧版。

版本按十进位规则从 `2.6.2 → 2.6.3` 更新。本轮仅本地交付；已交付的 `0.5.160` 及更早历史版本继续保留原版本号和文件。

- 页面专项通过：四人物九图初选、取消临时选图、图片调序，以及 720p 预览、控制器提交和实际 API 请求序列化一致；两次模拟提交，外部 API 调用为 0。报告：`output/playwright/video-seedance-character-binding/report.json`。
- 确认手改稿中的明确冲突在建立远程任务前停止；选择图与实际上传图数量不一致时停止提交。源分镜、原对白和时间轴保持，历史音频预览直接沿用冻结文本。

- 最终 TypeScript 检查、生产构建和 Windows 64 位便携包生成通过。生产启动专项通过，无页面运行错误；包内 67 个生产文件与本次构建逐一一致。构建仍有既有的分块循环依赖和大分块提示。

本版专项命令：`npm run test:seedance-request-consistency`。验证范围包括素材声明清理、字面量保护、图片与音频区分、视频规格同步、明确冲突处理及既有 Seedance 参考图绑定；页面专项覆盖九图、取消临时选图、调序、原稿保护、720p 预览与实际请求序列化一致。

`npm run pack:win` 已包含 TypeScript 检查、生产构建和 Windows 64 位便携包生成，不在打包前重复运行相同构建检查。本版所有验证与交付状态以本轮实际执行记录为准，不沿用上一版通过结论。

## 本地交付

先执行 `npm run pack:win`，再执行 `npm run deliver:2.6.3`。交付目录包含：

- `莲华视频导演台-2.6.3-便携版.exe`
- `莲华视频导演台-2.6.3-恢复源码.zip`
- `莲华视频导演台-2.6.3-更新说明.md`
- `启动莲华视频导演台-2.6.3-便携版.bat`
- `莲华视频导演台-2.6.3-SHA256.txt`

SHA-256 清单覆盖本版固定名称交付物；无版本启动器更新为指向本版。历史版本文件不覆盖、不删除。
