# 莲华视频导演台 1.5.4 发布说明

普通生图新增 Google 香蕉 / Nano Banana 与 Grok Imagine 两套模型规则、18 个分类预设。根据 Google、xAI 官方提示策略和国内使用的中文兼容平台资料整理，采用自然语言画面描述；这些是应用内预设，不是厂商要求的固定格式。

## 使用位置

进入 **图像工作台 → 普通生图 → 生图规则集**，选择 Google 香蕉 / Nano Banana 或 Grok Imagine；下方“分类预设”按当前资产类型显示可用选项。

每家包含 9 个预设：角色参考图、多人角色同框、角色设定图、五视图参考板、场景参考图、道具参考图、分镜单帧与首尾帧、多人分镜与动作关系、多宫格视觉母版。

- 肖像、半身、全身由当前画面规格决定；选择五视图时推荐该模型的五视图预设。保留用户手选、修改、禁用和删除的选择。
- 兼容 API 通道在没有手选规则时，根据已知图像模型名称推荐对应规则；聊天和视频模型不误判为生图模型。第三方自定义别名可手动选择规则，不改写 API 模型名。
- 规则中心可继续编辑、复制、导入和导出这些规则及预设，不新增操作按钮。

## 画面约束

人物外貌只描述当前画内可见部分，侧背面、遮挡和局部特写不为展示正脸而改变；动作与视线指向具名对象。参考图只在本次实际附图时引用，区分身份、衣着、构图与风格用途。首尾帧按当前时刻和运镜终点取景，五视图沿用两个头肩特写加三个全身的布局。

普通规则不自动引入私密资料或微 NSFW 风格。没有独立负面字段的模型也可使用自然语言约束，不依赖 SD 权重或 NovelAI 标签。

## 升级与接口范围

旧内置目录一次性补入新规则和预设，保留现有自定义内容、默认选择与历史任务。空目录或只有自定义规则的目录保持原样，新增条目被删除后不会反复恢复。

本次增加提示词规则与分类预设，继续使用现有 API / 工作流接入方式。Google 原生 Gemini 和 xAI 原生编辑的请求协议与各兼容平台不同；选择规则不会替代接口配置，也不会自动开通模型。未统一硬编码各代模型的分辨率和参考图上限，实际以所用渠道支持为准。

调研来源包括 [Google 官方提示指南](https://cloud.google.com/blog/products/ai-machine-learning/ultimate-prompting-guide-for-nano-banana)、[Gemini 图像文档](https://ai.google.dev/gemini-api/docs/image-generation)、[xAI 图像文档](https://docs.x.ai/developers/model-capabilities/images/generation)、[HopBase 中文图像文档](https://hop-base.com/zh-tw/docs/media/grok-image)；完整笔记见仓库 `docs/research/google-grok-image-rules-2026-10-09.md`。

## 验证与交付

83 项规则与目录测试通过，覆盖模型识别、预设选择、五视图推荐、用户设置保留与目录迁移；打包中的 TypeScript 检查及前端构建通过。初次启动检查发现新规则目录跨打包模块的初始化顺序问题，已调整为同组打包，重新构建后的实际 EXE 启动及两家人物、五视图预设选择全部通过，正常关闭，无运行时错误。

构建仍有项目既有的循环分块和大分块提示；本次实际 EXE 使用隔离数据验证启动与相关选择操作，没有运行全量回归或调用真实付费生图接口，不把预设测试等同于图片效果保证。

交付包含 1.5.4 便携版、恢复源码、更新说明、启动器及 SHA-256 文件，历史版本保留。更新时保存并关闭旧版，保留原目录中的“莲华视频导演台数据”文件夹。

构建：`npm run pack:win`；交付：`npm run deliver:1.5.4`。
