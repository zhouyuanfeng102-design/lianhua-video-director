# 莲华视频导演台 1.2.9 发布说明

## 版本定位

修复视频提示词生成中的重复交付错误及英文失败导致中文无法保存的问题。便携包为 `莲华视频导演台-1.2.9-便携版.exe`。

## 本次修复

- 正文输出与 JSON 交付按当前阶段分别指定，减少模型同时收到两种冲突格式要求的情况。人物绑定继续作为附带数据，H3 正文的官方字段保持原格式。
- 兼容明确的动作字段别名、纯文本动作数组、全角括号及已标明动作的无括号写法。缺失动作、相互冲突的字段、人物或时长错误仍需修复。
- 时间轴有效时，缺失镜头字段只修复指定位置；其他有效镜头、动作与时间保持不变。若时间轴也损坏，仍由 AI 联合修复，不通过本地补镜或猜动作消除错误。
- 缺少或不匹配的人物绑定先尝试只补绑定数据；确实缺少正文身份句时，在原有重试预算内修复必要的配套正文。未通过校验的草稿不再锁定错误声源；已确认人物、主体与声源映射继续保护。
- 单段和逐段新生成时，合格中文在英文请求前写入项目并立即保存。英文失败后显示待重试，可使用“仅重试英文”；不重做已合格中文，也不把旧英文附到新中文上。全片总稿按原事务完成后保存。
- 本地字段错误保留具体字段与原因，不再把已知的人物映射错误显示成接口未知错误。继续限制自动修复次数，切项目或修改已保存内容后拒绝迟到结果。

## 使用

保存并正常退出旧版，在原交付目录打开新版。进入出错分段后重试；已有合格中文而英文未完成的分段使用“仅重试英文”。历史已提交的视频任务保持原快照，软件不会自动重新提交或产生新的生图、生视频费用。

## 验证范围

使用中性虚构剧情和模拟接口检查格式兼容、定点修复、人物绑定、有限重试、中文保存、英文单独重试、项目切换和迟到写入保护。执行相关回归、严格类型检查、生产构建、新包启动、保存和重载检查。

未调用真实付费模型或重跑用户视频；接口继续返回缺失或矛盾内容时，仍会明确报错，不能保证外部模型每次生成都成功。

构建：`npm run pack:win`。交付：`npm run deliver:1.2.9`。交付包含便携 EXE、恢复源码 ZIP、更新说明、启动器及 SHA-256 清单；历史版本保留。
