# 莲华视频导演台 1.0.2 发布说明

版本日期：2026-10-01

## 版本定位

V1.0.2修复镜头时间和分镜图片规划的解析兼容问题，并让生成失败按实际阶段、请求配置和服务端原因显示。AI继续负责剧情理解与结构修复。

## 本版修复

- 镜头时间兼容数字秒、带单位秒数、时码及明确的字段别名；在生成源头统一局部与全局时间坐标。真正无效的字段和值类型会连同具体错误交回原AI修复，不在本地补造时间、缩放镜头或裁剪剧情。
- 分镜图片规划支持完整`frames`数组、`data/result`等JSON包装，以及说明文字中的JSON代码块；保留完整最终规划，不把示例、截断或不完整结果当作最终输出。
- 相关自动结构修复由一次增加到最多三次。修复使用最新失败结果、具体原因及完整冻结的原始输入，保留当前剧情、API配置和项目条件。
- `content_filter`明确显示为文本API服务端返回的内容过滤，保留真实错误码及原因；不会误报成本地JSON解析错误，不按JSON恢复路径重试或改写请求绕过过滤。
- 失败日志区分前置图片规划、提示词转换、图片API请求与保存阶段，保留任务发起时的API和项目快照，避免切换配置或项目后显示错误来源。
- 移除提示词导演台“剧情与输入”区域中的“导演模式 / 智能导演”整条界面以及剧情识别说明；后台智能导演功能、原文载入提示和生产模式导航继续保留。
- H3格式、现有NSFW规则、每段和总时长权限、参考图及分辨率选择保持不变；不新增独立AI审核或本地剧情门禁。

## 使用与数据

升级后重新发起对应生成即可使用修复后的解析与恢复流程。失败会显示实际阶段和原因；服务端明确拒绝不会被解释成格式错误。

版本从1.0.1按十进位更新为1.0.2。已有项目、API配置、提示词和图片视频保持；不自动重跑已生成结果。1.0.1及更早历史编号交付文件保留，不重编号、覆盖或删除。启动新版前先保存并关闭旧版。
