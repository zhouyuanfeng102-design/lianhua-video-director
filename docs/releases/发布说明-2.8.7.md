# 莲华视频导演台 2.8.7 发布说明

发布日期：2026-10-21（亚洲上海）。

## 本次修复

针对空手比试出现刀剑音色的提示词来源问题，修正分镜规划、H3 交付、Seedance 编写与翻译中的声音规则。原稿的“拿回刀剑检查”曾被扩成金属碰响，且结尾局部声音又进入全局声景；全片武侠风格和持械参考资料也缺少明确的当前事件作用域。

- **动作与材质决定拟音**：新稿按当前发声对象、实际接触双方的表面和材质、力度及时间写声音。空手招式不因“武侠”“剑客”、静置道具或持剑身份图生成出鞘、碰刃声。拿取、携带、查看兵器不等于碰刃；真实发生的金属接触仍保留。
- **全局声景不复述局部事件**：H3 一次性拟音只在对应 Shot 中出现，`overall_soundscape` 简短说明整体听觉关系与有依据的持续声床，不逐镜列举动作、器物和音效。`non_diegetic_music: N/A` 的默认无配乐意图保持。
- **风格与参考服从当前事件**：兵刃碰撞、金属反光等风格偏好只用于本段确实发生的对应事件，不引入额外兵器和声音；参考图的既有人物关联保留。
- **Seedance 与英文保持声音事实**：Seedance 直接生成和单段生成使用同一声音表达规则；声音随已有事件保留接触对象、材质、时间与距离。翻译、格式修复和参考更新不据此重新导演历史稿。
- **完整计算收尾时间**：源头安排全文行为、位移、停顿和收尾所需的实际过程，不能把余下动作塞进 `15–15秒` 或单个结束时点。AI 适配在已有授权内重排完整生成窗口；固定或已确认总长、段界不被静默改变。保留动作和明确次数，不改成一个动作一段。

本次只修改既有请求的编写规则，不新增按钮、运行时内容校验、审核、生成拦截、自动重试或模型调用，不修改生成服务参数。不迁移、不改写已有项目或视频。2.8.6 的 Seedance 英译、首尾帧独立失败处理和此前修复继续保留。

## 使用

保存项目并退出旧版后启动 2.8.7，保留 EXE 旁完整的“莲华视频导演台数据”文件夹。已有视频的音轨不会随软件更新改变；需要从原剧情重新生成对应提示词，再用新提示词生成视频。直接载入旧视频的相同设置会继续使用冻结旧稿，仅翻译或更新参考图也不会重做旧稿声音。

已有零时长收尾的长剧情计划，需要通过现有 AI 分段操作重新做源头规划；下游单段转换不会自行增减已确认段数、总时长或动作归属。
