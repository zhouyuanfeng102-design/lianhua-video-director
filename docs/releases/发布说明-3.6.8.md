# 莲华视频导演台 3.6.8 发布说明

发布日期：2026-11-01（亚洲/上海）。

## 图片资产库筛选收成一排

图片资产库的搜索框和筛选项放在同一行，控件高度为 26 像素。搜索框保持较窄，类型、实体、职责和章节平分剩余宽度，文字过长时在框内省略。生成视频、检查文件和翻页留在这一行末尾。

已有素材、提示词和成片不改。不新增运行时校验、内容拦截、自动重试、按钮或模型请求。

## 版本定位与交付

Windows x64 便携包：`莲华视频导演台-3.6.8-便携版.exe`。构建命令为 `npm run pack:win`，交付命令为 `npm run deliver:3.6.8`；3.6.7 及更早历史版本文件保留。交付目录同时提供恢复源码、更新说明、启动器与 SHA-256 清单。
