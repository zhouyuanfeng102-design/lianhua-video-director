# 莲华视频导演台 4.6.0 发布说明

发布日期：2026-11-13（亚洲/上海）。

## 画面稿里的人物编号不再打断解析

画面描述转化给人物编的场次编号，不再被当成项目资料 ID。项目里没有这份资料时，解析按姓名新建或关联，不再弹出「AI 引用了项目中不存在的资料 ID」。

已保存的画面稿和正文不改写。名称对应多份资料，或真实资料的形态不同时，仍会请你选择。

## 交付

- Windows：`莲华视频导演台-4.6.0-便携版.exe`。
- Android：`莲华视频导演台-4.6.0-安卓版.apk`，最低 Android 8.0 / API 26。
- 4.5.9 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.6.0`。剧情解析两端共用，EXE 与 APK 一起交付。

## 验证

打包流程自带类型检查和前端构建。关联逻辑已用离线样例核对：空资料库里的 `bibidong` 不再产生冲突，目录里已有同名人物时仍连到那一份资料。
