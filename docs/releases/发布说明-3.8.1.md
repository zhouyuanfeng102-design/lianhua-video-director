# 莲华视频导演台 3.8.1 发布说明

发布日期：2026-11-06（亚洲/上海）。

## RH 网页参数可以修改并用于生成

管理页「其它参数」里的时长、比例、百万像素、自动提示词、LoRA、强度、输出开关和机型都可以改。生成时把这些改过的值写进网页。

绑到时长、比例或百万像素时，导演台这次如果另外填了，就用导演台的。图片和音频仍用本次选中的文件。

## 版本定位与交付

Windows x64 便携包：`莲华视频导演台-3.8.1-便携版.exe`。构建命令为 `npm run pack:win`，交付命令为 `npm run deliver:3.8.1`；3.8.0 及更早历史版本文件保留。

## 验证

- Windows x64 便携包：`npm run pack:win`
- 交付文件：`npm run deliver:3.8.1`

已有项目、提示词和成片不作改写。
