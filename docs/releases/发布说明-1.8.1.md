# 莲华视频导演台 1.8.1 发布说明

2026-10-11

本版减少图像 API 的手动配置：生图协议默认自动识别，按所填服务地址和模型名称选择请求接口，并在设置中显示识别结果。

## 生图协议自动识别

图像连接增加「自动识别」选项。根据服务地址和模型名称区分 Gemini 原生、香蕉聊天兼容及 Images 等接口，修改地址或模型后同步显示当前识别结果。模型完整别名继续传入原服务，参考图片按识别后的协议提交。

自动识别在本地完成，不发送试探生图请求，也不在生成失败后切换另一协议重复扣费。第三方服务的模型别名和接口实现可能不同，仍保留手动指定协议的入口，必要时可以按服务商文档覆盖自动识别结果。

已有任务继续使用其保存的冻结协议；修改连接协议不会改写旧任务或自动重跑任务。原默认「OpenAI 兼容」配置在新任务中自动识别；已明确指定的原生、聊天等协议继续保留手动选择。

## 验证与交付

只检查本次改动，不运行全量回归。12 组针对性检查通过，覆盖协议识别、手动指定、请求格式、参考图顺序、保存恢复及旧任务协议兼容；使用模拟接口，没有真实生图或付费请求。

便携版打包所含的类型检查与生产构建通过。已启动最终 1.8.1 EXE，在隔离的空白数据目录检查启动和图像 API 设置：默认自动识别、切换香蕉与 GPT 生图模型、手动指定及切回自动均通过，未发现页面运行错误。未读取或修改用户项目和密钥。

本版按十进位从 1.8.0 升级至 1.8.1，交付便携版、恢复源码、更新说明、启动脚本及 SHA-256 校验清单。1.8.0 及更早发布说明、交付文件与交付入口继续保留。
