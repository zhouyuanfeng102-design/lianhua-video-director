# 莲华视频导演台 0.5.92 发布说明

## 版本定位

本版补齐 NSFW 剧情状态、人物私密资料与私密参考图链路，整理视频任务与 API 设置界面，并让新生成视频使用图片式可读名称。目标便携包为 `莲华视频导演台-0.5.92-便携版.exe`；完成构建与验证后，使用 `npm run deliver:0.5.92` 生成版本化交付与 SHA-256 清单。

## NSFW 状态、人物资料与参考图

- 视频提示词按人物保存“入镜衣物状态 → 当前穿脱动作 → 镜尾状态”。已脱衣物不会被默认衣橱或含服装的普通锚点重新套回；剧情明确重新穿回时才恢复，多人物状态分别追踪。
- 裸露程度、具体接触、动作阶段、残留状态及脱下衣物的位置可跨镜继承；首帧读取入镜状态，尾帧与普通分镜图读取镜尾状态。
- “解析并补全”只为原文明示 18+、实际参与 NSFW 情节且年龄无冲突的人物建立稳定私密外貌档案，覆盖裸体全身及适用部位；姿势、临时接触、穿脱过程和残留不写入稳定身体资料。
- 图像工作台增加私密全身与部位资料、私密全身图和部位特写。私密生图使用独立的墨色江湖 NSFW 图片规则，不混入默认服装、装备、其他部位或含服装的普通锚点。
- 私密参考图按成年状态、人物归属、当前镜头和具体部位严格匹配；普通镜头、其他人物及归属不明的多人镜头不会借用。手工资料优先，补全失败不覆盖已有资料。
- 导出包含私密人物资料或图片资产的项目时会显示明确的私密文件保管提醒。

## 界面与任务归位

- 视频导演台只负责建立视频任务，不再重复展示任务列表。提交后可直接前往“生成任务”，统一查看进度、耗时、取消、恢复、重试下载、来源跳转和按原设置再生成。
- API 设置中的视频 API 与 ComfyUI 常用配置改为随窗口高度自适应的网格；常用折叠态在一页显示，不需要页面或表单滚动。
- 高级协议、请求模板及 ComfyUI 节点映射默认折叠；用户主动展开长内容时只在该表单内部使用有界滚动，避免整页被撑出可视区域。

## 视频可读文件名与落盘安全

- 新生成或重新下载的视频以冻结的剧情/任务名称落盘，例如 `assets/video/剧情名称 · 第 1 段.mp4`；同名异内容按 `· 第 2 版`、`· 第 3 版` 递增。
- 任务名、资产名、来源快照与最终文件名保持一致。并发完成不会互相覆盖；同名同内容复用已有文件。
- 文件名会处理 Windows 非法字符、历史保留名、尾随点空格、空名、超长文本与 emoji，且不会写出目录逃逸或无效路径。
- 后缀根据真实 WebM、MP4、MOV 容器确定；MKV、伪装成视频的 M4A、3GP、未知 EBML/ftyp 品牌及明确不支持的 MIME 会被拒绝。无法识别签名时仍可采用标准 MIME、Content-Disposition 或 URL 扩展名。
- 项目包导入遇到同路径异内容时会分配新版本，并同步更新 `relativePath`、文件名、资产名、URL 和关联视频任务名；外部备份同时核对校验值。

## 兼容性与边界

schema 保持 22，时间轴规则 1.2.0、通用转换器 1.3.0 保持不变。新增人物私密资料字段为可选字段；旧项目、素材、任务、模型、API 参数、种子和生成参数均保留，不会自动重跑任务或调用外部生成服务。

内置生图规则目录由 v1 升至 v2，只为旧内置目录补充缺失的私密人物分类；自定义规则、禁用状态和升级后主动删除的规则不会被恢复。官方 H3 来源指纹由 v4 升至 v7，旧派生 H3 提示词会标记为待重新编译，原分镜、原提示词和 AI 转换记录不会被删除。缺少人物归属、明确成年证据或具体部位元数据的旧私密任务不会猜测恢复，需要回到图像工作台重新创建。

已有哈希路径视频不会自动重命名，以避免破坏旧项目引用；新生成及重新下载成功的视频使用可读路径。0.5.91 移除跨镜 NSFW 词表式保真误杀的修复继续保留。

## 验证与交付

源码变更覆盖 NSFW 连续性、私密参考路由、图片规则、视频草稿、视频生成与恢复、并发下载、容器识别、项目包导入、API 设置布局、任务归位、TypeScript 严格检查、生产构建及隔离 Electron 验收。真实外部文本、图像和视频服务未被自动调用。

生成命令：

```powershell
npm run test
npm run pack:win
npm run deliver:0.5.92
```

交付完成后，通过 `交付\启动莲华视频导演台-0.5.92-便携版.bat` 或无版本启动器打开。现有 0.5.91 及更早版本化产物保留。
