# 莲华视频导演台 0.5.154 发布说明

## 版本定位

为长剧情分段增加AI衔接画面与人物身份分工的组合参考方式，原尾帧操作与历史任务保留。

## AI选尾帧＋参考图

- 长剧情批量每段增加“AI选尾帧＋参考图”，顶部增加“一键尾帧＋人物参考”。原“用上段尾帧”按钮保留；不弹配置窗口，不自动提交视频。
- 第1图片槽放准确上一段的AI衔接帧，负责开场画面、构图、站位、朝向和动作；第2槽起放本段普通人物身份图。优先当前明确选择，缺少时取本段人物已绑定的普通主图，不扫历史图或私密图。服装按当前剧情与逐镜状态。
- 本次提示词的H3 Picture编号与实际提交顺序同步，Subject编号、H3章节、镜头、对白、声音正文保留。原场景/首帧职责交给尾帧时明确提示，不能可靠对应的旧编号不会猜接；原分镜稿不被覆盖。
- 已有上一段本地成片时，按钮直接调用已配置的视觉AI选帧，可能产生分析费用；前段在本次批量内时，仅先设置依赖，最终确认后等前段完成并保存再选帧。不自动增选收费段、不借用不相邻视频；AI失败不回退原尾帧。
- 按实际API、ComfyUI或RunningHub映射检查所有图片槽及用途。槽位不足明确显示需要和可用数量，不截断人物图、不填重复图、不自动拼图。普通参考槽只作衔接参考，不承诺强制首帧；仅支持首尾帧的接口不支持额外身份图。
- “恢复原选图”会恢复本段原图与原稿编号，已生成的尾帧素材保留；取消、切换项目/连接、图片变更和迟到结果有保护。组合任务继续沿用原队列、并发、重启和批次继续机制。

## 保持不变

- 不增加本地内容语义审核，AI选帧仍由当前视觉API执行；本地只核对图片关联、编号、文件和接口结构。
- 不自动重跑旧任务，不修改真实项目、模型/API参数、审核参数或系统代理，不修改背景音乐。
- 0.5.153五视图、分类预设、私密资料作用域、视频排队/并发与错误详情全部保留；旧版本交付文件不覆盖。
