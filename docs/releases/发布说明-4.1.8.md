# 莲华视频导演台 4.1.8 发布说明

发布日期：2026-11-08（亚洲/上海）。

## 安卓隔离网页登录能打开

手机上点「隔离网页登录」、刷新或读取网页时，创建网页和显示窗口仍在界面线程，等网页打开改到旁边的线程。界面线程不再停住，登录窗口可以画出来。登录结果写在登录位旁边。

电脑版仍用系统浏览器的独立登录目录，登录方式不变。

## 交付

- Windows：`莲华视频导演台-4.1.8-便携版.exe`。
- Android：`莲华视频导演台-4.1.8-安卓版.apk`，最低 Android 8.0 / API 26。
- 4.1.7 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.1.8`。本版含安卓登录和登录位上的结果文字，EXE 与 APK 一起交付。

## 验证

打包流程自带类型检查和前端构建。未在真机上点按隔离网页登录。
