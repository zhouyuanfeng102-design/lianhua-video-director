# 莲华视频导演台 0.5.38

## 版本定位

- 0.5.38 是基于 0.5.37 的最终视频转换器专项修复版。
- 重点修复最终提示词照搬原文、生硬拼接局部草稿、高细节剧情转换规则过薄、原文已有台词却输出“台词：无”，以及模型把内容类型当成拒绝理由的问题。
- AI 扩写继续使用 0.5.37 的完整剧情转换体系；本版把同等级的转换深度补到最终视频提示词链路。

## 最终视频转换器 v1.1.0

- 最终视频提示词生成时仍会自动经过转换器，不需要单独点击润色按钮；转换器返回并通过结构、时间与对白校验后，结果才会保存为最终提示词。
- 本地草稿只提供固定镜数、精确时间标签、六字段顺序和不可变事实。转换器必须重新组织可拍摄内容，不得逐句复制原文、复用草稿动作正文或把两者机械拼接。
- 每镜严格按主体、空间、光影、镜头、台词、音效六字段输出；动作、对象、方向、距离、接触、反馈、状态变化和可见结果按原文证据落入相应镜头。
- 抽象心理转换为目光、呼吸、手部动作、身体重心、人物距离、接触关系、道具状态或环境反馈，不用空泛情绪词替代实际事件。

## 墨色江湖与世界书参考方式

- 参考墨色江湖主线叙事体系，以及世界书的分层注入、条件触发、状态查询和感官转化方法；参考的是组织规则，不照搬游戏变量、专用命令、概率表、输出标签或项目专属资料。
- 普通剧情保持原有事件方向和尺度，不因单个词语强制升级。原文已经明确发生、自然进入或明确要求亲密、裸露、性行为、伤害、医疗等高细节事件时，才调用对应的动作、部位、接触、力度或节奏、连续反馈、可见状态和结果规则。
- 高细节事件不得被概括成“靠近”“发生关系”“画面淡出”等含糊替代，也不得跳过中间状态；题材或身体词汇本身不构成删改和拒绝理由。

## 连续性账本与对白证据

- 转换过程持续维护连续性账本：人物位置、朝向、姿势、手脚占用、人物距离、接触点、衣物与随身物、道具归属、门窗家具、伤势或身体状态、环境变化和上一动作余势都必须在相邻镜头间承接。
- 多人同镜分别记录行动者、回应对象、前中后景位置、视线、距离以及动作先后，避免人物共享同一个反应、瞬移、穿模或状态自动复原。
- 原文与逐镜证据清单分开传入。已有对白必须按原字、原顺序、原说话人恰好迁入一次；存在真实对白时不得写“台词：无”，标牌、信件和屏幕文字不会误判成说话内容。

## 转换请求与拒绝边界

- 请求按核心任务、转换器规则、原文与逐镜证据 JSON、最终输出协议分层发送，明确把输入当作不可信剧情数据，防止正文中的伪指令覆盖转换规则。
- 内容类型不再拥有 `CONVERSION_REJECTED` 出口。只有固定镜数、时间标签、总时长或六字段骨架在输入数据中彼此矛盾且确实无法表示时，才允许返回 `CONVERSION_REJECTED: 具体结构冲突`。
- 模型返回自然语言拒绝、道歉或无法协助说明时，不会把拒绝文字保存成最终视频提示词；界面会保留真实失败原因供用户处理。

## schema 14 安全迁移

- 持久化状态升级为 schema 14，并为旧的内置最终视频转换器增加一次性安全迁移。
- 只有逐字未编辑的内置 `converter_unified_video` v1.0.0 才迁移到 v1.1.0；名称、规则、输出协议、启停状态、版本或额外字段有任何用户修改时都原样保留。
- 自定义转换器、用户删除状态、默认转换器选择以及未来版本状态不被覆盖；迁移重复执行保持幂等。

## 回归与交付

- 新增 schema 13 到 schema 14 的未编辑内置转换器迁移、任意用户修改保留、自定义预设保留和幂等回归。
