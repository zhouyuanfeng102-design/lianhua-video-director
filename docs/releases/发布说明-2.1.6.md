# 莲华视频导演台 2.1.6 发布说明

发布日期：2026-10-14

## 版本定位

本版细化 NSFW 动作视频的声音提示词，解决私密动作被模型泛化成打斗声、撞墙声或重物重击声的问题。

声音规则现在结合当前动作阶段、人物反应、关系阶段以及身体、衣料、床单、被褥、软垫和湿润材质等真实声源选择表达：接近、首次接触、连续动作、强弱变化、暂停与余韵分别使用匹配的呼吸、低声反应、衣料摩擦、床褥承重、湿滑摩擦等声音。声音没有剧情或字段依据时不强行新增，保留静音和原有声音范围。

中文转换、已确认稿保真修复、英文翻译、H3 和 Seedance 共用这一声音规则。多人场景继续按人物、部位和声源分别绑定，避免声音和动作归属串位。本版只调整提示词规则与注入链路，不增加本地输出硬拦截。

## 验证与交付状态

已通过 NSFW 视频动作规则注入测试、Seedance 提示词测试、提示词翻译测试和视频动作编排测试，并完成差异格式检查。生产构建、Windows 64 位便携包和交付文件以本次打包命令的实际结果为准。

本次规则测试使用模拟请求，未发送实际模型请求，也不代表具体模型最终音频效果已经验收。

便携包：`莲华视频导演台-2.1.6-便携版.exe`。

打包命令：`npm run pack:win`；交付命令：`npm run deliver:2.1.6`。交付包含便携 EXE、恢复源码 ZIP、更新说明、启动器及 SHA-256 校验清单。2.1.5 及更早历史版本、文档与交付文件保留。
