# 莲华视频导演台 0.6.3 发布说明

版本记录日期：2026-09-26。

## 版本定位

本版修复长剧情批量生成被无参考图的配角阻止的问题。便携包为`莲华视频导演台-0.6.3-便携版.exe`；完成构建与验收后，使用`npm run deliver:0.6.3`生成交付文件、恢复源码与SHA-256校验清单。

## 本版修复

- 修复长剧情一键设置“AI尾帧＋人物参考”时，因摊主等非主要角色没有身份图而中断的问题。
- 只有明确选中或已有身份图绑定的人物才需要维护图片绑定。仅在本段文字中出现、未绑定身份图的配角不强制补图、不占槽，其动作、对白和人物描述保持原样。
- 三张主要人物图加一张AI衔接帧使用四个槽；不自动增加配角图片、不拿其他人物或重复图片补槽。手动选中的配角图仍会保留。
- 对旧六段式H3的复合场景图，只调整可准确识别的角色图片来源说明：无身份图的配角依照原有文字定义，不把尾帧或其他主角图误作其身份图。Subject编号、镜头、时间、对白、音效和原保存稿不变；中英文绑定一致。

## 说明

- 现有资料没有主角/配角等级字段，本版依据用户已有选图和绑定，不按姓名、职业词或出场频次猜测主次，不新增AI请求或本地剧情审核。
- 已明确绑定但缺失、不可用或用途不符的图片仍显示具体原因。工作流真实槽位数量校验保留，不静默丢弃图片，也不填充重复图片。
- 不改正式项目、已有媒体或历史任务，不自动发起收费生成。0.6.2及更早交付文件保留，不覆盖、不删除、不重编号。

## 验证范围

- 新增普通姓名/摊主/路人、三人物四槽、手选配角图、显式绑定损坏、旧中英文H3来源信封和原稿不变等回归。
- 使用隔离的界面数据和模拟提交检查批量选图流程，不调用真实收费API。实际视频效果仍取决于视频模型。
- 尾帧人物参考28组回归、23项隔离界面场景通过；RunningHub中英文三人物加尾帧的四槽映射通过，没有新增配角槽或额外AI请求。
- 类型检查、H3多参考图和生产构建通过；51项发布检查与8项工作流测试通过。
- 打包程序在隔离目录的启动、保存、重新载入和恢复检查通过，数据结构仍为schema 23；22个打包前端文件与生产构建逐字节一致。
