# 莲华视频导演台 0.5.86 发布说明

## 本轮调整

剧情页取消模式下拉，直接提供两个按钮：

- **AI扩写**：直接调用原有 `expand` 模式，扩写剧情。
- **AI剧情优化**：直接调用原有 `optimize` 模式，进行视频化整理。

无需先选择模式，再点击同一个按钮；本轮只是拆分原有操作入口，没有新增功能、调用步骤或额外 API 请求。

## 保持不变

两个入口继续使用当前配置的 API、模型和原有规则。返回结果仍先审阅再确认，并保留还原原文，不在升级时自动改写已有剧情。

schema 22、时间轴规则 1.2.0、通用转换器 1.3.0、左侧导航一页自适应、主体正文的字体和滚动完全不变。旧项目、资产、存稿、种子、生成参数，以及视频导演台、API / ComfyUI 和任务功能继续保留。

## 使用方式

完成交付后，保存工作并关闭旧版，通过 `交付\启动莲华视频导演台-0.5.86-便携版.bat` 打开新版。在剧情页直接点击所需按钮，随后沿用原有结果审阅和确认流程即可。

## 验证与交付

已通过 TypeScript 检查及 `npm run test:story-preparation-buttons-ui` 专项页面验证：

- 两个按钮分别直接发送 `expand`、`optimize` 模式，旧模式下拉已移除。
- 处理期间两个按钮均禁用，重复点击不会增加请求。
- 返回结果先预览，确认保存才更新原文；可精确还原原稿（包括边界空白）。
- 请求期间修改原文或切换项目，过期结果不会覆盖新内容或其他项目。

专项验证共使用 4 次模拟请求，浏览器错误为 0；报告位于 `output/playwright/story-buttons-0.5.86/report.json`，页面截图已目检。

正式构建 `npm run build`（TypeScript 与 Vite）已通过。

打包内 `app.asar` 的版本为 0.5.86；8 个 JS / CSS 资源及入口 HTML 与本次构建逐字节一致，已确认两个直接按钮存在、旧模式选择器移除。
