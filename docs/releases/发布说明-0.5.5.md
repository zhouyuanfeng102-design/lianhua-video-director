# 莲华视频导演台 0.5.5

## 横向角色四视图

- 角色“三视图”已统一升级为四视图，按正面、严格 90° 左侧面、背面、45° 前侧三分之四视图排列。
- 四个视图强制保持同一主体、同一物种结构、同一比例、同一相机高度与同一足底基线，并完整保留尾巴、角、翼和其他附肢。
- 四视图使用横向 1536×1024（3:2）画布，其他头像、半身和全身构图继续使用 1024×1024。

## 怪兽与非人角色保护

- 四视图身份词不再套用脸型、发型、鞋靴或自然站立等人类模板，改为按真实物种生理结构生成静态设定姿态。
- 文本转换器若删掉角度、画幅、正交投影或背景约束，应用会自动补回；若改成三视图或绿幕，则回退到确定性的四视图提示词。

## 图片 API 尺寸

- OpenAI 图片接口会收到 `1536x1024` 的横向 `size`。
- SD WebUI 会收到 `width: 1536`、`height: 1024`；普通构图未指定尺寸时仍回退为 1024×1024。

## 中性灰背景与一屏布局

- 默认采用无彩中性灰无缝棚拍背景，避免绿布污染毛发、反光甲壳、半透明边缘和发光纹理。
- 图像工作台已针对 1120×720 与 1280×720 短窗口压缩为一屏显示，无横向溢出、控件遮挡或页面滚动。

## 兼容说明

- 内部仍使用既有 `turnaround` 标识，因此历史项目和已有资产无需迁移。
