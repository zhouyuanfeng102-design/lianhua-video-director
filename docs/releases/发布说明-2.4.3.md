# 莲华视频导演台 2.4.3

发布日期：2026-10-16。

## 资产库图片支持绑定场景和物品

修复资产库的“绑定”弹窗只能选择人物的问题。现在可切换人物、场景或物品类型，并选择当前项目中的对应资料，物品图和场景图也能保存各自的绑定。

绑定支持保存后重载、更换对应资料和明确解除。后续选用图片生成视频或作为生图参考时，参考用途跟随当前绑定；未绑定图片仍可直接使用。

手动绑定与原始生成来源分别保存，保留原来源、实体已有素材列表、分镜以及已保存的中英文提示词。旧项目继续兼容，修改绑定不会自动重跑历史任务。

## 验证与交付

新增实体绑定的 7 组针对性测试、原有人物绑定的 13 组测试通过，覆盖跨类型改绑、明确解绑、失效 ID、保存重载、冻结图片快照和 H3 场景替图。原分镜、中英文原稿及图片生成来源保持不变。

已使用本次生产构建在 1280×800 隔离浏览器中验证人物、场景、物品绑定、更换、取消、刷新恢复和解绑，按钮可达且无重叠，未读取用户真实项目或调用生成 API。开发服务器启动等待超时后改用现成生产构建完成该验证，未重复构建。

打包流程中的 TypeScript 类型检查、Vite 生产构建与 Windows 便携包生成通过。构建保留已有分包循环及包体大小提示；未追加全量界面与功能回归。

便携包：莲华视频导演台-2.4.3-便携版.exe。随包提供恢复源码、更新说明、启动脚本和 SHA256 校验文件。
