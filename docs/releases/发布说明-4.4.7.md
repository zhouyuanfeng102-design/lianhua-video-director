# 莲华视频导演台 4.4.7 发布说明

发布日期：2026-11-11（亚洲/上海）。

## 自定义生视频聊天界面

视频导演台的“自定义生成”改成与自定义生图一致的聊天式工作区：历史记录按本次提示词、参考图、连接信息、生成状态和结果视频分组展示；一个任务返回的全部视频继续完整显示。

底部输入区保留原有能力：选择或上传参考图、填写原文提示词、选择视频 API、RunningHub 云端、RH 网页应用或 ComfyUI 工作流后提交。图片用途、H3 输入模式、参考音视频、视频名称和生成参数收进折叠设置，草稿与普通单段生成保持独立。

本次只调整界面组织和移动端布局，没有新增运行时校验、内容审核、生成拦截、自动重试、模型请求或额外按钮。已有任务、提示词和成片保持原样。

## 交付

- Windows：`lianhua-video-director-4.4.7-windows-x64-portable.exe`。
- Android：`lianhua-video-director-4.4.7-android.apk`，最低 Android 8.0 / API 26，沿用正式升级签名。
- 4.4.6 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.4.7`。提示词规则、任务存储和生成逻辑两端共用，EXE 与 APK 一起交付。
