# 莲华视频导演台 4.4.3 发布说明

发布日期：2026-11-10（亚洲/上海）。

## 网页比例选项点得上

RunningHub 的比例下拉是虚拟列表。目标项在可视区域外时，程序先在当前打开的列表里把它滚出来，再点击这一项。点不上时不再停在「提交中断待确认」。

已经停在待确认的任务不会自动重投。先到 RunningHub 看这条有没有生成；没有再点「继续批次」。

## 交付

- Windows：`莲华视频导演台-4.4.3-便携版.exe`。
- Android：`莲华视频导演台-4.4.3-安卓版.apk`，最低 Android 8.0 / API 26。
- 4.4.2 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.4.3`。网页提交是两端共用的，EXE 与 APK 一起交付。
