# 莲华视频导演台 4.4.3 发布说明

发布日期：2026-11-10（亚洲/上海）。

## 网页比例选项点得上

RunningHub 的比例下拉是虚拟列表。目标项在可视区域外时，程序先在当前打开的列表里把它滚出来，再点击这一项。点不上时不再停在「提交中断待确认」。

已经停在待确认的任务不会自动重投。先到 RunningHub 看这条有没有生成；没有再点「继续批次」。

## 交付

- Windows：`lianhua-video-director-4.4.3-windows-x64-portable.exe`。
- Android：`lianhua-video-director-4.4.3-android.apk`，最低 Android 8.0 / API 26。
- 4.4.2 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.4.3`。网页提交是两端共用的，EXE 与 APK 一起交付。

## 验证

本地假页面核对：25 项虚拟列表里，一开始看不见的最后一项可以点中，阅读选项时不改已选值，也不提交任务。打包流程自带类型检查和前端构建。未在真实 RunningHub 页面上再点运行。

APK 已完成正式签名核对，沿用原签名证书。尚无本版 Android 设备安装、原生功能与真实网站联调的实测记录；基础能力及既有测试边界见 [3.9.7 能力与验证记录](能力与验证记录-3.9.7.md)。安装和备份见 [安卓安装说明](../android-install.md)。
