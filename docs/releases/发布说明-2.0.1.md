# 莲华视频导演台 2.0.1 发布说明

发布日期：2026-10-12

## 视频动作编排

- 先明确事件实际起止、人物进入与结束状态，再安排摄影覆盖。自动镜数选择足以看清因果的必要视角，连续接触、物体路径和回应优先同镜呈现；用户指定镜数保持。
- 踢物明确视线、胸髋、支撑脚、发力脚、接触实体及具名目标，减少转身扫腿和脚部特写造成的朝向误解。
- 区分镜头时长与动作时长；短促倒飞和追击按连续事件推进，原文空中交锋保留在同一次腾空中，避免跨镜持续悬空填时。
- 连击逐次承接上一招的偏转、重心和武器末态；对白可在允许发音的动作中并行，快速动作使用正常播放速度的描述。

## 复核与参考图

- 在已有规划复核及获准重排的中文复核中，检查候选正文的具体朝向、完整事件跨度、每次接触和切镜依据。沿用现有调用数量。
- 修正后的中文、分镜与时间字段同步进入英文翻译；格式修复、参考更新及翻译继续遵守各自权限。
- 在可信 H3 派生稿中，按本次实际图片槽补齐开场、结束构图及场景等参考用途。人物身份绑定与已有正文图片映射继续保留。
- 多图参考中的首尾用途说明不代表云端强制首尾帧；实际能力取决于所选工作流接线。

## 使用与历史

已有项目、提示词、任务和成片继续保留。要应用新的动作编排，请重新生成中文或对应的本段提示词，再创建新的视频任务；仅重新翻译英文或重试旧视频任务会继续使用原稿。来自已确认全片总稿且锁定镜界的切片，需从源头重规划后生成。

## 验证

已通过动作规则、自动与指定镜数、两段动作的中文到英文同步、参考图用途到 RunningHub 请求等针对性离线测试。生产打包包含类型检查与构建。未调用收费视频生成，实际成片质量需在重新生成后对照确认。
