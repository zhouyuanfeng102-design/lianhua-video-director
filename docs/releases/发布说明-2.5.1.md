# 莲华视频导演台 2.5.1

发布日期：2026-10-16。

## 统一人物图片关联与修复的定位规则

修复同一人物已选中正确图片，点击修复提示“绑定已有效”，选图却仍显示“待关联”的问题。此前修复入口只检查定位文本是否存在，图片关联入口还会本地检查 Subject 编号、姓名文本与正文结构，两个入口得出相反结果。

现在两处共用同一定位规则：人物 ID 明确、定位文本在当前原稿中准确且唯一即可。取消图片关联对 Subject、声源编号、姓名展示文本、镜号、字段、标点与句法的本地审核。不根据这些内容改写或删除原稿及旧身份元数据。

自动加入的图片参考说明只写人物和实际图片槽编号，不再把旧 Subject 或声源编号注入正文。已有可用定位直接关联，点击修复无需调用 AI。缺失或重复的文本位置、损坏的 JSON、无法明确对应的人物 ID 等技术问题仍作提示；参考提示继续不阻止生成。

本次不迁移项目数据、不改变已选图片、不提交真实视频任务。保留分段设置同排布局和此前的一次请求行为。

## 验证与交付

针对性离线检查通过：人物图片关联 32 组、绑定修复 20 组、身份交付 14 组、交付数据结构 11 组及人物出场定位专项。覆盖普通身份句沿用旧 Subject/S 元数据、展示名差异、原稿和元数据不改、明确 ID 与真实图片槽、缺失或重复定位的技术保护。

实际“使徒”项目五段的中英文共 10 组已完成只读核对：所有已选人物图片均可关联，已有绑定修复均为 0 请求、0 改动。第 5 段两种语言的新奥特曼对应槽 4、二号机对应槽 5。存档索引和项目正文文件前后 SHA256 相同。

生产构建的隔离界面专项通过：第 5 段中文和英文选图弹窗均将新奥特曼显示为绿色“已关联图片 4”、二号机显示为绿色“已关联图片 5”，没有待关联状态。界面检查未调用 API 或提交生成，未修改原项目文件。
