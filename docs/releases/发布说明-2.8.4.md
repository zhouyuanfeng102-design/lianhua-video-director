# 莲华视频导演台 2.8.4 发布说明

发布日期：2026-10-20（亚洲上海）。

## 本次调整

压缩生成任务页上方标题、章节范围和任务分类区域的高度，减少大块留白，为下方任务列表腾出更多空间。

- **区域高度**：采用紧凑排列，常用桌面宽度下上方区域高度约减半。
- **自适应字号**：字号随可用宽度调整，章节选择与任务分类同排等高，计数、图标和文字居中对齐。
- **完整文字**：保留标题、说明、章节范围和任务分类文字，窄窗口按顺序换行，不用省略号截断。

本次调整仅涉及生成任务页布局。图片、视频和资料任务继续沿用现有操作，保留此前单段生成、人物参考图关联、提示词及视频工作台修复，不改写已有项目或任务状态。

## 使用方式

保存项目并退出旧版后启动 2.8.4，保留 EXE 旁完整的“莲华视频导演台数据”文件夹。打开“生成任务”即可使用新的紧凑布局，无需修改项目配置。

## 验证与交付

生成任务页定向界面检查通过：在 1600、1260、1040 像素窗口宽度下，标题至任务分类区域均由约 156 像素缩至 79 像素（减少约 49%），控件无溢出。窄窗口下切换章节与三类任务正常，130% 字号设置下布局保持整齐。检查仅使用隔离样例，没有提交生成请求或改写用户项目。

Windows 打包通过：`npm run pack:win -- --config.directories.output=.pack-release-2.8.4` 已完成 TypeScript 检查、Vite 生产构建和 Windows 64 位便携版生成。构建有已有循环分块及大分块提示，无构建错误。

本版便携包命名为 `莲华视频导演台-2.8.4-便携版.exe`。交付步骤使用 `npm run deliver:2.8.4` 生成版本启动器 `启动莲华视频导演台-2.8.4-便携版.bat`、恢复源码 ZIP、更新说明及 SHA-256 清单。

2.8.3 及更早交付文件继续保留，0.5.160 及更早版本不重编号、覆盖或删除。
