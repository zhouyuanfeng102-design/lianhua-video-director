# 莲华视频导演台 0.6.9

## 本轮更新

- 剧情页“AI扩写”新增自定义目标字数输入，默认约 600 字。目标篇幅只作为文本 AI 的近似提示，允许自然浮动；“AI剧情优化”不携带该目标，原文仍需用户确认后保存。
- 修复普通生图选择“全身”时容易变成膝上、半身或腰部以下裁切的问题。全身任务现在向文本转换器明确发送单主体、头顶（或最高点）到脚底/最低附肢端点完整入画、手脚和鞋靴不裁切、相机后退与留边要求。
- 全身任务同时带有针对性负面词（如 `lower-body crop`、`legs-only`、`cropped head`、`cut-off feet` 等），并在重生成时复用同一构图合同。
- 当 GPT Image 2.5 微 NSFW 角色预设的宽泛取景描述与用户明确选择的普通“全身”规格冲突时，以本次全身规格为准；不修改用户保存的预设，也不新增本地语义拦截或审核。
