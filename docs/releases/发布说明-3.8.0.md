# 莲华视频导演台 3.8.0 发布说明

发布日期：2026-11-06（亚洲/上海）。

## RH 网页账号名改用网页昵称

登录完成后，软件读取 RunningHub 账号资料里的昵称，用它替换「大号」这类临时名字。下拉框和「当前账号」都显示这个昵称。

页面上的应用名、作者名不再当成登录账号。

## 版本定位与交付

Windows x64 便携包：`莲华视频导演台-3.8.0-便携版.exe`。构建命令为 `npm run pack:win`，交付命令为 `npm run deliver:3.8.0`；3.7.9 及更早历史版本文件保留。

## 验证

- Windows x64 便携包：`npm run pack:win`
- 交付文件：`npm run deliver:3.8.0`

已有项目、提示词和成片不作改写。
