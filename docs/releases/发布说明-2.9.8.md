# 莲华视频导演台 2.9.8 发布说明

发布日期：2026-10-23（亚洲上海）。

## 修复 H3 对白与画面执行关系

本版同时修复 H3 人物参考图的重复身份句兼容问题：旧稿或模型输出将同一身份句复制到多个位置时，只要稿件来源、人物 `characterId` 和本次选图归属仍明确，图片继续沿用该人物绑定；新生成的执行稿会去除重复身份句，避免再次出现“已选·待关联”。身份句缺失或人物来源本身不明确时仍不会猜测绑定。

本版针对 H3 视频提示词中“非台词文字被念出”、发话人与听者视线不一致、尾帧人物朝向被结构化补充字段覆盖，以及对白和剧情画面错位的问题，修复提示词生成链路中的来源边界和画面权威关系。

具体调整如下：

- 只有当前原剧情中的明确对白事件承载可辨词句；动作、人物资料、声音说明和整体声景文字不再转成台词或旁白。原文没有对应人声时不新增可辨词句。
- H3 画内对白明确发话人、听者、身体/头部朝向和视线目标；摄影机取景方向单独表达，不以正脸或看镜头替代剧情中的注视对象。
- 最终 H3 末镜作为尾帧站位、人物朝向、视线和机位的唯一画面依据，结构化补充字段仅在最终 H3 未明确时提供连续性资料，避免尾帧人物错误看向镜头或用户方向。
- 局部笑、哭、咳等非词汇人声只保留在实际事件和时间范围内，不提升为跨镜声床；已有对白、镜数、切点和字段顺序继续保留。

本修复直接处理对白来源、人物关系和尾帧提示词优先级的根因，不新增运行时校验、内容审核、生成拦截、自动重试、按钮或模型请求。

## 版本定位

本版便携包为 `莲华视频导演台-2.9.8-便携版.exe`，恢复源码包、更新说明和 SHA-256 清单由交付脚本按同一版本生成。交付命令为 `npm run deliver:2.9.8`。

## 定向验证

本轮定向验证通过：音频提示词策略、H3 性能渲染、尾帧图片提示词、视线构图、H3 身份绑定和 H3 schema；`git diff --check` 通过。

以下两项既有定向测试仍未通过，未因本版打包改写结果：`dialoguePerformancePipeline.test.ts` 的翻译调用次数断言预期比实际多一次 `translate`（实际调用为 `convert, review, translate`）；`speechFirstPlanning.test.ts` 的深比较未接受实际 payload 中已有的 `sourceAuthority` 字段。它们不改变本版修复代码，也不代表新增运行时校验或重试。

打包流程会执行 TypeScript 检查、Vite 生产构建和 Windows x64 便携包生成；本版不改变用户项目存档。

交付后请核对 `莲华视频导演台-2.9.8-SHA256.txt` 中的 SHA-256 清单。

## 使用与交付

保存项目并退出旧版，打开 2.9.8 便携版，保留 EXE 旁完整的“莲华视频导演台数据”文件夹。使用 H3 生成视频提示词时沿用原入口即可；历史版本和交付文件保留。
