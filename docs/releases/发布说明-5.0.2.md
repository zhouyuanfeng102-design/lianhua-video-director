# 莲华视频导演台 5.0.2 发布说明

2026 年 11 月 22 日 · Windows x64 便携版与 Android 正式签名版

## 版本定位

本版修复近距离互动中肢体归属和台词口型串位的问题。两人贴在一起时，海螺会把正文里点到的每个部位、每张开着的嘴都画出来。Windows 与 Android 共用这套规则。

## 接触留在本人身上

含入只写茎身从源稿已写明的那名男性腹股沟伸到她的嘴唇，龟头留在口腔或喉咙里。阴唇，以及体外从腹股沟到阴唇的那一截，只在源稿已经写了阴道进入时才写。器官主人用源稿里的姓名，位置不改主人。后写到的一只手，是这个人还没放下的那条手臂。

## 台词口型留在说话人嘴上

画内每一句的口型留在说话人的嘴上。这一镜里其余每个可见的人，嘴保持闭合。听者只是其中一人。`(S1)` 只标记谁在出声。脸朝下、后脑朝向镜头的镜头仍不把别人的嘴写进这一句。

已保存的成片和提示词不因升级改写。需要更新时，可重新生成中文源稿并翻译，或根据本段表演计划重新成稿。

本版未新增运行时校验、重试、按钮或模型请求。

Windows x64 使用 `莲华视频导演台-5.0.2-便携版.exe`。Android 使用 `莲华视频导演台-5.0.2-安卓版.apk`。维护者使用 `npm run deliver:5.0.2` 整理两端安装包、恢复源码与 SHA-256 交付清单。
