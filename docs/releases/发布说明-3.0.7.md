# 莲华视频导演台 3.0.7 发布说明

发布日期：2026-10-25（亚洲上海）。

## 长剧情批量按所选视频工作流读取图片顺序

视频导演台的长剧情批量在给每一段准备 H3 参考图时，改为读取设置里当前选中的完整工作流。ComfyUI 使用该工作流保存的 JSON。云端和自定义视频接口使用现有的接口配置。

自己导入或另选的工作流可以按它自己的图片槽决定 Picture 编号。默认工作流仍然可用。指定的工作流已经不在列表里时，批量仍能打开，不改提示词、项目和设置。判断是不是同一次请求，仍用原来的连接摘要。

不新增运行时校验、内容审核、生成拦截、自动重试或模型请求。

## 版本定位

本版便携包为 `莲华视频导演台-3.0.7-便携版.exe`，恢复源码包、更新说明和 SHA-256 清单由交付脚本按同一版本生成。交付命令为 `npm run deliver:3.0.7`。3.0.6 及更早交付文件继续保留，0.5.160 及更早历史版本不重编号、覆盖或删除。

## 定向验证

`scripts/videoBatch.test.ts` 已通过。测试使用本地数据，不调用真实模型，也不提交视频生成。检查覆盖：指定工作流、默认工作流、已删除的工作流，以及批量加载不改原提示词、项目和设置。

Windows x64 便携包由打包流程执行类型检查、Vite 生产构建和便携版生成。本版不改变用户项目存档。

交付后请核对 `莲华视频导演台-3.0.7-SHA256.txt` 中的 SHA-256 清单。

## 使用与交付

保存项目并退出旧版，打开 3.0.7 便携版，保留 EXE 旁完整的“莲华视频导演台数据”文件夹。原有长剧情批量入口不变。
