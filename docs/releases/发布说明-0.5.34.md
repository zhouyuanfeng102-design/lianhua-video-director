# 莲华视频导演台 0.5.34

## 版本定位

- 0.5.34 是基于 0.5.33 的长剧情分段、资料补齐与分镜图片提示词转换链路修复版。
- 保留 0.5.33 的全局 FIFO 图片队列、图像长任务超时和全部既有功能，继续兼容旧项目数据。

## 长剧情与镜头连续性

- 长剧情从唯一母版切分，保持原剧情事件归属、顺序和可追踪边界，避免重复、拖沓或偏离原文。
- 被定位、观测或分析的人物不再误作现场动作主体；明确的动作执行者可以覆盖陈旧主体，宾语不会抢占主体。
- 抽象分析会转换成可见的观测来源、证据变化与结论标记，不再直接把规则、总结或不可见思维发送给生图模型。
- 首段首镜建立本镜轴线，后续段首镜承接上一段末镜，段内镜头与上一镜连续，不再依赖切段后失效的绝对镜号。
- 清除“动作目标”“剧情原文及延伸空间”等模板占位词，同时保留标牌、实体名称和真实剧情信息。

## AI 增强补齐

- 剧情分析与人物、地点、道具的 AI 增强补齐解耦；场景分析失败时，其余资料仍会继续补齐。
- 可用的部分补齐结果会正常写回，失败会显示真实原因，不再提示已经完成却没有资料。
- 补齐请求只由项目身份与剧情原文控制；图片任务更新项目时间不会误取消正在进行的补齐。

## 分镜图片提示词转换

- 分镜图片严格执行“文本转换 → 结构校验 → 保存最终提示词 → 图像生成”，文本转换失败时不会调用图像模型。
- 转换输入包含当前剧情、人物外观与服装、地点、道具以及匹配参考图，生成一个明确可见的电影静帧，而不是把规则原文直接交给生图模型。
- 原文、人物、地点、道具或参考图发生变化后，旧提示词和旧任务会失效；任务完成绑定前会使用当前项目上下文再次校验。
- 同一分镜批次新生成的图片不会反过来使后续 FIFO 任务失效，继续保持严格排队和逐张生成。

## 回归验证

- 长剧情真实回归覆盖唯一母版、主体与对白、语义节拍、完整时长和跨段连续性。
- LLM 与分镜图片回归覆盖 AI 增强补齐、单帧文本转换、资料与参考图绑定、失败阻断和上下文失效。
- 发布验收包括完整测试、生产构建、真实便携包三视口烟测、零控制台错误和 SHA-256 校验。
