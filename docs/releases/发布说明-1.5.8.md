# 莲华视频导演台 1.5.8 发布说明

修复生成首尾帧与分镜图片后，任务长时间不显示，以及多批操作时准备请求无记录退出的问题。沿用1.5.7的普通、私密、分镜和首尾帧1K／2K／4K分辨率设置与生图规则。

## 修复内容

- 同步配置检查通过后立即登记全部图片任务，再解析实际出镜人物、补齐资料、冻结参考图或规划自定义静帧。首尾帧立即登记2个，默认分镜按真实镜数登记，自定义数量和工作台勾选镜头按本次选择登记。
- 任务中心显示“准备中”及人物资料、参考图读取、静帧规划、提示词转换等阶段。准备完成补全原记录，任务ID和批次归属保持一致，再进入图片队列。
- 后台准备跟随所属项目和原分镜来源。切换页面、选中其它分镜、切换项目、其它图片保存或输出绑定变化不再无痕放弃批次。实际剧情或H3来源在准备期间变化时，未提交项停止并保留取消原因；已准备入队的任务继续使用冻结快照。
- 准备失败保留失败任务及原因；取消或删除准备任务后，迟到的AI响应不能重新提交已取消项或补回删除记录。部分取消不会阻止同批其余任务。
- 直接图生图采用相同的即时登记机制。需要转换的规则按每张任务依次转换，避免整批同时转换后才出现任务；转换成功前最终提示词留空，防止未经转换的原文进入重试生图。
- 保存恢复保留所有任务及分镜批次槽位。重启后中断的图片任务保留原记录，明确注明未完成阶段；不自动重发可能收费的生成请求。
- 图片任务预览延迟加载，减少大量历史图片的初始读取。

## 根因

旧流程先等待人物识别、外貌补齐、参考图读取及静帧规划，最后才创建任务。准备期间又比较当前选中分镜和整个资产集合，切换分镜或其它任务新增资产会使检查失效，直接退出而没有失败记录。未发现因任务数量上限而截断或删除任务；图片执行队列仍按任务顺序运行。

## 使用方法

保存项目并关闭旧版，用1.5.8打开原数据目录，保留整个“莲华视频导演台数据”文件夹。

点击生成后可立即到“生成任务”查看准备进度并取消。旧版从未登记的准备请求没有任务记录，无法自动找回，可在原分镜重新发起。准备尚未完成、缺少最终提示词或参考图快照的失败项，也应从原分镜入口重新发起。

隔离界面专项5项通过：人物识别挂起时立即显示任务；多批与普通资产新增保留原ID；准备失败留记录；取消后迟到响应不提交生图；工作台选中镜头切页后完成原任务。合成测试的首尾任务首次显示约550毫秒，这不是所有项目和设备的耗时保证。
