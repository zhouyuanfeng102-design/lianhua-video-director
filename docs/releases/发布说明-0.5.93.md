# 莲华视频导演台 0.5.93 发布说明

## 版本定位

本版修复 AI 长剧情分段在接口返回成功后被本地来源校验误拦的问题，并把完整落地校验接入同一文本 API 的自动返修链路。目标便携包为 `莲华视频导演台-0.5.93-便携版.exe`，交付同时生成恢复源码、更新说明、版本启动器和 SHA-256 清单。

## 精确来源区间

- 总镜头的 `sourceStart/sourceEnd` 表示镜头实际采用的 source-unit 精确原文子区间，不再被错误要求等于整个粗粒度剧情节拍。
- 一个粗粒度节拍可由多个总镜头的精确子区间共同覆盖；换行等纯空白缝隙允许，非空白正文缺口仍会拒绝。
- 每镜声明的 `sourceBeatIds` 必须与其精确区间实际相交的节拍一致；未知、重复、漏报、越界和单边来源区间继续严格拒绝。
- 旧镜头没有精确来源区间时保留兼容路径，不会强制改写历史项目。

## 同一 API 自动返修

- AI 分段首答除 JSON 与 ID 检查外，还会完整执行分段物化、来源对齐、总镜头覆盖和最终计划校验。
- 首答在上述可修阶段失败时，应用自动调用当前配置的同一文本 API 返修一次，不再要求用户手工修改剧情或项目数据。
- 返修请求包含精确错误、上一版模型结果、原始剧情节拍、总镜头和来源偏移，模型可据此修正分段结构。
- 只有完整校验成功的同一份计划才会写入项目；首答或返修失败均不会覆盖已经确认的计划。
- 请求过期或取消时，不再派发新的返修请求，也不会提交旧结果；`AbortError` 保持取消语义。
