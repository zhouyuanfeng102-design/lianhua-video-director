# 莲华视频导演台 4.1.3 发布说明

发布日期：2026-11-08（亚洲/上海）。

## 看不清的嘴不接这句台词

说话人的嘴在这一镜里看不清时，正文先写画面里其他人的嘴保持闭合，再写镜头以小幅度、慢速度转到这张嘴，然后才是这句台词和嘴张开。没有这句 `<d>` 的人只写嘴保持闭合。

英译整段保留 `<d>[中文] 原话</d>`，不翻译、不换标签、不在标签外再写一遍这句原话。

已保存的提示词和成片保持原样。重新生成该段的中文稿和英文稿，并再生成视频后，这句才会由原来的人用原来的中文说。

## 交付

- Windows：`莲华视频导演台-4.1.3-便携版.exe`。
- Android：`莲华视频导演台-4.1.3-安卓版.apk`，最低 Android 8.0 / API 26。
- 4.1.2 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.1.3`。本版是共享提示词写法，EXE 与 APK 一起交付。
