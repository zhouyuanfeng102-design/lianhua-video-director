# 莲华视频导演台 1.3.6 发布说明

版本日期：2026-10-05（亚洲/上海）。

## 版本定位

本版在 1.3.5 RunningHub 可变图片槽修复的基础上，增加视频工作流的画面比例节点映射与选择。

## 本版变化

- 工作流管理页“时长、比例与分辨率”支持绑定 `aspect_ratio` 节点，例如 `462.aspect_ratio`。
- 读取云端 COMBO 选项，单段与批量生成显示比例下拉框；提交时保留完整选项字符串，如 `9:16 (Portrait Widescreen)`。
- 比例节点按可选参数处理。没有比例节点的旧工作流继续按原值生成，不自动插入或强制绑定。
- 普通 API、ComfyUI 工作流及既有项目数据保持原有行为。

## 验证

- `npx tsx scripts/runningHubVideoOutput.test.ts`：20 组通过。
- `npx tsx scripts/runningHubVideoSettings.test.ts`：54 组通过。
- 比例参数专项测试通过，未实际调用 RunningHub，也未产生云端费用。
- 生产构建与便携版交付以本次构建记录和 SHA-256 文件为准。

构建命令：`npm run pack:win`；交付命令：`npm run deliver:1.3.6`。

交付文件包括 `莲华视频导演台-1.3.6-便携版.exe`、`莲华视频导演台-1.3.6-恢复源码.zip`、`莲华视频导演台-1.3.6-更新说明.md`、`启动莲华视频导演台-1.3.6-便携版.bat` 和 `莲华视频导演台-1.3.6-SHA256.txt`。其中 SHA-256 清单用于核对便携包与恢复源码。
