# 莲华视频导演台 0.5.137 发布说明

发布日期：2026-09-16

## 版本定位

补齐RunningHub工作流的节点发现与配置入口，解决导入空`nodeInfoList`提交模板后，提示词、参考图和参数下拉框没有可选项的问题。

## 问题原因与修复

- RunningHub示例中的`nodeInfoList: []`表示请求没有提供任何节点覆盖项，并不包含实际节点ID、字段名或默认值。旧界面仅从该数组生成下拉选项，因此没有可识别的参数；不能从空数组猜出云端节点。
- 工作流管理新增只读读取云端节点、导入节点JSON和手动添加字段入口，用实际结构补齐可选项。不会通过执行`/run`生成请求来探测节点，也不会把教程节点套到新工作流。
- 节点目录与生成请求的覆盖项独立保存。读取或导入结构不会自动提交整张图的所有默认值，仅在明确绑定或编辑字段时加入对应请求项，避免无意覆盖云端默认参数。
- 保留原请求中的其他字段、已有映射、输出节点限制和运行选项；长云端ID保持精度，认证信息不写入节点备份。
- 读取结构不自动保存或设为当前；切换工作流、连接或关闭管理器后，不用过期读取结果覆盖新配置。

## 使用方式

1. 打开“API 设置 → 视频生成 → RunningHub 云端 → 管理云端工作流”，选择需要配置的工作流并确认类型与云端ID。
2. 若提交模板的`nodeInfoList`为空，可读取云端节点；如云端无法提供结构，可导入实际节点JSON，或按RunningHub给出的节点ID和字段名手动添加字段。
3. 在提示词、参考图与参数配置中选择实际字段。不要把普通画布的节点位置或教程中的节点编号作为当前工作流的字段依据。
4. 检查请求及运行选项，明确保存后再按需设为当前。上述配置操作本身不提交视频生成任务。

## 兼容与数据

现有工作流和任务快照继续保留；不重写历史剧情、提示词、参考图或视频，不重新提交历史任务。本版继续保留导演自定义要求输入、RunningHub多输出ZIP接收及原任务恢复、AI全文分析等已有功能。现有项目、素材及0.5.136和更早版本交付文件不删除、不覆盖。
