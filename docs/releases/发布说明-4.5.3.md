# 莲华视频导演台 4.5.3 发布说明

发布日期：2026-11-11（亚洲/上海）。

## 第一句先写人和身后

时间轴正文不再把分镜标题接在动作后面。朝向或空间空着时，不再填上“按本镜动作与摄影描述”或“沿用本镜动作中的地点与空间关系”。

分镜规划和英文翻译都把同一组三句放在提示词开头，并在动作规则挪到末尾之后再放一次：她的脸朝向一个方向，髋朝向相反方向，头在背的这一头，髋在背的另一头；他的头留在他自己的脖子上，人留在她的背这一侧，舌留在他的嘴里。分镜标题不写进第一句。原文没有写阴蒂特写时，镜头不放到两腿中间。中间的运镜长段没有再加长。

程序仍只排版模型写好的字段，不另补一句。已保存的提示词和成片保持原样。重新生成提示词再出片才会改。

## 交付

- Windows：`莲华视频导演台-4.5.3-便携版.exe`。
- Android：`莲华视频导演台-4.5.3-安卓版.apk`，最低 Android 8.0 / API 26。
- 4.5.2 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.5.3`。提示词规则两端共用，EXE 与 APK 一起交付。
