# 莲华视频导演台 1.4.4 发布说明

## 本次改造

- “AI剧情优化”改为“AI画面描述转化”。先理解全文事件、人物称呼、被动句与侧面描写，再用自然段写成剧情画面描述；不强制固定栏目，原对白的原话、语言、说话人及动作时序保留。
- 原有 AI 扩写独立保留。采用画面描述后按项目与章节保存处理前原文和采用结果，可从“查看转化来源”对照、复制；编辑中的还原与异步结果保护继续有效。
- 分段增加可选事件因果记录，保存行动者、动作、目标、结果及来源依据。后续分镜获得独立的只读全文理解材料，补明上下文已有依据的行动来源，不把其他段事件搬进当前段，也不恢复用户明确删改的内容。
- 分镜、中文 H3、英文翻译和 Seedance 统一约束：不因只拍受击者而丢掉攻击来源，不把比喻变成真实力场、气刃或新能力，不凭主角身份猜造动作。
- 未修改的旧内置剧情预设升级；用户自定义、禁用和附加字段保留。旧项目没有转化前小说时，不伪造原文来源。
- 默认 MiniMax H3、按需生成 Seedance 和自定义秒数保持不变。

## 已有项目如何使用

本次升级不会自动重写已保存的提示词、分段或成片。

如果原有分段的关键事件完整，只是最终提示词遗漏攻击来源，可重新生成受影响分段提示词。若分段本身遗漏了关键动作，建议使用原小说进行“AI画面描述转化”，对照后采用、解析并重新分段，再生成提示词。旧工程只有整理稿时，可以先使用现有全文重新生成；程序不会假装恢复丢失的小说原文。

## 验证范围

针对性验证覆盖剧情转化请求、对白规则、事件因果与别名传递、用户覆盖、原文来源保存恢复、旧预设迁移、H3/Seedance 转换以及浏览器中的采用、还原与切换保护。1000/1280 宽度下按钮布局已检查。模型请求测试使用本地模拟响应，未执行收费模型、图片或视频生成，真实生成质量需以所选模型返回结果为准。

便携版通过 `npm run pack:win` 进行 TypeScript 检查与构建；使用 `npm run deliver:1.4.4` 生成便携 EXE、恢复源码 ZIP、更新说明、启动脚本和 SHA256 校验文件。历史交付版本保留。
