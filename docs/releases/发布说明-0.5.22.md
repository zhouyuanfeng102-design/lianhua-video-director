# 莲华视频导演台 0.5.22

## 版本同步

- 当前开发版由 0.5.21 递增为 0.5.22；0.5.21 及更早历史交付文件继续保留，不会被发布脚本覆盖。
- 现有项目数据、导演模式、输入模式与提示词生成逻辑保持兼容，本次仅调整导演工作区的列宽和左侧控件密度。

## 导演参数与生成结果等宽

- “导演参数”和“生成结果”改为严格 1:1 等宽，左右两栏始终平均分配导演工作区的可用宽度。
- 两栏允许内容在网格中安全收缩，避免固定结果栏宽度造成空间分配失衡。
- 现有面板结构、配色、文案、选中态和操作行为保持不变。

## 左栏容器自适应

- 左侧导演参数区的字号、图标、间距、内边距和控件尺寸按容器宽度自适应缩小，不再只依赖整个窗口宽度。
- 字体保留 8px 可读性下限；较窄列宽下同步收紧卡片、输入框、选项和生成栏，避免文字、图标或控件裁切与溢出。
- 1120×720 至 1430×894 的常用与紧凑窗口尺寸下，两栏均保持完整可用。

## 回归与交付

- 样式回归覆盖严格等宽列、容器响应式尺寸、字体下限以及窄窗口无裁切要求。
- 0.5.22 交付包含 Windows x64 便携版、恢复源码、更新说明、版本启动器、无版本启动器与 SHA-256 完整性清单。
