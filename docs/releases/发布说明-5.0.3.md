# 莲华视频导演台 5.0.3 发布说明

2026 年 11 月 22 日 · Windows x64 便携版与 Android 正式签名版

## 版本定位

本版修复分段视频提示词生成完成后，把人从其他栏目拉回提示词导演台的问题。Windows 与 Android 共用这一处界面状态。

## 生成完成停在当前栏目

分段提示词在后台生成时，可以先去资产库、剧情解析或其他栏目。原先每一段写完都会执行回到提示词导演台，所以人已经离开也会被切回来。

现在只在你还停在提示词导演台时保持这一页。你已经打开其他栏目，界面停在那里，这一段的结果照常保存，完成通知照常出现。单段生成也只在你还停在提示词导演台时，才打开分镜时间线。

本版未新增运行时校验、重试、按钮或模型请求。

Windows x64 使用 `莲华视频导演台-5.0.3-便携版.exe`。Android 使用 `莲华视频导演台-5.0.3-安卓版.apk`。维护者使用 `npm run deliver:5.0.3` 整理两端安装包、恢复源码与 SHA-256 交付清单。
