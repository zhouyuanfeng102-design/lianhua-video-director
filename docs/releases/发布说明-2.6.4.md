# 莲华视频导演台 2.6.4 发布说明

发布日期：2026-10-18（亚洲上海）。

## 版本定位

本版撤回 2.6.3 在修复 Seedance 提示词时新增的提交前校验和生成限制，保留提示词自动修正。素材声明与视频规格修正后，任务正常进入原有生成流程。

## 本次调整

- 删除 2.6.3 新增的提示词素材、规格冲突拦截和实际图片数量校验。
- 删除由上述检查引入的生成按钮限制；本次修复不再增加阻止生成的判断。
- 保留中英文参考素材声明清理，当前图片与音频分别处理；保留执行稿分辨率、画幅与本次参数同步。
- 保留参考段中的场景和动作事实、对白、画面文字、原始提示词及历史冻结任务。时长和连续时间轴保持原样。
- 不新增自动重试、重新生成提示词或 AI 请求。

本次撤回范围为 2.6.3 新增的 Seedance 提示词与图片一致性检查及其生成限制，原有生成流程继续使用。

## 使用与兼容

已有项目继续使用，无需重新生成提示词。历史冻结任务沿用原快照，不在升级时重写；已保存原稿与任务记录保留。

保存项目并退出旧版后启动新版本，保留完整的“莲华视频导演台数据”文件夹。版本按十进位规则从 `2.6.3 → 2.6.4` 更新；已交付的 2.6.3 及更早版本文件不覆盖、不删除。

## 验证

- 4 项针对性执行测试通过：素材和规格自动修正；手改稿及无法识别章节的稿件可提交；正常稿、手改稿及未识别稿各只发起一次模拟生成请求；音频和历史快照保留。未调用真实生成 API。
- 2 项版本元数据与发布说明测试通过；TypeScript 检查、生产构建和生产启动测试通过，无页面运行错误。本轮未重复执行全量回归。
- Windows 64 位便携包生成通过。构建仍有既有的分块循环依赖和大分块提示，生产启动测试未发现页面运行错误。

本版专项命令为 `npm run test:seedance-prompt-rendering`，覆盖素材声明清理、规格同步、自动修正后的执行流程、参考图绑定与音频参考。测试使用 `scripts/videoSeedanceExecution.test.ts`，不再使用新增一致性校验拒绝生成的测试预期。

`npm run pack:win` 已包含 TypeScript 检查、生产构建和 Windows 64 位便携包生成；本版验证与交付状态以本轮实际执行记录为准。

## 本地交付

先执行 `npm run pack:win`，再执行 `npm run deliver:2.6.4`。交付目录包含：

- `莲华视频导演台-2.6.4-便携版.exe`
- `莲华视频导演台-2.6.4-恢复源码.zip`
- `莲华视频导演台-2.6.4-更新说明.md`
- `启动莲华视频导演台-2.6.4-便携版.bat`
- `莲华视频导演台-2.6.4-SHA256.txt`

SHA-256 清单覆盖本版固定名称交付物；无版本启动器更新为指向本版，历史版本文件保留。
