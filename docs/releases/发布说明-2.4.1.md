# 莲华视频导演台 2.4.1

发布日期：2026-10-16。

## 补齐分镜与首尾帧的人物参考图

修复最终生图画面已经出现剧情人物，但实际上传参考图遗漏该人物身份图，导致生成结果中的人物外观不一致的问题。

首次生成分镜图片、首帧或尾帧时，在最终画面转换完成后，按画面中的具名人物补入项目内已绑定且有效的身份参考图。已有手动参考图保留原顺序，新发现人物的身份图追加到末尾，实际参考图同步写入任务快照。

使用当前镜头重新转换并生成时，同样补齐人物参考图。纯历史快照重放继续使用原快照；历史图片不自动重跑。需要更新已有图片时，请按当前镜头重新转换并生成。

## 验证与交付

人物参考补全、分镜图生图控制器、分镜人物别名和当前镜头重新生成的针对性测试通过，覆盖多配角、首尾帧、自定义静帧、引用顺序、快照恢复及读取失败阻断。接口调用均使用模拟数据。

真实生产包的“重新生图”按钮验证通过：配角同框时实际上传主角、场景与配角三张图；配角明确画外时只上传前两张。用途表、任务及资产快照与上传顺序一致，旧图、旧任务及完整视频分镜保留。

打包流程中的 TypeScript 类型检查、Vite 生产构建和 Windows 便携包生成通过；保留已有分包循环及包体大小提示。未追加全量界面与功能回归。

便携包：莲华视频导演台-2.4.1-便携版.exe。随包提供恢复源码、更新说明、启动脚本和 SHA256 校验文件。
