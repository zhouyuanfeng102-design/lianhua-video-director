# 莲华视频导演台 2.3.6

发布日期：2026-10-15。

## 优化大项目库启动

项目目录与正文分离：启动先读取目录摘要、当前项目及有待恢复任务的项目，其他项目点击后按需加载正文。项目列表中的名称、创建时间和数量信息来自对应项目的摘要。首次打开缺少摘要索引的旧库，会在后台为原项目块建立校验过的目录缓存；后续启动复用索引。旧项目块与历史快照保留。

启动只读取恢复点摘要，不再逐个展开所有恢复点。待校验状态明确显示；手动检查和实际恢复继续核验项目文件。没有修改时跳过启动自动保存，确需迁移或任务恢复产生的变更仍可保存。

## 按项目增量保存

未修改项目复用原有存储指针，变更项目单独编码与保存。保存应答只标记本次快照中的确切对象，不把保存期间产生的新修改误判为已保存。当前项目导出仍包含完整正文与素材，未加载项目不会被空数组覆盖。

有未完成、待取回、待选择结果或续跑任务的项目保留恢复处理。切换、挂起、删除当前项目后的回退均先读取所需项目正文，并保留后台更新与撤销历史。原子写入、凭据事务、关闭前持久化屏障及备份完成语义继续保留。

修复视频工作台启动恢复在没有处理中任务时仍刷新全部项目修改时间的问题。只有确实中断的本地处理任务更新所属项目；未打开项目的摘要保持不变。

界面缓存正文请求身份与配置等大型计算，减少保存状态变化引起的重复遍历。

## 兼容与交付

版本按十进位规则从 2.3.5 递增至 2.3.6。全部历史发布说明与交付文件保留。没有删除项目块、恢复点或用户素材，不自动重新提交远端未知任务。

便携包：`莲华视频导演台-2.3.6-便携版.exe`。交付命令：`npm run deliver:2.3.6`。
