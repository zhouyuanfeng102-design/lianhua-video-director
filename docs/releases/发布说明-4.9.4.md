# 莲华视频导演台 4.9.4 发布说明

2026 年 11 月 21 日 · Windows x64 便携版与 Android 正式签名版

## 资产库翻页留在窗口里

图片资产库右上角同时放着「用选中图片生成视频」「检查文件」和翻页。窗口宽度不够时，这些按钮被挤出右边缘，「下一页」点不到，当前页后面的图片也就翻不过去。

4.9.4 在一行放不下时，把这一组按钮整行换到筛选下面。「上一页」、页码和「下一页」保持完整。已有图片、提示词和成片不改。

## 已有项目如何使用

退出正在使用的 4.9.3，打开本版，进入「资产库」。素材超过一页时，右上角或筛选下一行可以看到「下一页」。

同版提供 Windows 与 Android 软件包、源码恢复包、安装说明、能力与验证记录、Windows 启动器及本说明。

签名与验证范围见 [4.9.4 能力与验证记录](能力与验证记录-4.9.4.md)。安卓安装与备份见 [安卓安装说明](../android-install.md)。
