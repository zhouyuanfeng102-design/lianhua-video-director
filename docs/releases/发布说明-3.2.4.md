# 莲华视频导演台 3.2.4 发布说明

发布日期：2026-10-26（亚洲/上海）。

## 扩写和画面转化的贴身动作

AI扩写和 AI画面描述转化会把整理后的正文交给后面的分段和视频。3.2.3 的视频稿已经要求缓慢起伏，这两处任务仍把贴身连续动作按打斗来写：锁定原动词，补节奏和力度，再按路径、停续和受力拆成一下一下。快速抽送是一串可见撞击，海螺会按接触帧配成撞墙那样的声音。器官只挂在动作主语上时，男方部位会被写到女方身上。

已经进入且双方还连着时，扩写补上的过程和画面正文只用这一句：髋和腰贴着对方做缓慢、小幅度、温柔的连续起伏，相接处一直贴着，这串起伏从头到尾保持缓慢。加快、深而急、抽送、一耸一耸、整根没入和短促进入声整句换掉，不和慢句并列。每个器官在每一句里写明主人。手碰到对方时写成「甲的手握住乙的肉棒」。

第一次进入写成一次缓慢连续滑入。离开或换姿势只写一次，仍然缓慢。听得见的事实是持续的湿滑黏连和压低喘息。家具晃动不写声音。台词里的「再深些」「再用力些」仍是口中的话。原文停在亲吻或隔衣爱抚，就停在那里。

拳脚、摔倒、撞门、拍桌和兵器仍按那一下真实打击写，踢、扔、躲、挡和胜负保持原样。普通剧情不使用这句。对白原话不动。

未改过的内置剧情预设升到 1.5.1。用户改过的预设保持原样；扩写的输出协议仍用上面这句。

已经保存的剧情和已经提交的视频不会变。要重新做扩写或画面转化，确认后保存，再解析并重新转化。载入相同设置再次生成会重交旧稿。

不新增校验、重试、按钮或额外模型请求。

## 版本定位

本版便携包为 `莲华视频导演台-3.2.4-便携版.exe`。交付命令为 `npm run deliver:3.2.4`。3.2.3 及更早交付文件继续保留。

## 定向验证

扩写与画面转化的贴身句子注入、普通与成人共用系统前缀、打斗动词保留、未改预设升级各测一次。打包中的类型检查和生产构建另计。
