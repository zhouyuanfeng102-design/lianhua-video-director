# 莲华视频导演台 4.0.4 发布说明

发布日期：2026-11-07（亚洲/上海）。

## 躲着时身体留在遮挡物下面

下次写提示词时，躲、钻、藏、趴、伏在床底、桌下、柜内或门后，躯干留在遮挡物的下沿或内沿以下，膝和髋是弯的，脚可以露在外面。身份图的站姿在这段不起作用。双膝伸直只在原文写明人还站着时使用。从遮挡物里出来时，从这套低姿势起身，不在空档里直接站直。

下次做全片分段时，躲进去并停在遮挡物下面，和从那里爬出或起身，都要占时间。先有躲着的低姿势，后一段才能从那个姿势接着出来。不能只用「床下来」或一声床帷代替。

已保存的分段、提示词和成片保持原样。重新做全片分段后，躲和爬出才会进入某一段。只重写单段提示词，能改成低姿势，补不回前面没分到的躲进去。

## 交付

- Windows：`莲华视频导演台-4.0.4-便携版.exe`。
- Android：`莲华视频导演台-4.0.4-安卓版.apk`，最低 Android 8.0 / API 26。
- 4.0.3 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.0.4`。本版是共享分段和提示词规则，EXE 与 APK 一起交付。
