# 莲华视频导演台 5.0.0 发布说明

2026 年 11 月 21 日 · Windows x64 便携版与 Android 正式签名版

## 版本定位

本版停止视频导演台在勾选或取消分段、以及选择或取消参考图时，把上面的标题和按钮挤到下一行。Windows 与 Android 共用这套界面。

## 顶栏保持一行

勾选一段会保存当前批量选择，顶栏随即把「本地恢复」换成「保存中」。按钮变窄后，同一排的项目库、导入、导出和新建项目换行，章节栏和视频执行方式跟着上下移动。取消选择时再跳一次。

本版按最长的状态文字留出按钮宽度，宽窗口里顶栏、章节栏和批量标题保持一行。分段状态改成单行省略，清单滚动不再把上面的内容顶走。

## 选图窗口

选择或取消一张参考图时，人物提示的文字会变长。本版把这块提示固定在原来的高度里，多出来的说明在框内滚动。图片大小一次写入，不再逐张把标题区撑高。

已保存的成片和提示词不因升级改写。本版未新增运行时校验、重试、按钮或模型请求。

Windows x64 使用 `莲华视频导演台-5.0.0-便携版.exe`。Android 使用 `莲华视频导演台-5.0.0-安卓版.apk`。维护者使用 `npm run deliver:5.0.0` 整理两端安装包、恢复源码与 SHA-256 交付清单。
