# 莲华视频导演台 1.2.5 发布说明

日期：2026-10-03。从 1.2.4 按十进位版本规则升级，历史交付文件保留。

## 版本定位

修复图像工作台人物资料为空却无法补齐、AI 识图未回填仍提示成功，以及普通生图模式错误请求私密资料的问题。

## 根因与修复

- 旧人物的空字段可能被标为“手工确认”。此前补齐请求跳过这些空字段，识图结果也被确认锁挡住。现在显式点击补齐或识图可填写这些空字段；已有非空手工资料仍受保护，自动重分析仍保留主动确认的空值。
- 普通模式此前会因剧情或已有私密资料触发私密补齐。现在普通模式只补普通人物资料，避免普通字段空白时出现私密资料警告。
- 此前返回一个空字段也可能被判为成功。现在按实际非空回填项计数；模型没有返回可用内容时明确提示，不再报告已补齐。
- 识图只接收可识别的资料字段。没有新资料可回填时明确说明；分析期间切换人物、参考图、来源选项或修改资料，迟到结果不覆盖当前表单。
- 保留“是否参考剧情”的选择：选是可使用剧情补齐，选否继续隔离剧情，仅使用允许的手工资料、自定义要求及参考图。

## 使用方法

1. 保存并正常退出旧版，在原交付目录运行 `莲华视频导演台-1.2.5-便携版.exe`，继续使用现有数据目录。
2. 打开原人物，无需删除或重建。按需要选择是否参考剧情，然后点击“AI 补齐资料”；使用参考图时先选择图片，再点击“AI 识图”。
3. 查看实际回填数量与左侧资料，确认后点击“保存”。模型无法从现有信息确定的字段仍可能留空。

## 验证

验证涵盖确认空字段的显式补齐、非空手工内容保护、是/否来源隔离、识图实际回填、空返回反馈、切换期间迟到结果、保存和重新加载，并使用模拟接口避免调用真实生成服务。交付前完成类型检查、生产构建和隔离数据目录的便携包启动、保存、重载检查。

构建：`npm run pack:win`。交付：`npm run deliver:1.2.5`。交付包含便携 EXE、恢复源码 ZIP、更新说明、启动器及 SHA-256 清单。
