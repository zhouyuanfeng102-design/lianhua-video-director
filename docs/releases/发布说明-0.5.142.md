# 莲华视频导演台 0.5.142 发布说明

发布日期：2026-09-22

## 版本定位

为上一段尾帧衔接增加可选的AI辅助选帧，减少只能机械取最后一帧的限制；不设置本地人物语义硬拦截。同时为图片生成任务增加完整最终提示词复制按钮。

## 本版新增

- 默认保留“直接使用原尾帧”。主动选择“AI 辅助选帧”后，从上一段末尾约2秒准备约6张候选画面，将完整前后段提示词、剧情和现有角色资料交给已配置的视觉分析API比较，不偷偷换用其他模型。
- 手动操作可预览候选、查看AI推荐及理由并自行改选；长剧情批量可选择逐段AI辅助衔接，等待上一段完成并保存后分析候选，再准备下一段参考图。
- 不以人物必须露脸、全身、人类外貌或本地完整度评分拒绝候选。AI配置不可用、请求失败或90秒超时，会明确记录原因并回退真实最后一帧；不无限重试，也不将回退标成AI分析成功。
- 每次分析只发起一次视觉请求。取消后不采纳过期结果；保存调用与选择记录，重启恢复时不自动重复分析。已发出的远端请求是否收费以接口服务商为准。
- 选择早于真实尾帧的候选时，显示时间差及可能动作回退的提醒；不自动裁剪原视频、删减对白或改写原提示词。辅助选帧不能补出未出现的外貌，也不能保证人物绝对一致。
- 图片生成任务新增“复制最终提示词”，复制任务记录的完整原文，不受列表两行省略预览影响。生成中已有提示词也可以复制，尚无最终提示词时禁用；成功和失败均提示对应任务，复制不重新生图或修改任务。

## 使用方式

1. 在“API 设置 → 视觉 API”中启用并配置支持图片输入的视觉模型。AI选帧会把候选画面和完整上下文发送到该接口，可能产生额外分析费用。
2. 在“视频导演台 → 长剧情批量”中打开“用上段尾帧”，选择AI辅助方式；已有上段视频时可预览建议并手动改选，尚未生成时可设置等待上段完成后自动衔接。
3. 需要整批连续衔接时，在批量自动衔接设置中选择AI辅助选帧，确认分段、参考图槽及费用提示后再开始生成。仅保存设置不发起AI分析或视频生成。
4. 在“生成任务 → 图片任务”中点击对应任务的“复制最终提示词”，即可复制完整内容；等待转换器生成最终提示词的任务暂不可复制。
