# 莲华视频导演台 3.3.0 发布说明

发布日期：2026-10-27（亚洲/上海）。

## 图片文件名

项目里的图片以前按内容校验值保存，文件夹里是一长串十六进制。现在按图片名称保存，并带上版本：`名称 · 第 1 版.png`。同一张图再保存一次，仍用原来的文件。内容不同的下一张是 `名称 · 第 2 版.png`。

已经在项目图片文件夹里的校验值文件，会在下次保存项目时改成这个名字。软件里的引用跟着改。别的项目还在用的同一文件会复制过去，不删原件。

## 版本定位

本版便携包为 `莲华视频导演台-3.3.0-便携版.exe`。交付命令为 `npm run deliver:3.3.0`。3.2.9 及更早交付文件继续保留。

## 定向验证

同名图片版本、相同内容不另存、校验值文件名改成名称加版本，各测一次。打包中的类型检查和生产构建另计。
