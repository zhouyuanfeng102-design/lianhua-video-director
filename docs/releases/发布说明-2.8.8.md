# 莲华视频导演台 2.8.8 发布说明

发布日期：2026-10-21（亚洲上海）。

## 本次修复

针对“夏娃修复归来与森林空地清点奖励”中群体成员被泛化、两次时间跳跃表达不足，以及视频参数为 720p 而实际提示词仍写 2K 的问题，修正既有转化、分段、导演和视频提交链路。

- **保留有依据的群体成员和事件**：AI 画面转化与分段结合完整原文、匹配的转化来源和连续场面，明确“她们、龙娘等人”的已知成员。共同拒绝、相视而笑和旁观反应作为实际事件传递，不只留下主角和代表发言者。不从全项目名单补人，也不把之后才到场的人提前安排入画。
- **传递已有身份记录**：语义段关联读取实施者、对象、说话者、听者及场面阶段中已有的人物身份；当前有效的场面记录可为主体定义补充身份资料。用户改写或已失效的来源不用于恢复已删人物。在场、镜内可见、画外行动和仅被提及保持区别，不强制全员同框。
- **分别表达时间跳跃**：保留开头“数天后”与段内“随后的日子里、这一天”各自连接的事件和前后状态。同一地点、同一场景编号不代表时间连续。现有导演步骤在既定时长中安排有依据的可见转场；Seedance 继续保留已采用的镜界与状态，不只用一句“数日后”接续上一动作。不新增无依据的天数、疗伤剧情、旁白或字卡。
- **实际提示词跟随视频参数**：预览和提交沿用同一有效请求参数，按技术字段渲染中文或英文的时长、比例与分辨率。兼容“2K 分辨率”“16:9 画幅”等值在前的写法，不再漏掉这类原稿规格。只更新视频规格，不自动伸缩已编排的动作时间线，也不改变对白、音效或其他正文。
- **明确关联不依赖标题**：有明确稿件来源、已知人物身份和本次选图时，即使正文缺少固定章节标题，也继续使用确定的人物参考关联；不凭标题缺失退回“已选人物仍待关联”。同步清理与当前已提交参考图冲突的“全部人物与场景均以文字设定为准”等旧声明，保留真正的剧情和引语。

本次没有新增按钮、运行时校验、内容审核、生成拦截、自动重试或模型请求。未迁移、自动改写用户项目及已有视频。此前声音、动作时长和 Seedance 英译修复继续保留。

## 使用

保存项目并退出旧版后启动 2.8.8，保留 EXE 旁完整的“莲华视频导演台数据”文件夹。

本次实际提示词的规格和已确定的参考图关联，在现有视频导演台预览与提交时生效。人物、反应或转场已丢失的旧稿，需要用保留的原文经过现有画面转化、AI 分段与单段导演操作重新生成对应稿件，再生成视频；仅重新提交旧稿、翻译旧稿或更新参考图不会自动重做剧情导演。已有视频不会随更新改变。

## 定向验证

以下离线定向测试已通过：

- `storyGroupTimePipeline.test.ts`：实际画面转化、分段和导演请求中的群体成员、两次时间跳跃、可见转场与既有调用数量。
- `semanticSegmentIdentityReferences.test.ts`、`officialPrompt.test.ts`：对象、听者、阶段身份与主体资料传递，用户改写和失效来源的优先级。同步调整两个旧声音断言以符合已交付的 2.8.7 声景策略，未修改声音实现。
- `seedanceWriter.test.ts`：Seedance 目标表达规则，森林场面五名已知人物、后到人物不入画及已采用转场的传递；保留一次既有编写请求。
- `videoSeedanceSpecification.test.ts`：中英文规格、值在前写法、实际请求参数及剧情时间线保留。
- `seedanceReferenceClaims.test.ts`、`videoSeedanceReferenceBinding.test.ts`：纯文字声明清理、无固定标题的明确关联，以及预览、任务快照恢复和实际传输使用一致内容。

测试使用模拟请求，未调用真实生成 API，不能替代实际视频生成效果检查。按本次范围执行检查，未追加全量或界面回归。
