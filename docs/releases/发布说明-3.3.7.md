# 莲华视频导演台 3.3.7 发布说明

发布日期：2026-10-27（亚洲/上海）。

## 转述话题整理为自然台词

修复“宋玉一路说着后山几处灵田今年的收成”被逐字当成台词、导致对白像摘要或在后续转化中遗漏的问题。

- 引号内或明确逐字原话继续逐字保留。
- 有明确说话人和话题、但没有逐字原句的转述，在获准生成、扩写和首次画面转化阶段整理为自然完整、可念的一句，只使用原文已有事实。
- 只有发声动作、没有具体话题或原句时不编台词。
- 听者只倾听、反应或行动，不把反应补成新发言。
- 剧情证据仍逐字引用；自然化的台词不冒充原文原句。

仅调整既有提示词规则和定向测试，不新增运行时校验、生成拦截、自动重试、按钮或模型请求。

## 版本定位

本版 Windows 便携包为 `莲华视频导演台-3.3.7-便携版.exe`。构建命令为 `npm run pack:win`；交付命令 `npm run deliver:3.3.7` 会生成 SHA-256 清单，本次按项目要求只构建便携包，不运行该交付清单命令。3.3.6 及更早交付文件继续保留。

## 定向验证

运行对白策略、剧情识别/扩写、语义分段、H3 提示词相关定向测试；便携包构建包含类型检查和生产构建。
