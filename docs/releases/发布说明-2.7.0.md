# 莲华视频导演台 2.7.0 发布说明

发布日期：2026-10-19（亚洲上海）。

## 小说动作与人物表演贯通编排

本版把小说影视化的动作编排推广到日常操作、人物互动、行走与起坐、观察、情绪停续、劳动技能、群体行为和战斗。新稿结合人物目标、处境和对象，写出同一事件必要的接近、操作、接触、交接、反应和末态；不把所有动作套成战斗步骤，也不靠增加微动作或形容词延长场面。

意图、假设、习惯、未遂、中断和已经发生的事件分别理解。人物没有完成的动作继续保持未完成，未知动机与原因不编成事实；原有悬念、静止、停顿、叙事省略和幻想设定保留。导演可以补足同一事件的可见实现，不借此另加台词、冲突、能力或结局。

## 资料与连续场面

- 统一源头与分镜使用的人物普通性格、动作习惯、身体尺度和相关道具资料。资料是演出依据，不要求每镜展示全部档案或执行人物习惯。
- 复用现有场面与事件记录，保持位置、朝向、持物、接触、物品开合和动作停续。递交后物品归接收者，下一段从已经发生的变化继续。
- 全片先安排自然行为、完整对白与可并行活动，再切分生成窗口；普通移动可以按叙事省略，关键交接与因果变化应可理解。
- 分镜与参考画面根据当前动作阶段安排取景；格式转换和英译保留已经采用的行动与状态，不用换图或翻译重新改编剧情。

## 使用与兼容

通过现有 AI 画面描述转化、直接原文规划和中文新稿生成入口使用新编排，无需新增前置操作。已确认稿件、图片、成片和历史任务保持；更新不会自动重写旧稿或修复旧视频。要采用新演出，应主动生成新的中文方案，再沿现有流程使用。

沿用既有模型调用阶段，不新增运行时校验、内容审核、生成拦截、自动重试或模型请求。人物参考关联继续使用原稿来源、身份记录与实际选图，不因缺少格式标题而跳过已有确定关联。
