# 莲华视频导演台 0.5.97 发布说明

## 版本定位

本版修正人物普通资料、私密资料补齐和生图年龄使用逻辑。普通资料会同时维护外观年龄、实际年龄与身高/高度；生图仍只按外观年龄控制画面年龄感，并按身高/高度稳定身体比例，避免修仙、长寿或特殊世界观角色因为实际年龄较大而被画老。目标便携包为 `莲华视频导演台-0.5.97-便携版.exe`。

## 人物资料

- 人物资料编辑区和图像工作台新增“实际年龄”和“身高 / 高度”，位置在“外观年龄”下方。
- AI 补齐普通人物资料时，外观年龄、实际年龄和身高/高度都必须根据用户要求、剧情、身份、称谓、种族、修为阶段、社会角色和外貌描写推算；没有精确数字时使用近似年龄、年龄段、近似身高或体量比例，不再留空。
- 故事分析与项目圣经补全同步输出外观年龄、实际年龄与身高/高度，并在修复请求中要求三者都不得空白。
- 图像工作台的“视觉风格”支持从提示词工作台同一套视觉风格库中选择，也可以继续直接输入自定义风格。
- 提示词导演台新增 8 种动漫视觉风格：4 种 2D（TV番剧赛璐璐、热血少年番、少女漫画动画、厚涂动漫插画）和 4 种 3D（三渲二动漫、卡通3D动画、游戏CG动漫、Q版3D萌系）。
- 旧项目继续兼容；缺少实际年龄或身高/高度的旧人物会以空字符串载入，后续可手动填写或用 AI 补齐。
- schema 升至 23，仅为旧项目补齐新增动漫风格预设；用户已编辑或已删除的现有风格不会被覆盖。

## 生图与私密资料

- 普通角色参考图和四视图提示词明确使用“外观年龄（按此绘制）”，并写入“身高/高度”作为比例锚点，不会把实际年龄写入生图提示词。
- 视频连续性和故事板生图上下文将年龄标为“外观年龄”，并携带身高/高度，降低模型误把设定年龄当画面年龄、或把体型比例漂掉的概率。
- 私密资料补齐继续去掉年龄门禁/年龄元信息，只根据普通人物资料中的姓名、性别、物种、身高/高度、外观、肤色、身形、动作习惯和连续性锚点生成匹配的人物私密资料。
- 私密生图模式不再因为年龄字段重复卡住；普通资料补齐和私密资料补齐可以在同一次补齐流程里各走各的字段规则。
- 私密生图新增“私密四视图”和“私密四合一”。私密四视图读取私密全身资料，生成正面、严格侧面、背面和三分之四视图；私密四合一以私密全身为主画面，三个私密部位只作为较小辅助窗补充细节。
- “自定义要求”输入框按按钮语义使用：点击“AI 补齐资料”时作为资料补齐要求；点击“生成图片”时作为本次生图额外要求，并随提示词转换源一起发送给文本 AI。
