# 莲华视频导演台 1.6.8 发布说明

2026-10-09

RunningHub工作流管理的“生成参数”增加“LoRA”和“其它”分区。已暴露的LoRA槽位可自动识别，主模型、开关及自定义节点字段可加入其它参数，保存后用于后续新生成。

## 配置入口

进入“API设置 → 视频生成 → RunningHub云端 → 管理云端工作流 → 生成参数”。这里分为“常用参数／LoRA／其它”三个分区。

常用参数保留时长、比例、分辨率和采样步数四张卡片。“高级：指定宽高”入口已移除，已有宽高字段、值和映射保留；需要编辑时可在“节点参数”中操作。

## LoRA槽位

自动识别工作流中真实已暴露的LoRA模型字段及其模型强度、CLIP强度，显示当前槽位数量，不把主模型字段误计为LoRA。也可手动指定模型与强度对应的节点位置。

有真实云端候选时使用候选列表；没有模型列表时，可填写实际文件名或自行配置候选。选择与保存使用真实字段值。手动配置的是作者已开放的字段位置，不会为只能调用的AI应用创建底层ComfyUI节点，也不会虚构云端模型列表。

## 其它节点参数

在“其它”中选择实际节点字段，可加入主模型、开关、自定义文本或数字等配置。支持文本、数字与下拉控件，以及对应候选、范围、步长等本地控件信息。范围只作提醒，不因超出建议值阻止保存。

卡片默认紧凑排列，每页最多显示四张；更多字段及较小窗口使用分页，不限制可配置的字段数量。

## 保存与兼容

保存工作流后，后续新生成使用保存的参数。原字段类型与数值精度保留，本地控件和展示元数据不进入云端请求。没有修改的节点值保持原值，旧任务继续使用创建时冻结的请求，不自动更新或重新提交。

## 验证与交付

已完成7组专项测试，覆盖LoRA识别、手动位置与其它字段、选项与原字段类型、强度精度、保存与恢复、请求编译及旧任务兼容；严格源码TypeScript检查通过。源码界面验证覆盖三个窗口尺寸、分区与分页、保存重载及原类型和精度，未调用真实云端生成接口。

本轮打包命令 `npm run pack:win` 包含TypeScript检查和生产构建，不再重复执行全量回归。历史发布说明和交付文件保留。
