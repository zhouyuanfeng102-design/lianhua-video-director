# 莲华视频导演台 2.7.5 发布说明

发布日期：2026-10-19（亚洲上海）。

## 共用动作时间安排

现有 Seedance“重新生成本段”和结果区“重新生成 Seedance”沿用中文生成与英文翻译两次调用，在中文返回中同步公共分镜与目标稿。固定段长、镜头身份、全部动作次数、对白及因果保持，允许根据自然动作完成点调整原有镜内时窗与切点。H3 后续读取更新后的公共源稿，已有另一格式的历史结果保留，不悄悄重新调用模型。

普通格式转换、参考更新和单独翻译继续保真。保留三步、多个照面、持续接触、脱开、收手与整理；速度、力度与镜头运动分开表达，不靠删动作或缩短固定视频处理慢演。

## 真实连接信息进入原有请求

原有源头规划、H3 和 Seedance 编写调用使用当前章节视频导演台所选连接；同计划批量任务使用其已保存连接，没有表单选择时沿用设置。仅传递模型、已知生成模式和明确输入映射等必要事实，不传凭据、地址、请求模板或任意参数。

稿件格式与实际模型独立。RunningHub 工作流名称不当作真实检查点，未知内部接线、量化和采样保持未知，不自动改模型、LoRA、采样步数或云端节点开关，也不发起探测请求。

## 动作视频参考

在现有参考素材区域选择资产库中的动作视频，可填写人物对应及参考用途；没有动作视频时继续按小说编排生成。单段选择与批量逐段覆盖随章节保存，任务复用保留原视频快照。

已配置的视频输入通过 RunningHub 视频映射、ComfyUI 视频映射，或通用 API 的明确请求模板传入。支持 `{{video_N}}`、`{{videos}}` 和 `{{video_references}}`，不根据 Seedance/H3 稿件名称推断第三方接口协议。不支持视频输入的连接不会假称已使用动作视频，资产与表单原选择保留。

动作视频负责运动、节奏、重心和接触过程，人物静图仍负责身份；本地参考说明不增加原剧情动作，不自动继承参考视频的配乐。上传、冻结、任务指纹和项目素材保存贯通视频引用。

## 声音

统一剩余 H3 声音规则：整体声景汇总已有现场声，全静音才写 `N/A`；无授权配乐为 `non_diegetic_music: N/A`。补全缺失声景时采用已有中英文同期声，保留历史已确认的声音安排。

提示词表达声音意图，不保证远端模型绝不生成配乐；关闭全部声音不能替代只禁背景音乐。

已通过动作重排、实际连接信息、图音视频共同绑定和视频任务传输的定向测试。真实 App 的现有 Seedance 重新生成入口仅使用两次模拟请求，确认完整动作、非均分切点、中英文和历史稿件保存；视频参考界面确认单段提交与单段、批量选择保存恢复。以上检查均未调用真实收费生成接口。

打包内 TypeScript 检查、Vite 生产构建与 Windows 便携版打包通过。实际 2.7.5 EXE 使用隔离数据目录启动，首页和视频导演台均正常显示，版本正确，无页面或渲染错误、无外部生成请求。另已通过批量参数与冻结连接归属的定向测试。

未进行收费视频生成，本次结果证明代码链路、保存和启动可用，不代表已实测远端模型的成片动作效果。构建仍提示项目已有的分包循环和大包警告；本次实际便携版启动未出现白屏。
