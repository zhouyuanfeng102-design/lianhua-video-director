# 莲华视频导演台 3.1.9 发布说明

发布日期：2026-10-26（亚洲/上海）。

## 私密身体接触不再配成硬物撞击声

NSFW 部位彼此接触时，提交给视频模型的声音被写成清脆拍击、臀腹相撞、石桌闷响和冲撞。模型按这些词取硬物撞击音，听起来像打墙。

新生成和获准重写声音的中文稿、H3 转写，把这种接触写成低而近的皮肤贴合、湿滑黏连和压低喘息。剧情里的撞、拍只保留成动作快慢和深浅。石桌、墙面只有家具自己在动时才单独写成更轻的擦动，不写进整段声景。打斗、落地、敲门和兵器碰撞仍用原来的碰撞声。

纯格式修复不改已确认的音效句。已经生成的旧提示词要重新走中文转换或 H3 转写，声音词才会换掉。

不新增校验、重试、按钮或额外模型请求。

## 版本定位

本版便携包为 `莲华视频导演台-3.1.9-便携版.exe`。交付命令为 `npm run deliver:3.1.9`。3.1.8 及更早交付文件继续保留。

## 定向验证

NSFW 声音规则注入和本地碰撞兜底各测一次。打包中的类型检查和生产构建另计。
