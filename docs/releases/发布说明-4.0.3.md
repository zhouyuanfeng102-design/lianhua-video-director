# 莲华视频导演台 4.0.3 发布说明

发布日期：2026-11-07（亚洲/上海）。

## 换地方的路留在分段里

下次做全片分段时，原文写了的换地方或换状态要占时间。出门、进门、从床下出来、走到门口、把门转到落闩，在它开始的那一段里演完，或者下一段从走到一半接着演。

下一段的入口就是上一段的出口，不能是更后面的结果。上一段还停在告辞或室内对话时，下一段不能直接开成门已落下、人已坐在门边，除非原文自己跳过了这段时间。结果标题和一句环境声不能代替这段路。

已保存的分段、提示词和成片保持原样。重新做全片分段后，这段路才会进入某一段。只重写单段提示词，补不回已经被分段跳过的行动。

## 交付

- Windows：`莲华视频导演台-4.0.3-便携版.exe`。
- Android：`莲华视频导演台-4.0.3-安卓版.apk`，最低 Android 8.0 / API 26。
- 4.0.2 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.0.3`。本版是共享分段规则，EXE 与 APK 一起交付。

## 验证

打包流程自带类型检查和前端构建。未把已有分段和成片重新生成。
