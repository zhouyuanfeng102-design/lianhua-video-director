# 莲华视频导演台 3.1.2 发布说明

发布日期：2026-10-25（亚洲/上海）。

## 降低导演台与视频提交卡顿

- 提示词导演台复用分镜 ID 索引，并缓存当前计划的校验结果，减少切换片段时的重复派生计算。
- 视频单项提交和批量预检复用项目素材索引；每个旧任务仍使用自己的冻结图片索引，保持原有首个重复 ID 语义。
- 关联图片统计从重复扫描改为线性索引，保留明确绑定、历史来源、重复图片和归档人物的既有处理语义。

本版不修改界面布局、样式、文案或交互，不增加模型请求、运行时拦截、自动重试或额外校验。任务快照、检查点、项目保存和正式 POST 前的持久化边界保持不变。

保存项目并退出旧版，打开 `莲华视频导演台-3.1.2-便携版.exe`，保留 EXE 旁完整的“莲华视频导演台数据”文件夹。
