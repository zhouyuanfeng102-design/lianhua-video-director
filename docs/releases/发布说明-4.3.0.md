# 莲华视频导演台 4.3.0 发布说明

发布日期：2026-11-09（亚洲/上海）。

## 排队只看当前项目

本地排队只数当前项目里还在生成的视频。别的项目里的任务不再占这个项目的名额。没有网页任务号、运行按钮也没点出去的这一段，不再把自己算成正在生成。同一项目里已经拿到远端任务号、还在生成的视频，仍然占着这个项目的名额。

已保存的提示词和成片保持原样。第 2 段需要再点一次「继续准备原任务」。

## 交付

- Windows：`莲华视频导演台-4.3.0-便携版.exe`。
- Android：`莲华视频导演台-4.3.0-安卓版.apk`，最低 Android 8.0 / API 26。
- 4.2.9 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.3.0`。这次改的是排队名额，EXE 与 APK 一起交付。

## 验证

打包流程自带类型检查和前端构建。队列用内存夹具核对：别的项目不占名额，没有网页任务号的任务可以再交一次，同一项目里已有远端任务号的视频仍占名额。未在真实 RunningHub 页面上再点运行。
