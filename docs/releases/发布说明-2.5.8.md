# 莲华视频导演台 2.5.8

发布日期：2026-10-17。

## 剧情生图保留道具尺寸

针对道具资料已经写明长度，转换后的图片提示词却仅保留名称与光效、没有保留尺寸的情况，调整共用剧情生图转换规则：当前可见道具的名称、尺寸维度、原数值与原单位一同进入最终生图正文，不混用不同物件或部件的尺寸，不凭名称或无标尺参考图补造数值。候选资料只决定物件是否在当前帧入画，实际可见时仍需保留其已知尺寸。

手持、穿戴和接触物件结合当前持有者与接触部位表现真实比例。透视、低仰角、近景和裁切保持摄影本身的投影效果，不改变物件实体尺寸；光柱、火焰与光晕的范围不当作道具本体大小。剧情明确变大、缩小、伸缩或变形时按当前帧已经发生的状态处理，首帧不提前采用尾帧大小，未知变形后的具体数值不编造。

普通分镜、首尾帧、自选静帧及相关剧情多宫格、场景抓拍沿用共用转换规则；自然语言、SD 和 NAI 格式均保留物件与尺寸的对应。未批量重写普通人物设定、无人场景或独立物品预设。

## 参考图用途

道具参考图提供外形、材质、配色与部件结构，不用图中占幅、三视图排版或无标尺外观推定实际大小。同批首图只提供原有的外观与光线连续参考，不覆盖当前明确的道具尺寸。已经清空或失效的绑定继续保持原有用途边界。

## 范围与历史内容

本版只调整提示词规则及参考用途说明，不新增尺寸字段、数据迁移、自动尺寸识别、运行时尺寸校验、AI 审核、重试或额外模型调用。自定义规则、历史任务与已有图片保留，规则组合只整理当前请求中的完整内置规则块。

来源镜头仍存在时，可通过资产卡“重新生成”按当前规则重新转换，新图另存。旧图片像素不会自动改变。规则增强仍由现有转换与生图模型执行，不保证每次模型输出都准确满足物理尺寸。
