# 莲华视频导演台 3.7.8 发布说明

发布日期：2026-11-06（亚洲/上海）。

## RH 网页标明当前登录账号

「添加国际站账号」「添加国内站账号」不再和登录放在一起。添加登录位只是多一个名字，用来分开保存不同登录，不会打开网页。

当前账号显示在登录按钮上面，写明名称和站点。点「登录这个账号」后，软件说明窗口对应的是哪一个。你在窗口里登录完成后，这里显示网页上的昵称和 RH 币。

## 版本定位与交付

Windows x64 便携包：`莲华视频导演台-3.7.8-便携版.exe`。构建命令为 `npm run pack:win`，交付命令为 `npm run deliver:3.7.8`；3.7.7 及更早历史版本文件保留。

## 验证

- Windows x64 便携包：`npm run pack:win`
- 交付文件：`npm run deliver:3.7.8`

已有项目、提示词和成片不作改写。
