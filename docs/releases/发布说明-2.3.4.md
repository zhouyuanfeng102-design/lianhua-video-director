# 莲华视频导演台 2.3.4

发布日期：2026-10-15。

## 修复 v6k 多图请求体积膨胀

旧版向 v6k 视频接口提交多张本地图片时，会把完整图片转换为 Base64 放入 JSON，并额外重复写入首帧与尾帧图片。多张 4K 图片因此可能组成超过 100 MiB 的请求，远端返回 HTTP 413。

2.3.4 对 v6k 官方域名的 `/v1/videos` 提交接口，在未使用自定义请求模板时采用文档协议：本地图片以 multipart 的 `images` 文件字段提交二进制，去除 Base64 膨胀和重复首尾帧字段。保留全部参考图、用户选择的图片顺序、提示词和生成参数；纯 URL 参考图按文档使用 JSON。

本次不自动降低图片分辨率或质量。已选原文件或用户明确应用的轻压缩副本继续作为提交内容。其它服务和自定义请求模板沿用原配置。

接口依据：[v6k 视频接口文档](https://www.v6k.top/docs?guide=unified&category=video)。服务端实际总请求上限和模型受理要求仍以上游为准，本次未猜测或新增固定的服务端大小阈值。

## 保留错误摘要与请求体积

失败信息保留脱敏后的文本或 HTML 错误摘要，帮助识别上游或网关返回的原因。HTTP 413 增加实际发送请求体积，便于核对远端限制。

版本按十进位规则从 2.3.3 递增至 2.3.4。2.3.3 及更早历史版本、发布说明与交付文件保留，不覆盖、不删除。已有项目、提示词、参考素材和任务记录保留，不自动重跑失败任务。
