# 莲华视频导演台 0.5.66 发布说明

## 版本定位

0.5.66 为图像生成任务和资产库图片卡片补充可控的手动“重新生图”入口。两个入口共用同一流程并跨入口防重复；它保留既有任务、图片、绑定和项目数据，不自动重试，也不改写历史交付文件。

## 手动重新生图

- 每项图像生成任务右侧提供“重新生图”，资产库图片卡片提供“重新生成”。
- 普通上传图片如果没有可恢复的生图提示词或任务，按钮会禁用并提示补充资料。
- 成功或失败的任务可由用户手动重新提交。
- 任务处于排队或运行中时，按钮仍保持可见但禁用；两个入口共用同一流程并跨入口防重复，避免同一图片并发重复提交。
- 系统不会自动重试，避免重复创建任务或产生重复计费。

## 保留与命名

- 重新生图不会覆盖旧任务、旧图片或旧绑定。
- 新任务和新图片沿用原名称，并追加 `-2`、`-3` 等唯一版本后缀。
- 已有项目、资产、提示词和绑定关系保持不变；0.5.65 及更早历史包继续保留。

## 请求复用边界

- 新任务复用原任务保存的最终提示词与尺寸。
- 重新提交使用当前配置的同一图像生成后端 API。
- 若旧任务没有保存最终提示词，会尽量从保存的来源恢复后再提交。

## 完整模型选择

- 原生 `datalist` 改为独立完整模型选择窗口，图片、文本和视觉模型共用同一交互。
- 获取模型后自动打开窗口；窗口支持独立搜索、显示接口返回的全部模型总数、滚动浏览和长模型名换行。
- 下箭头可随时重新打开窗口，不会按当前已选模型名过滤模型列表。
- 仍可手动输入模型名。

## 交付

- 便携包：`莲华视频导演台-0.5.66-便携版.exe`
- 恢复源码：`莲华视频导演台-0.5.66-恢复源码.zip`
- SHA-256 校验清单：`莲华视频导演台-0.5.66-SHA256.txt`
- 交付命令：`npm run deliver:0.5.66`
- 交付目录同时提供版本专属启动器、更新说明、恢复源码和 SHA-256 校验清单。
