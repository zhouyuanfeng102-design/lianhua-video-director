# 莲华视频导演台 4.6.8 发布说明

发布日期：2026-11-16（亚洲/上海）。

## 长分段保持半角冒号

Gemini 3 和 Gemini 4 的语义分段请求改为严格 JSON 结构。每个对象只保留分段解析需要的字段，属性名后面只能是半角冒号。长回复不再在写到一半时丢掉冒号或写成全角冒号，然后继续往下写。

AI 适配的共同规则不再把空的 `segments` 教给模型。固定时长仍然可以在排不开时返回不足，并说明具体冲突。

已经要求关闭思考的 Gemini 3 和 Gemini 4，同一次请求使用 `low` 思考档。Flash-Lite 保持原样。接口若把思考分片和正文放在一起，只读取正文。

最大输出仍使用 API 设置里保存的数值。已保存的分段、提示词和成片不改写。下次再执行「AI 理解剧情并分段」时使用这次请求。

## 交付

- Windows：`莲华视频导演台-4.6.8-便携版.exe`。
- Android：`莲华视频导演台-4.6.8-安卓版.apk`，最低 Android 8.0 / API 26。
- 4.6.7 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.6.8`。分段请求在两端共用，EXE 与 APK 一起交付。

## 验证

打包流程自带类型检查和前端构建。语义分段的严格结构和 Gemini 思考档位由对应定向测试核对。
