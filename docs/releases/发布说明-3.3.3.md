# 莲华视频导演台 3.3.3 发布说明

发布日期：2026-10-27（亚洲/上海）。

## 已停止不再显示排队

批次统计已经是「已停止」，卡片仍可能写着「本地排队中」和「尚未开始执行（排队不计时）」。那是停止前的运行记录盖在任务上面。现在以任务本身的停止状态为准，不再显示排队。这类已停止、尚未提交的项也不再挡住删除批次。

## 版本定位

本版便携包为 `莲华视频导演台-3.3.3-便携版.exe`。交付命令为 `npm run deliver:3.3.3`。3.3.2 及更早交付文件继续保留。

## 定向验证

已停止任务带着旧的排队运行记录时，批次状态仍是已停止，并且可以删除。打包中的类型检查和生产构建另计。
