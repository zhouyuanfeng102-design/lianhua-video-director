# 莲华视频导演台 2.5.5

发布日期：2026-10-17。

## 绑定保存后同步显示关联图

修复资产库提示“绑定已保存”，回到图像工作台调用同一人物时却仍显示“未生图”的问题。原显示只统计实体保存的生成图片列表，遗漏了在资产库手动绑定的图片。

图像工作台的“调用项目实体”和剧情实体列表统一按当前有效归属统计，显示“X 张关联图”或“未关联图片”。人物、场景、物品均适用；明确改绑或解绑后，当前关联状态随之更新，旧生成来源与旧列表不会重新恢复已解除的绑定。已删除图片、失效或归档目标、重复 ID 与非图片记录不计入有效关联数量；同名资料仍按各自的种类和 ID 区分。

资产库图片卡片直接显示绑定的人物、场景或物品，无需展开“详细信息”查看。未绑定或已绑定目标不可用时，也会直接显示当前状态，方便重新选择。

## 物品特写与三视图

物品画面规格移除“图标”和“展示图”按钮，保留“特写”，新增“三视图”。三视图在一张横向图片中按正面、严格 90° 左侧面、背面分为三个等宽区域，保持同一物品的尺度、结构、材质、配色和当前状态，完整展示轮廓；特写继续采用近距离取景，不强制拉远。

普通自然语言、SD/NAI 标签格式及各模型家族的内置规则与物品分类预设同步补充条件布局、参考图职责和负词；三视图只在本次明确选择时生效，避免旧“禁止重复物品”等宽泛负词抵消所需观察面。规则目录升级至 21，未修改的内置规则更新，用户修改、禁用与删除选择保留。旧图标和展示图记录继续兼容保存、读取与重试，已有图片和历史任务快照保留。

## 关联状态与本次参考输入

关联图片表示图片对应哪条人物、场景或物品资料。调用实体会载入资料，关联状态不会自动将图片选为本次图生图参考。需要携带图片生成时，仍在生图设置中使用“从资产库选择”，确认所选参考图与参考开关。

本版按现有绑定元数据读取关联状态，无需重新绑定图片，也不改写原生成来源和实体 `assetIds`。规则目录升级只更新未修改的内置规则，保留用户修改和禁用状态。历史提示词、已有任务、图片与旧版本交付文件保留，升级不会自动重跑任务。
