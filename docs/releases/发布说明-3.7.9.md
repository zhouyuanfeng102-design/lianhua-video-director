# 莲华视频导演台 3.7.9 发布说明

发布日期：2026-11-06（亚洲/上海）。

## RH 网页槽位改到管理页

图片槽、提示词和其它参数不再直接铺在 RH 网页主页上。主页只保留当前应用和一句摘要，点「管理网页应用」后，在和云端工作流管理一样的窗口里读取网页、绑定槽位和参数。

## 版本定位与交付

Windows x64 便携包：`莲华视频导演台-3.7.9-便携版.exe`。构建命令为 `npm run pack:win`，交付命令为 `npm run deliver:3.7.9`；3.7.8 及更早历史版本文件保留。

## 验证

- Windows x64 便携包：`npm run pack:win`
- 交付文件：`npm run deliver:3.7.9`

已有项目、提示词和成片不作改写。
