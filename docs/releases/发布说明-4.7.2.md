# 莲华视频导演台 4.7.2 发布说明

发布日期为 2026-11-18（亚洲/上海）。

本版修复 MiniMax H3 纯文字衔接中，下段首镜容易重复上段动作的问题。旧规则同时要求缩短开场和重合动作，容易让模型从上段动作的起手重新演一遍。规划、生成、衔接修复和翻译现统一从上段最后一刻的可见状态起步。已完成的动作从结果姿态开始，仍在进行的运动从当时的位置、接触点和方向接出。默认约 0.50 秒进入本段第一项新内容，确需调整时最晚在 0.80 秒开始。

Windows x64 使用 `莲华视频导演台-4.7.2-便携版.exe`。Android 使用 `莲华视频导演台-4.7.2-安卓版.apk`，最低 Android 8.0（API 26）。同目录提供 SHA-256 清单。
