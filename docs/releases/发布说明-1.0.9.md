# 莲华视频导演台 1.0.9 发布说明

日期：2026-10-01。

## 版本定位

修复H3中文生成请求受英文规则和示例影响，导致中文页签保存并显示英文画面正文的问题。本版从生成请求的语言来源分离中文与英文任务，保留既有H3官方结构和原语言对白。

## 中英文生成来源

- 中文H3生成使用中文画面、动作、镜头与声音描述；官方字段名、标签和参考图引用继续使用要求的原格式，不把字段语言误当成正文语言。
- 英文版本从当前中文H3派生，翻译画面与声音描述，保持对白原语言、语义、镜头安排及参考关系。
- 不新增语言比例检查、独立审核或额外AI调用，不在最终结果中用本地翻译、替换或硬拼内容补救。
- 本版只处理H3中英文来源，不调整剧情分段或模型思考模式。

## 已有结果与使用

已有提示词、图片、视频及正式项目数据不会因升级而自动改写或重新生成。对于中文页签已保存英文正文的旧段落，打开新版并选中该段，使用“修复对白与排时”重新交付中文H3，随后由现有流程派生英文；该操作保留段长和原台词，并保存旧版本，但允许重新安排本段分镜。仅重试英文不能恢复缺失的中文版本；仅修复衔接或更新参考图也不负责重译整份旧稿。

便携包：`莲华视频导演台-1.0.9-便携版.exe`。交付命令为`npm run deliver:1.0.9`，同时生成恢复源码、更新说明、专属启动器与SHA-256清单。

版本从1.0.8按十进位更新为1.0.9，下一版为1.1.0。保存并关闭旧版后再启动新版。历史带版本的文件保留，不覆盖、删除或重编号。
