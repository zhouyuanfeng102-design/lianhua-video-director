## 交付

- Windows：`莲华视频导演台-4.3.1-便携版.exe`。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.3.1`。这次改的是任务状态显示和批次标记，EXE 与 APK 一起交付。
