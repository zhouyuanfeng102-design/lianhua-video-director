# 莲华视频导演台 1.3.4 发布说明

版本日期：2026-10-05（亚洲上海）。

本版修复 RunningHub 同一工作流在不同分段使用不同数量参考图时的提交逻辑。

## 本版变化

- 每个分段独立提交实际选中的参考图数量，包含自动衔接的尾帧；不要求每段填满工作流的全部图片槽。
- 对已核实的 MiniMax H3 多图应用，自动更新 `827.value`（“使用几张图”），未使用槽位使用该应用声明的 `None`，避免空图进入 `BatchImagesNode`。
- 保持图片物理槽位和顺序，不复制图片凑数；已核实应用遇到中间留空会在提交前提示连续选择，避免静默重排。
- 工作流设置页可选择、关闭或手动绑定图片数量字段；普通工作流仍按自身云端协议处理，不擅自猜测空值。
- RunningHub 错误详情显示 `node_name`，例如 `858 / BatchImagesNode`。
- 旧任务的已提交快照和请求指纹保持兼容，不自动重新提交收费任务。

## 版本与交付

从 `1.3.3` 升级到 `1.3.4`，符合小版本位和补丁位均为 `0–9` 的十进位规则。已交付的历史版本不覆盖、不删除。

构建命令：`npm run pack:win`。

交付命令：`npm run deliver:1.3.4`。
