# 莲华视频导演台 3.9.4 发布说明

发布日期：2026-11-07（亚洲/上海）。

## RH 网页时长沿用页面上的数字

网页应用里的时长绑到导演台时长后，导演台这一格留空表示沿用网页上已经读到的数字。页面读回来的 30 以前按文本保存，批量生成会报「时长(秒) 需要数字」。现在按数字使用。百万像素同样处理。

已保存的提示词和成片不改写。

## 版本定位与交付

Windows x64 便携包：`莲华视频导演台-3.9.4-便携版.exe`。构建命令为 `npm run pack:win`，交付命令为 `npm run deliver:3.9.4`；3.9.3 及更早历史版本文件保留。

## 验证

- 留空时长沿用网页数字：`npx tsx scripts/runningHubWeb.test.ts`
- Windows x64 便携包：`npm run pack:win`
- 交付文件：`npm run deliver:3.9.4`

已有项目、提示词和成片不作改写。
