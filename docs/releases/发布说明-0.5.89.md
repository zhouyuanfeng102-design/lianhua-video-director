# 莲华视频导演台 0.5.89 发布说明

## 版本定位

本版包含资产库入口简化、图像响应格式误识别修复和错误中文显示，目标便携包为 `莲华视频导演台-0.5.89-便携版.exe`。构建并完成验证后，使用 `npm run deliver:0.5.89` 生成版本化交付与 SHA-256 清单。

## 本轮调整

- 取消资产库首页中转和“首页”页签。
- 从侧栏进入资产库，以及切换项目后，默认直接显示图片资产库。
- 保留图片、视频和音频资产入口，及原有选择、上传、关联视频等操作。
- 修复图像响应为裸 Base64，或 MIME 误标为 PNG 时，真实 JPEG/WebP 被当成 PNG 检查而遭拒的问题。根据实际字节识别 PNG/JPEG/WebP，保存原始字节、不转码，不改变图片尺寸、种子或生成参数。
- 错误响应体、非图像及签名无效的数据仍拒绝，不因格式兼容而把错误内容保存成图片。
- 错误默认中文显示，准确翻译截图中的“上游服务未返回预期图像”“生成的图像被安全策略拦截”，并处理 Electron 英文包装和常见网络、认证、限流、超时等错误；未知错误给出诚实中文概述，不猜测具体原因。

中文错误仅做本地显示转换，不调用翻译 API；原始 `task.error` 和日志继续保留用于排查。已有失败记录可直接中文显示，无需重新发起生成；不修改提示词、不自动重试，也不规避服务商安全拦截。

本轮不删除、移动或改写已有素材，不自动提交新生成，也不自动重跑已有失败或排队任务。

## 保持不变

生成算法、原模型、API 请求参数、无应用超时、种子及采样参数策略不变；图片响应只修正格式识别，不转码或重新生图。schema 22、时间轴规则 1.2.0、通用转换器 1.3.0、两个 AI 剧情按钮、左栏自适应和既有剧情与数据规则继续保留。

旧项目、资产、提示词和任务记录保留；现有 0.5.88 交付不变。本轮不会自动再次删除旧包，也不恢复此前已清理的文件。

## 使用方式

完成交付后，保存工作并关闭旧版，通过 `交付\启动莲华视频导演台-0.5.89-便携版.bat` 打开新版。点击侧栏“资产库”直接进入图片库；视频和音频仍在资产库内切换，无需经过首页卡片。

已有生成失败记录打开后按新规则显示中文说明，不需要重新生成才能看到中文错误。
