# 莲华视频导演台 3.3.8 发布说明

发布日期：2026-10-27（亚洲/上海）。

## 设置文件储存位置

顶部齿轮“设置”增加“文件储存位置”页签。可查看当前目录、选择文件夹或恢复默认；API 设置页面不承担位置管理。

- 选择新位置后，重启时迁移项目、素材、恢复点和本地记录。
- 原目录保留；目标位置已有莲华数据时，先将其另存为备份。
- 迁移目标不能与当前目录互相包含，也不会覆盖无关文件夹。
- 迁移中断后以仍在使用的源目录重新建立暂存，避免恢复已删除文件；无法确认归属的暂存目录不会被覆盖。
- 由 `LIANHUA_DATA_DIR` 启动参数固定位置时，界面显示固定状态且不能更改。

## 版本定位

本版聚焦桌面端设置入口和本地文件位置管理，不新增 API 设置分类，也不改变已有 API 连接配置。

## 版本与交付

本版 Windows 便携包为 `莲华视频导演台-3.3.8-便携版.exe`。构建命令为 `npm run pack:win`；将交付文件生成到项目内 `交付` 目录的命令为 `npm run deliver:3.3.8`。3.3.7 及更早交付文件继续保留。

交付目录同时生成恢复源码、启动器、更新说明和 SHA-256 清单；清单用于核对便携包与其它交付文件的完整性。
