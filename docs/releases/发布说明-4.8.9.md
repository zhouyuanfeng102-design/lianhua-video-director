# 莲华视频导演台 4.8.9 发布说明

发布日期为 2026-11-20（亚洲/上海）。

同一个姓名在这一镜只有一个身体。后面的走路、到达、挥手、近景和参考图都改这一个身体。参考图只提供这一个身体的脸和衣服。两种状态写成较后的那一种：人已经在近景里，步子就落在这一个身体的脚上；路程已经走完，远处不再有一个还在走的人。

已保存的成片和提示词不改写。重新生成本段提示词后再提交视频。

Windows x64 使用 `lianhua-video-director-4.8.9-windows-x64-portable.exe`。Android 使用 `lianhua-video-director-4.8.9-android.apk`，最低 Android 8.0（API 26）。

同版提供 Windows 与 Android 软件包、源码恢复包、安装说明、能力与验证记录、Windows 启动器及本说明。

签名与验证范围见 [4.8.9 能力与验证记录](能力与验证记录-4.8.9.md)。安卓安装与备份见 [安卓安装说明](../android-install.md)。
