# 莲华视频导演台 0.5.114 发布说明

发布日期：2026-09-12。

## 版本定位

本版修复长剧情一键批量生成视频的初始化断点竞态。批量任务壳写入项目后，自动状态协调可能在每项安全 `ready` 准备记录落盘前抢先执行恢复逻辑，将正常任务误判为“本地跟踪已停止”，从而整批停在尚未提交状态。本版保留 0.5.113 及更早的版本化交付、正式项目数据和历史任务。

## 批量视频修复

- 批量初始化期间不会让自动 `reconcile` 抢先恢复尚未完成安全准备的任务；每项先完成独立准备记录，再进入按段提交队列。
- 失败只影响对应批量项，已提交或提交结果待确认的任务继续按原快照追踪；不会因准备记录竞态重复 POST 或重复扣费。
- 任务页继续按批次汇总待提交、运行、成功、失败和已停止数量；停止批次时只停止尚未提交项。
- 保留每段中文/英文互斥选择、独立参考图、跨项目写回、重复请求保护和重启恢复逻辑。

## 数据与兼容性

- schema 保持 **23**，不新增破坏性迁移。
- 不自动重跑历史失败任务，不改写既有项目、资产、提示词、视频结果或日志。
- 保留 0.5.113 的图像接口内容安全拒绝诊断、正向视觉规则及历史交付文件。

## 构建与交付入口

本版交付产物包括 `莲华视频导演台-0.5.114-便携版.exe`、恢复源码、更新说明、版本专属启动脚本和 SHA-256 清单。

```powershell
npm run test:typecheck
npm run test:video-generation
npm run test:video-batch
npm run build
npm run pack:win
npm run deliver:0.5.114
```

正式交付文件以 `交付\莲华视频导演台-0.5.114-SHA256.txt` 中的 SHA-256 为准。自动化测试应使用隔离数据和 mock 接口；未实际连接的收费视频 API 或 ComfyUI 不在本说明中宣称已验收。

请先保存工作并完全关闭旧版，再启动 `交付\启动莲华视频导演台-0.5.114-便携版.bat`。旧版 0.5.113 及更早交付不会被自动删除或覆盖。
