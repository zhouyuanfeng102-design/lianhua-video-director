# 莲华视频导演台 3.8.3 发布说明

发布日期：2026-11-06（亚洲/上海）。

## 导演调度不再把缓慢写成整段慢动作

新生成的 MiniMax H3 正文里，导演调度只保留跟随、固定、推近这类镜头组织。开头不再写缓慢、慢慢、慢动作或 slow motion，避免整段被做成慢动作。

风格确实要求镜头慢时，只在对应的那一个运镜句写成运镜类型、幅度和 at slow speed。正常速度不写速度词。身体动作里已经写成的缓慢起伏保持原句。已保存的提示词和成片不自动改写，重新生成该段后才使用新写法。

## 版本定位与交付

Windows x64 便携包：`莲华视频导演台-3.8.3-便携版.exe`。构建命令为 `npm run pack:win`，交付命令为 `npm run deliver:3.8.3`；3.8.2 及更早历史版本文件保留。

## 验证

- Windows x64 便携包：`npm run pack:win`
- 交付文件：`npm run deliver:3.8.3`

已有项目、提示词和成片不作改写。
