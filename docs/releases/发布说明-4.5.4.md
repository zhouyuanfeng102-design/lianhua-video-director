发布日期：2026-11-11（亚洲/上海）。

## 本段用途增加私密部位

视频导演台选图的「本段用途」增加「私密部位」。选中图像工作台的私密资料图时，这一槽默认就是这个用途。人物参考、场景参考、首帧和尾帧的默认规则不变，私密图仍然不会自动进人物槽。

这张图沿用已有的人物身份。参考说明写成：这张图是该人物的这一部位，提供形状、颜色和纹理；这个人仍用人物参考。正文已经呈现这个部位时，形状、颜色和纹理沿用这张图；这一镜的衣着和遮挡仍按该镜原文。四合一资料板只取正文已经写到的那一格，分格版式留在资料里。

点「使用本段图片」后，沿用现有的参考说明更新，不另调模型，不改动作、对白和镜头时间。已保存的提示词和成片保持原样，直到这次参考说明更新。

## 交付

- Windows：`莲华视频导演台-4.5.4-便携版.exe`。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.5.4`。选图用途两端共用，EXE 与 APK 一起交付。
