# 莲华视频导演台 1.0.7 发布说明

日期：2026-10-01。

## 版本定位

本版将“本地末帧＋人物参考图”放开为“本地末帧＋自由参考图”：人物图仅为默认选项，用户可改选场景或其它参考图，不按分类阻拦生成。

## 本地末帧＋自由参考图

- 未手动选图时，末帧后的槽位默认选择本段普通人物参考图；默认不自动加入私密资料、道具或历史截图。
- 手动选择的场景、人物或其它可用图片均保留，可使用“本地末帧＋场景图＋人物图”或“本地末帧＋其它参考图”；也可清空辅助图，只保留末帧。
- 第1槽放准确上一段视频的真实本地末帧，第2槽起保留本段选图及用途。换图或取消图片不重排其它已选槽，不自动补回已取消的人物；包括先手动选图再开启组合。
- 单段与一键批量一致，批量按钮明确为“一键末帧＋参考图”。槽位用途保留在独立栏目，图片分类或用途不匹配只提示，不阻止生成。

## 引用、提交与边界

- 修复末帧插入后，混合用途在选图徽章、用途栏、预览、预检、任务指纹和最终冻结快照中的偏移不一致。
- H3仅同步必要的图片引用编号和绑定，保留结构及剧情、对白、镜头和声音正文；不调用文本或视觉AI重新生成提示词，不增加独立AI审核。
- 旧场景图的替图只有在明确属于同一场景资产且对应唯一时才绑定；不按名字或图片类型猜测。可靠原清单中已取消且没有可信替图的引用只移除图片绑定，保留角色、场景与剧情正文并显示提示。
- 文件缺失、真实接口容量不足、多个槽重复绑定同一输入、接口实际不支持多图等技术问题仍明确报错，不会悄悄丢图。普通参考接口无法保证视频严格从末帧起步，实际约束取决于所用工作流。
- 生图与NSFW规则、已保存历史成果及正式项目数据不因打包自动重写或重新生成。

## 使用与版本

便携包：`莲华视频导演台-1.0.7-便携版.exe`。交付命令为 `npm run deliver:1.0.7`，同时生成恢复源码、更新说明、专属启动器与SHA-256清单。

版本从1.0.6按十进位更新为1.0.7，下一版为1.0.8。请保存并关闭旧版后再启动新版；保存失败时先导出项目备份。历史版本文件与用户数据保留，不覆盖、删除或重编号。
