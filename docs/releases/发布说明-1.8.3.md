# 莲华视频导演台 1.8.3 发布说明

2026-10-11

本版整理“API 设置”中的图片 API 布局，把连接配置与模型规格明确分组，修复字段错位和控件被说明文字拉伸的问题。

## 连接与模型分组

图片 API 使用左右两组：左侧为连接配置，集中后端、API 地址与密钥；右侧为模型与生图规格，集中模型、协议、分辨率规格和原生生图档位。说明文字跟随所属字段换行，地址与原生档位不再被自动排到同一行。

字段顶部对齐，输入框和下拉框按统一高度显示，避免相邻字段的长说明将控件拉高或使标签上下错位。启用图像生成接口开关放到卡片标题旁，配置切换、保存、删除、快速填充和获取模型等入口继续保留。

## 现有配置与生成行为

已有后端、服务地址、密钥、模型、协议、分辨率规格、原生档位及 ComfyUI 工作流继续使用原设置。此次调整只整理页面结构与样式，设置保存、协议自动识别、图像请求和任务执行沿用现有行为。

原项目、历史提示词、资产和生成任务继续保留。打开新版后可直接使用已有配置，无需为此次布局调整重新生成内容。

## 验证与交付

打包流程中的 TypeScript 检查与 Vite 生产构建通过。直接使用 1.8.3 便携 EXE，在隔离数据目录中完成一次图片 API 页面检查：1120×720、1280×800、1920×1080 下，OpenAI 兼容表单完整可见，输入框与下拉框统一为 32px，分组与字段没有重叠或横向溢出，原生档位与“恢复模型默认”按钮对齐。

1120×720 下检查了 Stable Diffusion WebUI、NovelAI 与 ComfyUI 的主要设置入口；ComfyUI 较长内容可以在表单内部滚动查看。成品正常启动，检查期间没有页面初始化或控制台错误，也没有外部请求。未运行全量回归，未调用真实生图接口；本次检查仅覆盖布局与设置入口。

本版按十进位从 1.8.2 升级至 1.8.3，便携包名为 `莲华视频导演台-1.8.3-便携版.exe`，交付命令为 `npm run deliver:1.8.3`。1.8.2 及更早发布说明、交付文件与交付入口继续保留。
