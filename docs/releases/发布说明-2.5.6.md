# 莲华视频导演台 2.5.6

发布日期：2026-10-17。

## 动作与对白共享明确身份来源

现有源生成同时保存动作实施者、动作对象、说话人、听者和被称呼对象与已有角色 ID 的对应关系。动作实施者独立于说话人，台词里的“师父”“师姐”等称呼只表示被称呼对象；缺少明确来源的角色 ID 保持未填，不按称呼、邻近姓名或说话人反推动作归属。

H3 中文与英文沿用这份身份和事件资料。英文仍从已确认的中文来源文档翻译描述片段，中文原名与原始对白保持原字，动作、对象及发话归属随描述一起保留。既定镜头、切点、时间与排程保留；没有增加独立身份审核、文本 AI 调用或自动重试。

## H3 多参提交连接 Subject、Picture 与当前段声源

多参 H3 从同一份明确身份资料编译人物定义与正文提及，将人物连接到本次实际上传顺序对应的 Picture。Subject 表示视觉主体，Picture 表示实际参考图片，S 表示当前视频中的发声来源，三者分别对应，不能用图片槽号代替说话人身份。

已明确归属的声源按当前段首次实际发声顺序编排 S，同一段跨镜沿用；跨段人物身份继续依靠角色 ID 和中文原名保留。没有音频参考时，跨段使用相同 S 不能保证同一声线。选图、换图及参考用途更新使用本地确定性编译，不为此重新请求文本模型。已保存的来源正文及其身份元数据继续配对保留。

## 本段参考用途与同批首尾帧

从一个分段切换到另一个分段时，清理旧段首尾用途，并用当前段首尾图填入同一物理槽，共用的人物和场景参考保留。同段切换中英文保留手工首帧覆盖；明确换首帧替换旧首帧，不叠加两份首帧。当前段默认首图更新时替换旧自动图，不清掉手选覆盖。批量原有的各段选择覆盖继续保留。

构图、首尾状态与人物外观按各自用途提供参考；人物图用于身份和外观，不代替本段既定动作、站位、持物与摄影。

自然语言分镜图在转换完成后统一写入实际上传图号、角色 ID、中文原名与各自外观对应。有明确当前定格原句时保留该原句；缺少独立定格依据时不追加站位，不从全镜后续动作、上一段或下一段推算当前位置，也不把人物自身左右换算为屏幕左右。标签格式继续使用原格式。

首尾帧采用同批依赖：首图成功保存后，尾图携带这张新首图继续生成，只借用外观材质、光线和环境连续性。人物身份仍以各自角色图为准，尾图不继承首图的机位、站位、动作或持物。首图失败或取消时，尾图结束等待且不提交，不自动重试；单独生成尾图不额外生成首图。尾图实际参考与用途随任务、结果资产及恢复资料保存。尾图携带额外图片参考可能增加上游图片输入费用或处理时间，具体费用和可用参考图数量以所选模型或工作流为准。

## 升级与历史内容

本版修复提示词、身份资料与参考输入的衔接。已经生成的图片和视频像素不会因升级自动改变，也不能据此承诺真实模型从此不再出现错人、错位或错声。旧图仍含错误站位或持物时，需要由用户主动更新相关图片后再使用；升级不会自动触发收费生成。

旧项目中未填写的可选身份和事件字段继续保持未填，历史任务使用原提示词、参考图及参数快照。已有镜头与排程、保存的中英文稿、素材和 2.5.5 及更早版本交付文件保留，不自动重生成或覆盖历史结果。

## 验证与交付

已通过与本次改动相关的开发检查：

- 身份事件与中文来源翻译、动作实施者和对象独立于说话人、H3 多参编译及实际声源音频对应。
- 跨段首尾图选择、同段手选覆盖、中英文切换、历史任务提交边界及批量选择。
- 最终图片身份与当前定格来源、首尾依赖、取消和失败处理、单尾生成、实际参考快照及恢复；原有分镜图片生成绑定检查通过。
- 本地使用第 2、3 段真实中文稿编译检查，分别保留 8 句和 11 句原始对白，镜头数量、切点及动作时间保持；未调用真实图片、视频或文本生成 API。

打包流程内的 TypeScript 检查、Vite 生产构建和 Windows x64 便携版封装已通过。生产构建在独立浏览器上下文完成启动、版本号及“提示词导演台”“视频导演台”页面检查，无页面运行异常；未连接用户实际项目，也未请求外部生成服务。构建仍提示现有手工分包的循环依赖及部分文件体积偏大，本次启动检查通过。

本版交付命令为 `npm run deliver:2.5.6`，便携包名为 `莲华视频导演台-2.5.6-便携版.exe`；同时提供恢复源码、更新说明、启动器及 SHA256 文件。
