# 莲华视频导演台 0.5.30

## 版本定位

- 0.5.30 是基于 0.5.29 的全片总提示词异步生成修复版。
- 保留 0.5.29 的长剧情布局修复、生成链路、图片任务、AI 补齐和 Electron 安全能力，继续兼容旧项目数据。

## 全片总提示词生成

- 修复启用文本 API 后生成“全片总提示词”可能在第一次异步响应后停止、无法进入审阅区的问题。
- 相同名称和正文再次保存时不再刷新原文或项目时间戳，避免有效请求在模型异步等待期间被误判为过期。
- 剧情名称或正文实际变化时仍保留原有更新与派生数据失效规则，不会放宽跨项目、改参和取消请求的保护。
- 有效的全片时间轴生成异常会保留原始错误原因，不再被笼统的剧情、时长或导演设置提示覆盖；真实过期请求继续静默丢弃。

## 回归验证

- 新增隔离 Playwright 场景，通过延迟 OpenAI-compatible 文本 API 响应稳定覆盖 React 状态提交与异步等待顺序。
- 回归检查确认模型请求等待期间原文内容、原文时间戳和项目时间戳保持不变。
- 验证 24 秒全片总提示词能够显示审阅区、正文非空并从 0 秒开始，同时完整长剧情三阶段流程保持可用。
- 完整测试、生产构建、桌面 QA、长剧情 UI 和真实便携包烟测纳入本次发布验收。

- Windows x64 便携版 EXE。
- 恢复源码 ZIP。
- 更新说明、版本启动器、无版本启动器与 SHA-256 完整性清单。
- 0.5.29 及更早历史交付文件保持不变。
