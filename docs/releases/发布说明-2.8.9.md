# 莲华视频导演台 2.8.9 发布说明

发布日期：2026-10-21（亚洲上海）。

## 本次修复

修复 2.8.8 启动白屏。新增的 `storySceneParticipationRules.ts` 未加入既有独立规则分块，落入 `domain`，而 `novel-action-rules` 在初始化常量时读取它，形成跨代码块循环依赖。界面挂载前抛出 `Cannot access 'n' before initialization`，因此普通类型检查和编译可以通过，软件启动仍会白屏。

本次把该模块与读取它的规则目录放在同一独立代码块，直接消除这条初始化循环。保留 2.8.8 的群体人物、时间转场、实际视频规格及参考关联修复；未修改用户项目与素材，没有新增按钮、运行时校验、审核、拦截、重试或模型请求。

## 定向检查

用户现有渲染日志与 2.8.8 生产构建的隔离启动检查均复现上述同一异常。本次检查范围为生产构建和实际便携 EXE 的启动及视频导演台页面打开，不重跑无关功能回归。

- `packagedStartupSmoke.mjs` 对新便携 EXE 的隔离启动检查通过：版本显示 `v2.8.9`，主界面与视频导演台可见，页面错误、运行时异常及渲染错误均为空，正常退出。已查看视频导演台截图确认界面显示。
