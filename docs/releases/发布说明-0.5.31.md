# 莲华视频导演台 0.5.31

## 版本定位

- 0.5.31 是基于 0.5.30 的全片总提示词切段语义误判修复版。
- 保留 0.5.30 的异步生成修复、长剧情布局、生成链路、图片任务、AI 补齐和 Electron 安全能力，继续兼容旧项目数据。

## 按总提示词切段

- 修复全片总提示词已经确认后，按总提示词切段仍可能误报“相邻总镜头语义重复”的问题。
- 当动作链把真实目标拆到紧邻箭头片段，例如“涌向了→母巢→…”，语义规范化现在会恢复“母巢”目标，不再把缺少目标错误地当成可匹配任意目标。
- “涌向墙壁里的人”和“涌向母巢”会保留为两个不同剧情事件；系统不会要求用户手工删除或改写有效镜头。
- 恢复仅作用于没有新动作动词的短目标片段，“继续推进”“身体重心微移”“动作结果自然停住”等通用动作阶段不会被拼成目标。
- 真正同动作、同目标的相邻镜头仍会按原规则拦截，重复检测没有被关闭。

## 回归验证

- 新增动作级回归，覆盖箭头拆分目标、不同目标不重复、同一目标拆分前后仍等价及既有同义动作去重。
- 新增完整分段计划回归，确认不同目标的相邻镜头不会触发段内语义重复。
- 使用现有 122 秒、40 镜项目数据只读重放本地切段：生成 9 段、40 镜全部归属，第 23/24 镜同时保留在第 6 段，最终校验为 0 个错误。
- 完整测试、生产构建、桌面 QA、长剧情 UI 和真实便携包烟测纳入本次发布验收。
