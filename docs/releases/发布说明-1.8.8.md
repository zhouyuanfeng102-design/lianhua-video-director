# 莲华视频导演台 1.8.8 发布说明

2026-10-11

图片 ComfyUI 设置现在支持直接导入画布 JSON，自动转换为可提交的 API 工作流，修复 Lazy 合并工作台的参考图和提示词识别。

## 版本定位

本版集中处理图片 ComfyUI 工作流导入与参考图兼容，不涉及项目存储格式迁移。

## 导入与参考图

进入“API 设置 → 图片 API → ComfyUI”，使用“导入 JSON（画布 / API）”选择工作流。画布导入成功后提示已转换，并显示可用参考图节点数。管理框也可直接粘贴画布或 API JSON，生成前按相同规则解析。

转换保留有效节点、模型、LoRA、采样参数、Seed 和连线，排除关闭节点、说明和前端开关，处理可确定的旁路。优先使用画布保存的命名参数及输入定义；无法可靠映射的特殊节点、动态组件或旁路会明确指出问题节点，并提示从 ComfyUI 导出 API 格式，不猜测字段含义。

Lazy 合并工作流中的 LoadImage → LazyMergeWorkbench → LazyMergeGenerate → SaveImage 现在可识别为有效参考图链。本次真实上传的参考图按槽位顺序注入，关闭的图片槽不会进入执行图。关联的完整提示词节点和工作台备用提示词均更新为当前请求，避免沿用旧任务内容。

工作流原有尺寸控制继续保留；仅支持原有可确认的画布或显式尺寸占位符覆盖，不自动修改 Lazy 自定义画布开关。使用关闭的参考槽或特殊节点时，实际可用数量以导入结果为准；所需模型与自定义节点仍须安装在执行工作流的 ComfyUI 中。

## 验证与交付

画布转换、原有 ComfyUI 导入与参考图检查、设置入口和请求链检查通过。覆盖静音、旁路、前端控件排除、可靠字段映射、当前提示词注入及三张真实参考图片上传后的槽位绑定；所有网络请求均为模拟，没有执行真实生图。

用户提供的画布实际完成导入、构建及三参考图绑定验证：23 个画布节点转换为 14 个 API 节点，保留 3 张参考图、排除 5 张静音参考图，旧提示词被当前测试词替换，原始文件未修改。摘要位于 `output/comfyui-canvas-1.8.8/validation.json`。

`npm run pack:win -- --config.directories.output=release-1.8.8-build` 中的 TypeScript、生产构建和 Windows 64 位便携包生成均通过，未在打包前重复执行类型或构建检查。构建仍显示既有的分块循环与体积提醒，本轮没有改动模块分块。版本元数据和更新说明的交付检查通过；未追加全量回归或真实模型请求。

本版从 1.8.7 按十进位升级至 1.8.8，旧发布说明、便携包与恢复源码继续保留。交付包含 `莲华视频导演台-1.8.8-便携版.exe`、恢复源码、更新说明及 SHA-256 校验，使用 `npm run deliver:1.8.8` 生成。
