# 莲华视频导演台 1.3.5 发布说明

版本日期：2026-10-05（亚洲上海）。

本版修正 1.3.4 在 RunningHub MiniMax H3 多图应用中的空槽提交值。上一个任务快照虽然已把 `827.value` 写成实际数量 5，但第 6 个图片槽仍发送了 `None`，导致 `858 / BatchImagesNode` 报 `NoneType.shape`。

## 本版变化

- 对应用 `2104753059472990209` 的 6 个图片槽，未选中的槽按官方 API 示例恢复为 `example.png`，保留全部图片节点；`827.value` 继续填写本段实际图片数。
- 重试旧的 1.3.4 失败任务时，只在本次提交请求的副本中把旧的 `None` / 空值迁移为 `example.png`，不改写历史任务快照。
- 普通 RunningHub 工作流仍使用各自声明的空值规则，不套用 MiniMax H3 的占位值。
