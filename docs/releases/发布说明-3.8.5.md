# 莲华视频导演台 3.8.5 发布说明

发布日期：2026-11-06（亚洲/上海）。

## RH 网页登录区改成一行

RH 网页的登录位和「登录」「刷新」「删除」排在同一行，下拉框占满左侧。新登录位的名字、站点和「添加」排在下一行。账号状态只留一行：名字、站点、是否已登录、RH 币。原先叠在登录区和应用库下面的说明收掉。删除仍要再点一次「确认删除」，网站账号、网页应用和成片保留。

## 版本定位与交付

Windows x64 便携包：`莲华视频导演台-3.8.5-便携版.exe`。构建命令为 `npm run pack:win`，交付命令为 `npm run deliver:3.8.5`；3.8.4 及更早历史版本文件保留。

## 验证

- Windows x64 便携包：`npm run pack:win`
- 交付文件：`npm run deliver:3.8.5`

已有项目、提示词和成片不作改写。
