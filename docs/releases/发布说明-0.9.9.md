# 莲华视频导演台 0.9.9 发布说明

版本日期：2026-09-30

## 版本定位

V0.9.9整理提示词导演台的参考图入口，去掉重复快捷按钮，保留原来的选图和图生图工作流。

## 本版修复

- 删除提示词导演台上方“分镜参考图 / 选择参考图”重复入口，只保留右侧“参考图”页签，统一选择和查看当前段图片。
- 导演模式行改为单列铺满，不留下半栏空白；右侧页签继续显示已选图片数量。
- 选图、取消、清空、上传、各段独立参考图及图生图参数保持原流程。首尾帧、默认分镜和自定义数量图片仍通过“提示词结果”底部原按钮生成。
- 不改已生成的H3提示词、AI适配和自定义总时长、普通/私密生图及NSFW规则，不新增AI审核或本地剧情门禁。

## 使用

在提示词导演台右侧点击“参考图”，选择本段所需图片；返回“提示词结果”，使用下方原来的生图按钮即可。
