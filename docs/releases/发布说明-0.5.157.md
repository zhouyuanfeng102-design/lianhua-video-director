# 莲华视频导演台 0.5.157 发布说明

发布日期：2026-09-25

## 版本定位

修复旧ComfyUI任务占满名额、阻止新的RunningHub批次开始的问题。执行数量按任务的真实冻结连接分别计算，并显示具体占位任务；私密生图增加已保存API配置快捷选择。

## 私密生图API快选

- 在私密生图右侧直接选择“生图 API 配置”，默认跟随API设置，也可选择已保存的配置名称、后端和模型。私密通道的选择单独保存，不修改普通生图默认或已保存配置内容。
- 启用状态、尺寸策略、参考图能力和实际生成使用所选配置；沿用已有规则选择逻辑，手选和自定义规则不被强制替换，私密内容规则不改。
- 已排队的任务保持创建时配置，不因后来更换下拉选择而改用新API。新私密任务重试核对原配置和执行参数，保留原模型，仅从同一配置取得当前凭据；删除、停用、地址或执行参数不兼容时明确提示，不自动改投其它服务。
- 历史任务仅保存配置定位与安全指纹，不复制密钥、完整地址、请求体或工作流正文；无快照的旧任务保留既有兼容路径，不批量改写或自动重新生成。

## 视频连接队列

- 已知不同后端或服务地址分开排队，本地ComfyUI未确认记录不再挡住RunningHub新任务。同一个服务地址跨项目、工作流、配置名称和批次仍共享数量，不能通过改名或换工作流多开名额。
- API按规范化服务origin保守共享，不把密钥、路径、查询参数或工作流ID当成新队列；没有稳定账号ID时，同服务不同账号也保守共用。ComfyUI本机地址别名按同一服务处理，RunningHub省略端点时使用真实默认提交地址。
- 恢复检查、内存名额、提交候选、上传后最后检查和占位说明使用一致范围。调低并发不取消已经发出的任务，仍受服务商真实限额约束；尾帧链仍等准确前段完成并保存。
- 排队卡片显示占位任务的项目、名称、状态与尾号，最多列8条及剩余数量；正在准备图片并已锁定名额的任务也显示。内容经过各阻塞任务敏感信息脱敏，不包含请求体、图片、完整提示词或凭据。
- 缺少真实原连接的历史记录继续保守占位并明确标注来源待核实，不猜它属于新配置，不把未知结果伪装为结束。旧任务、日志和资产全部保留，不自动重发已提交或结果未知的任务。

## 保持不变

不改写正式项目、原提示词、背景音乐、图像预设、已生成媒体或已保存API配置内容，不新增本地内容语义审核。首帧自由选图、槽位标签、AI衔接与人物参考组合、批次继续及防重复收费保护保留。没有取消已有远端任务或自动创建新的收费批次。
