# 莲华视频导演台 3.9.6 发布说明

发布日期：2026-11-07（亚洲/上海）。

## RH 网页读出下拉选项

读取网页时，每个下拉框的选项都会读出来，不只留下当前这一项。例如 LLM 模型可以改选其它模型。生成时按选中的项填写到网页。

已经保存过的应用，再点一次「读取网页」就会带上选项。读取仍在后台进行，不弹出窗口。

## 版本定位与交付

这次只改 Windows 桌面里的网页读取。便携包：`莲华视频导演台-3.9.6-便携版.exe`。构建命令为 `npm run pack:win`，交付命令为 `npm run deliver:3.9.6 -- --ui-only=windows`；3.9.5 及更早历史版本文件保留。

## 验证

- Windows x64 便携包：`npm run pack:win`
- 交付文件：`npm run deliver:3.9.6 -- --ui-only=windows`

已有项目、提示词和成片不作改写。
