# 莲华视频导演台 4.4.0 发布说明

发布日期：2026-11-10（亚洲/上海）。

## H3 对白与英文交付

新生成的 H3 中文对白统一使用 `<d>[Chinese] 原话</d>`。用户主动英译时，本次英文结果会规范旧稿语言标签，保持标签内的对白原字；已保存的中文稿不因此改写。

英文 slot 将可译的画面、动作、摄影、声音和人物说明完整译为英文，人物原名、原语言对白及画面上实际出现的文字保持原字。稳定声线描述与每句话的 delivery 分开，减少同一句前后重复的气声、断续和呼吸修饰；剧情明确发生的笑、哭、咳等非语言声音继续保留。

只有本次明确授权安排新时间轴时，才为完整台词及语气留出可用时间，不强制加速把所有词塞进固定窗口。翻译及有限更新仍保留已确认的镜头、时间和任务范围。

## 音乐控制边界

没有明确配乐授权时，H3 的 `non_diegetic_music` 仍写 `N/A`。它表达无非剧情配乐的意图，不是服务端禁乐或关闭音轨的参数。当前使用的 RunningHub 网页应用没有已确认可用的禁乐开关；H3 返回音轨由上游生成控制，本版不能宣称已彻底消除背景音乐。

本次沿用现有生成与翻译请求，没有新增运行时校验、内容拦截、自动重试、按钮或模型请求。已保存的提示词和成片保持原样。

官方写法参考：[MiniMax H3 基础指南](https://huggingface.co/MiniMaxAI/MiniMax-H3/blob/main/docs/VIDEO_PROMPT_WRITING_GUIDE_base_en.md)、[全参考指南](https://huggingface.co/MiniMaxAI/MiniMax-H3/blob/main/docs/VIDEO_PROMPT_WRITING_GUIDE_ref_en.md)。

## 交付

- Windows：`莲华视频导演台-4.4.0-便携版.exe`。
- Android：`莲华视频导演台-4.4.0-安卓版.apk`，最低 Android 8.0 / API 26，沿用仓库外正式签名。
- 同版附更新说明、安卓安装说明、恢复源码 ZIP 和 SHA256 清单。4.3.9 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.4.0`。本次修改共用提示词与对白规则，EXE 与 APK 一起交付。

## 验证

定向测试通过：`h3PerformancePlan.test.ts`、`h3EnglishTranslation.test.ts`、`promptTranslationDocument.test.ts`、`h3PromptProtocol.test.ts`、`singleSegmentPrompt.test.ts`、`promptTranslation.test.ts`、`audioPromptPolicy.test.ts` 和 `h3StagingDelivery.test.ts`（22 个离线场景）。覆盖标签规范化、对白原字与跨镜接续、旧六字段台词写入 H3、slot 单次翻译及确认稿不改写。

`npm run pack:all` 通过 TypeScript 检查、Vite 生产构建、Windows x64 便携包构建及 Android Release APK 构建。APK 使用仓库外既有正式签名，`apksigner` v2 验证通过；签名证书与 4.3.9 相同，可覆盖升级。Vite 报告已有循环 chunk 与大 chunk 提示，不影响本次构建通过。

未进行 RunningHub 在线生成试听或 Android 设备安装验收；上游是否关闭生成音轨仍待服务端能力确认。本版没有运行哈希测试，交付时按既有流程生成 SHA256 清单。
