# 莲华视频导演台 3.1.1 发布说明

发布日期：2026-10-25（亚洲/上海）。

## 第一批阶段去掉原 NSFW Role，只保留 MAESTRO

针对 AI 扩写、画面描述转化子链（`story-visual-*`）和自定义生图规则转换（`image-custom-convert`）：

- 继续前置完整 MAESTRO PROTOCOL v7.0
- **不再叠加**原来的「莲华叙事编辑」NSFW Role / 世界书 / 创作指导前缀

原因：实测部分 Gemini 兼容模型会把该 Role 识别为 persona framing，从而拒写成人扩写或画面理解 JSON；去掉 Role 后，同内容在 argon / 3.1-pro 等模型上更容易正常输出。MAESTRO 的 Intimacy 层与任务正文协议继续约束成人写法。

分镜、剧情解析、H3、Seedance、估时等其它文字阶段本版仍使用原来的 NSFW 固定前缀，不做改动。

## 命中率

第一批阶段的系统前缀仍是固定内容（MAESTRO + 任务规则），普通/成人共用；用户要求仍在最后。不按内容类分叉前缀。

## 版本定位

本版便携包为 `莲华视频导演台-3.1.1-便携版.exe`。交付命令为 `npm run deliver:3.1.1`。3.1.0 及更早交付文件继续保留。
