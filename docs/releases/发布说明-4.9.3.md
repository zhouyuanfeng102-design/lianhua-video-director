# 莲华视频导演台 4.9.3 发布说明

2026 年 11 月 21 日 · Windows x64 便携版与 Android 正式签名版

## 分镜生图参考图包含资产库里的私密图

提示词导演台的「分镜生图参考图」以前只列出普通图片。资产库里已经有的私密资料图不会出现，所以无法点选。

4.9.3 按资产库同一条可读标准列出图片。文件能读到就会出现，私密资料图也可以勾选。缺文件的记录和视频仍然不出现。自动按人物补参考图仍不自己带上私密图，只有在这个列表里点过的图片才会用于本次分镜生图。

## 已有项目如何使用

退出正在使用的旧版，打开本版。进入「提示词导演台」的「分镜生图参考图」，即可看到资产库中能读取的私密资料图。已保存的图片、提示词和成片不会自动改写。

同版提供 Windows 与 Android 软件包、源码恢复包、安装说明、能力与验证记录、Windows 启动器及本说明。

签名与验证范围见 [4.9.3 能力与验证记录](能力与验证记录-4.9.3.md)。安卓安装与备份见 [安卓安装说明](../android-install.md)。
