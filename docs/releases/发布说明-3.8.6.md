# 莲华视频导演台 3.8.6 发布说明

发布日期：2026-11-06（亚洲/上海）。

## RH 网页生成时清掉示例

点生成视频后，RH 网页在后台填写，不弹出浏览器窗口。登录这个账号仍然会打开窗口。

网页应用自带的示例图会在提交前删除。这次选中的参考图再传进对应槽位；没有选用的图片槽和音频槽也会清掉里面的示例。提示词格里的「拍摄时尚杂志，性感姿势」会换成这次填写的短想法。没有短想法时，写入这次的视频提示词。表单还没加载出来时不会点击运行。

## 版本定位与交付

Windows x64 便携包：`莲华视频导演台-3.8.6-便携版.exe`。构建命令为 `npm run pack:win`，交付命令为 `npm run deliver:3.8.6`；3.8.5 及更早历史版本文件保留。

## 验证

- 提示词格替换示例句：`npx tsx scripts/runningHubWeb.test.ts`
- Windows x64 便携包：`npm run pack:win`
- 交付文件：`npm run deliver:3.8.6`

已有项目、提示词和成片不作改写。
