# 莲华视频导演台 3.8.4 发布说明

发布日期：2026-11-06（亚洲/上海）。

## RH 网页登录位可以删除

RH 网页里，当前登录位旁边有「删除这个登录位」。确认后，软件去掉这个登录位，并清掉保存在本机的网页登录。RunningHub 网站上的账号不会被注销。已保存的网页应用、项目和成片保留。登录位删光之后，可以再添加一个并登录。

## 版本定位与交付

Windows x64 便携包：`莲华视频导演台-3.8.4-便携版.exe`。构建命令为 `npm run pack:win`，交付命令为 `npm run deliver:3.8.4`；3.8.3 及更早历史版本文件保留。

## 验证

- 登录位删除与网页应用保留：`npx tsx scripts/runningHubWeb.test.ts`
- Windows x64 便携包：`npm run pack:win`
- 交付文件：`npm run deliver:3.8.4`

已有项目、提示词和成片不作改写。
