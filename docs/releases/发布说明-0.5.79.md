# 莲华视频导演台 0.5.79 发布说明

## 版本定位

- 本轮只调整 `optimize`：从小说润色改为适合剧情解析和后续视频生成的视频化整理，不再把原样小说或仅换词润色当作完成。
- 输出以 `【场景1：场景名/原文已知时间地点】` 这类场景标题组织，后接“出场人物：”“剧情：”“对白：”，必要时单列“背景信息：”。未知时间地点省略，剧情只写原文有依据的动作、对象、先后关系和可见结果。
- 非对白比喻、文学评价和冗余说明转成客观描述；必要背景与画面事实分开，不虚构新画面、新主线、人物或装备细节。原对白、说话人、原语种和顺序保留。
- 剧情接收流程支持场景化文本，已规范的场景稿可以保留有效内容；结果先审阅，确认后再解析，不直接输出 H3、分镜、秒数或镜头参数。
- 默认预设升级为“AI 剧情优化 · 视频化整理与扩写”1.3.0，仅精确升级未编辑旧内置预设，自定义规则、禁用/删除状态和默认选择保留。
- `expand` 扩写补全、对白语言保护、音频规则及其他功能不变；schema 仍为 21，H3 指纹 v4、参考素材、种子和生成参数不变。0.5.78 及更早版本化交付与正式数据保留。

## 使用方式

完成交付后，保存工作并关闭旧版，通过 `交付\启动莲华视频导演台-0.5.79-便携版.bat` 打开新版。在剧情页选择“视频化整理”并执行 AI 剧情优化，审阅场景稿后再确认解析；原有处理前文本还原流程保留。

对应便携包为 `莲华视频导演台-0.5.79-便携版.exe`。构建便携版后执行 `npm run deliver:0.5.79` 生成版本化交付。
