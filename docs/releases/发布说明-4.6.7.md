发布日期：2026-11-15（亚洲/上海）。

## 龟头留在阴道里面

进入时，根留在他的腹股沟。龟头穿过她两腿之间的阴唇，留在阴道里面，指向阴道深处。茎身从他的腹股沟穿过阴道口，连到留在阴道里面的龟头。露在体外的只有腹股沟到阴唇这一截。尿道口朝向阴道里面。

抽送和第一次滑入都停在这一句：进到阴唇贴上他的腹股沟，退时龟头仍留在阴道里面、指向阴道深处，再进到阴唇贴上。从她骨盆前面进入仍只说明靠近方向。

进入或抽送时，一个斜侧面固定中景看见脸、他的腹股沟、她的阴唇，以及露在体外、从腹股沟到阴唇的那一截茎身。含入时看见脸、腹股沟，以及从腹股沟伸到她嘴唇的这段茎身。没有阴茎接触、也没有露出时，才只拍脸、胸口或腰以上。

已保存的成片、分镜、章节和提示词不改写。下次扩写、画面描述转化、重新生成分镜或提交视频时使用这些句子。

## 交付

- Windows：`lianhua-video-director-4.6.7-windows-x64-portable.exe`。
- Android：`lianhua-video-director-4.6.7-android.apk`，最低 Android 8.0 / API 26。
- 4.6.6 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.6.7`。分段、分镜和视频提示词在两端共用，EXE 与 APK 一起交付。
