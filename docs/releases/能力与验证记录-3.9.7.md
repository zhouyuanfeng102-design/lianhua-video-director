## 本版能力范围

手机采用独立单列布局、四项底部主导航、功能菜单和可滚动编辑弹层。Android 原生层接入存档、密钥加密、素材、完整项目包、HTTP/上传/下载/取消、任务检查点、网页操作及原生视频处理。受管媒体仅在显示层映射到本地 HTTPS，持久项目和任务仍使用原有受管地址。保留 3.9.6 的 Windows RH 网页下拉选项读取与填写修复。

Android 最低 API 26，target 36，需要兼容现代网页功能的系统 WebView。rhTV WebView profile/document-start 等能力还有单独系统 WebView 要求。Media3 当前覆盖裁剪、直接拼接、尺寸/帧率和固定音量 BGM；交叉淡化、自动闪避及淡入淡出保留电脑版导出。强杀后本地队列不继续执行，恢复依赖已持久任务号和检查点。运行时 `live_site_verified=false`，不把本地假站场景写成真实网站生成通过。
