# 莲华视频导演台 2.0.4 发布说明

发布日期：2026-10-12

## 分段计划与视频批量

修复编辑区已按新原文生成分段、随后保存同一份原文时，计划被误标失效的问题。读取已有项目时，核对计划的完整原文、章节归属、来源指纹和参考资料，恢复有充分同源证据的计划；真实原文变化或来源证据不足的计划继续保留失效状态。

恢复后保留原有分段顺序、时长、分镜、中文与英文提示词、媒体和任务记录。完成的分段按有效分镜恢复；尚未生成的分段保持待生成。旧场景和缺乏来源证据的分镜不会因计划恢复而被自动解锁。

视频批量页显示已有过期计划并说明更新原因，不再把它们表示为“尚无已分段计划”。计划新增、替换或删除后同步当前选择，并清理已不适用的本轮批量配置；查看计划和切换页面不会提交视频任务。

## 资产编辑与音频导入

资产编辑记录打开时的项目归属。切换项目关闭编辑窗口，保存时再次核对项目和资产，避免撤销项目切换后将草稿保存到另一个项目的同 ID 资产；资产已删除时明确提示未保存。

外部项目导入遇到同名不同内容音频时，任务及成片来源快照中的音频路径和本地地址同步到实际恢复的文件。音频校验值、槽位、用途和原请求记录保留，本机原文件与源备份保持。

## 使用与交付

同源计划恢复专项、现有章节检查及视频批量计划生命周期检查已通过，覆盖不同原文与章节、指纹不符、图片证据变化、已有稿件保持和真正过期计划禁止提交。资产编辑 5 项与音频导入 9 项针对性检查通过；生产打包自带的类型检查与构建通过。验证使用隔离数据和模拟流程，未调用收费 API。

更新前保存项目并退出旧版。将新 EXE 放在原交付目录，保留旁边完整的“莲华视频导演台数据”文件夹，再打开新版。软件会在读取项目时检查同源计划，无需重新导入已有项目。

本版包含资产编辑、音频冲突导入和分段计划恢复修复。版本按十进位从 2.0.3 递增为 2.0.4，历史版本和交付文件保留。

便携包：`莲华视频导演台-2.0.4-便携版.exe`

打包命令：`npm run pack:win`；交付命令：`npm run deliver:2.0.4`。
