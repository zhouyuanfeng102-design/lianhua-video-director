# 莲华视频导演台 0.5.147 发布说明

发布日期：2026-09-23

## 版本定位

本版将完整分镜、长剧情分段和英文提示词的内容校验交给真实文本API执行，取消本轮截图中的本地主体匹配、固定分段切点和单镜15秒规划硬拦截。同时新增图片预览缩放按钮，并压缩长剧情批量顶部设置区。

## 本版变更

- 分镜生成后，独立调用当前配置的同一文本API，携带完整剧情、原始分镜、人物连续性与导演要求，由AI自行校验和修复后返回完整方案。
- AI总镜头跨越15秒或120秒目标切点、单镜超过15秒时，不再被本地规划规则直接否决。全片秒数也不再为了目标段长而自动向上取整。
- AI分段增加独立API复核；保留AI决定的完整镜头分组，不在本地拆镜、删对白、改写衔接文案。真实视频生成服务商或工作流的能力限制没有取消。
- 英文翻译和英文重试先生成候选，再通过同一API对照完整中文复核主体、对白、镜头、时间与遗漏内容。本地不再按主体字符串、占位符词频或时间戳数量否决已复核正文，也不本地替换或还原内容。
- 保留必要的JSON/必需字段读取、镜头ID关联、请求取消、过期结果与跨项目保护。损坏技术结构继续交给API修复，并设置次数上限；网络、鉴权、空回复等失败不会覆盖已有结果。
- 图片资产的“查看原图 / 查看并保存”弹窗增加缩小、放大、比例显示和还原按钮。100%表示适应窗口，范围25%–400%；放大后可滚动查看，保存使用原始图片。
- 视频导演台长剧情批量顶部设置区改为紧凑横排，常用窗口下高度约减半；设置折叠、参数、参考图、重新生成费用提示及底部提交入口保持可用。

## 使用与兼容

1. 先保存项目并完全退出旧版，再启动`莲华视频导演台-0.5.147-便携版.exe`。不要同时运行多个版本写入同一数据目录。
2. 独立AI复核会增加文本API调用、耗时和可能的费用，使用你当前配置的地址、模型和凭据；不会自动发起图像或视频生成任务。
3. 本版不会自动重跑旧任务、修订旧稿或清空旧日志。只有主动再次生成或重试，才会使用新的AI复核流程。
4. 项目数据结构保持schema 23；旧版交付包及正式项目数据保留。目标段长与实际视频接口支持时长仍需区分，AI判断不保证外部模型每次都返回正确结果。
