# 莲华视频导演台 3.4.7 发布说明

发布日期：2026-10-30（亚洲/上海）。

## 云端生图断线后继续查询原任务

RunningHub 接受生图请求并返回任务号之后，软件把任务号写入当前图片任务，再查询这一条。之后如果系统代理上的连接在 TLS 握手阶段被重置，或这次查询没有拿到 HTTP 响应，软件按原间隔继续查询同一个任务号，不重新上传、不重新提交。

云端返回成功、失败、取消，或任务号对不上时，仍按该结果结束。满 20 分钟仍无终态时，超时说明带上这个任务号。提交本身在拿到任务号之前失败，维持不自动再提交。接口明确拒绝的 HTTP 错误也会停止。

重新打开软件时，已经记下任务号、状态仍是生成中的 RunningHub 图片任务不再被改成「请重新生成」。启动后只查询该任务号。查询到图片后保存到资产库；人物、场景和道具会挂回原资料。还没有任务号的中断记录仍按原来的方式标为失败。

不新增按钮、校验或第二次付费提交。已经失败且没有保存任务号的旧记录不能自动接回云端任务。

## 版本定位

本版 Windows 便携包为 `莲华视频导演台-3.4.7-便携版.exe`。构建命令为 `npm run pack:win`，交付命令为 `npm run deliver:3.4.7`；交付同时生成恢复源码、更新说明、专属启动器和 SHA-256 清单，已有版本文件保留。
