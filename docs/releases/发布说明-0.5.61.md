# 莲华视频导演台 0.5.61 发布说明

## 版本定位

0.5.61 针对 MiniMax H3 官方视频格式的声音、动作和篇幅适配进行修复。H3 模式现在始终经过同一条 AI 适配链路，保留剧情因果与逐镜动作，不再用本地拼接或静态模板替代转换结果。0.5.60 及更早功能与历史交付文件保持不变。

## H3 唯一适配链路

- H3 生成会先把已确认的中文时间轴、人物连续性、对白和导演要求交给 H3 官方格式转换器，再生成最终视频提示词。
- 自动压缩只发生在转换器内部：它可以缩短重复的视觉锚点、环境套话和重复声音，但不能删除镜头、对白、动作结果、因果关系或明确时间点。
- 每个 Shot 的起止时间、镜头顺序和动作归属都保持稳定；动作不会被挪到相邻镜头，也不会因压缩而合并成无关的静态描述。

## 声音与配乐

- 没有明确配乐要求时，最终 H3 提示词输出 `non_diegetic_music: N/A`，不凭空添加背景音乐。
- 剧情或用户明确需要配乐时，输出低音量、让位于对白和动作声的非叙事音乐，并保留音乐的情绪、节奏和进入/退出时机。
- 风格预设中的物理环境声和动作声进入 `overall_soundscape`；鼓点、旋律、合成器、管弦、合唱等明确音乐元素进入 `non_diegetic_music`，避免把风声、脚步声误当配乐。
- 拳脚、开门、落地、金属碰撞等动作声留在对应 Shot，并绑定到动作发生的时间点，不能堆在片尾或独立成与画面无关的音效段。

## 动作链与篇幅控制

- 转换规则要求 AI 降低单位时间内的动作数量，每镜集中表现一条可读动作链，而不是把多个动作生硬并列在同一瞬间。
- 人物动作按剧情需要补足蓄力、传力、释放、反作用和收势的发力链；怪兽动作同时保留受力方向、可见位移或形变等结果，避免人物化或僵硬摆拍。
- 超出 H3 软预算时优先压缩长篇外貌与环境锚点、连接词及重复自动声音；逐镜动作、动作时刻、对白、结果和连续性锚点继续保留。

## 分镜图片与交付稿稳定性

- 分镜图片生成结果属于当前分镜的下游输出，不再被误当成 H3 官方交付稿的源参考，因此批量生图完成后不会让交付稿无故显示“已失效”。
- 生图前由文本 AI 自动补齐的人物身份与外貌资料会自动并入仍然有效的官方稿；如果等待期间用户主动修改剧情、人物、场景、道具或全局参考，旧稿仍会按真实变更保持失效，不会被后台任务复活。
- 图片绑定回写保留完整的官方稿字段；只有用户主动把生成图提升为全局参考时，才会按新的源输入触发重新生成。

## 交付

- 便携包：`莲华视频导演台-0.5.61-便携版.exe`
- 交付命令：`npm run deliver:0.5.61`
- 正式交付包含便携 EXE、恢复源码、更新说明、版本启动器和 SHA-256 校验清单。
- 0.5.60 及更早历史交付文件不会被覆盖。
