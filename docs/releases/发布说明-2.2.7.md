# 莲华视频导演台 2.2.7

发布日期：2026-10-15。

## 生成图片后 Seedance 稿继续可用

分镜图片和首尾帧图片生成完成后，软件会把结果自动关联回对应分镜。原先 Seedance 把这些自动关联也视为生成来源变化，导致中文、英文正文仍在，结果区却显示稿件已过期，视频导演台批量生成也找不到可用稿。本版修正这类误判。

只有同一分镜方案生成、作为结果自动关联且未由用户明确设为全局参考的图片，不再计入 Seedance 来源变化。其它参考图片、明确设为全局参考的图片及实际剧情、时长或参考资料变化，继续参与来源判断，需要时仍提示更新稿件。

已有 Seedance 稿兼容原先保存的来源记录，不批量改写正文或存档。视频导演台批量选择参考图继续只同步本次视频的参考说明、图片编号和人物关联，预览与提交使用本次稿，保存的 Seedance 原稿保留。
