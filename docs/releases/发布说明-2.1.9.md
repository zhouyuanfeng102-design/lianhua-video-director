# 莲华视频导演台 2.1.9

发布日期：2026-10-14。

## 通用视频 API 自动补齐与旧配置修复

2.1.8 切换到标准视频服务地址后，可能保留原 MiniMax 连接中的认证和结果字段。高级设置仍显示 `https://api.minimaxi.com/v1/files/retrieve?file_id={id}` 等旧配置，导致结果映射与当前服务协议不一致。

本版在通用视频 API 提供“自动获取并补齐”，从当前输入的 API 地址读取完整模型与可用 OpenAPI 接口说明，补齐提交和查询端点、认证及结果字段。没有可用说明时采用标准兼容配置并显示提示；无法唯一识别的字段仍需在高级设置中确认。已知服务继续使用对应的底层适配，不限定界面只能配置某个网站。

配置补齐时清除不适用的旧文件查询、图片上传、取消端点及请求模板，并精准修正已保存标准连接中的 MiniMax 原厂遗留字段。已选模型和本机保存的密钥保留，模型列表完整显示，由用户自行选择。

自动补齐只应用于当前连接。未选择的其他连接、自定义协议及历史任务的连接快照不重写，已提交任务继续沿用自己的执行快照，不自动重跑生成。已知旧文件查询路径在运行期也会被阻止，避免原任务使用旧服务地址。

协议来源：[老李视频 API 文档](https://video.laoliimage2.win/docs/video-api/)。密钥不写入代码、说明或恢复源码。

## 验证与交付

自动发现模块的多网站、部署前缀、OpenAPI 映射、查询参数、标准回退与取消检查通过；设置组件 27 项行为检查通过。旧字段精准迁移与历史任务恢复检查通过：原任务继续查询自己的地址，保留冻结连接和密钥，不向旧服务发送请求或重复生成。

本轮使用有效密钥实测自动补齐，读取当前网站的 OpenAPI 文档，完整获取 25 项模型，正确填入提交与查询端点并清空旧文件查询地址。没有发起收费生成。

生产构建的类型检查与构建通过，打包检查中已将两个新方法改为项目现有 JavaScript 目标兼容的写法。构建后的界面在 1280×800 和 1120×720 两种窗口尺寸下检查通过，通用按钮、完整模型选择和高级配置补齐正常；此项检查只使用隔离存储与模拟接口。
