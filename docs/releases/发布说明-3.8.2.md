# 莲华视频导演台 3.8.2 发布说明

发布日期：2026-11-06（亚洲/上海）。

## RH 网页管理页可以往下看

「管理网页应用」里的参数比窗口高时，右侧可以在窗口内往下滚动。第三组 LoRA、输出开关和底部说明不再被窗口裁掉。

## 版本定位与交付

Windows x64 便携包：`莲华视频导演台-3.8.2-便携版.exe`。构建命令为 `npm run pack:win`，交付命令为 `npm run deliver:3.8.2`；3.8.1 及更早历史版本文件保留。

## 验证

- Windows x64 便携包：`npm run pack:win`
- 交付文件：`npm run deliver:3.8.2`

已有项目、提示词和成片不作改写。
