# 莲华视频导演台 0.5.26

## 版本定位

- 0.5.26 是基于 0.5.25 的提示词边界与默认要求清理版，不改变现有导演流程和项目操作方式。
- 重点防止内部生成指令进入最终视频提示词，并将“额外要求”完全交还给用户控制。

## 最终视频提示词修复

- NSFW 场景仍会根据原文逐镜生成具体描述，保留身体状态、姿势、接触关系、动作顺序、动作幅度和每步可见结果。
- “NSFW 细节模式”等内部指令只用于指导生成过程，不再作为正文写入最终视频提示词、分镜提示词或目标模型适配稿。
- 保留用户原文中的人物动作和明确要求，不额外加入原文没有的动作，也不使用概括性要求替代实际画面描述。

## 额外要求改为用户自定义

- 视频导演台的“额外要求”现在默认留空，不再自动填入“保持人物身份、服装、关键道具和场景光源连续，不生成字幕、水印或 Logo”。
- 用户手动填写任何额外要求后，内容会按普通项目数据正常保存，不会被后续启动删除。
- 最终视频提示词仅在用户实际填写“额外要求”时才会追加对应内容。

## 旧项目一次性迁移

- schema 9 会对 0.5.25 及更早旧项目执行一次性迁移，清理系统自动加入的固定句子。
- 清理范围包括当前提示词、逐镜提示词、提示词计划、历史版本、英文稿来源和目标模型缓存；用户自己的动作、约束、模型选择和其他项目数据保持不变。
- 有效的全片总提示词确认会升级到清理后的内容；受影响的导演参数确认会要求用户重新确认，避免继续复用旧设置快照。

## 兼容与验证

- 继续兼容 0.5.25 及更早项目；迁移只执行一次，升级后的用户自定义内容不会被重复清理。
- 已通过全量自动化测试、类型检查、生产构建、字段交互验证和缓存迁移回归检查。

## 交付内容

- 0.5.26 交付包含 Windows x64 便携版、恢复源码、更新说明、版本启动器、无版本启动器与 SHA-256 完整性清单。
- 0.5.25 及更早历史交付文件继续保留，发布脚本不会覆盖旧版本。
