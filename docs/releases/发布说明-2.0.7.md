# 莲华视频导演台 2.0.7 发布说明

发布日期：2026-10-13

## 版本定位

本版收紧视频导演台“长剧情批量”中的分段卡片，收起及展开分段设置时的常规高度约缩至原来一半，让同屏显示更多片段。

标题与时长状态放在同一行，格式、语言与音频入口并排，参考图衔接操作单独一行。压缩文字、按钮和间距，字体随可用空间缩小。预览、选择参考图和展开分段设置仍可直接操作；音频详细编辑展开时按内容自然增长。

## 使用与交付

更新前保存项目并退出旧版，将新 EXE 放在原目录，保留完整的“莲华视频导演台数据”文件夹。

针对性卡片前后对比及收起高度复查通过：1430×870、100% 字体下，展开分段设置的卡片由 226.4px 降至 104px，收起卡片由 75.8px 降至 41px，分别为原高度的 45.9% 与 54.1%。三个展开卡片可同时显示，按钮文字无裁切，控件无重叠或越界，右侧预览和底部生成按钮完整可见。

1280×800、130% 字体下，展开卡片同样为 104px，已检查三槽参考音频的入口与详细编辑；音频编辑展开后随内容自然增长，控件仍在卡片内。检查使用隔离合成项目。

打包流程内的类型检查和生产构建通过。本次仅检查相关卡片布局，交付附带 SHA-256 校验清单。

便携包：`莲华视频导演台-2.0.7-便携版.exe`。

打包命令：`npm run pack:win`；交付命令：`npm run deliver:2.0.7`。交付包含便携 EXE、恢复源码 ZIP、更新说明、启动器和 SHA-256 校验清单。2.0.6 及更早历史版本与交付文件保留。
