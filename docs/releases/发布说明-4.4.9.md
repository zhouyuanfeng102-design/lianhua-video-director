# 莲华视频导演台 4.4.9 发布说明

发布日期：2026-11-11（亚洲/上海）。

## 清空当前资料

图像工作台「调用项目实体」一栏，在「新增」左侧增加「清空」。它清空当前选中的人物、场景或物品已经填写的资料，名称仍留在列表里。没有选中实体时，清空正在手写的新资料。关联图片不解除。

## 交付

- Windows：`莲华视频导演台-4.4.9-便携版.exe`。
- Android：`莲华视频导演台-4.4.9-安卓版.apk`，最低 Android 8.0 / API 26。
- 4.4.8 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.4.9`。这个表单两端共用，EXE 与 APK 一起交付。

## 验证

打包流程自带类型检查和前端构建。未在运行中的导演台里点过这个按钮。
