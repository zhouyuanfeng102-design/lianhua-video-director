# 莲华视频导演台 4.6.1 发布说明

发布日期：2026-11-13（亚洲/上海）。

## 成片可以指定封面首帧

视频工作台「输出与声音」增加「封面」。可以上传 PNG、JPEG 或 WebP，从当前项目资产库选一张图，或截取左侧预览的当前画面。导出时把这张图写成 MP4 的第 1 帧。

没有单独封面上传的网站、网盘预览和聊天视频，会把这一帧当作封面。原视频和时间线片段不改。画面淡入从第 2 帧开始，封面保持完整亮度。播放时这一帧只有一帧的时长。

B 站、YouTube 仍要在它们自己的封面入口上传。抖音自动封面经常不是第 1 帧。

## 交付

- Windows：`lianhua-video-director-4.6.1-windows-x64-portable.exe`。
- Android：`lianhua-video-director-4.6.1-android.apk`，最低 Android 8.0 / API 26。
- 4.6.0 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.6.1`。封面设置在两端共用，EXE 与 APK 一起交付。

## 验证

打包流程自带类型检查和前端构建。封面字段的旧稿兼容、缺图和校验失败，以及成片第 1 帧像素，由视频工作台定向测试核对。

本次 GitHub 发布沿用已生成的 EXE 与正式签名 APK，未重新打包、重跑检查或运行哈希测试。版本、签名与检查范围见 [4.6.1 能力与验证记录](能力与验证记录-4.6.1.md)，安装与备份见 [安卓安装说明](../android-install.md)。
