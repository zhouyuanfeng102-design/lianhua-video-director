# 莲华视频导演台 4.2.2 发布说明

发布日期：2026-11-08（亚洲/上海）。

## 没要求配乐就不再配乐

没有明确要求配乐时，`non_diegetic_music` 只写 `N/A`。镜头正文和 `overall_soundscape` 里自行补上的配乐、乐器、旋律不再留下。这次额外要求里写了配乐，或修复时稿里已经有确认的配乐，那一行按原配乐保留。

已保存的提示词和成片保持原样。重新生成这一段后，才会按新写法出声。

## 交付

- Windows：`lianhua-video-director-4.2.2-windows-x64-portable.exe`。
- Android：`lianhua-video-director-4.2.2-android.apk`，最低 Android 8.0 / API 26。
- 4.2.1 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.2.2`。本版是共享提示词写法，EXE 与 APK 一起交付。
