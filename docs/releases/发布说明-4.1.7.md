# 莲华视频导演台 4.1.7 发布说明

发布日期：2026-11-08（亚洲/上海）。

## 角色台词回到自己的声音

角色自己说的话写成 `名字 (S1) says: <d>[中文] 原话</d>`。人在门外、跪着或暂时看不见嘴，仍用 `says:`，画面里其他人的嘴保持闭合。

`says in an off-screen voiceover` 只留给不是角色开口的旁白。紧挨台词的 “lips move with the words” 不再写入正文。

已保存的提示词和成片保持原样。重新生成这一段后，说话才会回到这个人自己的声音。

## 交付

- Windows：`莲华视频导演台-4.1.7-便携版.exe`。
- Android：`莲华视频导演台-4.1.7-安卓版.apk`，最低 Android 8.0 / API 26。
- 4.1.6 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.1.7`。本版是共享提示词写法，EXE 与 APK 一起交付。
