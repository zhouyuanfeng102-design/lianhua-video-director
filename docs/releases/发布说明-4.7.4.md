# 莲华视频导演台 4.7.4 发布说明

发布日期为 2026-11-18（亚洲/上海）。

提交带有人物图、场景图或通用图的视频时，每个已写姓名的人只保留一个身体，并且只站在这一镜正文写的那一个位置。同一人物的多张图、图里的多个角度、未分开标注的设定图只提供外观。场景图、风格图和通用图里已经画着的人只作场面，不在具名人物旁边再复制一个。

已保存的成片、提示词和图片槽不改写。下次提交或更新参考图时使用这次写法。

Windows x64 使用 `莲华视频导演台-4.7.4-便携版.exe`。Android 使用 `莲华视频导演台-4.7.4-安卓版.apk`，最低 Android 8.0（API 26）。同目录提供 SHA-256 清单。
