# 莲华视频导演台 4.5.2 发布说明

发布日期：2026-11-11（亚洲/上海）。

## 头和髋分在背的两头

分镜标题只作动作名。主体仍是原文里的两个人。她的脸朝向一个方向，髋朝向相反方向；头在背的这一头，髋在背的另一头。他的头留在他自己的脖子上，人留在她的背这一侧，胸口和脸对着她的背。舌留在他的嘴里。摄影机站在他身后这一侧，看见他的背和她的背。原文没有写阴蒂特写时，不把镜头放到两腿中间。英文页用同一组句子。

程序仍只排版模型写好的字段，不另补一句。已保存的提示词和成片保持原样。重新生成提示词再出片才会改。

## 交付

- Windows：`莲华视频导演台-4.5.2-便携版.exe`。
- Android：`莲华视频导演台-4.5.2-安卓版.apk`，最低 Android 8.0 / API 26。
- 4.5.1 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.5.2`。提示词规则两端共用，EXE 与 APK 一起交付。
