# 莲华视频导演台 4.0.1 发布说明

发布日期：2026-11-07（亚洲/上海）。

## 没有要求时不写背景音乐

下次生成 H3 提示词时，用户没有明确要求配乐，`non_diegetic_music` 这一行只写 `N/A`。不写成 None、无、silence、no music，也不写乐器、旋律、节拍或柔和、电影感、亲密的配器。

`overall_soundscape` 只写屋里已经发生的声音，例如衣料、吞咽、呼吸。画面风格和导演分类只描述画面。英文稿在中文这一行是 `N/A` 时，原样留下 `N/A`。

用户自己要求的配乐，以及已经写明的动作声，仍然保留。已保存的提示词和成片保持原样，重新生成该段后才会去掉自动铺上的背景音乐。

## 交付

- Windows：`莲华视频导演台-4.0.1-便携版.exe`。
- Android：`莲华视频导演台-4.0.1-安卓版.apk`，最低 Android 8.0 / API 26。
- 4.0.0 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.0.1`。本版是共享提示词规则，EXE 与 APK 一起交付。

## 验证

声音规则检查已通过。打包流程自带类型检查和前端构建。未把已有成片重新生成。
