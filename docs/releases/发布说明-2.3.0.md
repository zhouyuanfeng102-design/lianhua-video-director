# 莲华视频导演台 2.3.0

发布日期：2026-10-15。

## 视频参考图片轻压缩

视频导演台单段和长剧情批量的参考选图弹窗新增逐图“轻压缩”和“压缩已选”操作。压缩只在该弹窗内主动执行，生成供当前段上传的副本，资产库原文件的尺寸和内容保持原样。

轻压缩保持原像素尺寸，不缩图。不透明图片使用质量 0.95 的 JPEG；透明图片使用质量 0.95 的 WebP 并保留 alpha，不支持 WebP 时用 PNG 保留透明度。不会反复自动降低质量，结果体积没有变小时保留原图。

界面显示每张图片和全部已选图片的真实 MiB、减少比例，以及原图和压缩后像素尺寸。可先预览，再明确应用压缩副本；也可恢复原图。压缩不会改变原 `assetId`、人物绑定和槽位用途。

## 保存与任务副本

压缩副本随当前段草稿保存，并包含在项目备份与导出中。实际提交任务的快照保留当时所用副本，重试继续使用该任务的冻结资料，避免后续选图修改改变历史请求。

本地压缩副本的专用读取与保存通道采用 64 MiB 预算，支持该通道预算内超过 32 MiB 的原图处理。

## 兼容与交付

原有选图、人物关联、首帧／中间帧／尾帧用途和模型图片容量读取继续保留。没有批量数据迁移，不自动压缩资产库图片或重跑任务；保留已有项目、原稿和历史交付文件。

版本按十进位规则从 2.2.9 递增至 2.3.0，补丁位进位后小版本加一。2.2.9 及更早历史交付不覆盖、不删除。
