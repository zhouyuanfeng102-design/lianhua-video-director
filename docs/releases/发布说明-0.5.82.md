# 莲华视频导演台 0.5.82 发布说明

## 版本定位

- 原导演栏目保留为“提示词导演台”，新增“视频导演台”：直接选择已保存提示词、当前段中英文稿或手填提示词，并选择图片资产作为参考，不强制重新解析剧情或重新生成提示词。
- 视频后端支持通用 API、MiniMax 与独立 ComfyUI 视频工作流。H3 工作流自动映射相关输入；视频工作流与生图工作流分开保存，互不替换。
- ComfyUI 通过服务端 WebSocket 事件显示真实节点进度和耗时，不用模拟百分比冒充生成进度；切换页面后后台追踪，重启后恢复已有任务状态。
- 每个任务冻结提交时的配置和输入，包含提示词、参考图、工作流与参数。无密钥任务快照与本机凭据库分离，后续修改设置不改变已提交任务，也不把密钥混入冻结快照。
- 上传、生成与下载不设置应用端总等待时限，支持主动取消；真实网络错误和后端失败仍按实际原因显示，无时限不代表忽略失败。
- 图片资产库与视频资产库使用独立入口，旧音频保留在次级入口。成功视频自动下载入库并关联来源；下载失败可以只重试下载，不重新提交生成；同参数再次生成会创建新任务。
- 保留完整原对白、原配置文本 API 合理排时与实际漏句补齐，不新增剧情字数、格式或预估语速门槛。自然动作声、默认无配乐/明确低配乐、去连续底噪、英文对白原语言保护和视频化整理/扩写补全继续保留。
- schema 升级为 22，仅扩展视频设置与任务快照，H3 指纹 v4 不变；旧项目、资产、存稿、自定义/禁用/删除状态及 0.5.81 及更早版本化交付保留，不自动重做旧提示词或旧视频。

## 使用方式

完成交付后，保存工作并关闭旧版，通过 `交付\启动莲华视频导演台-0.5.82-便携版.bat` 打开新版。

在视频设置中选择通用 API、MiniMax 或 ComfyUI 视频后端；使用 ComfyUI 时导入视频 API 工作流并核对 H3 输入映射。在视频导演台选择提示词来源、中文或英文稿及参考图片，核对工作流和实际生成参数后提交。原有提示词编辑与生成继续使用提示词导演台。

视频任务可切换页面后台追踪，完成后自动下载到视频资产库。仅下载失败时使用“只重试下载”，不会重复生成；“同参数再次生成”会新建生成任务，可能产生新的云服务费用。生成只在用户明确提交后启动，费用和额度以服务方为准。

对应便携包为 `莲华视频导演台-0.5.82-便携版.exe`。构建便携版后执行 `npm run deliver:0.5.82` 生成版本化交付。

## 验证与交付

本轮验证范围包括视频配置与 H3 工作流映射、桌面无总时限传输、WebSocket 节点进度、任务冻结与凭据分离、后台/重启恢复、取消、自动入库、仅下载重试、同参数新任务与来源关联；对白和音效行为做必要回归。

已通过视频运行层、视频选择草稿、9 项桌面真实 HTTP/WebSocket 本地夹具测试、旧视频状态映射与存储迁移测试，以及严格源码/测试类型检查。覆盖实际图片输入、H3 参数与音轨连接不变、真实进度、跨项目与重启恢复、未知提交不重投、首次直接成功的文件获取、仅下载重试、取消与连接凭据防篡改。

聚焦 Playwright 浏览器验证通过：图片/视频资产库入口、单段中文和英文描述选择、两张参考图片排序、37% 后端进度、切页后完成、自动入库及视频播放、来源追溯、同参数仅载入、ComfyUI 工作流导入和内嵌密钥拒绝保存。模拟接口记录为 1 次提交、3 次查询、1 次下载；1280 和 900 宽布局通过，900 宽无横向溢出，无浏览器控制台或页面错误。报告位于 `output/playwright/video-director-0.5.82/report.json`。

定向验证命令：`npm run test:video-generation`、`npm run test:video-director-draft`、`npm run test:video-desktop-transport`、`npm run test:video-director-ui`。仅使用隔离合成项目和本地测试服务，没有提交真实云视频/H3 生成，也没有修改正式存档；不能将以上验证描述为实际 GPU 出片或厂商收费接口已实测。

使用边界：远端 API 必须匹配所选协议/字段映射；ComfyUI 使用 API 格式工作流，不自动转换任意画布 JSON。当前可以按 ID 删除 ComfyUI 等待队列任务；运行中无法安全确认定向取消时，只停止本地跟踪并允许恢复查询，不执行会影响其他任务的全局中断。密钥需填写连接密钥字段，不支持在会保存的模板、工作流或参数内硬编码非空密钥。旧任务参数缺失时允许恢复已保存视频，不伪称可按完整旧参数重生成。
