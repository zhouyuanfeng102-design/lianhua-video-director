# 莲华视频导演台 2.7.1 发布说明

发布日期：2026-10-19（亚洲上海）。

## 修复 2.7.0 启动白屏

2.7.0 新增的两个纯规则模块未加入生产构建的分块配置，落入共享业务分块。静帧规则在模块初始化时读取其中的常量，形成循环依赖，导致界面挂载前报 `Cannot access 'vi' before initialization`。已在用户启动日志及隔离的生产页面中复现。

本版将 `novelActionDirection.ts` 和 `novelActionLegacyRequestRules.ts` 放入独立、无运行时依赖的规则分块，直接修正初始化依赖方向。保留 2.7.0 的全部小说动作编排功能；不改变项目数据格式、不清空缓存或项目、不重写历史稿件，不增加运行时校验、生成拦截、自动重试或模型调用。

## 验证与交付

- 使用现有 `productionStartupSmoke.mjs` 对 2.7.0 生产文件复现同一初始化错误。
- 2.7.1 打包内的 TypeScript 检查、Vite 生产构建和 Windows 64 位便携 EXE 生成通过；使用本地 Electron 41.10.7。构建仍有其他既有循环分块与大分块提示。
- `packagedStartupSmoke.mjs` 实际启动 2.7.1 便携 EXE，确认加载包内 `app.asar/dist/index.html`、显示 `v2.7.1`、主界面与侧栏可见、可以进入视频导演台，并保存两张截图。页面异常、运行时异常和独立渲染日志错误均为 0，程序正常退出，退出码为 0。
- 验证使用独立数据目录并确认实际数据路径匹配，不读取或改写用户项目；没有提交生成任务或外部请求。本次只验证启动故障，不运行完整功能回归或收费模型生成。

交付 2.7.1 便携 EXE、恢复源码、更新说明、启动器和 SHA256 清单，保留此前已交付版本。关闭白屏的旧窗口后使用 2.7.1，继续使用原有数据目录。
