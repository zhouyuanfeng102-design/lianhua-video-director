# 莲华视频导演台 0.5.117 发布说明

## 版本定位

视频工作台改为固定单页布局，保留0.5.116本地剪辑、抽帧与长剧情衔接功能；不修改既有素材、剪辑方案或生成任务。

## 单页视频工作台

- 顶部四个标签：剪辑拼接、抽帧衔接、输出声音、处理记录。左侧素材选择和视频预览常驻。
- 素材、剪辑片段、参考帧和处理记录按面板空间自动分页；所有项目均可翻页查看，不再截取最新80帧或10条记录。
- 选择片段后在同页编辑入点、出点、原声音量和转场，保留播放头分割、拖拽排序、跨页上下移动和长剧情装载。
- 底部固定显示消息、进度、取消及导出/抽帧操作。长错误可打开分页详情；错误和完成状态不会撑高页面。
- 历史记录的“查看抽帧”和“预览成片”改为页内切换定位，不滚动跳转。
- 1120×720及更大窗口支持无需页面或面板滚动完成操作；高DPI和大字号另行检查。顺序预览仍只检查顺序和裁剪点，混音/转场效果以导出成片为准。

## 验证与交付

回归包含原工作台数据/真实FFmpeg处理、12项单页结构测试、密集数据分页及窗口/字号/控件命中检查。未使用用户项目或真实收费视频API。
