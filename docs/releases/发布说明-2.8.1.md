# 莲华视频导演台 2.8.1 发布说明

发布日期：2026-10-20（亚洲上海）。

## 本次修复

针对“抢攻低扫、抓袖肩撞与抱腰破解 · 第 2 段”的实际工作流和提交记录，处理参考图错配、动作记录不完整及连续动作排程的问题。

- **H3 参考图顺序**：以 H3 消费节点的真实接线决定 Picture 编号，上传槽位与界面选图不变。完整 API 节点图导入时保存必要接线；当前已确认的旧工作流兼容原有保存配置，无需重新导入。空槽按实际消费情况处理。未知接线沿用已有非阻断提示，不猜测编号。
- **阶段图用途**：3.5、8.5、13.5 秒这类分镜构图图按来源时间及动作阶段描述，不因所在首尾槽位就要求整镜维持开场或结束姿势。真正首尾帧和尾帧接力继续保留原用途。
- **完整正文优先**：当前完整本段正文决定动作范围，旧 events/phase 是来源与连续性依据。旧记录只写到肩撞时，不能据此遗漏正文后续的肘扫、撑地踢腿及抱腰破解。用户编辑过的正文继续优先，旧记录不能恢复已删除剧情。
- **同一次时间安排**：语义分段与源头分镜在现有请求内安排完整行动、发话、因果先后及同时回应，正文、事件、场面记录与入口出口共同表达该安排。保留全部动作、明确次数、连续多次性质和固定时长，不把每个动作独占一段，也不以删动作解决慢演。
- **连续身体动作**：普通行进、转向、起身与退让体现支撑脚推动、落脚承重和躯干随动；攻防在来招接近时回应，接触后承接受力与下一行动。保留原文明确的慢绕行、停顿、滑步、跳跃和超常能力，不强套统一步态。
- **提示词交付**：H3 合并重复的外貌、服饰、光照和同一动作的复述，保留完整动作、对白和既定时间；手扫与腿扫、支撑肢与发力肢、持续接触与瞬间触碰保持区别。已有声音字段继续保留，无配乐时使用 `non_diegetic_music: N/A`，它不是视频服务的硬性禁乐开关。

通用动作理解同时作用于 H3、Seedance 的现有源头流程；消费图编号修复仅针对对应 H3 工作流。没有新增按钮、运行时内容校验、审核、生成拦截、自动重试或模型请求，也未调整 LoRA、采样步数和速度滑块。

## 已有项目如何使用

保存项目并退出旧版后启动 2.8.1，保留 EXE 旁完整的“莲华视频导演台数据”文件夹。当前已确认的旧工作流创建新任务即可采用正确图片编号；恢复进行中任务或明确复用旧任务仍使用原冻结快照。

旧视频、已确认提示词及已保存分段不自动覆盖。已有分段正文完整时，可从现有单段导演入口重新生成提示词；旧分段本身有问题时，使用现有 AI 分段入口重新规划。单纯重用旧提示词不会补回旧稿已经遗漏的动作。
