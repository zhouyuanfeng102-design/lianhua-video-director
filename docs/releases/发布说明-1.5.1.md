# 莲华视频导演台 1.5.1 发布说明

资产库图片新增可选人物绑定，便于后续选择参考图生成视频。

## 使用方式

1. 在图片卡片下方点击“绑定”，选择本项目的人物并保存。
2. 卡片显示“人物参考：人物名”。再次点击“绑定”可以更换人物，选择“不绑定人物”可以解除。
3. 后续在视频导演台选用这张图片时，使用保存的人物对应建立参考关系。不绑定也能正常选图和生成视频；人物无法在正文中明确定位时继续显示待关联提醒。

图片卡片上的“首帧”“尾帧”“绑定分镜”按钮已移除；视频导演台中的槽位用途设置继续保留。

## 数据与兼容

- 人物绑定单独保存，不覆盖图片原始生成来源，不修改人物档案与已有中英文提示词。
- 旧图片继续识别已有明确人物归属；手动换绑或解除后以用户的新选择为准，不会重新回落到旧人物。
- 已提交视频任务保持原有快照；绑定不会自动选图、重做提示词或提交新任务。

## 交付与验证

交付目录包含 `莲华视频导演台-1.5.1-便携版.exe`、恢复源码、更新说明、启动器及 SHA-256 校验文件。

针对性测试覆盖绑定、更换、解除、保存重载、原提示词保留和实际视频参考图关联。界面检查使用隔离数据，检查图片卡片与绑定弹窗，并确认未绑定图片仍可进入视频导演台；不调用真实付费接口。

构建命令：`npm run pack:win`；交付命令：`npm run deliver:1.5.1`。
