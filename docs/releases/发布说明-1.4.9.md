# 莲华视频导演台 1.4.9 发布说明

## 版本定位

1.4.9 修复图像工作台选择“不参考剧情补齐资料”后无法生成私密图片的问题。私密档案拥有独立的数据来源，不应被普通人物剧情字段的来源过滤器清空。

## 主要改动

- 选择“否”时，继续保留人物已保存的私密全身、胸部、外阴、后庭、阴茎和阴囊资料，私密全身图、部位图、五视图、四视图及四合一均可继续转换和生图。
- 项目剧情、旧分镜、旧身份锚点和来源不明的普通人物字段仍不进入本次请求；提示词转换器的剧情身份上下文保持为空。
- 普通生图继续排除私密档案，私密字段不会因本次修复串入普通人物图。
- 本版没有新增、复制或修改年龄门禁。

## 交付文件

- `莲华视频导演台-1.4.9-便携版.exe`
- `莲华视频导演台-1.4.9-恢复源码.zip`
- `莲华视频导演台-1.4.9-更新说明.md`
- `莲华视频导演台-1.4.9-SHA256.txt`
- `启动莲华视频导演台-1.4.9-便携版.bat`

## 构建与校验

资料来源过滤、私密全身提示词和“否 + 私密五视图”完整创建链路专项测试通过；测试使用本地模拟转换器与图像后端，没有调用真实接口。构建便携版使用 `npm run pack:win`，生成交付物使用 `npm run deliver:1.4.9`。交付目录中的 SHA-256 文件用于核对 EXE、恢复源码包、更新说明和启动器。
