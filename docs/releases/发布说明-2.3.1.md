# 莲华视频导演台 2.3.1

发布日期：2026-10-15。

## 视频选图顶部紧凑排布

视频导演台单段与长剧情批量的参考选图弹窗收紧顶部区域。人物提示、模型参数与图片容量、来源信息、切换操作和搜索按可用空间重新排列，减少留白，为图片列表保留更多高度。字体与控件随可用空间自适应缩小。

图片卡片下半部同步收紧：名称按卡宽和文字长度缩小字号，选中槽位与本段用途并排，大小对比和操作紧凑排列，轻压缩、恢复原图与放大预览放在同一行。长名称保留完整文字和悬停标题，图片预览高度保持原样。

## AI 分段规划区降低高度

提示词导演台 AI 分段的总时长来源、单段秒数、分段方式、操作行和横向分段条进一步紧凑排列，减少规划区占用，为本段内容编辑保留更多高度。相关字号、控件与间距自适应缩小。

## 修复本地轻压缩误报网络失败

本地原图通过桌面专用通道读取后，直接在内存解码为 Blob，不再对 Base64 图片调用 fetch，避免应用安全策略将其拦截并误报“网络请求失败”。保持现有安全策略；已有本地原图压缩过程不需要网络。

## 视频图片大小由模型接口决定

移除视频参考原图、压缩、保存副本、批量预检、快照冻结和实际提交路径的固定 32/64 MiB 本地门槛，视频 HTTP 上传也不再用固定 128 MiB 总正文大小拦截。上传图片不再按模型名称猜测每图 5/30 MiB 限制。已有本地原图可以先压缩成副本，再由实际模型接口决定是否接受。

当前模型资料若未提供图片字节上限，则不自行补数值；接口实际返回的超限错误继续保留，选图器显示同连接、同模型先前明确返回的合计上限。格式、文件路径、SHA 和上传回执校验保留。

## 兼容与交付

沿用现有选图、图片容量读取、槽位用途、轻压缩和分段操作。资产库原图保持原样，已有项目、原稿和历史任务继续保留。

版本按十进位规则从 2.3.0 递增至 2.3.1。2.3.0 及更早历史交付不覆盖、不删除。

## 验证结果

- 选图顶部针对性界面检查通过：1920×1080、1280×800 与 960×720，合成 3/6 人物、读取 30 槽、搜索、用途切换和应用重开、压缩入口及关闭均可操作，无横向溢出；顶部信息区缩至原来的 41.6%–51.7%。
- 图片卡片针对性界面检查通过：1280×800 与 960×720 的单段/批量、原图/压缩副本状态。长名称卡片下半部约 251→93–96 像素，压缩态约 278→104–108 像素；名称全文、大小对比、恢复和预览按钮无裁切重叠，预览图仍为 132 像素高。
- AI 分段规划区针对性检查通过：1920×1080、1280×800 与 1120×720，参数盒至段卡底部由 179→101 像素。总时长和单段时长输入、选段查看失败详情、折叠、请求中停止均可操作。
- 界面检查使用隔离项目和合成响应，资产库原图及项目未修改，未提交真实付费生成请求。
- 真实应用安全策略下的本地压缩专项通过：本地原图不调用 fetch 或桌面网络请求，透明通道、尺寸、实际字节数及 SHA 保持正确，合法 64 MiB+1 字节原图可压缩。
- 视频图片桌面读写、预检冻结与传输专项通过：超过 64 MiB 原图完成专用读取、冻结保存及 mock 视频请求，超过 128 MiB 正文/表单可进入传输；路径、格式、校验冲突与取消行为仍正确。
- 上游上传大小专项通过：65 MiB 原图进入模拟初始化，65 MiB 副本和 66 MiB 原图来源字节与 SHA 核对通过；上游 16 MiB 分片规格可用，错误回执仍拒绝，服务 413 错误保留。
- 压缩副本实际字节、冻结重试、请求身份和已保存章节参考回归通过。
- Windows 64 位便携版构建通过（包含 TypeScript 类型检查和 Vite 生产构建）。包内版本为 2.3.1，66 个 dist/electron 文件与当前构建内容一致；交付生成 SHA-256 清单。
