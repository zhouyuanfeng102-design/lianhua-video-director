# 莲华视频导演台 1.1.2 发布说明

日期：2026-10-02。

## 版本定位

修复 rhTV 自动上传将本机检查误写成“网页免压缩 10 MB 上限”的问题。原文件交给网页正常处理，不要求用户先缩图，不新增 AI 调用或改写提示词。

## 修改内容

- 删除上传前的 10 MB 门槛和网页预览的 3600 万像素门槛；这两项不是本次任务收到的平台拒绝。
- 删除专用桌面图片通道的 20 MB 限制和误用的 JSON 信封长度检查，23 MB 合成文件经真实 worker RPC 上传并重启恢复的回归通过。
- 不再要求网页预览编码与原文件 SHA-256 一致。网页可以压缩、缩放或使用 blob/CDN 预览；软件交给网页的仍是原文件，不自行缩图。
- 继续检查本机原图校验值、附件加载状态、名称、数量和顺序；记录准备好的预览，生成前如果附件被替换则暂停。实际生成画布仍核对模型、提示词、参数、引用节点及首尾帧用途，人物和原槽位绑定不改变。
- 零费用检查、提交前持久化边界、原任务恢复及不自动重投逻辑不变。尚未发出生成请求的大小检查失败，可以显式重试同一任务。

## 使用方法

1. 保存并关闭旧版，再启动 `莲华视频导演台-1.1.2-便携版.exe`。
2. 进入“API 设置 → 视频生成 → 视频 API”，选择原 rhTV 连接并启动桥接；必要时在独立 Edge 中登录原账号。
3. 在下方“rhTV 桥接任务”中找到这条暂停记录，点击“重新核验并继续”。保持“仅零费用自动提交”启用，才会继续自动流程。
4. 不必删除任务或重新创建批次。已有网页任务编号的任务仍只查询/下载原结果；网页明确拒绝或未完成上传时继续暂停，查看原网页实际提示。

本版不宣称网站无限制，也不取消整个软件的资源保护。原有 1 GB 本地桥接素材缓存容量、托管图片存储保护及可选 HTTP JSON 通道的 28 MB 缓冲限制保留；后者不用于桌面原图上传，报错已明确标识为本机传输保护，不能再当作网站图片限制。

## 版本与交付

从 1.1.1 按十进位更新到 1.1.2，下一版为 1.1.3。构建便携包后执行 `npm run deliver:1.1.2`，生成 EXE、恢复源码、更新说明、版本启动器及 `莲华视频导演台-1.1.2-SHA256.txt`（SHA-256 校验清单）。保留历史版本和正式项目，不自动改写或重生成已有媒体。
