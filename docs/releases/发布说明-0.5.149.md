# 莲华视频导演台 0.5.149 发布说明

发布日期：2026-09-23

## 版本定位

本版修正自动参考图收集把实体历史素材全部聚合的问题。此前两个实体的8张与5张历史图片被一起带入，形成不合理的13张参考图；本版从选择来源解决问题，不把增加传输数量当作参考图选择的修复。

## 本版变更

- 分镜参考图保留全部手动主图；自动部分按当前实际可见实体优先选择每个实体的一张当前绑定普通图片，不再整批加入实体历史图片。
- 当前绑定图缺失时回退有效相关图；相关私密部位参考图独立保留，不猜测名称或补入无关新图片。
- 旧分镜重试只在原任务已有手动或自动主图来源时整理同一份原始冻结参考池。显式参考图、最终提示词和原任务保持不变；缺少来源时不擅自推断。
- 整理后显示参考图数量变化，例如13张→2张。实际数量取决于手动主图、可见实体和相关私密参考，不设固定两张上限。
- 继续保留0.5.148对上游无可用图像额度、服务过载的中性提示，HTTP状态码和服务商错误代码、敏感信息脱敏，以及单张32MB/整个请求96MB的逐项传输检查。传输层不静默截断用户明确选择的参考图。

## 使用与兼容

1. 先保存项目并完全退出旧版，再启动`莲华视频导演台-0.5.149-便携版.exe`，避免多个版本同时写入同一数据目录。
2. 新建分镜图片任务或用户主动重试时应用新的选择逻辑；不会后台自动重跑旧任务、自动调用图像API或反复提交收费请求，不改写已有项目、任务、提示词和成图。
3. 上游额度和过载仍需等待服务商恢复后主动重试，本地无法修复服务端状态。
4. 0.5.148及此前的交付包、源码、说明和专属启动器保留；0.5.147的真实AI校验修复、图片缩放与批量面板压缩继续保留。
