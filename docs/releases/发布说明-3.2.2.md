# 莲华视频导演台 3.2.2 发布说明

发布日期：2026-10-26（亚洲/上海）。

## 资产库按项目分文件夹

资产目录仍在原来的数据根下。新保存的图片、视频和音频进入：

`assets/projects/项目名/image/`
`assets/projects/项目名/video/`
`assets/projects/项目名/audio/`

文件夹名用软件里的项目名称。Windows 不允许的字符会被去掉。两个项目整理后的名字相同时，后一个会加上项目编号的一小段，避免互相覆盖。项目改名时，同一次保存会把这个项目的文件夹一起改掉。

同一个项目里，内容相同的图片仍只存一份。另一个项目用到同一张图时，会复制进那个项目自己的文件夹。视频的「第 N 版」只在这个项目的视频文件夹里递增，所以两个项目可以有同名成片。

升级时不扫描、不删除现有文件。打开或保存某个项目时，只处理这个项目已经引用的文件。只有它在用，就把文件移进项目文件夹并改相对路径。别的项目还指向同一文件，就复制一份，原文件留到那个项目自己被打开。已经在 `projects/` 里的路径保持不动。旧的 `image/`、`video/`、`audio/` 里没人引用的文件留在原地。

正在下载的文件按它已经开始写入的位置完成。新的生成、导入和参考图直接写入目标项目的文件夹。资产库里的图片、视频、音频分页、筛选和播放不变。旧路径、旧项目包仍能打开和导入。

不新增按钮、校验、重试或额外模型请求。

更早的恢复点如果仍记录移动前的旧路径，恢复后可能找不到已经挪走的文件。当前项目在保存后使用新路径。

## 版本定位

本版便携包为 `莲华视频导演台-3.2.2-便携版.exe`。交付命令为 `npm run deliver:3.2.2`。3.2.1 及更早交付文件继续保留。

## 定向验证

项目文件夹命名、同名项目编号、独占文件移动、共享文件复制、缺失文件保持原路径、已在项目文件夹中的文件不重复移动，以及视频版本号按目录单独计数，各测一次。打包中的类型检查和生产构建另计。
