# 莲华视频导演台 3.3.9 发布说明

发布日期：2026-10-27（亚洲/上海）。

## 本地停止任务的退出计数

修复关闭软件时误报“还有 11 项任务未完成”的问题。

- 用户点击本地停止后，该视频任务视为本地已结束，不再阻止软件退出。
- 任务记录、远端任务 ID、历史证据和后续恢复入口继续保留。
- 未停止的图片、视频和资料任务仍按原规则阻止退出确认。

## 版本定位

本版 Windows 便携包为 `莲华视频导演台-3.3.9-便携版.exe`。构建命令为 `npm run pack:win`；将交付文件生成到项目内 `交付` 目录的命令为 `npm run deliver:3.3.9`。3.3.8 及更早交付文件继续保留。

交付目录包含恢复源码 ZIP、更新说明、启动器和 SHA-256 清单；历史版本文件不覆盖、不删除。

## 定向验证

- `npm run test:video-task-deletion`：原有视频任务删除测试和新增退出计数测试通过。
- `npm run build`：TypeScript 检查与 Vite 生产构建通过。
- 使用交付数据复核，原先 11 条本地已停止的视频记录不再计入退出阻塞数量。
