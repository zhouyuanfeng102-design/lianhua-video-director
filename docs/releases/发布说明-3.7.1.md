# 莲华视频导演台 3.7.1 发布说明

发布日期：2026-11-01（亚洲/上海）。

## 笔记本窗口可以看全

窗口第一次打开仍尽量用 1280×800。屏幕工作区更小时，窗口落在工作区里面。最小可以缩到 880×560；工作区比这还小，就跟工作区一样大。

页面不再锁死 1040 像素宽。顶栏按钮放不下时换行。资产库的上传行和筛选行在窄窗口里各自换行。窗口高度低于 800 像素时，API 设置、视频生成区和图片资产库可以往下滚。更高的屏幕仍按一屏排列。

左侧导航最多缩小到 0.82。再矮就停止缩小，导航自己出现滚动条。工作区字体不变。

## RunningHub 密钥可以切换

RunningHub API Key 这一列可以保存多把密钥。上面一行是已存密钥、名称、保存和新建，下面仍是密钥输入框。下拉框选中名称后，当前密钥换成那一把。

已有项目、提示词和成片不改。不新增运行时校验、内容拦截、自动重试或模型请求。

## 版本定位与交付

Windows x64 便携包：`莲华视频导演台-3.7.1-便携版.exe`。构建命令为 `npm run pack:win`，交付命令为 `npm run deliver:3.7.1`；3.7.0 及更早历史版本文件保留。交付目录同时提供恢复源码、更新说明、启动器与 SHA-256 清单。
