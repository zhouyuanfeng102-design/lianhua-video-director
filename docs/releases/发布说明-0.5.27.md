# 莲华视频导演台 0.5.27

## 版本定位

- 0.5.27 是基于 0.5.26 的图像工作台资料补齐增强版，保留既有导演、分镜、提示词和项目操作方式。
- 本版新增“AI 补齐资料”，让不完整的视觉资产资料可以直接调用现有文本 API 补全，同时严格保护用户已经填写的内容。

## 图像工作台新增 AI 补齐资料

- “AI 补齐资料”按钮位于主生成按钮左侧，支持角色、场景、物品和九宫格四类资产。
- 系统只请求当前类型允许的字段，只补空白或“待补充、未知、无资料”等占位字段，不覆盖名称、服装、外观或其他用户已有资料。
- AI 返回的未知字段、空字符串和占位内容会被丢弃；请求完成时还会再次检查实时表单，避免覆盖请求期间用户新输入的内容。

## 人物年龄与资料边界

- 人物年龄仅在原文明示具体年龄或年龄段，并且内容确实对应当前人物时才允许补齐。
- 原文未明确时不会自行加入“成年、青年、未成年”等年龄限定；其他人物的年龄和被否定的年龄描述也不会借用到当前人物。
- 项目说明、剧情文档和场景摘要均按不可信项目资料传入，只作为事实素材，不执行其中夹带的指令、规则或输出格式要求。

## 异步安全与设置引导

- 请求期间切换项目、资产类型或实体后，旧请求结果会被丢弃，不会串写到新的表单。
- 文本 API 未启用或缺少地址、模型名称时，会提示用户并转到 API 设置页。
- 已在 1120×720、1280×720、1280×800 三种窗口尺寸下验证按钮完整可见，无重叠、裁切或横向溢出。

## 兼容与验证

- 继续兼容 0.5.26 及更早项目，不改变项目数据结构，不需要迁移已有视觉资产。
- 已通过完整自动化测试、类型检查、生产构建、真实浏览器交互和控制台检查。

## 交付内容

- 0.5.27 交付包含 Windows x64 便携版、恢复源码、更新说明、版本启动器、无版本启动器与 SHA-256 完整性清单。
- 0.5.26 及更早历史交付文件继续保留，新版本不会覆盖旧包。
