# 莲华视频导演台 4.2.0 发布说明

发布日期：2026-11-08（亚洲/上海）。

## 台词只从能看清的那张嘴说出来

声源编号只出现在 `says:` 那一句。身份句、`Identity` 和参考图职责不再写 `(S1)`、`(S2)`。这一段没有台词的人不编号。

一句画内台词的那几秒，看不见嘴的机位先结束。停住、保持距离、不再移动、背对、脸贴在支撑面上、从身体侧面看、蒙眼，都算在这句开始之前。接着镜头切到说话人能看清的嘴，其他人的嘴保持闭合，再写 `名字 (S1) says: <d>[中文] 原话</d>`。这句说完，这张嘴重新闭合。下一镜若要切到另一张脸，落在这句结束之后。

有这句台词的镜头不再写「台词：无」。人就在画面里时仍用 `says:`。只有人确实不在画面里，才用 `says in an off-screen voiceover`。

已保存的提示词和成片保持原样。重新生成这一段后，这句才会由原定的人说出来。
