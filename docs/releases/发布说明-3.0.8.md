# 莲华视频导演台 3.0.8 发布说明

发布日期：2026-10-25（亚洲上海）。

## K2 分镜按参考图用途写画面

Krea-2 自然语言规则在分镜或剧情静帧带了参考图时，按每张图的实际用途来写。场景或环境图只保留空间结构、门窗、家具和材质，光线和时间以当前镜头为准。人物图只保留面部、发型、身体比例和服装，姿态、朝向和站位按当前镜头重排，不复制参考板里的站姿、朝向、背景或多格布局。

五视图、设定板和单人身份资料图仍按当前图片规格保留各自版式。「Krea-2 多人物绑定 · 分镜单帧」使用同一条用途规则。没改过的内置 K2 规则在打开项目后自动换成新文案。自己改过的规则保持原样。

不新增按钮、运行时校验、内容审核、生成拦截、自动重试或模型请求。

## 版本定位

本版便携包为 `莲华视频导演台-3.0.8-便携版.exe`，恢复源码包、更新说明和 SHA-256 清单由交付脚本按同一版本生成。交付命令为 `npm run deliver:3.0.8`。3.0.7 及更早交付文件继续保留，0.5.160 及更早历史版本不重编号、覆盖或删除。

## 定向验证

已核对内置 Krea-2 规则版本为 1.6.0，分镜预设为 1.2.0，新文案已进入系统规则，旧的「必须保持构图」句子已不在主规则里。检查使用本地规则文本，不调用真实模型，也不提交图片生成。

Windows x64 便携包由打包流程执行类型检查、Vite 生产构建和便携版生成。本版不改写用户自己编辑过的生图规则。

交付后请核对 `莲华视频导演台-3.0.8-SHA256.txt` 中的 SHA-256 清单。

## 使用与交付

保存项目并退出旧版，打开 3.0.8 便携版，保留 EXE 旁完整的“莲华视频导演台数据”文件夹。原有 K2 生图入口不变。
