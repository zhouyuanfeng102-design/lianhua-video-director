# 莲华视频导演台 2.6.2

发布日期：2026-10-17。

## 修复视频导演台卡顿

本版修复进入视频导演台、切换长剧情分段时的重复计算。人物参与分析此前会在检查每个人物、别名和正文段落时反复建立别名对应关系；界面准备草稿、尾帧依赖和最终参考图绑定时，又重复解析相同提示词。多个分段的同步计算累积后，会阻塞页面响应。

本次只读实测使用现有项目的 8 个人物、16 个分段及 30 份中英文稿。修复前，仅逐稿进行人物参与分析便耗时约 **1.924 秒**；这是本机该批文本五轮测量的中位数，不代表所有设备和项目的耗时。

人物解析现在在同次调用中只建立一次别名及正则索引，时间轴与主体声明共同使用，不保留会随人物资料修改而失效的跨调用缓存。视频导演台复用未变化的参考图绑定，选图、用途、连接或尾帧确有变化时重新计算；尾帧人物草稿按实际需要准备，隐藏的单段面板跳过计算，章节草稿只在初始化时读取，减少同一批内容的重复处理。

## 使用与兼容

- 继续识别 Seedance 主体连续性中的静默人物，并区分纯提及、画外和明确未出场人物。
- 图片调序、移除和人物资料变化仍按当前内容计算，不复用已经失效的关联。
- 保留已保存的中文、英文、参考图和历史任务，不要求重新生成提示词，也不增加 AI 请求。
- 保存项目并退出旧版后启动新版，保留完整的数据文件夹。

版本按十进位规则从 `2.6.1 → 2.6.2` 更新。提供便携 EXE、恢复源码、更新说明、版本启动器及 SHA-256 清单；历史版本文件保留。本次仅本地交付。

## 验证

- 同批 30 份文本五轮中位数：Seedance 人物识别 **1,923.8 → 38.2 毫秒**，完整参考图绑定 **1,961.6 → 77.4 毫秒**。四条解析与绑定路径的完整结果摘要与修改前一致。
- 人物参与语义、分段人物提醒、新增算法性能回归均通过。性能回归检查别名资料读取次数不会随主体子句或镜头数量反复增长，并覆盖同一对象原地修改姓名、别名、冲突及归档状态后的即时更新；已接入人物参与测试命令。
- 16 段、30 份约 20 万字符稿件、8 人物的合成页面对照：在双方都使用优化后人物算法的情况下，界面去冗余进一步使 React 首次挂载总渲染时间 **582.3 → 397.2 毫秒**、切换预览 **290.5 → 198.3 毫秒**；空闲两秒无额外渲染。这是开发态组件渲染耗时，不包含模块下载、磁盘读写或真实接口延迟。
- 18 组 Seedance 图片绑定专项通过；四人物九图、调序、取消临时选图、原稿保护、历史冻结任务原样重试、改图解除冻结及换连接重新绑定、请求序列化与预览一致均通过。尾帧组合按需准备，保留正文，仅更新图片编号。
- 页面合并报告：`output/playwright/video-director-performance/report.json`；真实文本只读性能报告：`output/seedance-participation-performance-2026-10-17.json`。测试夹具的折叠控件定位及来源适配修正后，仅重跑对应尾帧与重试窄项。
- 打包流程内的 TypeScript 检查、生产构建与 Windows 64 位便携 EXE 生成成功。构建仍提示已有循环分块和大分块；直接加载最终生产包的启动检查通过，视频导演台入口无页面运行错误。报告：`output/playwright/production-startup-2.6.2/report.json`。
