# 莲华视频导演台 0.5.50

## 版本定位

本版新增应用内更新日志，把近期连续版本的实际更新内容直接放进软件查看。更新日志入口位于左侧报错日志上方；0.5.49 及更早功能和历史交付文件继续保留。

## 应用内更新日志

- 左侧导航新增“更新日志”入口，并直接显示当前包版本，便于确认正在使用的版本。
- 入口固定在报错日志上方；原有报错日志的查看、复制、清空、持久保存和脱敏功能不变。
- 弹窗按新到旧展示 0.5.50—0.5.36 的连续版本记录，0.5.50 标记为“当前版本”。
- 每个版本使用独立卡片整理真实改动，覆盖 AI 扩写与最终转换器、ComfyUI、图像工作台、第一人称修复、长剧情处理、任意资产参考图、真正 AI 分镜、原文摘录修复和报错日志等近期更新。
- 较长的版本列表在弹窗内部滚动，不挤占主工作区。

## 近期版本内容

- 0.5.49：修复 AI 分镜原文摘录的等价标点与排版映射，无法定位时允许同一文本模型自动修复一次；新增持久报错日志。
- 0.5.48：AI 自动分镜改为由文本模型直接决定镜头数量并返回完整逐镜方案，不再用本地镜数公式冒充 AI 分镜。
- 0.5.47—0.5.40：接通任意资产参考图、长剧情 AI 切段、长文本请求、手工总提示词重新转换、第一人称归一化、图像工作台操作与 ComfyUI API Workflow。
- 0.5.39—0.5.36：调整最终转换结果接收边界，完善最终视频提示词转换规则、AI 扩写规则，并合并“解析并补全”流程。

完整逐版内容以软件内更新日志为准。

## 兼容与交付

- 本版只新增更新日志界面及内置版本记录，不改写现有项目数据、API 配置、素材资产或报错日志。
- 当前便携包名为 `莲华视频导演台-0.5.50-便携版.exe`，对应交付命令为 `npm run deliver:0.5.50`。
- 正式交付包含便携 EXE、恢复源码、更新说明、版本启动器和 SHA-256 校验清单。
