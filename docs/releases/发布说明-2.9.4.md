# 莲华视频导演台 2.9.4 发布说明

发布日期：2026-10-21（亚洲上海）。

## 恢复 Seedance 本段参考图预选

此前 Seedance 视频草稿只带入生成提示词时保存的参考清单，并跳过默认人物图。提示词先生成、人物图或首尾帧后补齐时，选图窗口可能仍显示“已选 0 张”。模型图片容量未知并不是清空选择的原因。

现在保留旧清单顺序，同时带入当前分镜明确绑定的参考图、首尾帧和本段可见人物的当前身份图。场景图使用已保存的场景、地点及空间编排 ID 关联；语义分段的虚拟场景没有地点列表时，仍能沿用空间编排中明确的地点 ID。原稿、参考清单和历史任务不改写，人物与场景不通过正文标题或文件名猜配。

手动取消、清空和改选仍按本次选择保存，其他段落保持独立；自定义多张静帧结果不自动整批加入。冻结任务复用保持原始参考。本次仅调整草稿默认选图，不增加校验、审核、生成拦截、自动重试或模型请求。

## 定向测试

只读使用用户当前项目的副本运行第 1 段草稿选图：自动选中首帧、尾帧、“异界，战舰外”场景图、吴小观人物图和夏娃人物图，共 5 张；资产 ID、用途和两个人物身份绑定均对应原记录。原提示词、项目对象及原文件内容均未改变，没有模型或网络请求。开发测试不转化为产品运行时新增校验。

`videoSeedanceDefaultReferences.test.ts` 的 4 组定向测试通过；`videoDefaultCharacterReferencesUi.test.ts` 中 H3、Seedance 的实际批量面板与选图回调测试均通过。覆盖空清单及后生成首尾帧、场景明确 ID 与快照、解除或改绑、不同分段隔离、人物绑定、单段和批量一致、清单顺序、自定义静帧排除，以及手动取消、清空、保存和恢复。测试使用隔离状态，没有 API 请求或生成任务，源项目保持不变。

打包流程中的 TypeScript 类型检查、Vite 生产构建及 Windows x64 便携包生成通过。构建仍有原有循环分块和大文件提示，本次未调整分块配置，未追加整套界面或功能回归。

## 使用与交付

保存项目并退出旧版，打开 2.9.4 便携版；保留 EXE 旁完整的“莲华视频导演台数据”文件夹。历史版本和交付文件保留。
