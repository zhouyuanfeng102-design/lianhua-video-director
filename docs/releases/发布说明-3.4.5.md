# 莲华视频导演台 3.4.5 发布说明

发布日期：2026-10-29（亚洲/上海）。

## 头留在胸口这一侧

胸口朝向谁，头就留在这一侧。下颌对着这个朝向，看对方的耳侧也停在肩线以内。推近、环绕、反打、越肩只改摄影机看见的一面。人在镜头身后时，正文写后脑和耳廓。要看他的脸，就把机位挪到已经能看到他朝向对方的那一侧。侧脸只指这一面。正面身份图只锁五官和衣服，不把正脸贴到后脑上。

贴身、越肩说话、背后跟拍、侧跟行走、对打时机位在身后，以及跪坐或躺着仍面对面，用同一句。剧情里的回头、转身仍按那个动作连续转。推近、要看正脸、身份图和口型不是转头的原因。

起伏时胸口和髋朝向对方，头留在这侧胸口上。英文稿写 head stays on the chest that faces them；从身后看见的是后脑和耳朵。

新生成或获准重写的每一镜正文写明胸口朝向和本镜看见的那一面。已经生成的视频和已经存下的提示词保持原样。要换这一段的画面，就重新生成本段提示词，再重新生成这一条视频。

## 版本定位

本版 Windows 便携包为 `莲华视频导演台-3.4.5-便携版.exe`。构建命令为 `npm run pack:win`，交付命令为 `npm run deliver:3.4.5`。3.4.4 及更早交付文件继续保留。
