# 莲华视频导演台 0.5.47

## 版本定位

本版打通当前项目资产库任意图片作为真实参考图的完整链路。图像工作台与视频导演台不再按角色、场景、动作或构图职责白名单漏图；0.5.46 及更早历史交付文件不会被改写。

## 任意资产库参考图

- 图像工作台新增“从资产库选择”入口，可搜索并单选当前项目中任意真实可读取图片，同时显示缩略图、类型、职责、尺寸和当前选中状态。
- 视频导演台继续支持多选，并改为展示所有真实可读取图片；`motion`、`general` 等非传统职责图片也能直接勾选。
- 缺失文件、纯提示词资产、视频、音频和不可读取媒体不会混入图片参考列表，避免选择后才发现没有可用像素。

## 真实图片链路与界面

- 资产库图片会先解析为真实图片像素，再作为主参考图统一传入 OpenAI、SD WebUI 与 ComfyUI，不再只把资产名称或提示词当作参考。
- 本地上传与资产库选择共用同一预览、AI 识图和图生图开关；切换项目或实体时会清理旧选择，避免跨项目误用图片。
- 新增响应式资产选择弹窗、搜索栏、图片卡片、缩略图、选中预览和视频导演台缩略图布局。
- 自动化 UI 回归覆盖 1120×720、1280×720、1280×800，并检查弹窗边界、选择回填、生成开关、横向溢出、重叠和控制台错误。

## 交付

- 当前便携包名为 `莲华视频导演台-0.5.47-便携版.exe`，对应交付命令为 `npm run deliver:0.5.47`。
- 正式交付包含便携 EXE、恢复源码、更新说明、版本启动器和 SHA-256 校验清单。
