# 莲华视频导演台 3.0.4 发布说明

发布日期：2026-10-25（亚洲上海）。

## 语义分段不再把带引号的原句写进 JSON

「AI 理解剧情并分段」仍使用当前填写的文字接口，包括中转上的谷歌模型。这一次请求里，模型不再把原文句子抄进 JSON。

证据和对白只返回在本次章节正文中的起止位置，以及说话人和事件 id。段正文里的对白写成 `【对白 对应id】`。摘要、事件说明和场面文字用「」，示例里不再放英文双引号。

解析通过后，程序用这次章节正文把对应原句填回证据、对白，并替换段正文里的记号。保存后的分段计划仍带这些原句。已保存的旧分段计划不按区间重切。后来手改某一段正文时，仍以手改内容为准。

不新增按钮、运行时校验、内容审核、生成拦截、自动重试或模型请求。扩写、画面描述转化、生图、分镜和 H3 的请求格式不变。

## 版本定位

本版便携包为 `莲华视频导演台-3.0.4-便携版.exe`，恢复源码包、更新说明和 SHA-256 清单由交付脚本按同一版本生成。交付命令为 `npm run deliver:3.0.4`。3.0.3 及更早交付文件继续保留，0.5.160 及更早历史版本不重编号、覆盖或删除。

## 定向验证

`scripts/semanticSequencePlan.test.ts` 36 项、`scripts/semanticSequencePlanner.test.ts` 25 项、`scripts/semanticActionWindowPlanning.test.ts` 2 项、`scripts/semanticSequenceCompatibility.test.ts` 24 组已通过。测试使用模拟请求，不调用真实模型，也不提交视频生成。

Windows x64 便携包由打包流程执行类型检查、Vite 生产构建和便携版生成。本版不改变用户项目存档。

交付后请核对 `莲华视频导演台-3.0.4-SHA256.txt` 中的 SHA-256 清单。

## 使用与交付

保存项目并退出旧版，打开 3.0.4 便携版，保留 EXE 旁完整的“莲华视频导演台数据”文件夹。原有「AI 理解剧情并分段」按钮不变。
