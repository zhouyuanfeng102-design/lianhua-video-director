# 莲华视频导演台 1.7.0 发布说明

2026-10-09

视频导演台的长剧情批量分段改为紧凑清单，减少重复按钮和说明占用的空间；生成任务的图像卡片增加完整提示词滚动框，界面设置新增日夜模式和五种配色。

## 使用方式

段名、勾选、状态、提示词格式、语言、参考图数量和衔接摘要直接可见；预览与选择参考图仍有直接入口。已选分段采用较淡的边框，当前预览段突出显示。

点击各段的“分段设置”可独立展开或收起格式、语言、复制上段选图、尾帧、组合参考与恢复原选图等操作。生成参数和详细衔接说明随设置展开，默认保持折叠。

图像任务的最终提示词移到卡片右侧，在元信息与操作按钮之间以独立框完整换行显示。提示词框固定高度，可上下滚动；卡片底部不再重复截断文本。复制、打开、重新生图等按钮保持原有行为。

顶部“界面与字体设置”新增日间、夜间和跟随系统模式，以及莲华粉、湖蓝、青竹、暖砂、紫藤五种配色。模式与配色独立选择，立即应用并通过现有设置保存，重启后恢复。旧 `ink` 设置按原日间外观兼容，未知模式或配色回退默认设置。

本次调整展示及界面设置。生成、衔接、稿件与项目保存逻辑保持原有行为，分段展开状态不写入项目数据。1.6.9 的资产库详细信息默认折叠继续保留。

## 配色参考

暗色设计参考 [Ant Design 暗色模式](https://ant.design/docs/spec/dark/) 的舒适对比和信息层级一致性原则。中性色用于界面层级、暗色共享色调整饱和度与亮度，以及状态色保持稳定含义的做法参考 [Fluent 2 色彩指南](https://fluent2.microsoft.design/color)。

莲华粉、湖蓝、青竹、暖砂、紫藤五种低饱和配色由本项目自行选择，用于主题重点和交互强调；成功、警告、失败等状态继续表达原有含义。

## 验证与交付

针对性界面检查通过，覆盖两个窗口尺寸下的分段清单与提示词滚动框，以及五种配色、日夜切换、跟随系统、设置保存与重新读取、旧设置兼容。夜间检查覆盖导航、表单、弹窗、任务提示词框和批量分段；末次补充验证侧栏报错日志入口与计数器的夜间样式。检查仅使用隔离合成资料，未调用真实生成服务。
