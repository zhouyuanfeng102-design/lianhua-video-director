# 莲华视频导演台 3.9.2 发布说明

## RH 网页补上应用名和账号昵称

应用库里仍显示「网页应用」加编号时，打开管理页会在后台再读一次页面标题，并把读到的名字写上。应用号 2114537196685627394 的页面标题是「Minimax-H3 无限长视频V2升级版」。

登录位已经显示已登录、名字却还是添加时写的临时名字时，会在后台打开已保存的登录并读取网页昵称，替换登录位名称。不弹出登录窗口。

已保存的提示词和成片不改写。

## 版本定位与交付

Windows x64 便携包：`莲华视频导演台-3.9.2-便携版.exe`。构建命令为 `npm run pack:win`，交付命令为 `npm run deliver:3.9.2`；3.9.1 及更早历史版本文件保留。
