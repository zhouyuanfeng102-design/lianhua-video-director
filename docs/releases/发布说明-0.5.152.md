# 莲华视频导演台 0.5.152 发布说明

发布日期：2026-09-24

## 版本定位

修复图片生成任务把真实网络错误隐藏为“操作失败，暂时无法识别具体原因”的显示问题，补齐桌面网络诊断。背景音乐不在本次修改范围。

## 本版修复

- `Client network socket disconnected before secure TLS connection was established` 明确显示为：与接口的TLS加密连接尚未建立就已断开。该错误属于网络连接阶段，不说明提示词、参考图数量、余额或内容审核有问题。
- 区分TLS握手、证书过期/未生效/域名不匹配/自签名/证书链错误，以及已连接后等待或读取响应时断开；不建议关闭证书验证来“修复”。
- 图片任务和报错日志新增“查看错误详情”与“复制错误详情”。可以查看脱敏原始错误、HTTP状态、错误码、阶段、接口域名与直连/系统代理路径，未知英文不再只能得到一句泛化说明。
- 详情显示与复制隐藏API密钥、认证/Cookie、请求正文、提示词、URL凭据及图片数据；错误对象中的getter或自定义序列化不会被执行。
- 桌面IPC仅保留Error.message时仍传回必要诊断；日志区分实际使用的图像接口和提示词转换接口，避免一律标成文本模型。
- 历史任务不改写即可使用新显示方式。不会自动重试收费POST、不自动重跑旧任务、不切换API地址、不修改系统代理，也不关闭TLS校验。

## 原因与边界

本次记录中的真实失败发生在TLS建立前，但旧版没有记录当时的具体路由和错误码，不能据此断言是代理或服务器单方故障。只读检查发现当前配置域名的直连与系统代理均可完成TLS和无鉴权HEAD请求；这仅证明检查时连通，不等于真实图像生成已成功，也不能保证网络不会再次中断。

本版修复错误显示及诊断信息丢失，不把接口连接故障伪装成提示词错误或声称已经修复远端服务。没有使用真实收费生成来验证。

## 验证与构建

验证覆盖TLS与证书错误中文化、重复显示稳定、原始详情脱敏和复制、HTTP/错误码/阶段传递、取消与单次提交、历史任务不变、图片任务和日志的隔离浏览器交互。严格类型检查、回归、构建、便携版启动及SHA-256验收以本轮实际执行记录为准。

本轮完整`npm test`、生产构建及分包预算通过；错误详情15组模拟测试通过，实际浏览器验证历史TLS错误、敏感信息脱敏、展开与7次单条/整份日志复制，小窗口无横向溢出，任务/资产/日志原始记录不变，零收费请求。便携包已在隔离数据目录通过启动、保存、恢复、重载和3种窗口尺寸验收，无脚本错误。背景音乐规则与混音文件已核对，与0.5.151一致。
