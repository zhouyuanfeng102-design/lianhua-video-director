# 莲华视频导演台 0.7.5 发布说明

## 版本定位

0.7.5 修复 AI 把人物受伤等普通剧情状态误拆为独立形态资料的问题。

- 移除“任何外貌、体表变化都必须拆分”的歧义要求，默认同一人物复用一份资料。
- 仅在剧情明确形成另一套可辨认的身份或身体设计时拆成“人物·形态”，例如性别、物种、身体结构转化或明确的独立外貌形态。短时、可恢复的真正变身仍拆分，不以持续时间或永久性作为门槛。
- 受伤、血迹、淤青、烧伤、脏污、疲惫、表情、姿态、动作阶段、普通换装和光线变化保留在场景状态中，不另建人物；跨场景持续的伤势同样引用原资料，不删除剧情中的伤情。
- AI 在原次解析中自行检查“漏拆真正形态”与“误拆普通状态”，修复结果及场景引用；未转化人物省略形态字段，不强加“原始形态”后缀。
- 普通资料补全遵循同一边界，不为受伤等状态补造兄弟资产。本地仅处理结构和显示名称，不新增关键词门禁、剧情语义裁决或额外付费审核请求。
- 新规则用于新解析和主动重新解析，不自动修改历史提示词、媒体和项目；原有 H3 格式不变，已绑定参考图的旧资料不自动删除。

当前便携包：`莲华视频导演台-0.7.5-便携版.exe`。交付目录同时提供恢复源码、更新说明、版本专属启动器和 `莲华视频导演台-0.7.5-SHA256.txt`（SHA-256 校验清单）。
