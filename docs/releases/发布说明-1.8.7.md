# 莲华视频导演台 1.8.7 发布说明

2026-10-11

本版在图像工作台新增“自定义生图”栏，方便临时输入自己的要求、带参考图生成图片，并自动保存到资产库。

## 自定义生图

“自定义生图”放在人物、场景、物品和分镜图入口旁。点击后使用聊天样式显示要求、任务状态和图片结果；可只输入文字，也可上传 PNG、JPEG、WebP 参考图或从资产库选图。设置分辨率后点击“发送并生图”，或按 Ctrl+Enter 发送，每次生成 1 张。

“使用规则转换”默认关闭，要求原文直接提交当前生图模型，不调用文本模型补齐资料，不套分类预设、剧情信息或旧对话。需要时可开启转换，选择已有生图规则，使用文本 API 转换本次要求；原文、实际提交词与规则内容快照分别保存，转换失败直接报告，不自动改为原文直发。

每次发送独立处理，只使用本次明确选中的参考图。点击结果卡的“用这张继续改”，可将结果图加入下一次请求的参考图栏，再输入修改要求。草稿、分辨率、选图和规则开关按项目保存，规则删除或停用后会提示重新选择。

## 资产保存与重新生成

生成结果下载并保存到本地资产库，保留实际尺寸、原要求、最终词、模型与参考图快照。切换项目或页面后，后台结果继续写回发起项目。自定义图不自动绑定人物、场景或分镜。

“按原提示词再生成”复用当时实际提交的最终词、模型、尺寸与原参考图，不再执行规则转换；“编辑要求”或“重新选择规则转换”可修改后创建新任务。转换未完成时可明确重试转换，原任务和旧图继续保留。

图片已经生成但本地保存未完成时，可“重试保存”处理原结果，不再发起生图。删除原任务后，结果资产仍保留恢复原请求所需的快照；参考原图随项目导出和备份。

参考图数量、分辨率和最终生图效果以配置的模型、服务或工作流实际能力为准。原有普通、私密和分镜生图流程继续保留，历史项目、规则和交付文件不重编号、不覆盖、不删除。

## 验证与交付

自定义提示词、任务执行、持久化恢复和参考图导出检查均已通过，覆盖原文直发、可选规则转换、固定参考图、项目归属、任务撤销、原词再生成及保存恢复。相关原有图像再生成、参考图导出、ComfyUI 占位符和规则历史检查通过。`npm run pack:win` 中的 TypeScript、生产构建和 Windows 64 位便携包生成均通过。

使用实际 1.8.7 便携 EXE、独立测试数据目录和本地模拟接口完成针对性界面验证：原文中的空格、竖线与占位符原样提交；上传和资产库选择的两张参考图按顺序发送；明确选择另一条用户规则后仅转换一次；结果原像素托管入库；草稿、参考图、规则与历史记录重载后恢复；任务和资产入口均复用最终词再生成。共验证 1 次文本请求和 5 次生图请求，未调用真实付费模型。1280×800 下输入、选图、规则与发送控件可见且可操作，未发现页面异常或控件裁剪。报告位于 `output/playwright/custom-image-workbench-1.8.7/report.json`。本轮未执行与改动无关的全量回归。

新增 `npm run test:custom-image` 汇总自定义提示词、任务执行、持久化恢复和参考图导出检查。本版打包中的 TypeScript 与生产构建检查由 `npm run pack:win` 完成，不在打包前重复执行。

本版按十进位从 1.8.6 升级至 1.8.7，便携包名为 `莲华视频导演台-1.8.7-便携版.exe`，交付命令为 `npm run deliver:1.8.7`。1.8.6 及更早发布说明、交付文件与交付入口继续保留。
