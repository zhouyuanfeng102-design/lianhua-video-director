# 莲华视频导演台 0.5.77 发布说明

## 版本定位

- “AI 剧情优化”提供 `optimize` 优化整理（默认）和 `expand` 扩写补全。优化理顺表达、指代和自然分段，不强制加长；扩写围绕原主线补充有效信息。
- 保留人物代号、原对白、事件时序、因果与结局；结果仍为中文剧情正文，不是 H3 或逐镜字段。
- AI 结果先作为草稿审阅，确认后再解析，并可还原原文，不直接覆盖既有剧情成果。
- 默认内置预设更新为“AI 剧情优化 · 整理与扩写”1.2.0，精确迁移未编辑旧内置内容。原预设 ID、保存格式、自定义内容、禁用/删除状态和默认选择保持，schema 仍为 21。
- 原有连续环境声清理、同步动作声、本地不限字符、Krea-2 与 ComfyUI 功能保留；0.5.76 及更早版本化交付和正式数据不改写。

保存工作并关闭旧版后，通过 `交付\启动莲华视频导演台-0.5.77-便携版.bat` 打开已完成构建的新包。实际验证和交付状态以执行记录及产物为准，本说明不预先宣称测试或打包完成。

构建便携版后，对应交付命令为 `npm run deliver:0.5.77`。

## 针对性验证

- `scripts/storyPreparation.test.ts` 的 10 组定向检查通过：短/同长/原样优化、长小说、两种模式、原对白与说话人顺序、输出结构、预设优先级及取消。
- 旧默认规则的精确升级与自定义保护测试通过。
- 一个 1280×800 隔离页面完成两次模拟请求：优化 97 字为 95 字、精确还原，再扩写为 390 字；已保存项目全程不变，控制台错误为空。
- 本轮按要求只验证相关核心流程，未重跑整套旧功能回归；未调用用户真实文本 API。
- `npm run build` 与本地 Electron 便携版构建已完成。此次 UI 检查针对功能代码、采用模拟响应；未额外重复旧版全场景或完整便携包回归。
