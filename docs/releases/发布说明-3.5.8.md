# 莲华视频导演台 3.5.8 发布说明

发布日期：2026-10-31（亚洲/上海）。

## ComfyUI H3 单图首帧

MiniMax H3 `ImageToVideo` 工作流只有一个已绑定图片槽时，图片槽即可继续提交，不要求追踪不透明的中间节点或猜测 H3 图片编号。明确能解析的直接 `first_frame` / `last_frame` 关系仍按原有映射同步；无法证明的关系保留正文，不再因唯一图片槽显示“未声明 H3 实际图片消费顺序”。多个图片槽、首尾帧或其它关系仍沿用原有明确映射与谨慎处理。

不新增按钮、运行时校验、内容审核、生成拦截、重试或模型请求。已保存的提示词和成片不作改写。
