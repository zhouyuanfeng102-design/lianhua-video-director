# 莲华视频导演台 1.5.5 发布说明

剧情解析新增章节内的“文生视频 / 图生视频”选择。图生视频可以逐张上传参考图，让 AI 分别保存完整画面资料，再根据你的剧情要求扩写、转化为画面描述和解析资产，继续沿用现有提示词、分镜与视频制作流程。

## 使用方法

1. 选择当前章节，在原文输入位置点击“图生视频”。
2. 每次上传一张图片，可以连续添加多张；图片自动进入资产库，也可从已有资产选择。
3. 对每张图片点击“AI 识图”。在“查看与修改”中检查人物、地点、道具、可见动作、关系、风格、构图、光线、文字和不确定信息，按需要修正完整描述、补充说明和主体名称。
4. 剧情输入区可写“图1中的人物与图2中的人物互动”“背景改为夜晚酒馆”等要求。“我”可以设置为图中人物、已有人物或自定义角色；不同图中的同一主体可关联同一资料或另一张图。
5. 继续使用原有 AI 扩写、AI 画面描述转化、保存原文与解析并补全。启用图片的完整有效资料参与这些请求，解析后建立人物、地点、道具与来源图片的关联。
6. 后续导演台与视频任务沿用现有流程，相关参考图和人物对应一同传递，生成前仍可检查实际选图。

AI 识图使用 API 设置中的识图连接；扩写、画面转化与解析使用文本连接。图片与剧情要求可以采用不同背景或动作，明确的用户要求优先于原图的静态状态。图片提供可见外观依据，不把无法确定的姓名、关系或事件前因后果当成事实。

## 资料与保存

- 模式、参考图和“我”的设置按章节保存，同章两个模式共用剧情正文。
- 固定图号不因排序或移除而重新编号；“从本章移除”保留资产库原图。
- 原图保留完整像素，识别结果逐图保存；人工修订与识别历史保留，可单独重试失败图片。
- 识别中切换章节，结果归回发起章节；移除、换图或更新请求后，旧结果不会覆盖新资料。
- 修改参考资料会标记相关旧场景、分镜与计划，保留已有内容；画面转化来源记录当次图片及完整识别资料。
- 项目保存、备份及导出导入保留图号、识别资料和主体对应。旧章节默认文生视频。

实际视频模型仍有自己的参考图数量、角色用途和首尾帧限制，以现有接口及工作流支持为准。章节图号通过资产身份关联实际视频槽位，避免选图顺序变化导致人物错配。

## 验证与交付

章节与存储、单图识别、完整 AI 上下文、多人物参考图交接及视频请求的针对性模拟测试通过，相关既有章节、资产和剧情处理测试通过。隔离浏览器检查上传、逐图识别、切章、身份绑定、修订、固定图号、资产复用和重启保存通过；三类剧情操作及缺项补全的每次请求均完整携带两图资料、人工修订与叙述者设定。省略场景标题时，仅用于风格与构图的图片也准确关联到实际场景。未调用真实付费 AI 服务。

打包中的 TypeScript 检查与前端构建通过。最终便携包在独立数据目录中验证原生上传、原图字节一致性及本地保存恢复通过；清除测试浏览器镜像后，图生模式、剧情、固定图号和 1800 像素原图均从本地存储恢复，程序正常关闭，无运行错误。
