# 莲华视频导演台 4.8.3 发布说明

发布日期为 2026-11-19（亚洲/上海）。

私密部位特写、私密全身、四视图、三/四合一和私密五视图的生图资料都会带上当前视觉风格原文。没有选择画风时不另编一套。部位特写仍不因此写入整套外貌和服装。

已保存的私密图和旧提示词不改写。重新生成对应私密图时使用。

Windows x64 使用 `lianhua-video-director-4.8.3-windows-x64-portable.exe`。Android 使用 `lianhua-video-director-4.8.3-android.apk`，最低 Android 8.0（API 26）。

同版提供 Windows 与 Android 软件包、源码恢复包、安装说明、能力与验证记录、Windows 启动器及本说明。

签名与验证范围见 [4.8.3 能力与验证记录](能力与验证记录-4.8.3.md)。安卓安装与备份见 [安卓安装说明](../android-install.md)。
