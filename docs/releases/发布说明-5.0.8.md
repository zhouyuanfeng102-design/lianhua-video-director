# 莲华视频导演台 5.0.8 发布说明

2026 年 11 月 23 日 · Windows x64 便携版与 Android 正式签名版

## 版本定位

本版修复视频任务已经在 RunningHub 生成时，执行耗时停在 0分 0秒的问题。Windows 与 Android 共用这一处计时。

## 执行耗时在生成中继续走

任务显示「RunningHub 状态：running」，旁边却是「执行耗时 0分 0秒」。计时把一个无效的结束时间当成了终点。这个时间是 0，或者正好等于开始时刻，于是耗时被算成 0，并且不再往前走。

现在只有晚于开始时刻的完成时间才停表。生成过程中按开始时刻继续累计。排队中的任务仍然不计时。

本版未新增运行时校验、重试、按钮或模型请求。

Windows x64 使用 `莲华视频导演台-5.0.8-便携版.exe`。Android 使用 `莲华视频导演台-5.0.8-安卓版.apk`。维护者使用 `npm run deliver:5.0.8` 整理两端安装包、恢复源码与 SHA-256 交付清单。
