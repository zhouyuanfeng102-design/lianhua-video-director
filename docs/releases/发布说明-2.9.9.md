# 莲华视频导演台 2.9.9 发布说明

发布日期：2026-10-24（亚洲上海）。

## 文字请求共用成人叙事前缀

本版让全部文字模型使用同一套叙事前缀，用来把已经给出的成人虚构剧情写成当前任务要求的正文。生图提示词和微 NSFW 规则保持原样。

具体调整如下：

- 扩写、画面转化、解析、资料补全、分段、分镜、H3、Seedance 和单段请求，系统规则最前面是同一段前缀：叙事身份、成人情节直写、前置检测、历史身体记录和输出用词。
- 原文这一段已经是成人情节时，创作指导接在用户资料之后、原有输出协议之前。普通段落不展开这段指导。
- 中文稿使用直接身体词。英文稿保留 penis、glans、vulva、clitoris、nipple、anus、thrust、semen。人物已有的身体记录继续沿用，不另造器官，也不把规则名写进正文。
- 时长估算、导演分类、导演视觉、出镜名单和漫画识别只保留前缀，不写性过程。
- 固定规则仍在共享资料之前，本次变化的剧情、段号和修稿稿仍在后面。JSON 字段、H3 栏目和秒数合同保持原来的输出协议。

本版直接改文字请求的提示词组装，不新增运行时校验、内容审核、生成拦截、自动重试或模型请求。

## 版本定位

本版便携包为 `莲华视频导演台-2.9.9-便携版.exe`，恢复源码包、更新说明和 SHA-256 清单由交付脚本按同一版本生成。交付命令为 `npm run deliver:2.9.9`。

## 定向验证

已通过：`scripts/nsfwTextFraming.test.ts`、`scripts/textPromptServiceCache.test.ts`、`scripts/semanticSequencePlanner.test.ts`、`scripts/storyPreparation.test.ts`、`scripts/nsfwVideoActionPromptRules.test.ts`。这些测试使用模拟响应，不调用真实模型，也不提交视频生成。

`scripts/llm.test.ts` 里，分镜 NSFW 规则只注入一次、导演视觉不展开性过程，这两项随本次前缀通过。该文件里其余失败来自更早的断言与现行文案不一致，本次没有改那些请求的输出合同。

打包流程会执行 TypeScript 检查、Vite 生产构建和 Windows x64 便携包生成。本版不改变用户项目存档。

交付后请核对 `莲华视频导演台-2.9.9-SHA256.txt` 中的 SHA-256 清单。
