# 莲华视频导演台 0.5.17

## 版本同步与质量修复

- 本次版本同步将当前开发版号从 0.5.16 提升到 0.5.17，并在生成新包前完成整体检查和缺陷修复。
- 生成独立的 0.5.17 Windows 便携版、恢复源码、更新说明、版本启动脚本与 SHA-256 清单；0.5.16 及更早的历史交付文件继续保留，不被覆盖。

## 修复内容

- 连续性检查现在会把负数时间识别为无效镜头范围，避免错误时间轴被当成有效结果。
- 分镜历史即使包含异常导入数据，也会生成真正唯一的版本 ID，避免恢复或 A/B 版本互相覆盖。
- 移除视图上下文中的宽泛类型，使用完整 AppContext 契约统一连续性报告和生成任务类型；生产代码与测试代码均纳入严格类型检查。
- 渲染进程加入 Content-Security-Policy，Electron 41 控制台事件改用新参数格式并保留旧测试桩兼容；Vite 不再扫描 release、交付、output 和运行临时目录。
- 图像工作台在 1280×800 与 Electron 实际内容区 1269×765 下启用紧凑布局，生成按钮和资料控件不再裁切、重叠或被遮挡。

## 验证与兼容

- 已执行完整测试、生产构建、Windows Electron 桌面回归、多尺寸 UI 回归、依赖树检查和安全审计。
- 恢复源码包包含生产与测试 TypeScript 配置，解压安装依赖后可复现完整测试流程。
- 现有项目 schema、兼容迁移、视觉风格、长剧情三阶段流程和已生成提示词保持不变，旧项目继续非破坏载入。
