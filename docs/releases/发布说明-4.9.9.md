# 莲华视频导演台 4.9.9 发布说明

2026 年 11 月 21 日 · Windows x64 便携版与 Android 正式签名版

## 版本定位

本版修正多人相遇时的机位句。有人朝另一位在场的人走、停或看，并且这一镜要看见那个人时，摄影机站在行走者侧后方，或站在被看的人肩后。Windows 与 Android 共用这套分镜、重写和英译规则。

## 视线落在被看的人身上

第 3 版《槐树下的等候与走近》把摄影机放在两人斜前方，又把玉小刚写进画面纵深。斜前方是脸前，画面纵深是这台摄影机的远处，玉小刚落到她们脑后，脸冲向镜头。先沿路走向他，下一镜一切，看起来像背对他离开。

新稿直接使用这两句。要同时看见行走者和他们看的人时，摄影机在行走者侧后方，顺着胸口看，那个人留在前方的画面纵深里，胸口和眼睛朝向他。要看清脸上的反应时，摄影机在被看的人肩后，行走者留在镜头前方。下一镜保持这个前后，可以推近，或换到肩后。迎面后退跟拍只在被看的人留在镜头后方、不进入画面时使用。

## 已有项目如何使用

打开本版后，重新生成本段即可采用新机位句。已保存的成片和提示词不因升级改写。普通英译按源稿传递；源稿仍是“斜前方看、被看的人在画面纵深”时，英译改用侧后方这一句。

根因调查见恢复源码中的 `docs/research/h3-eyeline-and-blocking-2026-11-21.md`。本版未新增运行时校验、重试、按钮或模型请求。

Windows x64 使用 `莲华视频导演台-4.9.9-便携版.exe`。Android 使用 `莲华视频导演台-4.9.9-安卓版.apk`。维护者使用 `npm run deliver:4.9.9` 整理两端安装包、恢复源码与 SHA-256 交付清单。
