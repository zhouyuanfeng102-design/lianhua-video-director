# 莲华视频导演台 2.9.2 发布说明

发布日期：2026-10-21（亚洲上海）。

## 本次修复

修复提示词导演台切页和选择分段时的重复计算。原页面重新挂载后会重新读取分段的提示词来源与衔接状态，分段条还会遍历当前方案以外的分镜；Seedance 来源处理为读取逐镜资料，又构建一次完整的 H3 输入。

现在由父页面持有当前项目快照的显示计算结果，进入、离开再返回以及切换分段时按需复用。分段条只处理当前方案的分段；逐镜资料直接读取，不再触发无关的完整 H3 构建。

缓存随项目快照变化而替换，修改来源、人物、参考图、分镜或分段计划后会重新计算。缓存只用于界面显示，生成、异步保存与执行继续读取最新状态。已有剧情、提示词及任务不被改写；不新增运行时校验、内容审核、生成拦截、自动重试或模型请求。

## 定向验证

- `promptDirectorReadCache.test.ts` 通过：同一快照复用显示计算，来源、人物、参考图及计划变化后重新计算，保留原数据。
- `officialPrompt.test.ts` 通过：提取逐镜资料函数后，原 H3 输入及来源关联检查保持正确。
- `seedanceSourceTransport.test.ts` 通过：覆盖 Seedance 中英文来源、旧来源兼容及冻结提交快照，视频传输使用模拟响应。

`promptDirectorPerformanceUiQa.mjs` 使用隔离浏览器中的完整应用，载入 15 段、8 人物、每段约 6400 字中英文 Seedance 稿及上段衔接记录。点击到随后两帧的测量如下：

| 操作 | 修复前 | 修复后 |
| --- | ---: | ---: |
| 首次进入提示词导演台 | 1445 ms | 528 ms |
| 切换分段 | 1270 ms | 349 ms |
| 离开后再次进入 | 1286 ms | 123 ms |

再次进入时，Seedance 来源构建、稿件状态和衔接计算为零次；显示正文与保存稿完全一致。无空闲重复计算、页面异常或外部请求。报告位于 `output/playwright/prompt-director-performance/before.json` 与 `after.json`。这是含 React StrictMode 的开发环境合成数据测量，不代表用户项目或便携版的绝对耗时。

`pack:win` 内的 TypeScript 检查、Vite 生产构建和 Windows 便携包打包通过。构建仍输出现有循环分块及大分块警告；便携包在隔离数据目录中启动并打开提示词导演台通过，无页面或渲染异常、无外部请求。报告：`output/playwright/packaged-startup-2.9.2-mRJtm2/report.json`。首次入口检查误用了视频导演台的标题定位条件，更正测试定位后通过；未因此修改产品。

## 使用与交付

版本按十进位规则从 2.9.1 升至 2.9.2，历史版本与交付文件保留。保存项目并退出旧版后，运行新便携版；保留 EXE 旁完整的“莲华视频导演台数据”文件夹。
