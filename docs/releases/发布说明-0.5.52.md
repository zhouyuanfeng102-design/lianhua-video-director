# 莲华视频导演台 0.5.52 发布说明

## 版本定位

0.5.52 修复最终视频提示词结构错误被直接上报、没有先让 AI 自己返修的问题。历史 0.5.51 及更早交付文件保持不变。

## 最终视频提示词结构自动返修

- 当首次转换结果的镜数、时间轴和六字段看似完整，但主体缺少“正在 [动作链]”、缺少有效主体名或无法同步到分镜时，不再立即把错误交给用户处理。
- 软件会把本地校验器给出的精确失败原因、上一次不合格候选、逐镜剧情证据和受保护视觉风格原子作为不可信数据，交回同一文本模型自动返修一次。
- 返修请求使用独立的结构修复硬契约，要求保持镜数、精确时间标签、剧情事实、人物身份、原对白、因果和风格原子不变，只重建合格的完整逐镜正文。
- 返修结果必须再次通过与首次结果完全相同的时间轴和主体动作结构校验，不能因为进入返修分支而绕过验证。

## 数据与失败边界

- 自动修复只由 AI 完成，不由本地代码拼接或补写“正在 [动作链]”。
- 本地结构草稿不会被保存为最终视频提示词；返修仍不合格、返回空内容或拒绝说明时，原有结果保持不变。
- 本版没有增加本地内容关键词拦截，也没有增加年龄限制措辞。

## 发布验证结果

- `npm test` 完整通过，包含最终视频提示词结构自动返修、时间轴同步、工作流、严格类型、图像链路、安全与发布脚本回归。
- `npm run build`、`npm run test:ui`、`npm run test:ui-workflow` 和 `npm run test:ui-sequence` 通过；1120×720、1280×720、1280×800 三个视口无重叠、溢出或控制台错误。
- `npm run pack:win` 通过；0.5.52 便携包在隔离数据目录完成版本、schema 17、保存重载、恢复点、加密能力及三个视口冒烟验证。
- 交付脚本与 SHA-256 清单在生成后再次核对，0.5.51 及更早历史交付文件不覆盖。
