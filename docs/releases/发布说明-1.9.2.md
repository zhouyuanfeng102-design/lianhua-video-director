# 莲华视频导演台 1.9.2

发布日期：2026-10-11

## 参考图分镜恢复规则转换

修复选择参考图后，普通生图规则和“分镜单帧”等分类预设被跳过的问题。导演台首尾帧、逐镜生图、自定义图片数量，以及图像工作台勾选镜头生成，统一先由文本模型按当前所选生图规则和分类预设转换镜头文字，再把最终图片提示词与选定原图一起提交给生图 API。微 NSFW 保留对应附加规则。

首尾时刻、景别和裁切约束进入转换输入，最终提示词以转换出的具体画面为主体，不再前置本地拼接的首尾帧制作说明。OpenAI 自然语言请求继续附带必要的参考图用途与顺序信息；标签格式保持其对应协议。负面提示词按所选规则和预设保存并传递。

参考图原始像素单独冻结，仅提交给生图接口；任务保存实际规则、分类预设、版本、格式、转换来源及系统规则。文本 API 未配置、转换失败或返回空内容时停止该任务，不会把未转换内容直接送去生图。

## 缓存与重新生图

升级参考图提示词缓存标识，旧版未经转换的提示词不再复用；所选规则、分类预设内容或身份依据变化会触发重新转换。已有历史记录保持原样，不补写未实际执行的规则信息。

有来源镜头的参考图任务重新生图时，从当前镜头重新转换，并保留原始参考图快照、顺序、API 和尺寸。旧任务若没有可恢复来源且提示词未经转换，或原图快照缺失，会提示重新创建任务，避免继续发送旧制作说明或偷偷替换原图。

版本按十进位从 1.9.1 升至 1.9.2，历史版本文件继续保留。使用新版后主动创建或重新生成任务，旧历史任务不会自动调用 API。

## 针对性验证

通过参考图生成控制器、缓存与转换输入、排队快照、当前镜头重新生图、参考图任务保存与恢复、通用重新生图及原按钮分流测试。覆盖普通规则和分镜单帧、首尾帧、自定义数量、标签格式、规则记录、负面提示词、转换失败阻断、原图冻结与顺序、取消及项目切换。请求使用模拟接口，没有调用真实付费 API；未重复运行整套 UI 回归。
