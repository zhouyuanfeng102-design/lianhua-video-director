# 莲华视频导演台 5.1.0 发布说明

2026 年 11 月 24 日 · Windows x64 便携版与 Android 正式签名版

## 版本定位

本版取消本机视频处理「同时最多 2 个」的名额。抽尾帧、保存成片可以一起进行。已经停在「自动衔接暂停」的后段，升级后点一次「重试尾帧衔接」。Windows 与 Android 一起交付；这条名额只存在于电脑端的本地处理。

## 本地视频处理

电脑端抽尾帧和保存成片时，不再因为已经有 2 个本地任务就拒绝下一个。同一条任务重复提交仍然会被拦住。

RunningHub 上已经在生成的任务不受影响。这个上限不是上游返回的。

Windows x64 使用 `莲华视频导演台-5.1.0-便携版.exe`。Android 使用 `莲华视频导演台-5.1.0-安卓版.apk`。维护者使用 `npm run deliver:5.1.0` 整理两端安装包、恢复源码与 SHA-256 交付清单。
