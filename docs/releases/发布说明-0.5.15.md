# 莲华视频导演台 0.5.15

## 28×28 视觉风格与可编辑预设

- 视觉风格库扩展为 28 种风格，覆盖写实、动画、插画、类型片等方向，并加入“末日废土”等可直接选择的明确风格。
- 28 种视觉风格与 28 个规则预设一一对应，形成 28×28 的同名映射；每个预设都可在规则中心继续编辑，不是只用于展示的标签。
- 每个预设提供可执行的具体锚点，包括主辅色与色温、表面材质与质感、主光/辅光/轮廓光、天气与空间氛围。锚点会进入完整提示词，也会下沉到逐镜锚点，帮助同一项目保持连续视觉语言。
- 用户选择视觉风格时，系统会自动匹配并切换到该风格一一对应的预设；自动切换完成后，用户仍可手动覆盖。手动选择优先，后续生成不会擅自改回自动结果；加载旧项目不主动联动。

## 兼容与迁移

- 存储结构升级到 schema 8。旧项目在载入时执行非破坏迁移，保留已有规则、提示词、分镜与用户选择；未使用新字段的项目继续兼容。
- 动画类风格保留动画语汇；选择无风格（`no_style`）时保持中性，不会被强行注入摄影写实、真实材质或其他写实化要求。
- 迁移只补充新版视觉风格所需的缺省数据，不覆盖用户已经编辑的完整提示词、逐镜锚点或手动预设。

## 版本同步与交付

- 本次版本同步将当前开发版号从 0.5.14 提升到 0.5.15，并生成独立的版本化便携包、恢复源码、更新说明、启动脚本与 SHA-256 清单。
- 0.5.14 的历史发布与交付制品继续原样保留；0.5.15 使用新的文件名，不覆盖旧版本文件。
