# 莲华视频导演台 3.4.0 发布说明

发布日期：2026-10-28（亚洲/上海）。

## 视频尾帧链不再等待项目保存

- 上一段视频文件写入本地并登记资产后，立即开始尾帧抽取和下一段任务。
- 不再等待整库自动保存或视频结果断点写入完成。
- 结果断点继续后台写入；ZIP 返回多个视频时仍要求明确选择来源。
- 视频下载尚未完成或下载失败时，后续段仍保持等待。
- 尾帧准备及收费请求的独立断点仍作为各自操作边界。

## 版本定位

本版 Windows 便携包为 `莲华视频导演台-3.4.0-便携版.exe`。构建命令为 `npm run pack:win`；生成到项目内 `交付` 目录的命令为 `npm run deliver:3.4.0`。已有 3.3.9 及更早交付文件保留。

交付目录包含恢复源码 ZIP、更新说明、启动器和 SHA-256 校验清单。
