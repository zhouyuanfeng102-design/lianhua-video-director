# 莲华视频导演台 2.6.0

发布日期：2026-10-17。

## 修复 Seedance 英文翻译占位符

此前 Seedance 的英文翻译路径仍可能把中文原名、对白等内容替换为内部占位符后交给模型，模型未正确保留这些标记时，英文交付会失败。本版发送完整、未遮蔽的中文原稿，让模型在完整上下文中翻译描述，并保留原名、原始对白、参考引用和时间范围。

正常翻译只进行一次请求。返回结果确实出现内部占位符，或引用、对白、时间范围等交付内容损坏时，最多追加一次修复请求；修复后仍不满足要求则报告失败，不循环重试。API 服务错误、网络失败和超时不因这项修复自动重试。

英文失败保留已经保存的中文结果，可以单独补英文，无需重新生成公共分镜和中文。2.5.9 的首次生成来源一致性、有效中文衔接推进与持久报错记录继续沿用。

## 正确展示新段生成状态

新分段已经开始生成但尚未返回结果时，结果区显示正在生成。避免仅因当前没有提示词结果，就把仍在运行的任务显示为已中断。失败、停止和运行状态按实际任务状态区分。

## 已有项目与本地交付

已有项目、中文稿、提示词历史和任务内容保留，不自动重跑历史任务。英文失败的段可主动使用补英文入口重试。

版本按十进位规则从 `2.5.9 → 2.6.0` 更新。交付命令为 `npm run deliver:2.6.0`，便携包为 `莲华视频导演台-2.6.0-便携版.exe`，同时提供恢复源码、更新说明、启动器及 SHA-256 文件。2.5.9 及更早历史文件保留。本次为本地交付，不代表已发布到网络下载页。
