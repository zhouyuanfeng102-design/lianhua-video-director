# 莲华视频导演台 2.3.3

发布日期：2026-10-15。

## 修正 2.3.2 删除批次后仍无法重新生成

2.3.2 解决了停止追踪后无法删除批次的问题，但遗留了另一处判断：批次删除后，任务列表已经显示 0，隐藏的已停止未知提交记录仍被界面和任务引擎当作进行中。再次手动生成相同片段时，因此出现“待提交 0、跳过 3”；“重新生成已有成功任务”的开关只针对成功记录，也不能解除这类误拦。

2.3.3 统一界面预检与任务引擎的判断，让已删除且安全停止的历史任务退出新批次去重。2.3.2 已删除的历史记录自动兼容，无需找回后再次删除。

## 原任务证据保留，手动生成创建新任务

原提示词、参考图、参数、提交边界、断点与凭据保持原样。删除历史批次或重新启动软件不会自动提交，不会取消远端任务，也不将原未知提交记录改成成功或失败。

用户主动生成仍经过原费用确认，确认后创建新任务与新 ID。原请求是否被上游受理、运行或扣费，仍以上游可核对记录为准；本次新生成不会证明旧请求已经失败或退款。

## 保留仍需保护的任务

正在运行、下载、取消中、待取回结果，以及续跑占位尚未释放的任务继续受到保护，不能通过删除历史记录绕过原有检查。保留原任务证据供查询和核对，不自动重放旧请求。

## 兼容与交付

版本按十进位规则从 2.3.2 递增至 2.3.3。2.3.2 及更早历史版本、发布说明与交付文件保留，不覆盖、不删除。已有项目、提示词、参考素材和任务参数不自动改写。

便携包：`莲华视频导演台-2.3.3-便携版.exe`。交付命令：`npm run deliver:2.3.3`。实际构建与交付状态以下方验证记录为准。

## 验证结果

- 批次候选与删除专项通过：旧版已删除且安全停止的 HTTP 524 记录不再被判为“已在队列”，相同原稿可以重新选入；仍在运行、取消中、待取回结果及未释放续跑占位继续拦截。
- 任务引擎单项和三项专项通过：删除、重启、撤销不自动提交，原提示词、参考图、参数、提交边界、断点及凭据保留；用户手动生成创建新 ID，每项仅增加一次模拟 POST，新活跃任务继续阻止重复提交。三项用例初次因模拟设置仍为顺序执行而等待超时，改为显式并发后通过。
- 真实应用界面专项通过：删除 3 项旧任务后，视频任务数为 0；导演台显示“已选 3 段 · 待提交 3 段 · 跳过 0 段”，成功项重新生成开关两态和完整重开均正确。费用确认前没有生成请求，主动确认后恰好 3 次模拟 POST 和 3 个新任务 ID；活跃任务重新打开后仍阻止重复提交，旧记录不变。
- 界面检查使用完整 App、控制器、任务引擎与保存 Worker，最小 Vite 配置和独立健康检查解决前一轮测试服务启动阻塞；使用隔离项目和本机模拟接口，未读取用户项目或发起真实付费请求。
- Windows 64 位便携版打包通过，包含 TypeScript 类型检查和 Vite 生产构建。包内版本为 2.3.3，66 个 dist/electron 文件与当前构建内容一致；交付附便携 EXE、恢复源码、更新说明、启动器与 SHA-256 清单，历史交付保留。
