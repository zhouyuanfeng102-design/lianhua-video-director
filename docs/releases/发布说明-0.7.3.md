# 莲华视频导演台 0.7.3 发布说明

## 版本定位

0.7.3 增加人物转化形态的独立资料与引用，避免同一人物的原始形态和转化后形态混用。

- 全文 AI 分析根据剧情区分人物原始形态，以及性别、外貌、物种、身体结构等转化形态。
- 资料名称采用“人物·形态”；每种形态独立保存资料、ID 和参考图。
- 场景、分镜与最终 H3 根据具体形态引用对应人物资料及参考图，保留现有 H3 格式。
- 普通换装、表情变化不拆卡；旧项目未变化人物保持兼容。
- 形态判断、复核与修复由 AI 完成，不增加本地剧情语义门禁。

当前便携包：`莲华视频导演台-0.7.3-便携版.exe`。

## 构建与交付

```powershell
npm run test:character-variant-ui
npm run test:release-review
npm run pack:win
npm run deliver:0.7.3
```

本轮已完成上述测试、生产构建、便携版打包和交付。另已通过 `npm run test:prompt`、`npm run test:llm`、`npm run test:app-effects`、`npm run test:official-prompt`、`npm run test:character-variants` 以及隔离数据目录的便携版启动烟测；烟测确认版本 `v0.7.3`、资料持久化、数据目录隔离和无控制台错误。交付脚本生成便携 EXE、恢复源码、更新说明、版本专属启动器及 `莲华视频导演台-0.7.3-SHA256.txt`；SHA-256 以交付目录中的实际清单为准。

遵守十进位版本规则，`0.7.2 → 0.7.3`。0.7.2 及更早版本的文件不重编号、不覆盖、不删除；正式项目与历史生成结果不自动重跑。更新前请保存并关闭旧版，避免同时使用多个版本写入同一项目目录。
