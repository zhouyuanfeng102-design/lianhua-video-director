# 莲华视频导演台 2.2.2

发布日期：2026-10-14。

## 提示词正文空间恢复

提示词导演台的右侧结果面板在展示目标格式、长剧情状态、格式切换和语言切换后，上方操作区占用过多高度，正文可见区域被压缩。

本版重新排列结果标题、操作入口、页签、状态、格式、语言及复制按钮，缩短操作区的纵向占用。字号和间距随结果面板的可用宽度调整，提示词正文优先使用剩余高度，并在自己的区域内滚动。

提示词导演台顶部的章节工具栏、目标格式、当前提示词及“剧情与输入”流程也采用紧凑合排，缩短整段顶部区域的高度，并按可用空间调整字体和间距。单段/长剧情模式与全片导演、AI 分段、单段导演等入口继续可用，其他页面的章节工具栏保留原布局。

单段与长剧情共用这套结果布局。Seedance / MiniMax H3 已有稿切换、中文与英文切换、复制、重试、参考图、分镜编辑和发送视频导演台等入口继续保留，较多操作仍通过“更多”打开。

本轮调整提示词导演台顶部与结果面板展示，不改变已有提示词正文、格式生成流程、项目保存结构或历史视频任务。升级后继续读取原数据目录；2.2.1 的生成前格式选择和失败续跑功能沿用。

## 验证记录

已对构建后的 2.2.2 完成一次针对性界面验证，覆盖 1996×1248、1366×900、1120×720 三种窗口，100% / 125% 字体，以及单段、19 段长剧情导演和全片规划。

顶部章节至工作区的高度：单段和长剧情导演从 235–254px 降至 144–151px，全片规划从 224–243px 降至 123–129px。右侧操作区从 166–264px 降至 74–112px，提示词正文从 160–360px 增至 279–912px。布局测量包含 18 个顶部场景与 24 个 H3 / Seedance 结果场景，小窗口控件未发生遮挡或重叠。

格式、语言、复制、更多菜单、参考图切换和正文独立滚动检查通过，已保存稿件未改写；无浏览器运行错误、上游请求或媒体生成任务。检查报告为 `output/playwright/prompt-header-2.2.2-final/report.json`。

`npm run pack:win -- --config.directories.output=.pack-release-2.2.2` 成功完成类型检查、生产构建及 Windows 便携打包；包内版本为 2.2.2，全部 34 个构建资源与当前构建一致。交付文件随附 SHA256 清单。
