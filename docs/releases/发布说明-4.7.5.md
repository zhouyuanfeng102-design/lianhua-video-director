# 莲华视频导演台 4.7.5 发布说明

发布日期为 2026-11-18（亚洲/上海）。

提交带人物图的视频时，这张图上的尾巴、兽耳、翅膀、角和爪只留在已绑定的那一个姓名身上。其他已写姓名的人保持正文为他写的头、躯干和附肢。朱竹清的猫尾留在朱竹清身上，宁荣荣不接过这条尾巴；小舞仍留自己图上的兔耳。

已保存的成片、提示词和图片槽不改写。下次提交或更新参考图时使用这次写法。

Windows x64 使用 `lianhua-video-director-4.7.5-windows-x64-portable.exe`。Android 使用 `lianhua-video-director-4.7.5-android.apk`，最低 Android 8.0（API 26）。

同版提供 Windows 与 Android 软件包、源码恢复包、安装说明、能力与验证记录、Windows 启动器及本说明。

签名与验证范围见 [4.7.5 能力与验证记录](能力与验证记录-4.7.5.md)。安卓安装与备份见 [安卓安装说明](../android-install.md)。
