# 莲华视频导演台 4.6.4 发布说明

发布日期：2026-11-14（亚洲/上海）。

## 脱掉的是已经穿在身上的那一件

脱、扯、解、滑落作用在这个人此刻已经穿着的那一件上。这一件来自人物资料里的衣服，或上一镜已经穿上的那一件。手里的衣领是这一套的衣领，滑下去的布是这一套的同一块布。

原文里的外袍、外套、外衣、中衣、内衣，如果不是这件已经在身上的衣服，就写成这件衣服，不另加一层。露出的是这套衣服里面本来就有的下一层。资料里没有下一层，就露出这套衣服松开后本来会露出的身体。

原文明确先穿上、披上某件资料里没有的衣服时，那件从穿上的动作出现，之后才能被脱掉。人物资料里本来就有的袍子仍留在那个人身上。

已保存的成片、分镜和提示词不改写。下次重新生成分镜或提交视频时按这个写法。

## 交付

- Windows：`莲华视频导演台-4.6.4-便携版.exe`。
- Android：`莲华视频导演台-4.6.4-安卓版.apk`，最低 Android 8.0 / API 26。
- 4.6.3 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.6.4`。分段、分镜和视频提示词在两端共用，EXE 与 APK 一起交付。
