# 莲华视频导演台 1.2.1 发布说明

日期：2026-10-03。

## 版本定位与修复内容

修复 RunningHub 旧视频任务的凭据缺失后，点击继续仍发送无鉴权图片上传请求，导致 `HEADER_API_KEY_NOT_FOUND` 的问题。

- 继续准备原任务、继续批次和恢复远端结果统一使用严格匹配的原连接恢复凭据。
- 排队后段在首次提交准备阶段也能恢复缺失凭据，保留原任务 ID、提示词、图片、参数和前后段关系。
- 缺少可用密钥时先在本地停止并完整显示处理说明；不会发送匿名 RunningHub 请求。
- 批次续跑在调用 AI、抽帧和取消旧准备队列前检查凭据；恢复不了时保留可恢复的原链。
- 已保存的有效任务密钥继续沿用；不从不同主机或不同工作流借用密钥。允许匿名访问的通用 API 和 ComfyUI 保持原行为。

## 继续这次视频任务

1. 等旧版保存完成后关闭，启动同一交付目录中的 `莲华视频导演台-1.2.1-便携版.exe`。
2. 打开项目 `9464944946`，进入“生成任务 → 视频任务”。
3. 在最新失败批次的第 1 段任务卡，点击 **“继续准备原任务”**。
4. 软件恢复原连接密钥后继续上传和首次提交；后续段仍沿原批次等待并继续，无需另建批次。

本次已只读核实该任务冻结连接与当前对应 RunningHub 配置完全匹配。更新包沿用原数据目录，不修改历史任务或自动提交生成；实际云端生成结果以接口返回为准。
