# 莲华视频导演台 4.0.0 发布说明

发布日期：2026-11-07（亚洲/上海）。

## 中文台词按原话念

下次生成 H3 提示词时，中文台词写成 `<d>[中文] 原话</d>`。这句话只出现在这个标签里一次。标签外只写是谁在说、声线和嘴张开。没说话的人嘴保持闭合。

英文稿把 `<d>[中文]…</d>` 整段按源稿原字复制。语言标签写成 `[中文]`，不改成 `[Chinese]` 或 `[English]`，也不把这句话的意思再写到标签外面。

已保存的提示词和已经生成的视频保持原样。要听到原来的中文，需重新生成该段。

## 交付

- Windows：`莲华视频导演台-4.0.0-便携版.exe`。
- Android：`莲华视频导演台-4.0.0-安卓版.apk`，最低 Android 8.0 / API 26。
- 3.9.9 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.0.0`。本版是共享提示词规则，EXE 与 APK 一起交付。

## 验证

H3 对白格式、英文翻译说明和表演翻译规则检查已通过。打包流程自带类型检查和前端构建。未把已有成片重新生成。
