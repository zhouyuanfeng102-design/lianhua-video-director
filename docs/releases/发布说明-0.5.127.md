# 莲华视频导演台 0.5.127 发布说明

## 版本定位

整理视频生成 API 设置与 ComfyUI 视频多工作流管理；修复 AI 完整分镜结果被本地原文覆盖检查否决、错误说明又被误归为上游未知错误的问题。

## 视频生成设置与工作流库

- 主页面按连接、接口配置和工作流库分卡显示，常用设置不再与大量映射字段和 JSON 编辑器混排。通用视频 API 的请求模板、认证与结果映射、图片上传和取消设置移至高级设置窗口。
- ComfyUI 视频提供独立“管理 Workflow”窗口，支持新建、复制、重命名、保存、设为当前、删除和 API JSON 导入/导出。导入追加一份存档，不覆盖已有工作流；选择编辑某项不会自动改变实际生成使用的当前工作流。
- 管理器按基本信息、节点映射、参数设置和 API JSON 分页。修改某个原始参数仅替换目标值，保留其它输入、连接和大整数种子；不会因编辑一个参数而重写整份工作流。
- 保存 JSON 与重新识别映射分开，已有手动映射不被静默重置。离开未保存草稿与删除工作流均需确认；空草稿不能误设为可用工作流。
- 导出的是 ComfyUI API JSON。软件内设置的参考图用途等自定义映射保存在本地工作流库，不能用单份 API JSON 导出替代完整恢复备份。
- 既有接口配置、工作流存档及已提交任务的冻结快照保留。修改设置不自动发起生成，也不修改正在运行任务的原始参数。

## AI 全文分析与同请求自检

- 旧版“AI 分镜未覆盖全部原文”的结论来自本地原文切片覆盖检查，不是模型自行判定。错误格式化又将技术片段误归为“服务返回了未识别的错误”，混淆了真实来源。
- 完整分镜生成现在直接提交完整剧情，让 AI 自行理解、提取镜头并检查剧情覆盖、人物、对白和连续性，在同一次请求内完成修正后返回最终方案。
- 不再把本地切片覆盖率、摘录匹配或语义质量疑点当作拒收可读结果的理由；也不因为这些疑点隐式增加一次 AI 返修调用。AI 自检说明缺省或提示需要复核，不等于本地生成失败。
- AI 母分镜的动作、摄影、光影、声音和明确对白按返回内容排版，不再套本地模板删改。手动改写无法证明原文来源时保留新内容并清除不可靠的来源标签，不冒认来源、不删除素材。
- 后续长剧情分段沿用完整 AI 母镜与全文，可接收 AI 自己组织的分段内容和连续性说明，不要求原文摘录逐字覆盖本地切片；实际镜头重复、遗漏、乱序与无效时轴仍作为数据结构问题处理。
- 仍保留真实 HTTP/网络失败、空输出及无法读取结构等运行边界。只有必要的结构错误会请求同一文本 API 最多修复一次，明确说明是“本地结构读取失败”，不冒充剧情内容判断或上游未知错误。
- 失败保留已有结果；取消、过期响应和跨项目写回保护继续有效。宽松接收不保证 AI 内容必然准确，生成后仍可人工核对和编辑。
