# 莲华视频导演台 0.5.138 发布说明

发布日期：2026-09-17

## 版本定位

整理RunningHub节点配置界面：区分接口外层运行参数与工作流内部输入字段，按用途显示常用候选，避免提示词和参考图下拉框默认混入整张工作流的全部内部字段。

## 问题原因与修复

- 云端文档中的`addMetadata`、`nodeInfoList`、`instanceType`、`usePersonalQueue`、`retainSeconds`和`webhookUrl`是6项接口外层参数，不是6个可绑定的内部节点。`nodeInfoList`内才放具体节点的覆盖值。
- 原界面将读取到的内部标量字段统一作为可选项，一个节点可能包含多个字段，导致用户需要从大量无关字段中寻找提示词和图片输入。
- 提示词、参考图片与常用参数按用途显示候选，增加搜索与高级全部字段入口。候选分类只是查找辅助，不自动绑定节点，不把节点数量限制为6，也不凭空生成节点信息。
- 已有映射保持可见；筛选、搜索和查看高级字段不改变保存的请求及映射。节点目录继续独立于请求，只有明确绑定或编辑字段才加入对应覆盖项。
- 保留只读云端结构读取、节点JSON导入、手动添加、工作流隔离与过期响应保护，不通过生成请求探测节点。

## 使用方式

1. 打开“API 设置 → 视频生成 → RunningHub 云端 → 管理云端工作流”，选择要编辑的工作流。
2. 在“提示词与图片”中查看对应用途的常用候选，可搜索实际节点名称、ID或字段名。
3. 需要特殊内部字段时，主动切换到高级全部字段再选择；不要把接口运行选项当作提示词或图片节点。
4. 核对映射与请求后保存，再按需设为当前。浏览、搜索和筛选本身不会提交视频生成任务。

## 兼容与数据

保留已有工作流、映射、运行选项和任务快照，不重写历史剧情、提示词、参考图或视频，不重新提交历史任务。导演自定义要求、RunningHub多输出ZIP接收与原任务恢复等功能继续保留。现有项目、素材及0.5.137和更早交付文件不删除、不覆盖。
