# 莲华视频导演台 3.7.7 发布说明

发布日期：2026-11-06（亚洲/上海）。

## 读取网页不再弹出窗口

点「读取网页」只在后台读取应用页上的槽位和参数，不再打开浏览器窗口。

登录和验证码仍通过「登录 / 切换」打开窗口完成。已保存的登录状态继续用于后台读取和之后的生成。

## 版本定位与交付

Windows x64 便携包：`莲华视频导演台-3.7.7-便携版.exe`。构建命令为 `npm run pack:win`，交付命令为 `npm run deliver:3.7.7`；3.7.6 及更早历史版本文件保留。交付目录同时提供恢复源码、更新说明、启动器与 SHA-256 清单。

## 验证

- Windows x64 便携包：`npm run pack:win`
- 交付文件：`npm run deliver:3.7.7`

已有项目、提示词和成片不作改写。
