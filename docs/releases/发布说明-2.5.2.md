# 莲华视频导演台 2.5.2

发布日期：2026-10-16。

## 连续场面先于摄影与身份展示

将空间与动作规则改为统一的源头生成顺序：剧情事实、连续场面、人物行动及末态、摄影机、实际可见范围、必要身份信息。适用于交谈、行进、观察、追逐、接触与战斗，不硬编码人物或剧情。

在现有调用中记录可选场面调度，分别保存人物位置、身体朝向、注意对象、运动路径和终点。同一场面跨段与切镜继承稳定的场面、参与者和动作阶段；后退或受力倒飞不隐含转身，特写不重新安排人物。新字段只保存模型的编排选择，不作本地几何裁决。

摄影只观察已经成立的事件。完整身份资料保留为辨认依据，逐镜先确定时刻、机位、遮挡和裁切，再展开实际可见部分。允许有依据的正脸、侧背、反打、环绕、回头及背身动作。

## 下游表达沿用已采用的场面

普通视频转换、H3和Seedance表达、英文及静帧规划使用已采用的场面与镜头，减少原始导演口号、未采用运镜偏好和人物动作习惯反复参与调度。H3按真实参考模式选择基础三节或全参考六节；提交时不自动改写已保存稿。

本次不新增内容校验、审核调用或自动重试，不迁移用户项目、不重写历史提示词，也不提交收费视频生成。场面记录随新稿保存，版本快照与恢复配对保存；恢复旧版本不会借用较新稿件的场面。
