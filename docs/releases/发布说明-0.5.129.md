# 莲华视频导演台 0.5.129 发布说明

发布日期：2026-09-15

## 版本定位

本版调整项目库的创建时间展示、排序及旧数据兼容处理，并取消最终视频提示词转换中残留的本地人物名单硬拦截，改由 AI 根据全文自行检查并修正内容。

## 项目库按创建时间排列

- 项目库改为按项目创建时间从新到旧显示，最近创建的项目排在前面。
- 卡片明确标注“创建于”，使用项目保存的创建时间，不再显示最后保存时间而让用户误认为是创建时间。
- 编辑、生成、自动保存和切换项目不再因为更新时间变化而改变项目库顺序。
- 旧项目缺失或包含非法创建时间时显示时间未知；不以本次打开、保存或迁移时间冒充原始创建时间。已有合法创建时间保留。

## 最终提示词由 AI 全文自检

- 移除最终提示词转换中的本地 `allowedSubjects` 人物名单硬门禁，不再因 AI 使用的称谓未与本地名单逐项匹配而拒收可读结果。
- 完整原文与现有上下文交给 AI，在同一次转换请求内自行检查人物、对白、剧情覆盖与连续性并修正；不使用本地规则代写内容，也不因本地语义疑点额外发起一次隐藏请求。
- 后续使用已确认母稿时，不再用本地对白复判触发隐式重试，避免反复转换已确认内容。
- 保留真实 HTTP/网络失败、空返回和必要的结构错误。只有结构无法使用时才允许同一文本 API 最多进行一次携带全文与完整候选的修复；失败不覆盖已有结果，取消和跨项目过期写回保护保留。
- 旧版人物名单检查相关日志明确标明来源为本地校验，不再误写成上游服务返回的未知错误。

## 保留范围与验证

本次不批量重写已保存的剧情、提示词、资产或生成任务，不删除项目，也不自动重新生成历史结果。原视频 API、ComfyUI、RunningHub 云端配置及历史工作流继续保留。

新增 `test:project-library`，用于项目库排序与创建时间边界回归，并加入完整 `npm test`；最终提示词转换补充人物称谓、全文自检、母稿复用、结构修复与错误归属回归。完整测试、真实界面、构建与便携包启动的结论以本轮实际执行记录为准；本说明不预先宣称尚未执行的检查已通过。验证使用隔离数据与模拟接口，不调用收费生成接口，也不以模拟响应代替真实模型质量验证。

## 构建与交付

```powershell
npm test
npm run test:release-review
npm run pack:win
npm run deliver:0.5.129
```

交付包为 `莲华视频导演台-0.5.129-便携版.exe`；配套生成恢复源码、更新说明、版本专属启动器和 SHA-256 校验文件。哈希以实际构建后生成的 `莲华视频导演台-0.5.129-SHA256.txt` 为准，不预填未生成文件的校验值。

请先保存并完全关闭旧版，再启动新版，避免多个版本同时使用同一数据目录。0.5.128及此前的便携包、恢复源码、SHA-256文件、历史说明、专属启动器及正式项目数据保留，不自动清理旧包。
