# 莲华视频导演台 0.5.21

## 版本同步

- 当前开发版由 0.5.20 递增为 0.5.21；0.5.20 及更早历史交付文件继续保留，不会被发布脚本覆盖。
- 现有项目数据、导演模式、输入模式与提示词生成逻辑保持兼容，本次仅调整顶部模式选择区域的视觉密度。

## 导演台界面压缩

- “导演模式 / 输入模式”卡片由纵向标题、按钮、说明的三层布局改为标题与按钮同排，常规 1430×894 工作区下总高度由约 79px 降至约 37px，接近原高度的一半。
- 智能导演的判断说明仍保留在紧凑第二行；窗口高度不超过 760px 时隐藏辅助说明，进一步释放下方导演参数空间。
- 卡片内边距、间距和按钮高度同步收紧，按钮高度调整为 22px；粉色与紫色分组、激活态、边框和渐变保持不变。

## 自适应文字与图标

- 卡片标题、模式按钮文字及图标统一使用 `clamp()` 随可用窗口宽度在可读范围内缩放。
- 1040×760 紧凑窗口下，“单张/多张参考图”等最长按钮文字保持单行，无横向或纵向裁切。
- 纯文字、参考图、图片 + 故事、智能导演和九宫格的切换逻辑及选中态保持不变。

## 回归与交付

- 样式回归覆盖紧凑模式卡片的字体下限、按钮高度和两列布局；生产构建继续执行 TypeScript 与 Vite 校验。
- 0.5.21 交付包含 Windows x64 便携版、恢复源码、更新说明、版本启动器、无版本启动器与 SHA-256 完整性清单。
