# 莲华视频导演台 3.3.4 发布说明

发布日期：2026-10-27（亚洲/上海）。

## 成片落地后即记为成功

云端文件下完以后，任务要等整份项目记录写完才从「生成成功，正在保存」改成已完成。项目一大，这一步会停很久，批次就一直是运行中、成功 0。

现在文件进入视频文件夹后，马上记为已完成，后一段可以继续。项目记录在后面写。还没写完时，卡片写「成片已在视频文件夹，项目记录仍在保存」，不再算运行中，也不再提供停止本任务。

已经下完、还停在保存里的这一条，用 3.3.4 打开后会按已完成显示。不要点停止，也不要重新生成。

本版便携包为 `莲华视频导演台-3.3.4-便携版.exe`。交付命令为 `npm run deliver:3.3.4`。3.3.3 及更早交付文件继续保留。
