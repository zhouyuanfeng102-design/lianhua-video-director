# 莲华视频导演台 0.9.3 发布说明

发布日期：2026-09-29

## 版本定位

V0.9.3 修复 GPT Image 2.5 微 NSFW 普通全身图在横向 3:2 画幅中偶发身体拉宽、人物过度撑满画布，以及原服装过厚导致微 NSFW 效果不足的问题。

## 本版修复

- 保留普通全身图的 3:2 横向画幅选择，不把全身图强制改成方图或竖图。
- 横向 3:2 全身图改用环境全身构图：人物从头到脚完整居中，但不为填满横向画布而放大或拉伸；左右保留连续的雨雾、庭院、室内、湖面或对应场景留白。
- 调整全身构图合同，删除容易诱导模型把人物撑满画面的“完整身体轮廓占据画面主要区域”措辞，继续保持自然相机距离、正常透视和稳定头身、肩胯、四肢比例。
- GPT Image 2.5 微 NSFW 规则遇到厚外袍、披风、重布、厚礼服或护甲时，会改写为同题材、同身份、同配色和同纹样的轻薄版本，例如轻罗裙、薄纱外衫、湿润中衣、披帛、丝质内层或卸甲后的轻便内衬。
- 微 NSFW 只通过衣料厚薄、湿度、透光、褶皱、水光、逆光和环境氛围表达，不通过放大胸胯腿、近距离广角、横向拉伸、纵向压缩或裁切身体表达。
- 角色参考图、分镜单帧和微 NSFW 五视图共用轻薄湿润衣料规则；五视图保持同一套服装状态，不生成多套不一致衣服。
- 目录版本升级到 16，只精确刷新未编辑的原厂 GPT2.5 微 NSFW 规则和预设；用户改名、编辑、禁用或删除的选择不会被覆盖或补回。
- 本版不新增年龄门禁，不添加固定剧情前缀，不改私密资料图、Krea-2、ComfyUI 或其它模型规则。

## 使用方法

1. 在普通生图设置中选择 `GPT Image 2.5 微 NSFW 生图规则`。
2. 普通全身图可以继续选择 `3:2 横图`；转换后的提示词会要求人物完整居中并保留左右环境。
3. 原角色服装较厚时，转换器会保留身份、配色和纹样，把衣料改写成符合原题材的轻薄或湿润版本。
4. 五视图选择 `GPT2.5 · 微NSFW五视图` 时，五个区域会共用同一套轻薄湿润服装状态。
