# 莲华视频导演台 5.2.6 发布说明

2026 年 11 月 27 日 · Windows x64 便携版与 Android 正式签名版

## MiniMax H3 提示词

- 正文把人物动作和运镜分开。已经发生的接触按当前姿势延续，首次接触只描述一次。运镜围绕现有站位取景。前后站位保持原有身体朝向和视线，两人正面相对时才描述同时看见两张脸。
- 同一个人在一镜中保持唯一的站位和脸部朝向。情绪通过目光、呼吸、停顿和动作呈现，耳朵、脸和脖子的肤色沿用参考图。

## 参考图与本地处理

- 人物参考图的关联沿用资产记录中的人物编号。身份句出现在人物首次实际出镜的正文，选图面板展示该人物可用的参考图。
- Windows 本地抽尾帧和保存成片可以并行处理。两端共享提示词和参考图变更。

Windows 下载 `lianhua-video-director-5.2.6-windows-x64-portable.exe`。Android 下载 `lianhua-video-director-5.2.6-android.apk`。维护者可用 `npm run deliver:5.2.6` 整理本地交付。
