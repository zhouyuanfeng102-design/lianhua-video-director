# 莲华视频导演台 3.5.7 发布说明

发布日期：2026-10-31（亚洲/上海）。

## ComfyUI H3 图片槽按实际输入顺序绑定

ComfyUI MiniMax H3 `ImageToVideo` 工作流现在按 H3 节点输入顺序解析 `first_frame`、`last_frame`，分别对应 `<Picture 1>`、`<Picture 2>`。已明确映射的图片槽不再误报“未声明图片消费顺序”。`ReferenceToVideo` 原有参考图映射保留；来源无法追溯时继续保留原有处理。

不新增按钮、运行时校验、生成拦截、重试或模型请求。升级不改写已保存的提示词和成片。

## 版本定位

本版 Windows 便携包为 `莲华视频导演台-3.5.7-便携版.exe`。构建命令为 `npm run pack:win`，交付命令为 `npm run deliver:3.5.7`；交付同时生成恢复源码、更新说明、专属启动器和 SHA-256 清单，已有版本文件保留。
