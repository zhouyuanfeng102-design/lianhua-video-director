# 莲华视频导演台 2.2.8

发布日期：2026-10-15。

## 多张中间帧参考图

视频导演台单段和长剧情批量的参考图片槽新增“中间帧”用途。多张中间帧按实际槽位顺序和保存的用途自动编号为中间帧 1、2、3 等，不固定为两张。可用数量仍取决于当前接口或工作流提供的参考图片槽容量。

空槽可设置用途，取消选图和后续补图沿用已选用途；保存恢复后继续保留本次参考设置。批量段落与单段采用相同的编号与参考职责。

Seedance 和 H3 的本次参考职责同步中文、英文，说明首帧、中间帧和尾帧各自用途。预览与提交沿用本次稿，保存的原始提示词保留，不改写原稿正文。

## 接口与兼容

RunningHub 和 ComfyUI 继续按已配置的节点绑定传图，通用接口继续按原有协议发送参考图片。“中间帧”表示本次参考职责，不代表接口提供原生中间帧硬控制，也不保证服务在指定时刻精确复现图片。MiniMax 官方接口仅首尾帧的限制继续保留。

没有数据迁移，不自动重新生成提示词或任务；保留已有项目、原稿和历史交付文件。版本按十进位规则从 2.2.7 递增至 2.2.8，2.2.7 及更早历史交付不覆盖、不删除。
