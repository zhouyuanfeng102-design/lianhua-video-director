# 莲华视频导演台 4.5.0 发布说明

发布日期：2026-11-11（亚洲/上海）。

## 对白重复与无意义发话的输入根因处理

本次定位到的异常视频中，三句台词都先在动作引语里写一遍，再以 `<d>` 写一遍；重复已经存在于中文稿。最终 JSON 示例还省略了前文要求的 performance，使新回包继续落入保留自由正文并从旧排程补对白的兼容分支。

本版统一现有生成请求中的交付契约：新稿由 performance 的 speech 事件承载原话和发话身份，明确视觉、语气和声景字段的职责。取消 canonical 排程补写第二份对白，以及从视觉正文猜说话人并另起发话的代码。历史无 performance 稿保留原正文，不在加载时自动补写。

翻译的对白上下文改为读取同一组 speech 事件，保持事件 ID、角色、原话、语种和时间；真实重复发话和跨镜词段仍分别保留。中文固定发话句改用中文。现有生成指令同时交代话后闭口和尾镜中可见人物的发话状态，保留原动作与确认排程，不靠扩写台词、加底噪或配乐填空。

新完整 H3 执行稿按已有 prompt/idea 绑定原样传入；网页已明确识别的自动提示词开关在该次新请求中关闭，云端不再包裹短想法扩写指令。显式历史任务复用保持原快照，自定义 raw 继续原文发送。没有可控映射的远端节点、模型权重和 tokenizer 不作猜测或改动。

没有新增运行时内容校验、审核、生成拦截、自动重试、按钮、模型调用或哈希测试。

## 应用范围

- 共享生成、翻译和传输模块同时用于 Windows 与 Android。
- 旧提示词、任务和成片不自动改写。请通过原有入口生成新的本段提示词，再使用新提示词生成视频；“载入相同设置再次生成”继续使用原任务快照。
- 本地输入修复不能保证远端 H3 每次原生语音都逐字正确。未修改本例远端网页工作流内部的 tokenizer、权重、LoRA、调度器或步数。

## 交付

- Windows：`莲华视频导演台-4.5.0-便携版.exe`，Windows x64 portable。
- Android：`莲华视频导演台-4.5.0-安卓版.apk`，沿用正式升级签名，versionCode 450，最低 Android 8.0 / API 26。
- 同目录提供恢复源码 ZIP、更新说明、安卓安装说明、能力与验证记录和 SHA256 清单。
- 4.4.9 及更早历史版本保留，不覆盖、不重编号。

## 验证范围

本次复用既有定向测试，覆盖单一 speech 输出、兼容正文保留、真实重复与跨镜词段、翻译原话/角色/时窗、完整 H3 与短想法分流、历史任务复用和快照保持。双端打包流程包含 TypeScript 与 Vite 构建，APK 执行正式签名验证。

没有发起真实视频或额外模型请求，没有执行 Android 实机安装或全量界面回归；不将本地测试或构建通过表述为语音已经永久正确。
