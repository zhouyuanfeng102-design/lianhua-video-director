# 莲华视频导演台 4.6.3 发布说明

发布日期：2026-11-14（亚洲/上海）。

## 家具尺寸跟着这一镜里的人

人已经靠着家具时，分镜和视频正文的第一句用身体写出接触高度。后腰抵着的边留在腰的高度，垫子留在台面上，头后面仍是远处的墙。近景只露出真正挨着身体的那一截。

场景图留下建筑、固定陈设和光线，以及陈设自己的材料和结构。道具图留下这件东西的材料、颜色和结构。尺寸跟着这一镜里的人。墙上或台座上的纹样留得比这个人的头小。铺满画面的标志图只留下这枚纹样的画法。这一镜保持正文写明的取景。

已保存的成片、分镜、地点图和提示词不改写。下次重新生成分镜或提交视频时按这个写法。

## 交付

- Windows：`莲华视频导演台-4.6.3-便携版.exe`。
- Android：`莲华视频导演台-4.6.3-安卓版.apk`，最低 Android 8.0 / API 26。
- 4.6.2 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.6.3`。分段、分镜和视频提示词在两端共用，EXE 与 APK 一起交付。

## 验证

打包流程自带类型检查和前端构建。场景和道具的保留句、分镜接触高度由对应定向测试核对。
