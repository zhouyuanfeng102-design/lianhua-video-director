# 莲华视频导演台 1.8.0 发布说明

2026-10-11

本版针对生产包启动白屏，以及 Nano Banana 图像连接使用错误接口协议导致的生图失败进行修复。

## 启动与生产构建

已复现 1.7.9 的启动异常：规则模块跨分块相互引用，模块初始化时提前读取未初始化的常量，触发 `ReferenceError: Cannot access 'n' before initialization`，导致 React 主界面未能挂载。调整规则与请求上下文模块的分块关系，让初始化依赖处于正确的分块中。修复后的 1.8.0 便携版已实际启动，主界面、侧栏和提示词导演台正常显示，没有初始化异常或控制台错误。

保留 1.7.9 的动作对象、人物视线、空间距离与对白归属规则，原项目、历史提示词、图片、视频和已保存任务继续保留。

## Nano Banana 与图像接口

图像连接增加显式的聊天兼容生图接口。提供此协议的转发平台可以通过聊天接口提交 Nano Banana 生图请求，参考图片随请求传入，用户配置的模型别名保留。此接口与 Images 接口分别配置，避免把只在聊天接口开放的模型提交到仅支持 Imagen 等图像模型的接口。

Gemini 原生接口继续使用原生生图协议。接口类型、模型名和服务地址应与所用平台的实际文档一致；相同模型在不同平台可能使用不同别名与端点，软件不擅自替换用户配置的模型名。

接口类型与模型不匹配、返回结果未包含图像等情况提供明确提示，方便选择平台实际支持的接口。软件不会把失败请求自动切换到另一协议重新扣费，也不会自动重跑已保存任务。

对于支持聊天生图的香蕉中转通道，在「API 设置」的图像连接中，将「生图协议」设为「OpenAI 聊天生图兼容（香蕉）」，保留完整模型名称和原服务地址，保存后回图像工作台创建新任务。修改协议不会改写旧任务的冻结配置；谷歌官方连接继续使用「Google Gemini 原生」。

## 验证与交付

本次只检查相关改动，未运行全量回归：

- 打包内置的 TypeScript 检查与 Vite 生产构建通过。下载 Electron 时出现网络超时，改用本机同版本 Electron 41.10.7 完成包装。
- `scripts/productionStartupSmoke.mjs` 使用实际便携 EXE、`file://` 入口和独立空测试数据目录，确认版本、主界面、侧栏、提示词导演台及启动异常；未读取正式项目和凭据。
- `scripts/geminiChatImage.test.ts` 的 13 组针对性模拟检查通过，覆盖请求与别名、参考图顺序、输出解析、单次失败、错误说明、配置保存及冻结快照。相关分辨率传输兼容检查通过。

香蕉检查全部使用本地模拟请求，没有真实付费生图。中转服务实际支持范围尚未实测，不声称服务已成功生成图片。配套 SHA-256 校验文件由交付流程生成，用于核对本版交付文件。

本版按十进位进位从 1.7.9 升级至 1.8.0，提供便携版、恢复源码、更新说明、启动脚本和配套 SHA-256 校验文件。1.7.9 及更早发布说明、交付文件和交付入口保留。
