# 莲华视频导演台 0.5.73 发布说明

## 版本定位

0.5.73 仅修复多参考图人物绑定与源组稿重复：同一人物出现在多张生成构图参考图中时，不应每张图都复制一套人物档案成为额外 Subject。

本次问题涉及的当前段保留原有 3 镜、15 秒、原剧情、固定镜头时间边界与生成参数；不重新拆镜、不重做全片或其他段，也不把其他段强制为这一规格。全局数据 schema 仍为 21，模型、随机种子、工作流和其他设置不变。

## 同一人物关联多张参考图

- 对可证明属于同一人物的多张生成 composition 构图参考，复用单一人物定义，并在该定义中关联多个 Picture。
- 不再因选了多张同一人物的参考图，就按图片复制人物档案或扩充额外人物 Subject。
- 只有身份关系能够确认时才复用；未知、矛盾或用户独有资料继续保留，不凭名称相似或推测强行绑定。
- 原参考资产、实际图片、用户独有内容与每张图的独特事实不删除，不通过减少选图数量掩盖问题。

## 参考用途与 Shot 动作分开

- 已关联图片独特的构图、姿态或其他参考用途在 `retention_analysis` 中各写一次，仍能追溯到对应 Picture；未能可靠关联的图片继续保留自身参考定义，不丢弃其独有资料。
- 参考用途不再混进 Shot 的剧情动作，避免同一份参考描述在人物定义、参考保留说明和每镜动作中反复堆叠。
- 仅整理可确认的重复身份与参考用途，不删原剧情事件、对白、因果、镜头或独特视觉资料。

## 继续保留的功能

- 保留 0.5.72 的英文结构单元预算与有限局部返修；英文仍失败时保留已校验合格的中文，可“仅重试英文”，不重转中文或刷新其他段。
- 保留当前段 API 参考刷新中的结构、时间与对白校验，取消/过期响应保护及空 `targetBindings` 的规范化。
- 保留 Krea-2 规则目录一次性补齐、既有规则与选择，不重置规则库。
- 保留 ComfyUI 无整单等待上限和全部启用生图规则手选；实际模型、工作流与种子不变。
- 默认无配乐，明确要求的配乐保持低音量；本版不另行改动声音策略或处理已有视频音轨。
- 全部 0.5.72 及更早版本化交付、项目、历史任务和资产继续保留。

回归需覆盖：

- 未知身份、矛盾信息和用户独有内容不被猜测绑定或删除。
- 每图独特参考用途写入 retention 一次，且不混入 Shot 剧情动作。
- 当前问题段维持 3 镜、15 秒及原剧情，其他段、模型、种子与全部生成参数不变。

## 使用方法

正式交付完成后：

1. 保存当前工作并关闭旧版，启动 `交付\启动莲华视频导演台-0.5.73-便携版.bat`，沿用原数据目录。
2. 在长剧情当前段选择需要的参考图，再点击“刷新本段提示词”；无需删除同一人物的其他参考图或重做全片规划。
3. 检查人物定义的多 Picture 关联和各图独特用途；如果英文失败而中文已保存，可继续使用“仅重试英文”。
