# 莲华视频导演台 3.9.5 发布说明

发布日期：2026-11-07（亚洲/上海）。

## 安卓 APK 与手机布局

新增 Android APK。手机使用单列页面、底部导航和触控操作。安卓接入本地存档、素材、文件选择和原生网络，项目可通过项目包转移。

后续常规版本同步交付 Windows EXE 与 Android APK。已有提示词和成片保持原样。安装、备份和能力范围见 [安卓安装说明](../android-install.md)。

## 版本定位与交付

Windows x64 便携包：`莲华视频导演台-3.9.5-便携版.exe`。Android 安装包：`莲华视频导演台-3.9.5-安卓版.apk`。交付命令为 `npm run deliver:3.9.5`；3.9.4 及更早历史版本文件保留。
