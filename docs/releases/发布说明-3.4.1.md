# 莲华视频导演台 3.4.1 发布说明

发布日期：2026-10-28（亚洲/上海）。

## 修复保存超时

- 哈希命名图片已经位于当前项目目录时，不再每次保存都重新整理或复制。
- 素材迁移不再逐个读取 `project-library` 下的全部历史项目正文。
- 无法确认旧素材路径是否仍被历史项目或恢复点使用时，保留原文件，避免破坏旧引用。
- 解决大型项目库中保存线程长时间扫描并超过 30 秒超时的问题。

## 版本定位

本版 Windows 便携包为 `莲华视频导演台-3.4.1-便携版.exe`。构建命令为 `npm run pack:win`；生成到项目内 `交付` 目录的命令为 `npm run deliver:3.4.1`。已有 3.4.0 及更早交付文件保留。

公开 Release 提供便携 EXE、恢复源码 ZIP、更新说明和启动器；本版不生成或上传 SHA-256 校验清单。
