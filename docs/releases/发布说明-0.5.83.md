# 莲华视频导演台 0.5.83 发布说明

## 本轮修复

- 提示词导演台增加关联成片入口，可查看当前提示词对应的视频。从视频返回来源时同步切换正确的长剧情计划、分段和分镜，不再只切换分镜 ID 后仍显示上一段。
- 成片资产独立保存完整的无密钥来源快照：提示词及版本、参考图及顺序、工作流、生成参数、原任务 ID、生成状态和耗时。删除任务记录后视频与这些资料仍保留，可查看来源、载入相同设置；不会把已删除任务重新放回任务队列。
- 内嵌和远程图片在首次提交生成前保存实际原像素；复用原任务时读取冻结图片，不受同资产 ID 后来换图、改网址或删除图片记录影响。工作流、种子和采样参数继续按原快照复用，不静默切换到当前配置。
- 已明确没有发出生成 POST 的准备任务可以恢复，保留已冻结的原图和已完成的素材上传。独立的提交边界记录在请求前落盘；已提交但确认丢失仍查询原任务或显示结果待确认，不自动重新提交，避免重复生成与重复扣费。
- 来源查询和复用限定在所属项目；密钥继续由本机加密凭据库管理，成片快照不包含密钥，也不因删除任务而清掉仍被成片复用依赖的原连接凭据。旧记录缺少原图证据或完整参数时不伪造精确复用。

## 保留的行为

提示词导演台、视频导演台、图片资产库和视频资产库的主流程不变；通用视频 API、MiniMax、独立 ComfyUI 视频工作流、真实进度与耗时、后台追踪、自动入库和仅下载重试继续保留。视频上传、排队、生成和下载不增加应用端时长上限。

本轮不改提示词正文、原对白、对白语言、自然动作声、默认无配乐/明确低配乐和去连续底噪规则，不增加剧情字数、格式或预估语速审核。schema 保持 22，H3 指纹 v4；旧项目、资产、存稿、自定义/禁用/删除状态及 0.5.82 和更早版本化交付保留，不自动重做旧视频。

## 使用方式

完成交付后，保存工作并关闭旧版，通过 `交付\启动莲华视频导演台-0.5.83-便携版.bat` 打开新版。

在提示词导演台查看关联成片，或从视频资产的“来源提示词”返回原段；视频资产中使用“载入相同设置再次生成”只建立草稿，不立即提交付费任务。核对后点击“生成视频”才创建新任务，旧成片不会覆盖。

重新打开软件后，明确尚未提交且素材条件完整的准备任务可以继续；已有远端任务 ID 的任务继续查原 ID。结果待确认不会盲目重投；生成已成功而仅保存失败时只重试下载。外部服务自身的失败、失效或素材不可读取仍如实显示，不由本地猜测成片成功。

旧内嵌/远程参考图记录如果没有留下原始像素，不能从后来改过的资产还原历史原图；新版不会用当前图片冒充原图，也不会自动重做旧视频。新任务会在提交前固化所选原图。

## 验证与交付

已通过视频运行层、准备断点恢复、来源保留、原图预览、来源导航及 5 项原生提交记录测试，以及严格源码/测试类型检查。覆盖原图同 ID 被替换和原资产/任务被删除后仍复用原像素、远程图片固化、只重传未完成素材、提交边界不回退、记录缺失/损坏/身份不符时 0 次重投、落盘失败时不提交、已知任务 ID 和成功终态保护。冻结原图的托管文件也纳入项目包导出，不因删除原资产记录漏打包。

聚焦 Playwright 界面验收通过：两个计划各两段，从 A1 成片来源跳到 B2 的计划/段号/长剧情模式；只筛 B2 两条关联成片；删除任务后仍可查看来源和按原种子 424242 载入；原图片被换成不同像素或删除记录后，缩略图与放大预览仍显示原图，明确选择当前图片才解除旧快照。测试为 0 次生成提交、0 次下载、0 浏览器错误，报告与截图在 `output/playwright/video-gaps-0.5.83/`。

本轮只使用隔离合成项目和模拟接口；真实用户 ComfyUI / H3 GPU 出片、云视频收费 API 和实际成片效果尚未实测，不能以本地验证代替。

生产构建及便携包构建已通过，打包内的 7 个界面代码包、桌面传输和新增提交记录模块与最终源码构建一致。构建仍有大于 500 kB 的代码分块提醒，本轮未扩展拆包重构。
