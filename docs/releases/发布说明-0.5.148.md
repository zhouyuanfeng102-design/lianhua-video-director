# 莲华视频导演台 0.5.148 发布说明

发布日期：2026-09-23

## 版本定位

本版修正图像接口故障提示与桌面参考图传输。服务商返回“No available image quota. Please try again later.”或“System is overloaded...”时，明确显示上游当前无可用图像生成额度或服务负载过高，不推断为用户账户余额不足。取消桌面通用图片编辑请求最多8张参考图的任意限制，同时保留必要的传输体积保护。

## 本版变更

- 上游额度不可用、服务过载等错误使用清楚的中文提示，并保留服务商建议稍后重试的含义。它们属于上游服务状态，不代表提示词被本地拦截，也不能通过本地改动恢复额度或消除过载。
- 图像接口HTTP错误保留HTTP状态码和服务商错误代码；错误记录继续脱敏密钥、提示词、图片及媒体数据，不直接输出完整请求或原始敏感响应。
- 桌面通用图片编辑请求不再限制最多8张参考图，按原顺序保留全部已选参考图，不静默丢弃第9张及后续图片，覆盖13张独立参考图的实际传输场景。
- 单张参考图32MB、整个请求96MB的安全上限继续保留，并在请求组装时逐项检查，超限立即明确提示，避免先累计大量数据再判断。不压缩、重写或删减参考图以绕过限制；服务商自身数量和体积限制仍适用。
- 保留0.5.147的独立真实AI校验修复、图片25%–400%缩放与还原、长剧情批量顶部设置区压缩，以及原有取消、过期结果和数据保护。

## 使用与兼容

1. 保存项目并完全退出旧版，再启动`莲华视频导演台-0.5.148-便携版.exe`；不要同时运行多个版本写入同一数据目录。
2. 如果仍提示上游无可用图像生成额度或服务过载，需要等待服务商恢复后主动重试。新版只改善提示和本地传输，不声称修复服务端状态，也不会自动调用收费接口反复尝试。
3. 本版不改写图像内容、已有提示词、任务、正式项目或既有生成结果；不会自动重跑历史失败任务。
4. 0.5.147及此前的交付包、恢复源码、说明和版本专属启动器保留。旧版本更新说明仅记录对应版本的行为，不作为新版的额外限制。

## 验证与构建
