# 莲华视频导演台 0.5.37

## 版本定位

- 0.5.37 是基于 0.5.36 的 AI 扩写完整剧情转换修复版。
- 重点解决默认扩写规则过薄、模型照搬原文、扩写规则与原文生硬拼接，以及旧包仍使用旧规则的问题。

## 完整剧情转换规则

- 默认扩写预设由四段概要升级为九层完整协议：任务身份、原文事实锁、场面与因果递进、连续性账本、人物与情绪连续、对白转换、题材自适应文风、条件命中的高细节场景、写前写后复核。
- 明确禁止只做同义复述、机械换词、重复原句或堆叠形容词；新增内容必须带来空间、动作、阻碍、反馈、状态变化、转折、结果或余波。
- 动作按“触发、准备、行动、反馈、状态变化、结果、余波”承接，并持续追踪人物站位、姿势、衣物、道具、身体状态与环境变化。
- 已有对白保留说话人和原话；新增对白服从人物身份、关系、口吻、情绪与知识边界，并实际推动动作、信息、冲突或关系变化。

## 墨色江湖与世界书参考方式

- 参考的是墨色江湖主线叙事体系，以及世界书的分层注入、条件命中、状态查询和感官转化方法，不再误用它要求“同等信息量”的文章优化层。
- 普通剧情不会被强制带入亲密、露骨或其他特殊细节；仅当原文已经自然进入或明确要求时，才按原有事件方向和尺度调用相应动作、接触、反馈、感官与状态连续规则。
- 不复制玩家变量、游戏命令、输出标签、概率表、专有身体分类和数百条专属资料项；不要求用户手工复制附加世界书。
- 本地不按正文关键词拦截、替换或改写用户输入。

## 四层请求链路

- OpenAI 兼容接口按“核心任务 → 完整扩写规则 → 序列化原文数据 → 最终输出协议”四层发送，避免把规则、原文和输出格式压成一段生硬文本。
- Claude 接口按照其消息格式保持同样的逻辑边界，并把最终输出协议放在原文数据之后。
- AI 扩写正式请求纯剧情正文，不再强迫模型返回 JSON；旧模型仍返回 `expandedStory` JSON 时继续兼容。

## 安全迁移

- 状态 schema 升级为 13。
- 只有名称、规则正文、输出规则、启停状态和版本都与旧内置 v1.0.0 逐字相同，且没有额外字段时，才自动迁移为 v1.1.0“AI 扩写 · 完整剧情转换”。
- 用户修改过名称、规则、输出协议、启停或版本，添加过自定义字段，或创建了自定义预设时，全部原样保留；默认预设 ID 也不改变。

## 回归验证

- 新增完整规则内容、真实消息顺序、OpenAI 兼容接口、Claude 映射、纯正文返回、旧 JSON 兼容和对白约束回归。
- 新增未编辑旧规则迁移、任意用户修改保留、空预设列表保留、迁移幂等和默认 ID 保留回归。
- 交付包含 Windows x64 便携版、恢复源码、更新说明、版本启动器和 SHA-256 完整性清单；0.5.36 及更早历史交付文件不被改写。
