# 莲华视频导演台 0.6.1 发布说明

版本记录日期：2026-09-25。

## 版本定位

本版修复私密资料 AI 补齐在 NSFW 内容下容易返回说明文字、导致“私密资料补齐结果不是有效 JSON 对象”的问题。目标便携包为 `莲华视频导演台-0.6.1-便携版.exe`，完成构建后使用 `npm run deliver:0.6.1` 生成版本化交付与 SHA-256 清单。

## 本版变更

- 私密资料补齐参考墨色江湖的正向 NSFW 视觉规则，明确私密身体资料属于稳定外貌档案补齐范围，不把说明文字、政策讨论或剧情续写当作可保存资料。
- 私密资料补齐输出协议强化为 JSON 对象本体：以 `{` 开始、以 `}` 结束，只包含本次目标字段，字段值为中文字符串；已有非空私密字段仍不覆盖。
- 首轮若返回非 JSON 说明文字，会用同一批人物资料自动做一次 JSON 格式返修；返修不回灌上一轮失败原文，避免把“抱歉/无法”等话术继续污染上下文。
- 第二轮仍无效时显示“私密资料补齐自动修复后仍无效”及结构原因，不保存半份结果，不把失败内容写回角色档案。

## 保持不变

- 不新增、不移动、不重复年龄门禁；年龄门禁继续由既有位置负责。
- 不修改正式项目、历史任务、已有私密档案、图像 API 参数、普通资料补齐和旧生图结果。
- `0.6.0`、`0.5.160` 及更早历史交付文件继续保留，不覆盖、不删除、不重编号。

## 验证

- `npm run test:llm`
- `npm run test:image-generation`
- `npm run test:nsfw-private-assets`
- `npm run test:typecheck`
- `npm run test:version`

生产构建、发布检查和便携包验收以本轮最终执行结果为准；不会调用真实收费文本或生图服务。
