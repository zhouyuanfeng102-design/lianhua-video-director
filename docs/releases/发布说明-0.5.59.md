# 莲华视频导演台 0.5.59 发布说明

## 版本定位

0.5.59 新增全局界面字体大小设置，让不同显示器、分辨率与观看习惯下都能直接调整应用文字，同时保持原有界面布局和项目数据不变。0.5.58 及更早功能与历史交付文件保持不变。

## 字体大小设置

- 主工具栏右上角新增齿轮设置按钮，任一工作页面都能打开“界面设置”。
- 字体大小支持 80%–130% 范围滑杆，步进按钮可快速减小或增大，自定义数字框可输入整数百分比。
- 修改会立即应用到侧栏、顶栏、卡片、表单、按钮、提示词、日志和弹窗等界面文字，不需要重启应用。
- 设置属于本机全局偏好，不会写入项目撤销记录，也不会因切换或导入项目而被覆盖。
- 当前比例自动保存；关闭或重启应用后仍会保留。“恢复默认字体”可一键回到原始 100%。

## 布局与无障碍

- 字号使用统一 CSS 变量缩放，不使用会放大整个窗口并产生横向滚动的 `zoom` 或 `transform`。
- 顶栏改为自适应高度，标题、副标题和项目名支持省略；小窗口及大字体下会缩小操作间距，避免左右区域重叠。
- 设置弹窗支持键盘 Tab 焦点环与 Esc 关闭，打开后聚焦可操作控件，关闭后焦点回到设置按钮。
- 字体数值会在存储迁移时归一化；旧项目默认 100%，非法值安全回退，超出范围的值限制在 80%–130%。

## 同步完善

- 最终视频提示词的逐镜补齐与结构自动返修继续携带对应角色性别资料，避免返修链路丢失已经建立的性别连续性。

## 交付

- 便携包：`莲华视频导演台-0.5.59-便携版.exe`
- 交付命令：`npm run deliver:0.5.59`
- 正式交付包含便携 EXE、恢复源码、更新说明、版本启动器和 SHA-256 校验清单。
- 0.5.58 及更早历史交付文件不会被覆盖。
