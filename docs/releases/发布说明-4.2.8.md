# 莲华视频导演台 4.2.8 发布说明

发布日期：2026-11-09（亚洲/上海）。

## 点得到立即运行，没提交的任务可再交一次

运行按钮按它自己的文字「立即运行」或 Run Now 来点。旧页面里包着这几个字的格子仍然算同一个按钮。没有这个按钮时，这次仍不算提交。

失败原因是「这次没有提交」的任务，点现有的「恢复查询原任务」，会把这一段按原来的设置再交给网页一次。已经有远端任务号的，仍只查询原来的那一条。

已保存的提示词和成片保持原样。

## 交付

- Windows：`莲华视频导演台-4.2.8-便携版.exe`。
- Android：`莲华视频导演台-4.2.8-安卓版.apk`，最低 Android 8.0 / API 26。
- 4.2.7 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.2.8`。电脑和手机都会点 RunningHub 的运行按钮，EXE 与 APK 一起交付。

## 验证

打包流程自带类型检查和前端构建。手机网页适配测试确认：没有旧格子、按钮文字是「立即运行」时，仍会提交一次。未在真实 RunningHub 页面上再点运行。
