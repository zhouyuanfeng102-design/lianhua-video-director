# 莲华视频导演台 5.0.1 发布说明

2026 年 11 月 21 日 · Windows x64 便携版与 Android 正式签名版

## 版本定位

本版修复窗口比 1280×800 小时，新建项目对话框里的名称和说明点不进去的问题。Windows 与 Android 共用这套界面缩放。

## 新建项目可以命名

界面按窗口缩小后，新建项目窗口仍画在屏幕中间，但名称框和说明框的可点击范围留在了未缩放的位置。点到看见的输入框没有光标，文字也进不去。

本版让这层窗口跟缩小后的界面使用同一块区域。点项目名称或项目说明即可输入。不填名称时仍使用「未命名视频项目」。已保存的项目不因升级改名。

本版未新增运行时校验、重试、按钮或模型请求。

Windows x64 使用 `莲华视频导演台-5.0.1-便携版.exe`。Android 使用 `莲华视频导演台-5.0.1-安卓版.apk`。维护者使用 `npm run deliver:5.0.1` 整理两端安装包、恢复源码与 SHA-256 交付清单。
