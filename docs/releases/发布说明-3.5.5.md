# 莲华视频导演台 3.5.5 发布说明

发布日期：2026-10-31（亚洲/上海）。

## 参考图可多选，私密图也能选

图像工作台的「从资产库选择」列出当前项目里能读到的图片，私密资料图和普通图都在里面。点卡片是勾选或取消，可以一次留下多张，顺序按点选先后。仍用「使用所选图片」确认。

「将当前普通图片作为本次图生图参考」仍是开关：勾上就按这个顺序提交全部已选图，取消就不带参考图。上传新图会加进已选，不把其余已选清掉。

分镜和视频的自动配图仍不自动带上私密图。只有在这个框里点过的私密图才作为本次参考。不新增校验、拦截、重试或按钮。已生成的图片和视频保持原样。

## 版本定位

本版 Windows 便携包为 `莲华视频导演台-3.5.5-便携版.exe`。构建命令为 `npm run pack:win`，交付命令为 `npm run deliver:3.5.5`；交付同时生成恢复源码、更新说明、专属启动器和 SHA-256 清单，已有版本文件保留。
