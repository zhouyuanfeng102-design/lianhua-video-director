# 莲华视频导演台 4.4.6 发布说明

发布日期：2026-11-11（亚洲/上海）。

## 她是一个人，他留在身后

模型写这一镜时，用她的姓名写头留在脖子上、背留在躯干上、躯干连着髋。被抬着的是这个人的屁股。玉小刚留在她身后，胸口对着她的背。进入和抽送写他的阴茎从她屁股后面进入并留在她的阴道里。英文页保持同一个人、同一个身后。

程序不把这些句子贴进正文，也不改模型写好的句子。已保存的提示词和成片保持原样，重新生成该段后才会改。

## 交付

- Windows：`莲华视频导演台-4.4.6-便携版.exe`。
- Android：`莲华视频导演台-4.4.6-安卓版.apk`，最低 Android 8.0 / API 26。
- 4.4.5 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.4.6`。提示词规则两端共用，EXE 与 APK 一起交付。

## 验证

H3 规则夹具核对：交付规则含「他留在她身后，胸口对着她的背」和「她的头留在她的脖子上」，不再含「髋朝向这头并对准」。打包流程自带类型检查和前端构建。未在真实 RunningHub 页面上再点运行。
