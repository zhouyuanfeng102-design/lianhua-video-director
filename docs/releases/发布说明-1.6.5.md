# 莲华视频导演台 1.6.5 发布说明

RunningHub工作流管理补齐采样步数。常用生成参数按两行两列排列：第一行是视频时长、画面比例，第二行是分辨率、采样步数。卡片和输入控件随窗口可用空间调整大小，常用参数同页完整显示。

## 采样步数与提交

采样步数支持选择实际节点字段、查看和修改工作流默认值。用户提供的“全能视频·星轨H3”请求对应 `124.steps`，原默认值为字符串 `"10"`。请选择该真实字段并保存工作流；软件不会按节点编号猜测或覆盖已有映射。

单段和批量视频生成均可设置采样步数，留空沿用工作流默认值。输入方式依据实际云端元数据或明确保存的输入设置，支持真实选项与数值输入，不捏造固定档位或采样范围。数值提交保留请求节点原有类型，例如原字段是字符串 `"10"`，覆盖20时仍按字符串 `"20"` 提交。未绑定或连接未声明支持采样步数时，不向服务强加参数。

步骤绑定、默认值和输入设置随工作流保存与导出恢复。单段及批量新任务使用本次设置；历史任务保留原快照，恢复时继续查询原任务ID，不以当前参数重新提交。其他采样参数、参考图、提示词及云端运行设置保持用户原配置。

## 界面与使用

工作流管理的常用参数区按剩余高度调整卡片间距、输入框高度与字号；输入选项编辑不持续撑高四个参数卡片。底部保存与完成操作保持可见。

运行 `莲华视频导演台-1.6.5-便携版.exe`。保留原数据目录和历史交付文件。版本按用户十进位规则从1.6.4递增至1.6.5。
