# 莲华视频导演台 2.0.2 发布说明

发布日期：2026-10-12

## 人物声音身份

- 源头分镜逐句绑定项目已知人物身份；只有原剧情、用户要求或有确认依据的设定才提供具体声线。没有特殊声线要求时保持已知性别的基本发声身份，不因怯懦、结巴、低声或角色姓名自行补成另一性别的声音。
- 新候选分镜、中文转换稿或 H3 中模型自行补出的声线，不因已经写入候选而成为用户确认事实。中文人物身份与逐句发声保留已知性别，英文承接中文明确的身份与指代。
- 在已有请求数据中区分新稿声音事实与已确认稿保真；翻译、参考更新、衔接和纯格式修复不获得重新配音权限。旧预设的已知原版规则仅在请求组装时替换，不迁移保存数据。

## 身份参考与摄影

- 本段身份参考使用当前正文的唯一姓名或别名、既有事件行动者与对象、实际对白说话人和保存的场景身份，不再以有限动作词决定是否保留人物资料。
- 人物资料只提供身份参考，不是必须出场、入画或发声的名单。用户编辑本段正文后，不用旧事件、对白或历史名单恢复已删除人物。
- 分别决定人物视线目标、攻击目标、摄影主体、取景范围与焦点。“盯住某部位”不自动生成局部特写、推近或定格；观察破绽可由关系构图与观察者反应表达。必要信息、当前景别无法辨认的细节及用户明确指定的特写保留。

## 动作排程与使用

沿用 2.0.1 已接入的事件排程：短促倒飞、立即追击、空中攻防和对白在同一次连续事件中推进；镜头时长不替代动作时长，不以持续悬空等待切镜。用户固定时长与指定镜数保持。

已有项目、提示词、冻结视频任务和成片保持。要应用本版修复，请重新生成相关中文或本段提示词，然后创建新的视频任务；仅重译英文或重试旧任务仍沿用原稿。纯英文翻译只处理已确认中文，不读取图像资料重新导演。

本版修改输入事实和生成规则，不新增声音检测、语义校验、重试或独立审核调用，不硬编码个别人物或身体部位。

## 验证与交付

完成声线规则、人物身份参考、摄影规则、中文到英文声音身份与动作排程的针对性离线验证。生产打包包含类型检查与构建。未调用收费视频生成，离线验证确认规则与数据传递，不代替真实模型成片评估。

版本按十进位从 2.0.1 递增为 2.0.2；历史版本与交付文件保留。

便携包：`莲华视频导演台-2.0.2-便携版.exe`

打包命令：`npm run pack:win`；交付命令：`npm run deliver:2.0.2`。
