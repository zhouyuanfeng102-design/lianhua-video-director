# 莲华视频导演台 3.1.7 发布说明

发布日期：2026-10-25（亚洲/上海）。

## 修复长剧情语义分段原文位置错误

语义分段请求改为在 `sourceEvidence.text` 和 `dialogues.text` 中返回本段对应的逐字原文摘录，不再要求模型计算完整原文中的字符偏移。解析器按对白记录中的原话替换正文标记，历史计划中的有效原文区间仍保持兼容。

本次改动不新增运行时校验、重试、按钮或模型请求，仍保持单次分段请求。

## 版本定位

本版便携包为 `莲华视频导演台-3.1.7-便携版.exe`，恢复源码包、更新说明、启动器和 SHA-256 清单由交付脚本按同一版本生成。交付命令为 `npm run deliver:3.1.7`。3.1.6 及更早版本文件继续保留。

## 定向验证

语义分段解析测试通过（37/37），规划器测试通过（25/25）。便携包流程另执行 TypeScript 检查和 Vite 生产构建。
