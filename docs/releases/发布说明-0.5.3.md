# 莲华视频导演台 0.5.3

## 资产库图片查看与保存

- 资产库中的图片缩略图可直接点击，卡片新增“查看 / 保存”入口，可打开大图预览弹窗。
- 预览弹窗新增“保存图片”，桌面版可通过原生保存对话框导出到电脑，便携版和 QA 场景也支持固定路径落盘。
- 大图、元数据和保存按钮在 1120×720、1280×720 下同屏显示，无需滚动查找操作按钮。
- 资产缺失时会明确提示“无法查看或保存”，避免用户误以为只是按钮没找到。

## 保持不变

- 0.5.2 的 API 设置首屏五标签单屏改造继续保留。
- 现有图片、文本、视觉、视频任务和密码本的布局与交互不变。
- 项目数据、恢复点、备份和现有资产管理流程保持兼容。

## 验证范围

- 已覆盖失败测试、`saveMedia` IPC 字节一致性、Vite 生产构建、桌面 QA、Web QA 和资产卡片/大图交互。
