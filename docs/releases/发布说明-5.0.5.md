# 莲华视频导演台 5.0.5 发布说明

2026 年 11 月 22 日 · Windows x64 便携版与 Android 正式签名版

## 版本定位

5.0.4 只写了「每个人留着自己的头」。两人贴在一起时，海螺仍把最显眼的那张四视图安到两个人头上。本版把每张人物图点名到这个人。Windows 与 Android 共用这套成稿。

## 每张人物图只属于这一个人

提交视频时，每个人物参考图写成：这张图只属于这个姓名，这个人的发型和发饰留在这个人头上，并带上身份句里已经写明的辫子、卷发或发饰。旁边的人用自己的那张图。

已保存的成片不因升级改写。需要更新时，用这一版重新生成视频。

本版未新增运行时校验、重试、按钮或模型请求。

Windows x64 使用 `莲华视频导演台-5.0.5-便携版.exe`。Android 使用 `莲华视频导演台-5.0.5-安卓版.apk`。维护者使用 `npm run deliver:5.0.5` 整理两端安装包、恢复源码与 SHA-256 交付清单。
