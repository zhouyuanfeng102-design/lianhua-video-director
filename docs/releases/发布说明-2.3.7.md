# 莲华视频导演台 2.3.7

发布日期：2026-10-15。

## 修复切换段落方案后无法生成

切换到另一个已确认的段落方案后，原先仍沿用上一方案的确认记录，导致当前方案被误判为“全片计划已变化或尚未确认”，生成按钮无法操作。

现在切换时恢复目标方案已保存的方案确认及节奏偏紧风险确认，并清除上一方案的来源差异接受记录。提示词导演台切换、分镜时间线选方案，以及从视频来源跳转，均使用相同处理；返回已确认且未修改的方案后，可继续生成或重新生成本段提示词。

尚未确认、确认后又修改或与当前剧情来源不匹配的方案，仍按原规则要求先处理确认，避免错误沿用其他方案的状态。
