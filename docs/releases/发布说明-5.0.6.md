# 莲华视频导演台 5.0.6 发布说明

2026 年 11 月 22 日 · Windows x64 便携版与 Android 正式签名版

## 版本定位

本版修复首帧、尾帧生成时，已经绑定的场景图没有自动带上的问题。Windows 与 Android 共用这一处选图。

## 已绑定的场景图进入首尾帧

资产库中已绑定到该地点的场景参考图，生成首帧时曾未随人物和道具一同带入。选图原先只认地点资料上的旧图片列表和生成来源，不认后来在资产库改的场景绑定。

现在本镜地点已经绑定的场景图会和人物、道具一起进入首帧和尾帧。原来已选的参考图顺序不变。

本版未新增运行时校验、重试、按钮或模型请求。

Windows x64 使用 `莲华视频导演台-5.0.6-便携版.exe`。Android 使用 `莲华视频导演台-5.0.6-安卓版.apk`。维护者使用 `npm run deliver:5.0.6` 整理两端安装包、恢复源码与 SHA-256 交付清单。
