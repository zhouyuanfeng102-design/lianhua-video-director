# 莲华视频导演台 2.9.0 发布说明

发布日期：2026-10-21（亚洲上海）。

## 本次调整

长剧情模式的结果区右上角“重新生成 Seedance”与左下“重新生成本段 Seedance 提示词”进入同一重生成流程。本次移除右上角重复入口，保留左下本段按钮及原有调用。

单段模式继续保留右上角入口。已有生成、动作排时和保存流程不变，不新增按钮、模型请求或运行时校验。此前启动白屏修复继续保留，历史项目、提示词与素材不自动改写。

生成任务页将“章节范围”移到标题行右上方，下方只保留三项任务分类。窄屏时按可用宽度调整排列，保持章节选择与任务分类清晰可用。

## 验证

完整结果已通过 `npm run pack:win -- --config.directories.output=.pack-release-2.9.0-final`：TypeScript 检查、Vite 生产构建及 Windows 64 位便携打包完成，退出码 0。构建仍有已有分块及包作者字段提示，无构建错误。

在生产构建上使用独立浏览器数据检查 1600、1200 和 1040 像素三种窗口宽度，并查看宽屏及窄窗口截图：章节选择位于标题行右侧，长章节名称在选择框内省略显示，任务分类保持等宽且不与筛选区域重叠，切换章节仍生效。页面脚本错误和外部请求均为零。记录位于本地 `output/playwright/jobs-header-layout-2.9.0/`。

本次未改动用户数据，未调用真实生成 API，未追加无关功能回归或产品运行时校验。

版本按十进位规则从 2.8.9 升至 2.9.0，保留历史版本号与交付文件。
