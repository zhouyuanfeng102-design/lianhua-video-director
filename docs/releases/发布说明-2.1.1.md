# 莲华视频导演台 2.1.1 发布说明

发布日期：2026-10-13

## 版本定位

本版按 RunningHub 图片工作流实际暴露的尺寸参数提交生图，兼容只提供分辨率档位与画面比例、没有宽度和高度字段的云端工作流。

工作流明确绑定可识别的 `resolution` 时，可按所选档位提交，无需为不存在的 `width`、`height` 添加映射；绑定 `aspect_ratio` 后按所选比例提交，未绑定时由工作流决定比例。档位保持云端要求的数值或字符串格式，比例使用云端 COMBO 的完整选项值；展示像素为估算，实际尺寸以返回图片为准。

没有尺寸映射时，可选择工作流默认尺寸，保留模板中的尺寸参数。显式自定义像素仍要求真实的宽度和高度绑定，缺少绑定时明确阻止提交，避免静默忽略输入。旧像素任务及其重试继续保留原尺寸意图，不自动改成档位或默认尺寸。

已有开关与数量参数原值保留，包括 `195.value` 的 `false` 和 `191.value`（Quantity/Piece）；仅在用户明确修改相应参数时覆盖，不根据数量字段名称推断额外协议。

修正保存后仍显示“未保存”的状态：成功保存时，以归一化后的实际配置同步工作流编辑草稿和保存基准，显示“已保存”；后续编辑才重新标记“未保存”。

## 使用与交付

更新前保存项目并退出旧版，将新 EXE 放在原目录，保留完整的“莲华视频导演台数据”文件夹。

针对性验证通过：6 组云端尺寸 helper 检查、7 项图片尺寸检查，以及全模拟传输检查，确认分辨率计划从生图入口透传到实际请求，2K 与完整比例选项写入相应字段，原有开关和数量参数保留；自定义像素在缺少双维绑定时于上传前拒绝，已有双维含空默认值的精确像素覆盖继续可用。

尺寸界面检查覆盖档位切换、工作流默认尺寸、旧比例偏好主动恢复及比例映射。真实图片设置与工作流管理器的保存专项一次通过：连续保存、关闭重开显示“已保存”，真实未保存编辑仍提示，同一工作流外部变化仍阻止覆盖，其它工作流变化保留。所有请求均使用模拟数据，未调用真实生图服务。

打包流程中的类型检查、生产构建与 Windows 便携包生成通过。交付附 SHA-256 校验清单。

便携包：`莲华视频导演台-2.1.1-便携版.exe`。

打包命令：`npm run pack:win`；交付命令：`npm run deliver:2.1.1`。交付包含便携 EXE、恢复源码 ZIP、更新说明、启动器和 SHA-256 校验清单。2.1.0 及更早历史版本与交付文件保留。
