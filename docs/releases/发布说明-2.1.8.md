# 莲华视频导演台 2.1.8

发布日期：2026-10-14。

## 通用视频 API 设置

通用视频 API 改为与图片 API 类似的布局：填写 API 地址和密钥，点击“获取模型”，再从列表选择或手工填写模型 ID。模型列表完整显示服务返回的名称与别名，由用户自行选择，不过滤模型。

提交端点和任务查询端点按 API 地址自动生成，不再要求在常用面板逐项填写。旧自定义端点、请求模板、认证和响应字段映射保留在高级设置，已有连接与任务继续按保存的配置使用。

## 老李视频服务适配

视频地址使用 `https://video.laoliimage2.win`，设置中提供地址预设。按服务文档使用 JSON 视频请求、稳定的提交幂等键、参考图分片上传、任务查询及成片鉴权下载；特价模型按其协议直接使用原图 Data URL，其余支持的图片参考模型使用上传后的素材地址。

本次接入已有视频任务流程，参考图顺序与首尾帧用途随实际请求传入。视频参考素材和该服务的参考音频选择界面尚未扩展，不能将 RunningHub 音频槽配置直接用于此服务。

密钥由用户在本机连接设置中保存，不写入代码、测试、发布说明或恢复源码。

服务协议来源：[老李视频 API 文档](https://video.laoliimage2.win/docs/video-api/)。支持范围与可用模型以服务端实际返回为准。
