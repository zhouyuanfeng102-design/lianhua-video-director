# 莲华视频导演台 2.0.9 发布说明

发布日期：2026-10-13

## 版本定位

本版修正 RunningHub 图片工作流导入及字段推荐，依据应用 `2079381758411587586` 提供的 API 资料识别提示词与参考图片入口。

包含 2.0.8 的批量设置约半高布局、自适应字号和预览底部按钮修复。

导入后，工作流草稿自动同步 API 资料中的 3 个真实参考图片槽。提示词识别支持唯一且字段说明明确为 Prompt 的文本字段；通用字符串 `value` 开关不再误推荐为提示词入口。

新导入该应用时，提示词绑定为 `107.text`。`195.value` 保留原来的 `false`，`191.value`（Quantity/Piece）保留原值，程序不根据该字段名称自动推断参考图片数量协议。

已有工作流的显式绑定保留。若旧配置已把提示词绑定到 `195.value`，请在输入映射中改选 `107.text`；若已把 `191.value` 绑定为实际参考图数量，请选择“不绑定（保留数量字段原值）”，再保存工作流。也可将原 cURL 重新导入为新的工作流，新导入会识别上述提示词与三个图片槽。

## 使用与交付

更新前保存项目并退出旧版，将新 EXE 放在原目录，保留完整的“莲华视频导演台数据”文件夹。

针对性验证通过：15 组字段推荐检查、16 项图片导入与请求检查，覆盖三个实际图片字段、唯一的 `107.text` 正文映射、0–3 张参考图按顺序绑定，以及其余云端参数保留。

隔离界面检查确认 cURL 导入与模拟读取 9 个字段均显示 3 个图片槽；保存后重开保留三槽，取消编辑不保存，已有槽位顺序及用途保留，新发现的槽追加到末尾。真实网络、上传和生成调用均为 0。打包流程中的类型检查、生产构建及 Windows 便携包生成通过，交付附 SHA-256 校验清单。

便携包：`莲华视频导演台-2.0.9-便携版.exe`。

打包命令：`npm run pack:win`；交付命令：`npm run deliver:2.0.9`。交付包含便携 EXE、恢复源码 ZIP、更新说明、启动器和 SHA-256 校验清单。2.0.8 及更早历史版本与交付文件保留。
