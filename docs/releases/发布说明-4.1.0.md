# 莲华视频导演台 4.1.0 发布说明

发布日期：2026-11-08（亚洲/上海）。

## 画外的人不再由画面里的人代说

人不在这一镜里说话时，镜头写成说话人留在画面外。英文使用 `says in an off-screen voiceover`。这句后面写画面里已有的嘴保持闭合。听的人已经点名时，写他们的嘴保持闭合。

画外的人、旁白和内心声音用同一句。不再把胸口、眼睛或站姿接在这句后面，也不在同一镜把这个人写成正在入画的脸。人本来就在画面里说话的写法不变。

已保存的提示词和成片保持原样。重新生成该段后，画外的台词才会留在画面外。

## 交付

- Windows：`莲华视频导演台-4.1.0-便携版.exe`。
- Android：`莲华视频导演台-4.1.0-安卓版.apk`，最低 Android 8.0 / API 26。
- 4.0.9 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.1.0`。本版是共享提示词写法，EXE 与 APK 一起交付。

## 验证

打包流程自带类型检查和前端构建。表演计划渲染测试已通过。未把已有成片重新生成。
