# 莲华视频导演台 3.2.8 发布说明

发布日期：2026-10-27（亚洲/上海）。

## 分镜静帧写清走向

后山上行、朝石亭走的首帧，以前会把人画成脸朝镜头、亭子在身后。后移跟拍只表示摄影机在人物前方后退，用来看见正脸。目的地仍在人物身体前方。

分镜静帧现在各写一次：人物身体和脚步朝向目的地；摄影机在人物哪一侧；这一张背后看见的是已经走过的路。目的地不画在他们身后。这一张若必须看见石亭，改从侧后方看，石亭在画面前方，人朝它走。人物参考图只锁脸和衣服。

已经生成的首帧不会变。要改方向，用 3.2.8 重新生成该段分镜图片。

不新增校验、重试或按钮。
