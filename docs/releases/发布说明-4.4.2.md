# 莲华视频导演台 4.4.2 发布说明

发布日期：2026-11-10（亚洲/上海）。

## 镜头句子由模型按剧情写

站位、接触的两端、同一个人站在哪一处、嘴的开合、配乐，都由模型读完这一镜的剧情后写进镜头正文。程序把模型写好的句子原样放进 H3，不再按关键词另补一句，也不再改写模型写过的句子。

已保存的提示词和成片保持原样。重新生成该段后才会改。

## 交付

- Windows：`莲华视频导演台-4.4.2-便携版.exe`。
- Android：`莲华视频导演台-4.4.2-安卓版.apk`，最低 Android 8.0 / API 26。
- 4.4.1 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.4.2`。这次改的是提示词怎么写成，EXE 与 APK 一起交付。

## 验证

打包流程自带类型检查和前端构建。H3 正文用内存夹具核对：模型写进镜头的句子原样保留，程序不另补站位、接触、嘴或配乐句子。未在真实 RunningHub 页面上再点运行。
