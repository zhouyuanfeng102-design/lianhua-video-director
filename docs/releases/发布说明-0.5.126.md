# 莲华视频导演台 0.5.126 发布说明

## 版本定位

优化 ComfyUI 视频任务引起的界面刷新和大存档保存开销；支持人物、部位连续入队与一次多张生图；修复单图连接带入多张分镜参考图时仍要求手动取消选图的问题。

## ComfyUI 与本地保存

- 高频进度进入独立运行状态订阅，只有相关任务组件更新；同值进度不重复刷新整页。同一连接的队列查询合并，工作流解析不随每次进度反复执行。
- 对已提交较久、持续多次在成功返回的队列及历史中都查不到的任务，只暂停本地跟踪并给出原因。保留原任务ID和结果待确认状态；网络失败不等于任务不存在，不删除任务，不自动重新提交收费请求。
- 大存档的序列化、校验和磁盘写入交给后台工作线程，下载改用异步写盘和节流进度。系统密钥加解密仍在主进程，状态完整性及原子写入保护保留。
- 关闭时先锁定编辑并保存渲染端最新内容，再等待后台写盘完成。保存失败或等待超时保留窗口，可返回查看或继续等待，不因窗口关闭静默丢弃未保存修改；不取消服务器上的生成任务。

## 连续入队与多张生图

- 不同人物、同一人物不同部位可以连续点击生图，不必等其它生图任务完成。
- 普通生图和私密生图各有1–8张数量选择。例如选择3张全身图，会建立3个独立图片任务；每张保存独立结果，并在支持的后端/采样输入上分配不同种子。
- 完成后可从结果缩略图切换、挑选图片。异步结果写回发起的人物、部位和通道，不覆盖正在查看的其它人物，也不把结果图自动当成参考图。
- 后台继续FIFO逐张生成及保存，取消或失败按单项处理，其它排队项继续。连续入队不等于无限并发占满GPU；上游接口能力、费用与限额保持不变。

## 上段尾帧直接替换整组选图

- 单图 ComfyUI 工作流或仅使用 `{{first_image}}` 的单图API，即使本段从分镜带入多张人物/场景参考图，点击“用上段尾帧”也可直接确认“全部X张→1张真实尾帧”，无需先手工取消选图。
- 自动衔接配置保留原选图，取消即可恢复；原分镜、提示词、图片资产和已生成视频都不删除。有效多图连接仍只替换明确选择的槽，保留其它参考图；多槽歧义不擅自整体覆盖。
- 预检、图片读取和任务快照按最终输入执行，被确认整体替换的旧图缺失不阻塞。后段仍等待本批次准确上一段生成、保存并抽取真实末帧，再提交本段；不拿历史尾帧或假图代替。
- 普通/构图参考只提供连续性参考，严格从该帧起画仍取决于模型和工作流明确支持首帧。

## 验证范围

`test:video-generation` 加入进度外部状态、同值去重、共享队列、遗留任务暂停和控制器回归；`test:image-queue` 加入多张入队、取消隔离和种子检查；`test:storage` 纳入后台保存、关闭握手与隔离 Electron ASAR 工作线程测试。

73MiB合成存档后台保存专项已观察到主事件循环持续心跳；视频链专项使用合成媒体完成6段视频和4次真实末帧抽取。以上均为隔离专项，不代表真实 ComfyUI 满载时保证不卡顿，也不代表真实收费API已验收。最终完整测试、交互界面、生产构建与新包启动烟测以本轮实际执行记录为准，不预先宣称打包验收完成。
