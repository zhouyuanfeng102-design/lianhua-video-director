# 莲华视频导演台 1.7.3 发布说明

2026-10-10

视频导演台新增多人参考音频，支持项目人物音色预设与逐段声音选择。

## 使用方式

项目声音预设可关联人物音频，各段可沿用项目预设、单独覆盖或明确不用。参考音频用途区分人物声音、旁白和氛围，支持试听；选择参考音频不自动新增台词、旁白或整段环境声。

单段与长剧情批量使用独立音频槽。移除音频不会让后续槽号前移，实际容量以当前工作流映射为准；三槽工作流显示三个入口，其他工作流可按真实映射使用更多槽位，不静默丢弃超出容量的选择。

音频文件通过真实工作流输入映射传入。reference、fully_copy、partially_copy、weak_reference模式在本次任务提示词的声音参考说明中表达，不自动添加云端工作流不存在的模式字段；实际执行效果由模型与工作流决定。发现音频输入与识别说话人是不同能力，字段名不能证明音色克隆效果。

任务冻结音频素材、人物用途、槽位和模式，保存重载及重试沿用原输入。经典原色、可选日夜主题、长剧情分段条夜间修复、紧凑批量分段、图像任务提示词滚动框与资产库详细信息默认折叠继续保留。

## 验证与交付

本次针对性检查已通过：工作流真实音频输入识别与映射、标量音频开关排除；实际说话人物的预设继承与逐段覆盖或不用；正文编辑后的声音说明更新及重复渲染幂等；删除音频后的预设解绑；保存重载与独立音频任务识别。未选择音频的旧任务识别值保持不变，历史冻结输入保留。

真实组件界面检查通过了 6 次单段及 1 次三段批量模拟提交，覆盖人物、旁白、氛围用途、四种保留模式、稳定空槽、语言切换、预设更新、保存恢复及日夜显示，无运行时错误或新控件横向溢出。引擎和桌面桥的模拟冻结、上传回执、恢复与重试检查也已通过。这些验证使用隔离合成音频与模拟传输，不执行真实上传或收费生成，不代表任何模型已经实现音色克隆。

应用导入专项已通过：浏览器原文件与校验和、音频时长和波形，桌面托管文件模拟导入，预设保存重载，格式与本地大小限制，以及导入过程中切换项目时防止错误归属。FLAC 格式提示完整保留。

`npm run pack:win` 已通过 TypeScript 检查、生产构建和 Windows 便携版打包。`npm run deliver:1.7.3` 生成便携 EXE、恢复源码 ZIP、更新说明、启动脚本及配套 SHA-256 校验文件。1.7.2 及更早发布说明和交付文件保留。
