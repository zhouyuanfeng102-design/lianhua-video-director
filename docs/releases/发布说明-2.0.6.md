# 莲华视频导演台 2.0.6 发布说明

发布日期：2026-10-13

## 版本定位

本版将新的提示词选择默认设为 H3，修正普通稿选图提示，并收紧视频导演台“长剧情批量”的批量设置布局，让常用设置可以一起查看。

批量提示词格式改为紧凑的行内选择，批量设置的字体、控件高度和间距同步缩小。取消该设置区域内部滚动，提示词格式、全片计划、生成方式与连接、选段操作及生成参数完整展开。打开高级公共参数 JSON 时，与生成参数并排显示；较小窗口进一步压紧字号，为底部生成按钮保留空间。

修正普通稿选图提示：普通稿即使包含旧 H3 同名章节，也以明确选择的稿件格式为准，不再进入 H3 人物锚点诊断。人物参考图已选中时显示“已选 · 图片槽 3、4”等实际编号，正文和原图片槽保持原样；真正的 H3 稿仍按原有身份绑定规则提示。

新建或尚未准备内容的单段、批量，以及从提示词导演台重新选择的入口，默认选择 H3 视频提示词。没有可用 H3 稿时明确提示需先生成，不会自动改选普通稿。已准备草稿保留实际格式、正文、选图与参数，失败任务重试沿用原任务快照；普通稿与 Seedance 可主动选择。

## 使用与交付

更新前保存项目并退出旧版，将新 EXE 放在原目录，保留完整的“莲华视频导演台数据”文件夹。

针对性布局检查通过：1996×1248、1430×870 的默认字号，以及 1280×800 的 130% 字体下，全部常用批量设置完整可见，无内部滚动、遮挡或控件重叠。1280×800 同时展开高级 JSON、指定宽高和参数说明后，设置区与底部生成按钮仍完整显示。检查使用隔离合成项目。

打包流程内的 TypeScript 检查与生产构建通过；未重复执行全量回归。交付附带 SHA-256 校验清单。

人物图片绑定专项测试 28 组通过，新增普通稿保留 H3 章节时的中英文用例，确认原文、选图和稀疏图片槽不变，真正 H3 稿缺少绑定时仍给出提示。

默认 H3 的草稿与批量计划专项检查通过，确认新建、空草稿、未指定格式的入口采用 H3，已准备内容及重试格式保持。隔离界面检查通过：新单段选择器与新批量默认 H3，手动普通稿仍可使用，重新打开选择器回到 H3 且不改已有正文；缺少 H3 稿时不回退普通稿。1280×800、130% 字体下设置和底部按钮完整可见。普通稿人物图选择与槽 3、4 保留的隔离界面检查亦通过。

便携包：`莲华视频导演台-2.0.6-便携版.exe`。

打包命令：`npm run pack:win`；交付命令：`npm run deliver:2.0.6`。交付包含便携 EXE、恢复源码 ZIP、更新说明、启动器和 SHA-256 校验清单。历史版本和交付文件保留。
