# 莲华视频导演台 2.8.2 发布说明

发布日期：2026-10-20（亚洲上海）。

## 本次修复

长剧情中单独生成当前段时，不再要求先完成上一段提示词。当前段可以根据自己的原文和规划生成，已有有效前稿仍用于真实末镜衔接。

- **已有有效前稿**：继续使用紧邻上一段的真实末镜与当前段衔接，保留原有连续性处理。
- **没有有效前稿**：仅按当前段原文和规划独立生成，不借用更早段落或全片稿充当前稿，不把独立生成的结果标记为已完成衔接对齐。
- **重新生成和英文补全**：单独重新生成当前段时，前稿按需使用；独立生成且没有衔接标记的中文稿可以直接补全英文。已经引用前稿的中文稿继续保留原有衔接来源与翻译关系。
- **顺序生成与显式修复**：顺序生成仍按原有次序衔接；用户明确执行衔接修复时，继续使用原有修复语义。

沿用现有入口和调用流程，不新增运行时内容校验、生成拦截、自动重试或模型请求。

## 已有项目如何使用

保存项目并退出旧版后启动 2.8.2，保留 EXE 旁完整的“莲华视频导演台数据”文件夹。进入长剧情对应段落，通过原有生成、重新生成或英文补全入口处理当前段即可。

此次不自动重写已有项目、旧稿、分段和已生成视频。此前的人物参考图关联、镜头、项目状态、工作台布局及动作连续排程等修复全部保留。

## 验证与交付

衔接资料与单段提示词两组定向检查通过，覆盖 H3、Seedance 的有效/缺失/过期前稿、禁止借用更早段和总稿、严格模式保留，以及独立新稿清除旧衔接标记、原稿不改写和调用次数保持。

隔离界面流程通过：直接生成前段缺稿的第 2 段、完成稿不强制发起衔接请求、仅补英文，以及第 3 段使用已有第 2 段真实最终稿。测试样例按现版规划参数与 JSON 交付格式更新后通过，全部使用本地合成响应，无付费 API 请求或用户项目写入。

Windows 打包通过：`npm run pack:win -- --config.directories.output=.pack-release-2.8.2` 完成 TypeScript 检查、Vite 生产构建和 Windows 64 位便携版生成。构建仅提示已有循环分块及大分块警告，无构建错误。

本版便携包命名为 `莲华视频导演台-2.8.2-便携版.exe`。交付步骤使用 `npm run deliver:2.8.2` 生成版本启动器 `启动莲华视频导演台-2.8.2-便携版.bat`、恢复源码 ZIP、更新说明及 SHA-256 清单。

2.8.1 及更早交付文件继续保留，0.5.160 及更早版本不重编号、覆盖或删除。
