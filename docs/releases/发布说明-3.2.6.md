# 莲华视频导演台 3.2.6 发布说明

发布日期：2026-10-27（亚洲/上海）。

## 贴身接触声改成很轻的湿滑

海螺把对白和拟音混成一条立体声，不能单独把彭彭声拉小。看得见的身体接触仍会被配成撞击采样。这次把已经进入且还连着时的声音写成：持续的、很轻的、贴在耳边的湿滑黏连，没有房间敲击回响，停在压低喘息和台词下面。身体仍是缓慢、小幅度、温柔的连续起伏。

第一次进入是一次缓慢滑入，滑的过程用这层很轻的湿滑，滑完不再另加一声。离开或分开只写一次很轻的湿声分离。家具晃动仍只留画面。打斗、摔倒、撞门、拍桌和兵器仍按那一下真实打击写。喉咙里的闷哼保留。对白原话不动。

已经生成的视频不会变。要听到这一层，需要重新生成对应片段的视频提示词。

不新增校验、重试或按钮。

## 版本定位

本版便携包为 `莲华视频导演台-3.2.6-便携版.exe`。交付命令为 `npm run deliver:3.2.6`。3.2.5 及更早交付文件继续保留。

## 定向验证

贴身声音句、保真替换句和英译句各测一次。打包中的类型检查和生产构建另计。
