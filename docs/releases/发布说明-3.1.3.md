# 莲华视频导演台 3.1.3 发布说明

发布日期：2026-10-25（亚洲上海）。

## 文本 API 设置改成对齐的两列

文本 API 设置卡片不再把地址、密钥拆到外层格子里，也不再把操作按钮撑到卡片底部。服务商和模型、地址和密钥、温度和最大输出 Token 使用同一套两列，左右输入框对齐。

「获取模型」从模型名称框里移出，和「测试连接」一起放在字段下方。视觉 API 使用同样的字段排列。接口地址、密钥、额度和已保存配置都不改。

不新增校验、内容审核、生成拦截、自动重试或模型请求。

## 版本定位

本版便携包为 `莲华视频导演台-3.1.3-便携版.exe`，恢复源码包、更新说明和 SHA-256 清单由交付脚本按同一版本生成。交付命令为 `npm run deliver:3.1.3`。3.1.2 及更早交付文件继续保留，0.5.160 及更早历史版本不重编号、覆盖或删除。

## 定向验证

已核对文本 API 与视觉 API 的字段都落在同一套两列里，获取模型和测试连接跟在字段后面。检查使用本地界面结构，不调用真实模型，也不提交图片或视频生成。

Windows x64 便携包由打包流程执行类型检查、Vite 生产构建和便携版生成。本版不改写项目存档和 API 配置。

交付后请核对 `莲华视频导演台-3.1.3-SHA256.txt` 中的 SHA-256 清单。

## 使用与交付

保存项目并退出旧版，打开 3.1.3 便携版，保留 EXE 旁完整的“莲华视频导演台数据”文件夹。原有 API 设置入口不变。
