# 莲华视频导演台 1.9.0

发布日期：2026-10-11

## 风格参考图与 AI 分析填写

提示词导演台“导演与视觉”增加单张参考图上传入口，支持 PNG、JPEG、WebP。上传只保存图片；点击原有“AI 分析填写”后，有图使用 API 设置中的视觉模型，无图保持原来的文本模型分析流程。纯图片也可以分析，有自定义要求时优先按明确要求保留或调整图片风格，并结合当前剧情补充导演调性。

分析填写导演分类、导演风格、导演风格说明和视觉风格，识别媒介、写实程度、材质、调色、光影与美术气质。单张静态图不能证明真实剪辑或动态运镜，这部分根据剧情与要求提出合适调度。图片风格保留具体描述，内部匹配合适的基础预设；无法准确匹配时优先使用现有中性预设，减少旧预设与新风格冲突。

上传按钮沿用当前紧凑布局，有图后原位显示缩略入口，点击弹窗查看、替换或移除；小窗口使用短文案，大图预览不占用参数区高度。

## 保存与请求归属

图片通过现有项目托管资产保存，独立风格引用随当前章节保存和恢复，同章各片段沿用。上传图片不改变已确认生成参数，也不自动加入人物或视频参考槽。换图、移除、改要求或切换章节时使旧分析失效，避免晚返回结果覆盖当前设置；API 或图片读取失败保留原风格。删除资产清理相关章节引用，旧项目缺少新字段时保持原流程。

版本从 1.8.9 按十进位升级至 1.9.0，历史版本和交付文件保留。

## 验证

- 风格图文服务的针对性检查通过，覆盖 OpenAI 兼容及 Claude 图片协议、纯图、图片加要求、同图格式修复、取消、错误和无图兼容。
- 章节保存、重载、切章、更换/清空引用、资产删除、导入导出和旧项目兼容检查通过；草稿原子回填检查通过。旧草稿测试补齐真实章节恢复依赖后重新运行通过。
- 隔离界面检查通过：正常页 7 次模拟请求，换图、改要求及章节往返的 3 种过期结果均未回填；1280×800、1120×720 配合 100%/130% 字号的上传前后共 8 组布局无遮挡。空剧情且关闭文本 API 的纯图、图文两次视觉模拟请求，以及 1120×720/130% 空页上传前后布局也通过。
- 全程使用合成图片及模拟 API，没有调用真实视觉模型。本轮不追加全量回归。

- 最终 `npm run pack:win -- --config.directories.output=release-1.9.0-build` 通过，包含类型检查、Vite 生产构建和 Windows x64 便携包。保留构建既有的分块循环依赖、大分块及作者元数据提示，未阻断打包。

## 交付

`npm run deliver:1.9.0` 生成独立便携 EXE、恢复源码、更新说明、版本启动器和 SHA-256 校验文件；历史版本保留。使用前配置支持图片输入的视觉 API，然后在“导演与视觉”上传参考图并点击“AI 分析填写”。
