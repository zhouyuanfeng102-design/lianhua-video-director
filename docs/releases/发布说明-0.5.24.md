# 莲华视频导演台 0.5.24

## 版本定位

- 0.5.24 是基于 0.5.23 的稳定性修复版，不改变现有导演流程、提示词结构和项目数据格式。
- 继续保留 0.5.23 的 6列×2行紧凑场景区、双栏等宽和字体自适应布局，历史项目保持兼容。

## 项目状态与导入修复

- 修复撤销/重做快照方向错误，并避免切换项目后异步结果写入错误项目。
- 项目导入基于最新工作区状态并保留本机 API 设置；预设往返保留模式、工作流、输入模式和作用域。
- 修复 MoRan API-only 文件导入与活动配置同步；空对象、数组及未知字段不再误报导入成功。
- 视频任务改为公平轮询；剧情分析支持主动取消，并丢弃过期请求结果。

## 模型接口与返回解析加固

- 修复完整接口地址、尾斜杠和查询参数的路径拼接。
- 改进模型返回 JSON 提取，采用最后一个结构有效的对象，并严格校验剧情场景、视觉九宫格和图片响应。
- 图片地址不再误把 Base64 或相对路径当作远程 URL；剧情分析与资料补全会正确传递取消信号。

## 大型版本对比与交付质量

- 优化大型分镜提示词版本对比，避免大文本卡顿，并保留移动行和高重复内容中的主要共同段落。
- 加固便携启动、桌面/媒体/界面自动检查及端口隔离；媒体检查避免偶发空视频样本。
- 修复交付启动器生成路径，确保交付目录中的版本启动器与无版本启动器从自身目录启动便携 EXE。
- 全量测试、生产构建以及 Web、Sequence、Desktop、Media QA 均纳入发布验证；1120×720 至 1430×894 视口检查无重叠、裁切或越界控件。

## 交付内容

- 0.5.24 交付包含 Windows x64 便携版、恢复源码、更新说明、版本启动器、无版本启动器与 SHA-256 完整性清单。
- 0.5.23 及更早历史交付文件继续保留，发布脚本不会覆盖旧版本。
