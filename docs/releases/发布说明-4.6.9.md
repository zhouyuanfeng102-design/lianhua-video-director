# 莲华视频导演台 4.6.9 发布说明

发布日期：2026-11-16（亚洲/上海）。

## 视频导演台交互性能

- 长剧情批量使用分段缓存和独立行组件。切换一段语言、勾选或预览时，复用未改变的中英文 H3 候选。
- 尚未展开的分段设置不创建音频、动作视频等完整编辑器；已展开的编辑器保留本地状态，折叠不打断已有操作。
- 单段选图只更新相关候选；人物身份、物理图片槽和真实尾帧依赖继续按现有记录处理。素材和历史任务索引按各自数据集合复用。
- 视频草稿使用独立的非历史更新路径，不再逐次重写全部撤销/重做快照；撤销其他编辑时保留当前视频草稿。仅表单变化不唤醒全库任务协调。
- 参考图弹窗按可见范围创建卡片，复用现有缩略图和缓存；所有搜索结果和选择值完整保留，可滚动访问全部图片。放大预览和视频提交继续使用原资产或原有传输副本。
- 精简重复的整份草稿、连接和尾帧范围序列化。

没有新增按钮、运行时校验、内容审核、生成拦截、自动重试或模型请求，没有做哈希测试。已保存的分段、原稿、图片、任务快照和成片不改写。

## 定向检查

- 草稿保存分支、撤销/重做、任务协调依赖、单段缓存、历史重复任务优先级及旧任务别名定向检查通过。
- 既有视频草稿选择与槽位/冻结快照检查通过；其中三处旧角色名断言与改造前 4.6.8 基线不符，已同步为基线已有角色名，没有为此改产品行为。音频引用 25 项检查通过。
- 当前真实组件使用 34 段、68 份中英文 H3 稿、320 张小图的隔离数据检查通过。切换语言和勾选均不重建 H3 候选；打开图片弹窗不重跑后台行编辑器；应用图片只准备目标段。全部素材末尾滚动、搜索、选择恢复及 390px 弹窗边界已检查。
- 开发版 React Profiler 同组合成数据：语言切换累计渲染约 473 → 22 ms，勾选约 419 → 16 ms，打开图片弹窗约 135 → 39 ms。这些是诊断样本，不是生产包 INP、真实用户项目或 Android 真机性能承诺。
- 手机尺寸检查针对本次弹窗；不冒充 Android 真机安装、覆盖升级或 WebView 设备验收。双端构建、签名和最终启动结果见同版能力与验证记录。

## 交付

- Windows x64：`lianhua-video-director-4.6.9-windows-x64-portable.exe`。
- Android：`lianhua-video-director-4.6.9-android.apk`，正式发布签名，最低 Android 8.0 / API 26。
- 本地交付保留更新说明、恢复源码和既有 SHA256 清单；GitHub Release 不上传该清单。签名私钥与口令继续保存在仓库外。
- 4.6.8 及更早版本保留原文件名和版本号，不覆盖、不重编号、不删除。

构建：`npm run pack:all`；交付：`npm run deliver:4.6.9`。共享前端由打包流程执行一次类型检查和生产构建，两端复用同一次结果。

本次 GitHub 更新沿用现成双端包，未重新打包、重跑上述测试或进行哈希测试。构建、签名和验证边界见 [4.6.9 能力与验证记录](能力与验证记录-4.6.9.md)，安装与备份见 [安卓安装说明](../android-install.md)。
