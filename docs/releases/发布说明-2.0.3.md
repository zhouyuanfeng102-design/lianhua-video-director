# 莲华视频导演台 2.0.3 发布说明

发布日期：2026-10-12

## 漫画生视频

剧情解析 → 图生视频中新增“漫画生视频”。支持多选 PNG/JPG 多页漫画与条漫；漫画页序与永久图号独立，可上移、下移，并选择右至左、左至右或从上至下阅读。

原漫画页与普通人物、场景参考图分别标明用途。普通参考仍使用原有 AI 识图和身份绑定；漫画页按顺序一起发送到用户配置的多图视觉 API，在一次请求中识别图格、动作、跨页人物和文字，生成连续剧情预览。

每格保留区域、人物、动作及结果、同一事件标识、进入和结束状态、气泡原文、文字类别、说话人及不确定项。看不清的文字与未知说话人保留未知；对白、内心、旁白与拟声分别处理，拟声不自动成为人物朗读。同一动作的多个画格承接为一次事件，漫画格不等于镜头或固定时长，不借衔接补造攻击、胜负和对白。

对白可保留原文或在来源阶段采用中文，原文与中文对照仍保存为证据。后续英文视频提示词翻译保持已采用对白的语言。成片可选择连续动画或动效漫画，设置进入现有剧情和视频生成上下文。

剧情预览可编辑后采用到本章原文，再使用现有“解析并补全”、分段、分镜和视频提示词流程。原页、逐格资料、设置和预览随项目保存。来源或设置变化会提示预览失效；取消、项目或章节切换、迟到响应不会覆盖当前编辑内容。

## 视频参考

漫画整页默认只作为剧情证据，不自动加入人物、场景、道具资产引用或视频参考。详情中可将有有效区域的单格裁图存入资产库，再在导演台为当前片段选择参考或首帧；裁图只截取原始像素，不去除气泡或文字。用户也可在导演台明确选择整页作为故事板参考。

本版暂不导入 PDF/漫画压缩包，不新增本地漫画模型、语义审核或自动重试。多图识别质量取决于所配置的视觉模型，需要用户对照原页修改不确定文字与归属。

## 验证与交付

漫画资料保存恢复、普通参考兼容、页序与来源隔离、共享身份变更、原子保存、取消/迟到响应及重复图片映射的针对性离线检查已通过。多图视觉与分镜上下文模拟请求检查已通过；专项界面验证覆盖多页上传、编辑采用、刷新恢复、旧预览失效、取消、防串章及真实裁图尺寸，报告无界面异常。生产打包中的类型检查、构建及包内版本与功能核对已通过；未调用收费视觉或视频服务，离线模拟不能代替真实漫画识别与成片质量评估。

版本按十进位从 2.0.2 递增为 2.0.3；历史版本与交付文件保留。

漫画规则与读取它的 LLM 模块统一分块，避免生产初始化时提前读取规则常量。隔离生产启动检查通过，应用正常挂载，漫画入口可见，无浏览器异常或外部 API 请求。

便携包：`莲华视频导演台-2.0.3-便携版.exe`

打包命令：`npm run pack:win`；交付命令：`npm run deliver:2.0.3`。
