# 莲华视频导演台 2.2.1

发布日期：2026-10-14。

## 生成前选择 Seedance 或 H3 提示词

原主生成入口固定先生成 H3，Seedance 编写入口依赖已有分镜和结果面板；首次生成或上一轮中断时，用户无法直接选择先生成 Seedance。

本版在提示词导演台的生成参数顶部提供 Seedance / MiniMax H3 选择，单段和长剧情均在生成前确定格式，空结果、失败状态也保留入口。按章节或当前计划保存选择，切换分段继续沿用所选格式。

选择 Seedance 后，生成流程为剧情 → 公共分镜与时间轴 → Seedance 中文 → 英文，不先编写或复核 H3。选择 H3 继续沿用原 H3 流程。结果面板的格式切换用于查看已有稿，切换本身不自动请求模型。

## 长剧情、保存与重试

长剧情的本段生成、顺序生成未完成段、完成判断与重试均使用所选提示词格式；后一段从上一段对应格式的已保存中文末态承接，不要求先生成视频。H3 与 Seedance 的稿件及衔接来源分别保存。

公共分镜转换完成就保存，所选格式中文完成后再保存。Seedance 编写失败可以复用公共分镜重试；英文失败保留中文，支持仅重试英文，避免再次拆镜或重新编写中文。当前项目、分段、参考资料或工作区变化时，异步旧结果拒绝保存。

旧项目缺少新选择字段时继续使用 H3 默认，已有两种稿件和旧资料保留。升级不会重写或自动重新生成旧稿；历史视频任务继续使用其已保存的提示词和执行配置。

## 使用

1. 在提示词导演台的导演参数中先选择 Seedance 或 MiniMax H3。
2. 单段直接生成所选格式；长剧情可生成当前段或顺序生成尚未完成的段。
3. 中文编写失败时重试对应格式；英文失败时选择仅重试英文。右侧切换查看已有的不同格式稿件。

## 已完成验证

本轮使用本地文本请求模拟，通过以下三个针对性测试：

- `seedanceFirstPipeline.test.ts`：实际公共生成管线、真实来源与参考映射、公共分镜与中文异步保存顺序、Seedance 编写失败后复用分镜、英文单独重试、保存边界取消、原 H3 字段保留和旧调用默认 H3。
- `singleSegmentPrompt.test.ts`：既有单段短剧情、长剧情切片与 H3 翻译流程兼容。
- `seedanceWriter.test.ts`：Seedance 专属编写、中文保存、英文失败与重试、旧来源拒收和不完整交付保留原稿。

新 Seedance 状态与衔接测试、既有 H3 衔接兼容测试通过，覆盖独立稿件、独立衔接记录、保存重载、失效判断和目标格式导出。新增衔接修复案例通过，公共转换限定在已有镜界内修复，不重新规划整段摄影。

最终构建中的 TypeScript 检查和 Vite 构建通过。实际构建界面两轮针对性场景各通过一次：单段从无结果首次选择 Seedance，编写失败后复用公共分镜，英文单独重试，格式偏好恢复及查看其他格式无请求；两段顺序生成使用对应 Seedance 中文末态，首段英文失败后仍可继续后段，续跑只补首段英文，并保留原 H3 与公共分镜。

所有接口行为验收仅使用本机文本请求模拟。未调用真实收费生成接口，没有创建图片或视频生成任务。
