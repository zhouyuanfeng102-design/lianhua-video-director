# 莲华视频导演台 3.7.5 发布说明

发布日期：2026-11-05（亚洲/上海）。

## 人物原名不再多出一张空卡

同一人已经有「原名·原始形态」和「原名·另一形态」时，人物栏里的原名不再单独再开一张没有外观的卡。场景里写的原名仍指这个人，挂到已有的形态上。

两份有外观的形态都保留。已解析的章节不自动改。再点一次「解析并补全」后，空卡才消失。

## 版本定位与交付

Windows x64 便携包：`莲华视频导演台-3.7.5-便携版.exe`。构建命令为 `npm run pack:win`，交付命令为 `npm run deliver:3.7.5`；3.7.4 及更早历史版本文件保留。交付目录同时提供恢复源码、更新说明、启动器与 SHA-256 清单。

## 验证

- `npx tsx scripts/characterVariants.test.ts`
- Windows x64 便携包：`npm run pack:win`

已有项目、提示词和成片不作改写。
