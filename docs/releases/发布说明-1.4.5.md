# 莲华视频导演台 1.4.5 发布说明

## 修复启动白屏

1.4.4 新增的剧情因果规则被生产分包规则放入 domain，而其他规则在模块加载时读取它，形成循环初始化。打包后的界面报 `Cannot access 'ra' before initialization`，导致主界面无法显示。开发模式与类型检查不会覆盖这种生产分包错误。

1.4.5 将这组无依赖的共享规则单独打包，消除该初始化依赖。保留画面描述转化、原文追溯、事件因果和双语提示词功能，不修改用户的项目数据或 API 配置。

## 使用方式

退出白屏的旧版，使用 1.4.5 便携 EXE 或对应启动脚本。保留 EXE 旁的“莲华视频导演台数据”文件夹，无需清空缓存、删除项目或重新导入。历史交付文件保留。

## 针对性验证

已先在 1.4.4 生产产物复现白屏并确认异常与用户日志一致。修复版通过类型检查、构建以及真实便携 EXE 的隔离冷启动检查，验证主界面、剧情页“AI画面描述转化”、规则中心与版本，检查启动异常并保存截图。测试使用全新隔离数据目录，不读取真实项目、不调用付费模型。

交付包含便携版 EXE、恢复源码 ZIP、更新说明、启动脚本和 SHA256 校验文件。
