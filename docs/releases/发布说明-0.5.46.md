# 莲华视频导演台 0.5.46

## 版本定位

本版修复长剧情 AI 全片分镜无法切成视频段、普通工作流 UI 回归没有接入强制转换器，以及旧便携包仍会因 schema 校验写死而错误通过三项问题。0.5.45 及更早历史交付文件不会被改写。

## 长剧情切段修复

- AI 镜头的 `sourceBeatIds` 与来源区间统一使用同一组实际相交节拍边界，不再同时保存局部摘录范围和完整节拍范围两套互相冲突的来源信息。
- 保留严格来源校验；未知节拍、单边区间、无效区间和真正不一致的区间仍会被拒绝。
- 新增真实跨模块回归，覆盖一个粗粒度剧情节拍包含多个 AI 局部原文摘录的情况。

## UI 回归与发包一致性

- 普通工作流 UI 回归现在配置隔离文本 API，并依次验证智能导演、AI 分镜规划和最终视频提示词转换器请求。
- 便携包 smoke 从当前源码解析 `CURRENT_SCHEMA_VERSION`，不再把 schema 15 写死为正确结果；也支持显式指定期望 schema 进行隔离验证。
- schema 15 的旧包会被判定为 `currentSchema` 失败，版本号仍采用完整精确匹配。

## 交付

- 当前便携包名为 `莲华视频导演台-0.5.46-便携版.exe`，对应交付命令为 `npm run deliver:0.5.46`。
- 正式交付包含便携 EXE、恢复源码、更新说明、版本启动器和 SHA-256 校验清单。
