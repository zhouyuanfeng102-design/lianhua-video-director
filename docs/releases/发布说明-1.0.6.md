# 莲华视频导演台 1.0.6 发布说明

日期：2026-10-01。

## 版本定位

本版修复AI语义分段中重复输出段数造成的协议矛盾，以及已知字段错误被显示成“未知服务错误”的问题。剧情理解、分段边界及内容继续由原有AI负责，不增加独立审核或本地剧情门禁。

## 分段协议与自动修复

- 新输出根字段只含 `reason`、`fitStatus` 和完整 `segments`，不再重复要求 `segmentCount`。实际段数由完整解析后的数组长度得到，本地不补写、复制、裁切或重新分配剧情。
- AI适配模式由模型结合全文决定实际段数，总时长始终为实际段数乘以用户选择的单段时长；每段都是完整时长，不产生短尾段。
- 自定义总时长模式按实际数组数量核对总时长除以单段时长，不能用一个正确的旧计数字段掩盖缺段，不擅自增加总时长或改变每段秒数。
- 旧格式的一致计数保持兼容；旧计数和实际数组矛盾时，仍由原有最多三次自动修复处理。每次携带完整原文及最近失败回答，要求AI先分清错数还是漏段，再交付完整新格式；不会在本地删除字段后直接接受可能缺失的剧情。
- 数量错误明确显示“AI声明几段、实际返回几段”；固定预算错误显示所需段数、总秒数、单段秒数及实际段数。摘要、详情与复制继续保留具体原因和重试次数，并沿用敏感内容脱敏。
- 失败不覆盖旧计划和已有成果，忙碌状态与请求锁正常释放，可在同一界面再次请求AI分段。

## 保持的边界

- 不增加独立AI审核调用，不以本地语义判断修改剧情；自动恢复与技术修复仍共用初始请求加最多三次重试的额度。
- H3视频提示词格式、生图规则、NSFW规则及参考图流程保持不变。
- 历史计划、最终提示词、图片、视频与正式项目不会因升级自动改写或重新生成。未知上游错误不会被伪装为分段计数问题，服务端拒绝与过滤仍沿用原处理。

## 使用与数据

便携包：`莲华视频导演台-1.0.6-便携版.exe`。构建后执行 `npm run deliver:1.0.6` 生成本版恢复源码、更新说明、专属启动器及 `莲华视频导演台-1.0.6-SHA256.txt`。SHA-256覆盖本版EXE、恢复源码、更新说明和专属启动器。

版本从1.0.5按十进位更新为1.0.6，下一版为1.0.7。请保存并关闭旧版后再启动新版；保存失败时先导出项目备份。历史发行文件和用户数据保留，不覆盖旧版本、不重编号、不删除。
