# 莲华视频导演台 0.5.81 发布说明

## 版本定位

- 本轮只修复生成视频提示词时原对白被裁剪或漏掉的问题，保留原台词，由原配置文本 API 按剧情合理安排时间，不扩展其他功能。
- 已定位的本地缺陷是 `clipDialogueToDuration` 按固定每秒 4.5 字估算容量并裁剪对白。本版删除该裁剪，不因字数或预估语速截断、删掉原台词，也不以这些估算硬拒绝结果。
- API 根据剧情、说话节奏与动作关系安排对白时间，保留原说话人与原语言，不为安排对白擅自更改总时长、镜长、种子或生成参数。
- 生成及 API 补齐只关注确实漏掉的原台词，允许标点、空白、拆句和合理跨镜安排，不新增格式或语速门槛，不因无关的严格检查反复报错。
- 保留 0.5.80 的 API 自动修复与自然动作声：不强制每次亲吻都有独立音效，中景轻吻可几乎不可闻，必要脚步、碰撞保留，不为每个小动作配声。
- 默认无配乐、明确要求时低配乐、去连续底噪、英文描述中的对白原语言保护、视频化整理与扩写补全继续保留。
- schema 21、H3 指纹 v4、参考素材、自定义/禁用/删除状态及旧存稿不改写，0.5.80 及更早版本化交付与正式数据保留。

## 使用方式

完成交付后，保存工作并关闭旧版，通过 `交付\启动莲华视频导演台-0.5.81-便携版.bat` 打开新版。基于含有完整对白的原剧情，重新生成所需的视频提示词；无需按估算语速手动删短台词。已经保存的旧提示词或已生成视频不会自动重做。

对应便携包为 `莲华视频导演台-0.5.81-便携版.exe`。构建便携版后执行 `npm run deliver:0.5.81` 生成版本化交付。

## 验证与交付

本轮仅针对本地源对白保留、API 最终对白防漏、标点/空白/拆句/合理跨镜安排与时间/参数保护进行验证，不跑整套旧功能回归。

已通过 `test:dialogue-source`、`test:dialogue-retention`、`test:app-effects`、`test:prompt`、单段共享生成测试和测试源码类型检查。覆盖草稿漏句、长对白不裁剪、多轮 API 补齐、单/双引号、标点空白变化、跨镜拆句、指定英文对白、H3 保留台词里的 2K/16:9、旧切片漏句补回及取消/网络失败保护。未增加固定语速或刻板台词格式门槛。

生产构建通过；仍有既有的大于 500 kB 分块提示，本轮未扩展性能改造。接口测试使用模拟返回，未调用真实文本模型或生成新视频，不将规则测试描述为实际视频效果验证。

交付脚本生成便携 EXE、恢复源码 ZIP、更新说明、版本专属启动器及 `莲华视频导演台-0.5.81-SHA256.txt`。SHA-256 清单核验四个版本化产物；未生成产物前不提供虚构校验值。旧版本和正式项目数据不改写。
