# 莲华视频导演台 3.6.1 发布说明

发布日期：2026-10-31（亚洲/上海）。

## 语义分段实际返回完整保留

固定总时长模式不再用用户目标 `T ÷ D` 拒收整份 AI 结果。解析时以完整 `segments` 数组作为实际段数唯一来源：AI 返回 20 段就保留 20 段，返回 25 段就保留 25 段，不截断、不补齐、不删除已返回正文。旧格式可选的 `segmentCount` 和总时长声明也不会覆盖数组实际内容。

成功计划的每段时长仍保持所选 `D` 秒，计划总时长统一按实际 `N × D` 计算；固定请求的 T 仅作为本次规划上下文，发布后不再制造“段数、总时长、输入恢复”互相矛盾的状态。`fitStatus=insufficient` 的既有失败诊断仍按原规则处理。

固定模式提示词同步说明：目标 T 和目标段数是规划参考，D 是固定窗口，成功结果的 N 以完整数组为准。仍只发起原有一次模型请求，不增加校验、内容拦截、自动重试、按钮或模型调用。

## 版本定位与交付

Windows x64 便携包：`莲华视频导演台-3.6.1-便携版.exe`。构建命令为 `npm run pack:win`，交付命令为 `npm run deliver:3.6.1`；3.6.0 及更早历史版本文件保留。交付目录同时提供恢复源码、更新说明、启动器与 SHA-256 清单。
