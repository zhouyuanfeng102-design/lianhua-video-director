# 莲华视频导演台 2.1.3 发布说明

发布日期：2026-10-13

## 版本定位

本版修复 RunningHub V3 AI 应用 `2079381758411587586` 选了参考图却仍带入模板示例图、选择画面比例后云端条件开关仍关闭的问题。

新导入该应用时绑定真实参考图片槽、分辨率与比例字段；兼容已保存配置中漏掉的真实图片槽。已选参考图按实际槽位上传替换，本次未选的 `181.image`、`182.image`、`183.image` 按官方可选值 `None` 提交，避免示例图继续参与生成。

指定比例时同步启用该应用的真实比例条件开关 `195.value`，零参考图文生图也启用该开关；有参考图且使用工作流默认尺寸时保留原尺寸开关。其它应用继续使用已有图片与尺寸协议。

参数依据为 2026-10-13 读取的[官方应用页面](https://www.runninghub.ai/ai-detail/2079381758411587586)：三个参考图输入均声明可选值 `None`；应用介绍说明，文生图需删除全部参考图并开启“其他比例”，图生图更改比例也需开启该开关。适配只更改本次提交副本，保存的工作流默认值不被改写；显式备份导入保留手工映射。

## 使用说明

更新前保存项目并退出旧版，保留完整的“莲华视频导演台数据”文件夹。

在普通或私密生图中上传图片，或从资产库选择匹配当前人物与部位的图片后，确认当前通道出现参考图缩略图、参考复选框已选，再生成图片。切换人物、私密部位或版式后，应确认当前通道仍有需要使用的参考图。

指定画面比例时选择对应比例及分辨率档位；选择“工作流默认尺寸”且带参考图时，沿用云端原有尺寸行为。修复仅针对上述已知 V3 应用，未将其节点和条件开关规则套用于其它工作流。

已保存的项目、任务记录、图片及历史交付文件保留，本次更新不自动重新提交历史任务。
