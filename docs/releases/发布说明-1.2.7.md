# 莲华视频导演台 1.2.7 发布说明

日期：2026-10-04。从 1.2.6 按十进位版本规则升级，历史交付文件保留。

## 版本定位

修复 H3 交付元数据的格式兼容、具体字段报错与定点重试，保留必要的一致性校验。

## 修复内容

- 人物绑定中未使用的可选编号支持省略、null 和空字符串；版本字段兼容数字 1 与字符串 "1"。必填人物 ID、姓名和身份定位句不补造、不清空。
- 交付格式说明与读取器使用共享规格，明确必填字段、数组/对象、允许空值的规则以及完整的结构示例。
- 人物绑定、镜头元数据和来源映射的格式错误显示具体字段路径、镜头序号、期望类型及实际结构，不再统一报“缺少字段”。诊断只记录类型、长度、数量，不记录响应正文。
- 修正本地交付错误被误显示为“服务返回了未识别的错误”的问题，旧日志的已知字段错误也可准确显示。
- 对可定位的元数据错误，只请求修复对应附带字段，逐字锁定当前 H3 正文和排程；响应试图修改锁定内容时拒绝接受。修复后仍经过完整的身份、来源、排程和 H3 检查。
- 正文或排程本身不完整时，仍使用完整交付修复；共享三次技术重试上限。取消、切换项目或修复失败继续保留原有保存结果。
- 沿用 1.2.6 移除图像工作台重复结果区域的调整。

## 使用

保存并正常退出旧版，在原交付目录运行 `莲华视频导演台-1.2.7-便携版.exe`，进入提示词导演台重试原来失败的分段。旧日志不会自动删除，旧失败记录不会自动变成成功。

本次不自动提交视频、不重跑用户项目。新包读取原目录的项目数据，无需重建项目或删除已有提示词。

## 验证范围

使用中性、虚构的离线样例检查可选空值、必填字段、来源映射、完整交付、定点修复、重试上限及取消时结果保留。完成相关回归、严格类型检查、生产构建及隔离目录的新包启动、保存与重载检查。

未调用真实 DeepSeek 或视频生成接口；模型实际能否按要求返回内容，仍由此次真实请求的响应决定。软件不会把缺失的必要资料伪装成校验成功。

构建：`npm run pack:win`。交付：`npm run deliver:1.2.7`。交付包含便携 EXE、恢复源码 ZIP、更新说明、启动器及 SHA-256 清单。
