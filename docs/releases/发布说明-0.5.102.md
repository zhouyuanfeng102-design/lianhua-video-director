# 莲华视频导演台 0.5.102 发布说明

## 版本定位

本版修复图像工作台没有显示提示词导演台 AI 填写视觉风格的问题。目标便携包为 `莲华视频导演台-0.5.102-便携版.exe`。

## 图像工作台

- 图像工作台的视觉风格会继承提示词导演台当前视觉风格，包括“AI 分析填写”生成的自定义视觉风格。
- 新建资料、切换项目、切换人物/场景/物品/九宫格时，图像工作台默认视觉风格不再回落为“电影写实”，而是使用导演台当前风格。
- 在图像工作台手动修改视觉风格后，会保留图像工作台自己的手写值，不会被导演台后续变化自动覆盖。
- 生图提示词转换继续读取图像工作台当前显示的视觉风格，规则中心和旧项目兼容兜底保持不变。

## 验证

本轮针对性验证：

```powershell
npm run test:typecheck
npm run test:styles
npm run test:workflow
npm run test:image-rule-app
npm run test:release-review
```

并使用 Playwright 打开开发页面验证：

- 在提示词导演台输入自定义视觉风格后，切到图像工作台，视觉风格字段同步显示该值。
- 图像工作台手动改过视觉风格后，再修改导演台视觉风格，图像工作台手写值不会被覆盖。

交付时使用：

```powershell
npm run pack:win
npm run deliver:0.5.102
```

交付应生成 0.5.102 便携版、恢复源码、更新说明、版本专属启动脚本和 `SHA-256` 清单；现有 0.5.101 及更早版本化产物继续保留。最终校验值以 `交付\莲华视频导演台-0.5.102-SHA256.txt` 为准。
