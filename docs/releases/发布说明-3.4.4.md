# 莲华视频导演台 3.4.4 发布说明

发布日期：2026-10-29（亚洲/上海）。

## 修复视频台词缺失与模糊发声

- 扩写、AI 画面转化、语义分段和逐镜规划明确区分完整可朗读台词与低声、隔门、画外等发话方式。
- 上下文已明确沟通目的时，整理出最短自然完整回应；笑、哭、咳、喘等非词汇人声仍按非对白声音处理。
- H3 在性能 sidecar 缺少对白时，从 canonical 镜头补齐原话，并保留说话人、原始标点、发话线索、镜头内时段和重复发话次数。
- 英文提示词沿用原语种台词，不把动作声或声源描述当成对白。
- 不新增模型请求、运行时校验、生成拦截、自动重试或按钮。

## 版本定位

本版 Windows 便携包为 `莲华视频导演台-3.4.4-便携版.exe`。构建命令为 `npm run pack:win`，交付命令为 `npm run deliver:3.4.4`；交付同时生成恢复源码、更新说明、专属启动器和 SHA-256 清单，已有版本文件保留。
