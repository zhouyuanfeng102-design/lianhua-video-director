# 莲华视频导演台 3.0.9 发布说明

发布日期：2026-10-25（亚洲上海）。

## 文本最大输出 Token 改为档位加自定义

文本 API 设置里的「最大输出 Token」改为选项加自定义。可选 32k、64k、128k、256k。32k 发出 32768，64k 发出 65536，128k 发出 131072，256k 发出 262144。新配置默认选中 64k。

选「自定义」后仍可手填其它正整数。已经保存的数值不会被改掉；不在这四档里的数字会显示为自定义。视觉 API 的最大输出额度仍是原来的数字框。

不新增校验、内容审核、生成拦截、自动重试或模型请求。这里只是原来那个额度的选法，请求仍只发一次。

## 版本定位

本版便携包为 `莲华视频导演台-3.0.9-便携版.exe`，恢复源码包、更新说明和 SHA-256 清单由交付脚本按同一版本生成。交付命令为 `npm run deliver:3.0.9`。3.0.8 及更早交付文件继续保留，0.5.160 及更早历史版本不重编号、覆盖或删除。

## 定向验证

已核对文本 API 控件提供 32k、64k、128k、256k 和自定义，新配置默认值为 65536。检查使用本地设置，不调用真实模型，也不提交图片或视频生成。

Windows x64 便携包由打包流程执行类型检查、Vite 生产构建和便携版生成。本版不改写已保存的文本 API 额度。

交付后请核对 `莲华视频导演台-3.0.9-SHA256.txt` 中的 SHA-256 清单。

## 使用与交付

保存项目并退出旧版，打开 3.0.9 便携版，保留 EXE 旁完整的“莲华视频导演台数据”文件夹。原有文本 API 设置入口不变。
