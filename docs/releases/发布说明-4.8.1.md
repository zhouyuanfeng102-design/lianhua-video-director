# 莲华视频导演台 4.8.1 发布说明

发布日期为 2026-11-19（亚洲/上海）。

导入 ComfyUI API JSON 时，接到 CFG 引导器或采样器正面口的 Qwen Image 文本编码节点也会被识别。提示词连线可以经过展示节点和开关；开关是布尔值时只走当前接通的那一路，占位符写在那一路的字符串上。系统提示词不替换。同一编码器上的负面提示词字符串单独写成负面占位符。

Windows x64 使用 `lianhua-video-director-4.8.1-windows-x64-portable.exe`。Android 使用 `lianhua-video-director-4.8.1-android.apk`，最低 Android 8.0（API 26）。

同版提供 Windows 与 Android 软件包、源码恢复包、安装说明、能力与验证记录、Windows 启动器及本说明。

签名与验证范围见 [4.8.1 能力与验证记录](能力与验证记录-4.8.1.md)。安卓安装与备份见 [安卓安装说明](../android-install.md)。
