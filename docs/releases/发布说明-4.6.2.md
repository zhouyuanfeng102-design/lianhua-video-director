# 莲华视频导演台 4.6.2 发布说明

发布日期：2026-11-14（亚洲/上海）。

## 同场的人从第一镜就在，门不再自己动

同一场原文已经把人写在房间里时，例如几步之外或已停在面前，这个人从这一段就在场。下一段从同一位置继续。第一镜写这些人站在门或台的哪一侧，房间只是他们所在的空间。只有这一拍确实没有人，第一镜才用空的地点。

场景、道具、服装和风格图写进对应的主体说明，只保留建筑、固定陈设、光线或外观。人物出现在这一镜写明的位置。单独的图片行只用于真正的首帧、尾帧或关键帧。

已经落锁或已经关上的门保持关上，可以有一声轻响，门扇不再自己移动。这一句写的是正在关上、房间里已经有人时，写成这个人的手留在门闩上。只有这一句已经写了魂力或其他能力，才写那种力作用在门上。

已保存的成片、分镜和提示词不改写。下次重新生成分段、分镜或提交视频时按这个写法。

## 交付

- Windows：`莲华视频导演台-4.6.2-便携版.exe`。
- Android：`莲华视频导演台-4.6.2-安卓版.apk`，最低 Android 8.0 / API 26。
- 4.6.1 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.6.2`。分段、分镜和视频提示词在两端共用，EXE 与 APK 一起交付。

## 验证

打包流程自带类型检查和前端构建。参考图职责、身份所在镜头、同场走位和落锁写法由对应定向测试核对。
