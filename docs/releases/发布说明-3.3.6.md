# 莲华视频导演台 3.3.6 发布说明

发布日期：2026-10-27（亚洲/上海）。

## 叙述里的已说内容进入台词

修复“宋玉一路说着后山几处灵田今年的收成”被同时当成动作和不完整对白的问题。现在，`说、道、问、答、笑说、一路说着、接着说、低声说`等发声动词后面已经写出的具体内容，按原字归入对应人物的 dialogue 和 H3 `<d>` 一次；动作正文只保留“一路说着”等说话动作，不重复同一内容。

只有“说了几句”“接着说下去”这类发声动词后没有具体内容时，才不新增台词。已有引号原话继续逐字保留。

画面描述转化和扩写入口也采用同一规则：先把这类叙述中的具体发声内容记录为对白事件，再交给后续正文或 H3 排版；`dialogueMode=not-required` 只表示不强制创作原文没有的新对白，不会压掉原文已经写出的发声内容。

本次只调整现有语义分段、对白交付和 H3 编写规则，不新增运行时校验、内容拦截、自动重试、按钮、哈希测试或模型请求。
