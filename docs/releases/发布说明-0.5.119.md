# 莲华视频导演台 0.5.119 发布说明

## 版本定位

本版针对 Krea-2 和 ComfyUI 多人物生图时的角色属性串位、身体部位错位、服装道具互换、重复全身等问题，升级生图提示词规则和分类预设。单人图默认路径继续保留；多人同框时可手动选择新的多人绑定预设。

## 多人物生图规则

- Krea-2 自然语言规则新增多人空间绑定：先锁定左侧、右侧、前景、后景、遮挡层和接触点，再逐人写身份、身体结构、发型脸部、体态、服装、动作、表情和道具。
- ComfyUI / SD 标签规则新增单提示词兼容结构：基础质量、场景、机位和光影放在 `BREAK` 前；多人角色按 `left character`、`right character`、`foreground character`、`background character` 等方位分组放在 `BREAK` 后。
- ComfyUI 负向提示补强 `gender swap`、`swapped anatomy`、`swapped clothing`、`attribute leakage`、`fused bodies`、`duplicate body`、`extra full body` 等常见多人串位控制词。
- 新增 Krea-2 多人物绑定、ComfyUI 单提示词多人绑定和 ComfyUI 多区域绑定预设。多区域预设面向支持区域/蒙版 conditioning 的 ComfyUI 工作流；若仍使用单个文本节点，也可作为方位绑定提示词使用。

## 兼容边界

- 不加入年龄门禁，避免与既有门禁重复。
- 不把 ComfyUI 强行改成 NovelAI 的多竖线角色分段；当前 `sd-tags` 输出仍保持最多一个 `BREAK`，兼容现有清洗与工作流注入逻辑。
- 提示词规则能降低多人串位概率，但 ComfyUI 多人物要更稳定，仍建议配合区域 conditioning、蒙版、姿态或参考图控制工作流。
- 生图规则目录升级到 v6；旧项目只补齐内置多人预设和未编辑过的内置 Krea-2/ComfyUI 规则。用户自定义规则、禁用状态、删除记录、默认选择、模型和工作流参数不被覆盖。
