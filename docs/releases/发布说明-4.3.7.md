# 莲华视频导演台 4.3.7 发布说明

发布日期：2026-11-09（亚洲/上海）。

## 没要求的音乐不再留在正文里

没有明确要求配乐时，`non_diegetic_music` 仍只写 `N/A`。镜头、动作说明、拟音和环境声里讲音乐、配乐、旋律、乐器、伴奏、鼓点或 BGM 的句子一并拿掉。`<d>` 里的原话不动。剧情里的收音机、哼唱和现场演奏留在对应镜头。不写「不要配乐」。画面风格只留色彩、材质、光影、质感。

已保存的提示词和成片保持原样。重新生成该段后才会改。

## 交付

- Windows：`莲华视频导演台-4.3.7-便携版.exe`。
- Android：`莲华视频导演台-4.3.7-安卓版.apk`，最低 Android 8.0 / API 26。
- 4.3.6 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.3.7`。这次改的是配乐怎么写进提示词，EXE 与 APK 一起交付。
