# 莲华视频导演台 3.7.6 发布说明

发布日期：2026-11-06（亚洲/上海）。

## RH 网页可以读取槽位并生成

视频连接在「RunningHub 云端」旁边增加「RH 网页」。打开应用页后，读取图片槽、音频槽、时长、比例、百万像素和提示词，再绑到导演台已有的参数和槽位。

生成使用已登录的网页窗口和账号里的 RH 币。云端 API Key 和已保存的云端工作流不改。

网页生成完成后，软件打开「我的生成」，对上任务 ID，点这一条的「下载」，把视频存进当前项目。播放器里的预览不入库。

## 版本定位与交付

Windows x64 便携包：`莲华视频导演台-3.7.6-便携版.exe`。构建命令为 `npm run pack:win`，交付命令为 `npm run deliver:3.7.6`；3.7.5 及更早历史版本文件保留。交付目录同时提供恢复源码、更新说明、启动器与 SHA-256 清单。

## 验证

- `npx tsx scripts/runningHubWeb.test.ts`
- `npx tsc --noEmit --skipLibCheck`
- Windows x64 便携包：`npm run pack:win`

已有项目、提示词和成片不作改写。
