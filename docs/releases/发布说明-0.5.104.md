# 莲华视频导演台 0.5.104 发布说明

## 版本定位

本版修复提示词导演台“导演与视觉”的 AI 分析填写在 NSFW 剧情下把导演分类、导演风格和视觉风格写成“无法提供”的问题。目标便携包为 `莲华视频导演台-0.5.104-便携版.exe`。

## 导演与视觉

- “AI 分析填写”新增 NSFW 风格分析规则；遇到裸露、私密身体、性行为或亲密状态时，只提炼导演分类、导演风格说明和视觉风格。
- 该规则不加入年龄门禁；年龄门禁继续由软件其它位置负责，当前按钮只处理镜头调度、节奏、构图、光影、材质、色彩和媒介风格。
- 如果文本模型仍返回“无法提供、无法协助、抱歉”等拒绝字段，本地会判为无效并调用同一文本 API 自动返修一次。
- 现有导演/视觉下拉选择和自定义输入保留，AI 分析结果仍然写入可编辑文本框。

## 验证

本轮针对性验证：

```powershell
npm run test:llm
npm run test:typecheck
npm run test:styles
npm run test:workflow
npm run test:image-rule-app
npm run test:release-review
```

交付时使用：

```powershell
npm run pack:win
npm run deliver:0.5.104
```

交付应生成 0.5.104 便携版、恢复源码、更新说明、版本专属启动脚本和 `SHA-256` 清单；现有 0.5.103 及更早版本化产物继续保留。最终校验值以 `交付\莲华视频导演台-0.5.104-SHA256.txt` 为准。
