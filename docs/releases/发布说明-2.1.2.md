# 莲华视频导演台 2.1.2 发布说明

发布日期：2026-10-13

## 版本定位

本版从分镜生成的源头改善切镜：先理解连续场面、人物目标、行动因果与局势变化，再确定观众此刻需要理解什么，选择少而充分的镜头和简单连贯的摄影。

同一镜头可以连续承载进入、交谈、攻防与回应，不把人物登场、动作阶段、每次碰撞或每句对白自动拆成新镜。关键揭示、真实换场、视点转移及必要反应仍可切换，不强制一镜到底，也不以复杂运镜替代必要切镜。风格与运镜偏好服务剧情，高速动作不自动变成快速剪辑。

普通转换、H3 转写及 Seedance 沿用源分镜已经确定的镜数、切点、机位、运镜和观看重点，保留动作强度、空间关系与完整原对白，减少下游再次导演。用户明确请求的对白排程修复仍按其授权范围处理。

身份资料用于辨认和连续性，必要的稳定身份、可见外貌与衣着事实保留，重复档案合并后只在需要的位置定义；姿势、手持道具及当镜变化写在实际演出中。普通微动作按自然先后表达，不逐项编造小数秒停留。

本版使用既有字段和请求，没有新增本地语义校验、审核调用或自动重试。历史工厂规则的识别指纹继续保持，已保存的项目、提示词与媒体不自动改写。

## 应用到已有项目

更新前保存项目并退出旧版，保留完整的“莲华视频导演台数据”文件夹。

历史稿需要主动重新生成源分镜，再生成对应 H3、英文或 Seedance 提示词，才能采用新的摄影方案。仅翻译、刷新参考资料或转写旧稿会保留原镜数与切点；沿用历史全片方案的片段仍使用该方案的已定镜头，应回到源头重新生成。旧稿与已生成媒体继续保留。

## 验证与交付状态

与本次改动相关的针对性源码检查已通过，覆盖源头分镜规则、语义分段与对白排程、下游转写权限、身份保真及历史规则兼容。请求检查使用模拟数据，未调用真实付费文本、图片或视频模型；这些检查不等于真实生成效果已经实测。

本次打包流程中的类型检查与生产构建已通过，Windows 64 位便携包已生成，并核对了包内版本与新规则。交付附有 SHA-256 清单，供核验文件完整性。未另做新包启动、界面或真实模型生成验收。

便携包：`莲华视频导演台-2.1.2-便携版.exe`。

打包命令：`npm run pack:win`；交付命令：`npm run deliver:2.1.2`。交付包含便携 EXE、恢复源码 ZIP、更新说明、启动器及 SHA-256 校验清单。2.1.1 及更早历史版本、文档与交付文件保留。
