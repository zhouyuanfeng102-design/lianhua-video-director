# 莲华视频导演台 0.5.110 发布说明

## 版本定位

本版修复“AI剧情优化”点击后没有结果、也没有可追查报错的问题，并完成九宫格母版绑定和 ComfyUI 参考图工作流校验。目标便携包为 `莲华视频导演台-0.5.110-便携版.exe`；0.5.109 及此前功能继续保留。

## 本轮修复

- 修复对白保护解析：`祂用和蔼的声音回答道` 这类“代词 + 说话方式 + 说话动作”不再被当成完整人物姓名。模型把说话者正确整理为已有实体时，结果不会再被错误丢弃；原文中明确出现的人名仍严格保护。
- DeepSeek 剧情优化请求明确关闭思考模式；配置的输出上限被接口拒绝且超过 8192 时，会使用 8192 重试。
- 视频化场景结构或原对白保真校验未通过时，会把具体问题交给同一文本模型自动修复一次。自动修复后仍不合格才判失败，原文始终不被覆盖。
- “AI剧情优化 / 扩写”的真实失败会写入左侧持久报错日志，按钮恢复可用，并保留完整中文原因；不再只依赖短暂提示。
- 九宫格模式统一只保留一张有效 `grid` 母版。上传、生成或从资产库选择新母版时替换旧母版，同时清理隐藏的失效或非九宫格选择，避免旧普通分镜冒充当前结果。
- 带九宫格母版的 ComfyUI 分镜生成会在人物补齐、任务创建、图片上传及请求发送前，验证当前 Workflow 是否有真正接到有效输出的 `LoadImage` / `IPAdapter` 参考图链。无效或断开的链路会明确提示并写入图像生成报错日志。
- 提示词导演台删除重复的“图片 + 故事”入口，仅保留“纯文字”和“参考图”。

## 升级与数据

请先保存当前工作并完全关闭旧版，再启动新版。推荐启动 `交付\启动莲华视频导演台-0.5.110-便携版.bat`；无版本启动器在本次交付完成后也会指向 0.5.110。

schema 保持 **23**，不新增数据迁移；既有项目、素材、任务、规则、API/模型配置及生成参数保留。本轮不删除旧包或任何正式数据，现有 0.5.109 及更早版本化交付继续保留。
