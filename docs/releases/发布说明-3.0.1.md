# 莲华视频导演台 3.0.1 发布说明

发布日期：2026-10-24（亚洲上海）。

## 修复英文视频提示词的行进方向歧义

英文提示词翻译现在明确将人物行进与摄影机运动分开表达：人物继续向前或沿同一路线前进，摄影机作为主语在人物前方后退跟拍，避免把镜头的后退误写成角色倒退。

对“转回身”等中文说法，翻译契约结合上下文区分头部/视线回到路线前方、身体重新面向路线后续行，以及真正的路线折返；同时要求用自然、简洁的英文视频提示词表达，避免生硬照搬中文语序。H3 槽位翻译指令明确要求逐项返回所有输入描述单元，避免遗漏单元后退回中文原文形成中英混杂。

源头场面规则补充了对话后续行的身体连续性：如果只是停步偏头交流，躯干和脚仍沿既有路线时只需让头部/视线回正，不将其扩写成掉头。以上均为既有提示词契约的定向修复，不新增产品运行时校验、内容审核、生成拦截、自动重试、按钮或模型请求。

## 定向验证

已通过 `scripts/videoActingCameraRules.test.ts`，覆盖源头续行规则、英译中摄影机主语/行进方向表达，以及 H3 完整槽位返回要求。

Windows x64 便携包由打包流程执行类型检查、Vite 生产构建和便携版生成；恢复源码包、更新说明、启动器和 SHA-256 清单由交付脚本生成。
