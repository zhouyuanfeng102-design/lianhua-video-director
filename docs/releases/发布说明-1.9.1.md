# 莲华视频导演台 1.9.1

发布日期：2026-10-11

## 自定义生图与图片提示词反推

图像工作台入口更名为“自定义生图+反推图片提示词”。在现有“上传参考图”“从资产库选择”旁新增反推按钮，继续复用原图上传与选择入口。单张参考图直接反推，多张先选其中一张；自定义要求可以为空，也可以补充需要关注的细节。反推使用当前视觉 API，独立于生图 API、规则转换和生成尺寸设置。

聊天按五项显示：可直接复用的完整反推提示词、人物详细信息、物品详细信息、场景详细信息、具体风格详细信息。补充构图、光线、配色、可读文字、关键还原点、避免项及不确定细节。修改背景、衣服等要求与忠实原图资料分开表达。可以复制提示词、复制全部分析或填入自定义要求；已有草稿先选择追加/替换，不自动提交生图。

反推使用原图像素，不使用界面缩略图。支持的 OpenAI 兼容接口可使用高细节图片输入，Claude 沿用其原生图片消息。返回五项结构化完整结果才显示完成，格式不完整时最多结合同图补正一次；网络失败、服务拒绝、输出截断及取消直接显示原因。

提示词用于尽量还原可见画面，无法仅凭图片唯一恢复原始提示词、生成模型或随机种子，也不能保证纯文字生成像素一致的图片。建议复现时保留原图作为参考，配合反推提示词和相同比例使用。

## 资料任务与后台执行

反推正式纳入“生成任务 → 资料任务”，与原有 AI 资料补齐一起查看。聊天和任务页共用同一条任务记录，状态、结果与删除同步。卡片显示原图、名称、视觉模型、时间、状态和关注要求，并使用与生图任务一致的独立滚动小框显示完整“反推提示词”；复制始终获取全文，完整五项可以展开查看或回到聊天记录。

切换页面或项目后后台继续执行，结果写回发起项目。排队时可以取消，运行时可停止分析，停止后晚到响应不能改为成功。失败或取消可以按原图快照和原要求创建新反推任务，明确使用当前视觉 API，保留旧记录。运行中先停止再删除；删除反推记录同时移除对应聊天记录，保留原图与已生成图片。

## 保存与恢复

任务保存原图托管快照、校验信息、尺寸、关注要求、模型、状态和完整分析。原图快照纳入桌面媒体保存、项目导出与导入路径恢复，避免只保存文字而丢失任务原图。重启时未完成任务提示“上次分析中断，可重试”，不自动再次调用 API。旧项目和原有资料补齐、生图任务保持兼容，版本从 1.9.0 按十进位升级至 1.9.1，历史包保留。

## 验证与交付

针对性模拟检查已通过：视觉请求与五项完整输出、格式补正、停止与迟到响应保护、重试与防重复提交、项目归属、保存恢复、媒体导出与导入，以及原有自定义生图与风格参考图调用兼容。界面检查通过纯图、图片加要求、多图单选、全文复制、草稿追加或替换、资料任务与聊天同步及定位、原图预览、提示词滚动小框；1280×800 与 1120×720 窗口在 100% / 130% 字体下均可完整操作，并检查了实际截图。

最终类型检查、Vite 生产构建与 Windows x64 便携包封装通过，已核对包内版本、入口名称及编译资源与最终代码一致。封装采用本机同版本 Electron 41.10.7，构建仍有既有分块循环依赖和大文件提示，本次未调整分块。

测试使用隔离合成图片和模拟 API，不读取用户项目或调用真实付费接口。最终交付包含便携 EXE、恢复源码、更新说明、版本启动器与 SHA-256 校验文件，历史版本文件保留。
