# 莲华视频导演台 2.7.2 发布说明

发布日期：2026-10-19（亚洲上海）。

## 进行中的生图任务支持强制停止

“生成任务”和“自定义生图”中的进行中任务新增“强制停止”按钮。转换、生成、轮询、下载或本地保存卡住时，可以立即结束本地等待、释放生图队列，无需关闭软件。停止的记录显示为已取消，可直接删除；其他独立任务继续执行，已完成图片保留。首尾帧有依赖时，停止首帧仍沿用原有规则，不再提交依赖它的尾帧。

任务停止按项目与任务实例定位，并同步中止本地请求连接或轮询。停止后的迟到结果不会入库、绑定或将任务改回完成；撤销、重做和重启不会自动重新提交。服务端是否真正终止计算以及是否计费，取决于接口服务，软件不承诺撤销已经提交的费用。

直接修复两层串行队列等待悬挂请求的问题，沿用现有 HTTP 取消能力。保留 2.7.1 启动白屏修复和原项目数据格式，不新增内容校验、审核、自动重试或模型请求。

## 验证与交付

- 请求链路定向测试通过 18 个场景，覆盖 OpenAI、SD、xAI、Gemini、NovelAI、ComfyUI、RunningHub 的请求、轮询或下载取消，包含取消 IPC 自身不返回的情况。
- 真实生产回调与任务运行时检查通过，覆盖转换、生成、保存挂起时释放队列，按项目与任务实例隔离，撤销/重做历史，以及停止后的迟到结果。自定义生图与分镜图生图的相关测试通过。
- 隔离浏览器实际操作“生成任务”和“自定义生图”两个入口通过：第一项请求保持悬挂，强制停止后其余任务完成；重载保留取消状态，删除记录保留已有图片。未使用用户项目或真实模型请求。
- 打包内 TypeScript 检查、Vite 生产构建和 Windows 64 位便携 EXE 生成通过。构建仍有既有循环分块与大分块提示。
- 实际启动 2.7.2 便携 EXE 通过：确认版本、主界面、侧栏与视频导演台可用，未出现白屏；页面异常、运行时异常和渲染日志错误均为 0，程序正常退出。使用独立数据目录，没有读取或改写用户项目，也没有提交真实生成请求。

交付新版本便携 EXE、恢复源码、更新说明、启动器和 SHA256 清单，保留此前已交付版本。
