# 莲华视频导演台 2.9.7 发布说明

发布日期：2026-10-23（亚洲上海）。

## 修复 Gemini 语义分段结构错误

此前使用 Gemini 模型执行语义分段时，模型可能返回缺少 `semanticSource` 的段对象，应用随后无法建立原文证据、事件和对白的关联，任务会以“AI 语义分段结构无效”失败。

本版在 Gemini 语义分段请求中提供现有解析器使用的结构化输出契约，明确根对象、段对象和 `semanticSource` 内 `sourceEvidence`、`events`、`dialogues` 的必需结构。解析器仍接收完整语义资料，原有消息顺序、单次请求和其他模型的请求方式保持不变。

本修复直接处理模型输出结构与解析器契约不一致的根因，不新增运行时校验、内容审核、生成拦截、自动重试或额外模型请求。

## 版本定位

本版便携包为 `莲华视频导演台-2.9.7-便携版.exe`，恢复源码包、更新说明和 SHA-256 清单由交付脚本按同一版本生成。交付命令为 `npm run deliver:2.9.7`。

## 定向验证

语义分段规划器测试通过，包含 Gemini 请求使用结构化 Schema、嵌套 `semanticSource` 字段、单次请求以及原有解析行为的覆盖；语义分段 JSON 诊断测试通过，TypeScript 定向检查通过。

完整 `scripts/semanticSequencePlanner.test.ts` 仍有一个与本次改动无关的既有断言失败（`fixed budget precedes shared prose`），该规则顺序在基线中已存在；本次新增的 Gemini Schema 用例单独通过。测试使用模拟响应，未调用真实模型。

打包流程会执行 TypeScript 检查、Vite 生产构建和 Windows x64 便携包生成；本版不改变用户项目存档。

交付后请核对 `莲华视频导演台-2.9.7-SHA256.txt` 中的 SHA-256 清单。

## 使用与交付

保存项目并退出旧版，打开 2.9.7 便携版，保留 EXE 旁完整的“莲华视频导演台数据”文件夹。使用 Gemini 进行长剧情语义分段时沿用原入口即可；历史版本和交付文件保留。
