# 莲华视频导演台 4.4.4 发布说明

发布日期：2026-11-11（亚洲/上海）。

## 视频导演台加入自定义生成

在视频导演台的「单段生成」「长剧情批量」右侧增加「自定义生成」页签，使用同一个导演台内容区域。左侧导航不增加新页面。

用户可以上传图片或选择项目图片资产，设置本次输入槽和图片用途，填写自己的视频提示词，选择视频 API、RunningHub 云端、RH 网页应用或 ComfyUI 工作流生成。支持的时长、分辨率、比例和参考音视频随当前连接显示；网页渠道使用已有适配，工作流继续使用明确配置的节点映射。

自定义提示词与草稿按项目单独保存，和章节单段、长剧情批量表单分开。原文模式不自动翻译、扩写、重绑人物或继承项目音色；只使用本次明确选择的素材。自定义 H3 不要求先创建分镜或导演交付稿。工作流内部若有提示词生成器，界面说明其处理边界。

## MiniMax H3 v2 独立连接

视频连接设置增加独立的「MiniMax 官方视频 API（H3 v2）」协议，使用 v2 创建与查询接口。首尾帧和多素材参考分别处理；旧 Hailuo v1 配置与历史任务保留原协议。

## 任务与结果

自定义任务复用现有视频队列、状态追踪和下载入库流程。生成历史显示全部返回视频，不只保留一段。已保存的提示词、成片和任务快照不因升级改写，也不自动重新提交。

本次不增加运行时内容审核、生成拦截、自动重试或提示词模型请求。

## 交付

- Windows：`莲华视频导演台-4.4.4-便携版.exe`。
- Android：`莲华视频导演台-4.4.4-安卓版.apk`，最低 Android 8.0 / API 26，沿用正式升级签名。
- 4.4.3 及更早交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver`。本次包含共享页面、草稿和任务提交改动，EXE 与 APK 同版本交付。

## 验证范围

定向检查覆盖自定义原文、H3 v2 请求与结果映射、显式素材和现有视频生成链路；打包流程包含类型检查与前端构建。最终构建和签名结果见同版能力与验证记录。本次未使用付费上游生成进行验证。
