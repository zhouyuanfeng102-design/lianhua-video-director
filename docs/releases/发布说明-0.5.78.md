# 莲华视频导演台 0.5.78 发布说明

## 版本定位

- 修复英文提示词把中文对白一并翻译的问题。英文只转换画面、动作、镜头等描述；默认对白逐句保留原语言、原字、说话人和时间，仅源句明确要求英语时才允许该句译为英文。
- 对白与说话人使用硬保护，返回后校验原字、顺序、镜头与时间；选择 English 不等于把角色说话语言切换为英语。
- 旧的错误英文缓存不再视为有效，合格中文提示词保持有效；不自动改写旧存档。
- 单段结果新增“重新生成英文描述”，只更新英文，不重做中文、分镜或其他段。
- schema 21、H3 指纹 v4、参考素材、种子及生成参数保持不变；小说优化/剧情扩写、本地不限字符及既有功能保留。0.5.77 及更早版本化文件和正式项目数据不改写。

## 使用方式

保存工作并关闭旧版后，通过 `交付\启动莲华视频导演台-0.5.78-便携版.bat` 打开新包。已有错误英文请使用“重新生成英文描述”；不需要重新生成分镜。

对应便携包为 `莲华视频导演台-0.5.78-便携版.exe`。构建后执行 `npm run deliver:0.5.78` 生成版本化交付。
