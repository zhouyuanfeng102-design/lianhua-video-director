# 莲华视频导演台 3.2.9 发布说明

发布日期：2026-10-27（亚洲/上海）。

## 对白和物件声

没有可整句念出的原话时，不再写成「不可辨低声」「不构成可辨台词」或「嘴唇随话语轻动」。这一段写成走路、笑、摆手或倾听，嘴不做说话口型，也不配说话声。原文已经写出可整句采用的话，只放进台词一次。不可辨只在原文自己写明听不清时保留。同一时刻只让一个人口中有词。

拂叶、拨衣和落叶离桌只写衣料和干叶摩擦。铜铃、风铃、门环、耳环、杯盏和金属饰只有原文写明它自己响的那一下才出声，写成远处、闷、短，不跟扫、碰、走、坐绑在同一句。脚步、敲门、拍桌、兵器相撞和东西真正落地仍按那一下真实接触写。

已经生成的视频不会变。要改声音，需要重新生成对应片段的视频提示词。

不新增校验、重试或按钮。

## 存档兼容

冻结旧版视频转换器内的 NSFW 规则文本，使 0.6.7 所带的工厂预设仍能按原始指纹识别并迁移。新预设继续使用当前规则；用户自定义内容不因此被改写。

## 版本定位

本版便携包为 `莲华视频导演台-3.2.9-便携版.exe`。交付命令为 `npm run deliver:3.2.9`。3.2.8 及更早交付文件继续保留。

## 定向验证

对白规则、物件声规则和历史转换器迁移各做定向测试。打包中的类型检查和生产构建另计。
