# 莲华视频导演台 1.5.2 发布说明

修复项目库增大后超过 256 MiB 导致自动保存失败的问题。

## 保存方式

- 取消整个项目库 256 MiB 的业务上限。图片与项目分别落盘，未修改的项目文件直接复用。
- 图片按原始字节保存为独立素材，核对校验和后才替换内嵌数据，不压缩、不重绘；人物绑定、原中英文提示词和任务内容保留。
- 图像工作台新上传的参考图直接保存为独立文件，避免继续向项目 JSON 写入整张图片。
- 项目文件完整写入后才原子更新项目库索引；写入失败保留上一份可读存档。保存失败时可以单独导出当前项目。

## 更新与恢复

更新前关闭旧版，将新 EXE 放到原便携版所在目录，保留“莲华视频导演台数据”文件夹。首次成功切换格式时自动保留 `project-state.legacy-original.json`，不删除旧图片和项目。

新存档由 `project-state.json` 索引、`project-library` 项目目录和 `assets` 素材目录共同组成。移动或备份时保留整个数据目录；不单独拿新索引给旧版本打开。旧 JSON 存档、旧恢复点及单项目 `.lhvd` 包继续兼容，新恢复点及跨盘备份包含所需项目引用。

备份或恢复点创建失败会单独说明，不把已经完成的本地保存误报成未保存。关闭前保存保护继续保留。

如果主存档及全部恢复来源均不可读，启动时停止自动保存并显示读取失败，避免临时空项目覆盖已有数据。

## 验证与交付

专项验证覆盖内嵌图片无损迁移、项目分文件存储、写入中断与磁盘错误、密钥事务、恢复点、跨盘备份以及重启和项目导入导出。测试使用隔离目录，不调用付费生成接口。

另用约 200.65 MiB 的真实项目库只读副本验证：87 个项目、1,903 项资产、308 个人物和 2,210 条任务保留，48 处内嵌图片逐份校验原始字节一致。该验证没有改写真实存档，也未全量检查原有外部素材。

交付目录包含 1.5.2 便携版、恢复源码、更新说明、启动器和 SHA-256 校验文件。历史版本保留。

构建：`npm run pack:win`；交付：`npm run deliver:1.5.2`。
