# 莲华视频导演台 1.1.6 发布说明

日期：2026-10-02。

## 版本定位

生成任务页面的视频批次卡片右下角新增“删除批次”。整批已停止、失败或完成后，可以一次删除全部任务记录；保留已生成的视频、素材和来源信息。顶部撤销可恢复记录。

仍在排队、提交、运行、下载、确认取消或等待远端结果的批次暂不可删除，按钮说明会显示原因。删除时重新核对当前项目、任务和运行状态，整批通过检查才删除，不会只删其中一部分，也不会自动取消或重新提交任务。继续批次的检查、准备或确认尚未结束时需先完成或退出该操作。

本版包含 1.1.5 的取消视频任务合并保存及界面进程异常退出后的手动恢复入口。

## 使用方法

保存并关闭旧版，启动 `莲华视频导演台-1.1.6-便携版.exe`。进入“生成任务 → 视频任务”，在需要清理的批次右下角点击“删除批次”。未提交的排队项可先用“停止未提交项”停止，确认停止后再删除。

从 1.1.5 按十进位更新为 1.1.6，下一版为 1.1.7。历史交付包保留，正式用户数据不由测试修改。

构建 `npm run pack:win` 后运行 `npm run deliver:1.1.6`，生成便携 EXE、恢复源码 ZIP、更新说明、启动器和 SHA-256 校验清单。
