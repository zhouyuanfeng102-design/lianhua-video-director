# 莲华视频导演台 2.5.9

发布日期：2026-10-17。

## 修复 Seedance 首次生成即过期

长剧情首次生成新分段时，公共分镜保存会建立分段与分镜的关联。此前 Seedance 编写仍可能使用保存前的项目来源，漏掉新建立的分段上下文；保存后按最新来源校验，就会把刚生成的官方稿判为过期，并阻止下一段衔接。再次手动点击使用已有分镜来源，才会恢复正常。

本版在公共分镜提交后读取当前项目来源，统一 Seedance 编写与保存校验的依据，修复每生成一段就需要手动重试的问题。真实剧情、分镜或参考来源改变时，现有过期提示仍然有效。

## 顺序生成与报错记录

顺序生成以已保存且有效的 Seedance 中文稿作为上下段衔接依据。本段中文稿保存有效后继续下一段；英文翻译失败保留中文结果，英文可以单独重试。

上下段衔接失败、结果保存失败及生成来源不一致等异常写入持久报错日志，记录当前分段、依赖的前段（适用时）、失败阶段与具体原因，同一次故障避免重复记录。

## 已有项目与恢复

已有公共分镜、提示词历史和项目内容保留。对旧版已经显示过期的段，可使用“刷新当前段 Seedance 提示词”复用公共分镜重新生成；不会通过修改来源标记将旧稿直接视为有效，也不会自动重跑历史任务。

## 交付

交付命令为 `npm run deliver:2.5.9`，便携包为 `莲华视频导演台-2.5.9-便携版.exe`，同时提供恢复源码、更新说明、启动器及 SHA256 文件。旧版本文件保留。
