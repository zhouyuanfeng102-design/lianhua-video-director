# 莲华视频导演台 1.4.0 发布说明

## 版本定位

1.4.0 是针对 Krea-2 私密生图版式稳定性的修复版本，重点处理私密五视图和私密四合一在局部资料、转换器规则和预设叠加后出现的重复部位、重复全身、槽位串位及额外面板问题。本版不新增年龄门禁，也不覆盖用户主动修改、禁用或删除的规则。

## 主要改动

- 私密五视图固定为两个头肩区域与三个全身区域，并为每个区域保留明确的取景职责。
- 私密四合一固定为左侧唯一全身主画面、右侧三个按顺序绑定的部位辅助窗，禁止模型自行增加第五个窗口或混合部位。
- Krea-2 生图规则和私密分类预设升级；仅对未被用户修改的旧内置版本执行一次性迁移。
- 转换器保留当前版式的结构约束，不再因结构性“不要/不得”描述被宽泛过滤；私密规则链路不重复注入年龄门禁。

## 交付文件

- `莲华视频导演台-1.4.0-便携版.exe`
- `莲华视频导演台-1.4.0-恢复源码.zip`
- `莲华视频导演台-1.4.0-更新说明.md`
- `莲华视频导演台-1.4.0-SHA256.txt`
- `启动莲华视频导演台-1.4.0-便携版.bat`

## 构建与校验

构建便携版使用 `npm run pack:win`，生成交付物使用 `npm run deliver:1.4.0`。交付目录中的 `莲华视频导演台-1.4.0-SHA256.txt` 提供 EXE、恢复源码包、更新说明和启动器的 SHA-256 校验值。
