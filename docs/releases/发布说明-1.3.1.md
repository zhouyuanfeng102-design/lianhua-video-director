# 莲华视频导演台 1.3.1 发布说明

版本日期：2026-10-05（亚洲上海）。

本版在一个项目内管理多个章节。章节分别保存原文与制作进度，人物、场景、道具和参考素材继续在项目内共用。

## 本版变化

- 章节支持手动新建、重命名、调整顺序和归档；归档保留原文及已有制作记录。
- TXT / Markdown 可按章节导入，保留完整原文。导入只整理章节，不自动调用 API 批量解析全书；选择要制作的章节后，由用户发起解析。
- 提示词导演台与分镜时间线按当前章节显示，切换章节恢复各自的原文和制作内容。
- 图像工作台与人物、场景、道具资料在全项目共享。解析其他章节时，能匹配已有名称或别名的人物复用原 ID，保留不同形态资料。
- 生成任务与资产库默认显示全项目，增加章节标签及章节筛选；项目共享和历史内容可单独查看，归档章节仍可筛选。
- 保持软件运行时，切换章节后已建立的后台任务继续执行，结果保存到原章节；已有视频任务继续使用原始快照。
- 旧单章项目可继续打开和制作，已有资料、任务、素材与历史版本保留。

## 使用与升级

保存项目并正常退出旧版，在原交付目录打开 `莲华视频导演台-1.3.1-便携版.exe`，或使用 `启动莲华视频导演台-1.3.1-便携版.bat`。

从章节管理入口导入 TXT / Markdown 或手动新建章节，选中章节后再解析剧情。切换章节可继续制作该章分镜与提示词；需要检查其他章节的生成结果时，进入生成任务或资产库，选择对应章节范围。

便携版默认读取 EXE 同目录下的 `莲华视频导演台数据` 文件夹。本项目交付目录内的正式数据位置为 `交付\莲华视频导演台数据`。升级保留该文件夹，不把它放进恢复源码包；设置了 `LIANHUA_DATA_DIR` 的环境继续使用该指定目录。

## 版本与交付

本轮验证已通过：章节迁移与原文完整性、人物 ID/别名复用与手工资料保护、分章导入及切换后的草稿/导演设置恢复、跨章延迟解析归属、视频导演台单段/批量草稿隔离、资产/任务全项目显示与筛选。测试使用独立中性数据和本地模拟接口，没有读取正式项目数据或调用付费生成接口。类型检查与 Windows 便携版构建通过；实际 EXE 的启动、保存、重新载入和本地视频工具检查通过。

从 `1.3.0` 按用户要求的十进位规则升级到 `1.3.1`，下一版本为 `1.3.2`。小版本位和补丁位限定为 `0–9`，例如 `1.3.9 → 1.4.0`。已交付的 `0.5.160` 及更早历史版本保留原版本号和文件；其他历史交付文件也不覆盖或删除。

构建命令：`npm run pack:win`。

交付命令：`npm run deliver:1.3.1`。交付脚本读取本发布说明，输出便携 EXE、恢复源码 ZIP、更新说明、版本启动器及 SHA-256 校验清单。
