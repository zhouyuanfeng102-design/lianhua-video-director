# 莲华视频导演台 1.1.4 发布说明

日期：2026-10-02。

## 版本定位

修复 H3 身份定位记录与最终提示词正文不同步，以及多条绑定警告挤占提示词预览的问题。

## 修改内容

- 统一校验人物身份句是否精确出现在最终正文中、是否唯一、是否处于可用于图片绑定的位置；生成、翻译和格式修复同步保存正文与绑定记录。
- 视频单段和批量提供“修复人物图片绑定”：明确点击才执行，优先仅修定位记录，必要时只补身份说明，保留原有剧情、对白、声音、镜头、时间与参数，保存修复前后版本。
- 旧记录中从未出现在正文里的 Subject / 声源编号仅移除悬空引用，不向正文补造编号或改变发声人；正文已有编号保持。中文修复同时校验已有有效英文，两语均通过后才一起保存。
- 本次选图涉及的人物才显示相应绑定问题；警告聚合折叠，RunningHub 映射说明单独显示，正文保持可见。
- 浏览和选图不自动调用 AI，修复操作不提交视频；项目、媒体、历史任务和已有历史版本保留。

## 使用方法

保存并关闭旧版，启动 `莲华视频导演台-1.1.4-便携版.exe`。在视频导演台选择原分段、语言和参考图，点击“修复人物图片绑定”。修复使用已配置的文本 API，失败或项目在等待期间改变时保留原稿；完成后核对预览和图片用途，再按原流程生成视频。

## 版本与交付

从 1.1.3 按十进位更新到 1.1.4，下一版为 1.1.5。构建 `npm run pack:win` 后运行 `npm run deliver:1.1.4`，生成便携 EXE、恢复源码 ZIP、更新说明、启动器和 SHA-256 校验清单。
