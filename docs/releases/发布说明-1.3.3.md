# 莲华视频导演台 1.3.3 发布说明

版本日期：2026-10-05（亚洲上海）。

本版压缩视频导演台顶部的章节栏、标题与模式操作栏、视频执行设置区域，让下方导演台内容获得更多可用空间，并使顶部字号与控件随窗口大小适配。

## 本版变化

- 缩小章节栏、标题与模式操作栏、视频执行设置区域的间距与控件高度，使顶部布局更紧凑。
- 顶部文字、按钮和输入控件随窗口尺寸调整，窄窗口下保持内容可读与操作可用。
- 保留章节管理、模式切换与全部操作入口；视频执行设置、保存方式及任务执行逻辑保持不变。

## 使用与升级

保存项目并正常退出旧版，在原交付目录打开 `莲华视频导演台-1.3.3-便携版.exe`，或使用 `启动莲华视频导演台-1.3.3-便携版.bat`。

进入视频导演台即可使用紧凑的顶部布局。调整窗口大小时，顶部文字与控件会随可用空间适配；已有视频执行设置继续沿用。

便携版默认读取 EXE 同目录下的 `莲华视频导演台数据` 文件夹。本项目交付目录内的正式数据位置为 `交付\莲华视频导演台数据`。升级保留该文件夹，不把它放进恢复源码包；设置了 `LIANHUA_DATA_DIR` 的环境继续使用该指定目录。

## 版本与交付

顶部布局验证通过：1996×1248 窗口下高度由约 190px 降到 99px；1280×800 窗口、130% 字号下由约 222px 降到 102px，两种尺寸均无横向溢出。Windows 便携版打包包含的类型检查与构建通过。本轮仅检查改动布局，没有运行全量回归或付费生成。

从 `1.3.2` 按用户要求的十进位规则升级到 `1.3.3`，下一版本为 `1.3.4`。小版本位和补丁位限定为 `0–9`，例如 `1.3.9 → 1.4.0`。已交付的 `0.5.160` 及更早历史版本保留原版本号和文件；其他历史交付文件也不覆盖或删除。

构建命令：`npm run pack:win`。

交付命令：`npm run deliver:1.3.3`。交付脚本读取本发布说明，输出便携 EXE、恢复源码 ZIP、更新说明、版本启动器及 SHA-256 校验清单。
