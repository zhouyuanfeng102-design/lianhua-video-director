# 莲华视频导演台 4.2.1 发布说明

发布日期：2026-11-08（亚洲/上海）。

## 没有预估也继续运行

网页上没有读到「预估 RH 币」时，不再停下，照常点击运行。页面上如果写了预估，任务记录里仍会带上。

已保存的提示词和成片保持原样。

## 交付

- Windows：`lianhua-video-director-4.2.1-windows-x64-portable.exe`。
- Android：`lianhua-video-director-4.2.1-android.apk`，最低 Android 8.0 / API 26。
- 4.2.0 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.2.1`。电脑和手机都会提交 RunningHub 网页任务，EXE 与 APK 一起交付。

## 验证

打包流程自带类型检查和前端构建。手机网页适配测试确认：没有预估的页面可以准备，且这次准备不会点击运行。

APK 已完成正式签名核对，沿用原签名证书。尚无本版 Android 设备安装、原生功能与真实网站联调的实测记录；基础能力及既有测试边界见 [3.9.7 能力与验证记录](能力与验证记录-3.9.7.md)。安装和备份见 [安卓安装说明](../android-install.md)。
