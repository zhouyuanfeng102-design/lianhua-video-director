# 莲华视频导演台 4.9.0 发布说明

发布日期为 2026-11-20（亚洲/上海）。

## 版本定位

本版修复 MiniMax H3 提示词交付中的两处信息丢失，涉及 Windows 和 Android 共用的逐镜表演与末帧衔接逻辑。

## H3 无对白镜头

在一个只有低笑、脚步和呼吸的片段中，两名角色的静默记录在生成 H3 执行稿时丢失，脚步声说明却写着“压在对白下面”。新版把无言表演写进对应镜头，保留原有低笑等非语言声。编写音效时，只有同一时段确实有人说话，才安排其他声音为台词让位。原稿中有台词的镜头继续使用原话和原语种。

## 用上一段末帧承接动作

原任务取到了第二段的真实末帧，但执行稿仅用它参考构图，还在交代抓腕之前写出了两人已经牵手前行的画面。新版在连续段的首镜指明上一段末帧对应的图片，从图中可见的取景、朝向、接触和持物状态起步，再按时间展开本段第一项新动作。人物图和场景图分别提供外观和环境。第三方工作流只提供普通图片槽时，首帧贴合程度仍取决于该工作流。

## 已有项目如何重做第三段

在「提示词导演台」选中第三段，点击「重新生成本段MiniMax H3提示词」。随后在「视频导演台」选用这份新稿。批量页只选中第三段，再点击「用上段尾帧」或「本地末帧＋参考图」，使用已保存的第二段最新成片，提交第三段。从历史任务直接重提会复用当时冻结的旧执行稿。

Windows x64 使用 `莲华视频导演台-4.9.0-便携版.exe`。Android 使用 `莲华视频导演台-4.9.0-安卓版.apk`，最低 Android 8.0（API 26）。维护者使用 `npm run deliver:4.9.0` 整理两端安装包与 SHA-256 交付清单。
