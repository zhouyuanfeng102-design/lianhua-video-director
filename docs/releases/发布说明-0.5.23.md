# 莲华视频导演台 0.5.23

## 版本同步

- 当前开发版由 0.5.22 递增为 0.5.23；0.5.22 及更早历史交付文件继续保留，不会被发布脚本覆盖。
- 现有项目数据、导演模式、输入模式、场景选择和提示词生成逻辑保持兼容，本次集中修复导演台纵向空间不足造成的重叠遮挡。

## 上方场景区紧凑排布

- 视频导演台上方“九宫格剧情片段”场景选择区改为 6列×2行，在保留 12 个场景入口的同时让高度约缩减一半。
- 紧凑布局减少场景区对纵向空间的占用，为下方导演参数中的“运镜与要求”释放更多可见空间。
- 现有场景文案、选中态、全选、仅当前与顺序合并交互保持不变。

## 容器自适应与防遮挡

- 场景按钮文字、图标、内边距和行间距按容器宽度自适应缩小，字号保持在 8–10px 的紧凑可读范围。
- 较窄窗口下同步压缩按钮和网格间距，避免上方场景区与下方分段导航、导演参数发生重叠遮挡。
- 保留 0.5.22 的双栏等宽、左侧参数容器自适应以及现有配色、文案和操作行为。

## 回归与交付

- 回归覆盖 6列×2行、场景区高度约缩减一半、8–10px 容器宽度自适应、上下区域无重叠遮挡及历史项目兼容。
- 0.5.23 交付包含 Windows x64 便携版、恢复源码、更新说明、版本启动器、无版本启动器与 SHA-256 完整性清单。
