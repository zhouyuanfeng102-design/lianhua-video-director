# 莲华视频导演台 2.1.4 发布说明

发布日期：2026-10-13

## 版本定位

本版修复 ComfyUI 本机与局域网访问许可提示已允许、复选框仍未勾选的状态同步问题。开关与提示以实际保存的许可值为准，图片与视频设置中的两个入口共用同一许可状态。

开关从轻量桌面配置初始化，不等待完整项目库和恢复点扫描；保存结果直接更新共享许可状态。迟到的轻量或完整状态读取不再覆盖刚保存的许可，保存期间暂时禁用两个开关，避免重复写入；保存失败保留原值。已有项目、工作流、任务记录及历史交付保留，许可设置不会自动提交模型任务。

## 使用说明

更新前保存项目并退出旧版，保留完整的“莲华视频导演台数据”文件夹。

需要连接本机或局域网 ComfyUI 时，在 API 设置的图片或视频 ComfyUI 入口开启对应访问许可。操作完成后，勾选状态与提示反映实际保存值；切换到另一个入口时使用同一许可设置。

许可控制访问权限，ComfyUI 服务地址与工作流仍需按原流程配置，生成任务由用户主动执行。
