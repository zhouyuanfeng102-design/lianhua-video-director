# 莲华视频导演台 1.4.3 发布说明

## 版本定位

1.4.3 在“生成视频 → 选择参考图”弹窗中显示本段剧情涉及人物，帮助用户判断应该选择哪些人物参考图。提示为只读信息，不改变视频生成行为。

## 新增内容

- 弹窗标题栏显示当前分段涉及的人物名称。
- 优先使用分段关联场景、分镜、语义对白和剧情文本识别人物，兼容旧项目缺失来源 ID 的情况。
- 有明确人物资产绑定时显示已关联的图片数量。
- 不自动勾选、不过滤图片、不要求选满，也不阻止“使用本段图片”或视频提交。
- 无法识别人物时保留手动选图和视频生成能力。

## 构建与校验

便携版使用 `npm run pack:win` 构建，交付物使用 `npm run deliver:1.4.3` 生成；针对性人物识别测试、TypeScript 检查和构建检查已完成。
