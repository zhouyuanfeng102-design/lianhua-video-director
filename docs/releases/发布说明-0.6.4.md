# 莲华视频导演台 0.6.4 发布说明

版本记录日期：2026-09-26。

## 版本定位

0.6.4 是针对背景音乐听感的提示词规则更新：音乐可有，但要自然、低存在感，不能盖过对白和现场声。

## 本版修复

- 背景音乐可以存在，但由 AI 按剧情、时代、场景和情绪选择自然简洁的配乐，保持柔和、极低存在感，不抢对白与必要现场声。
- 对白和关键动作声出现时平滑让位；台词停顿、对白结束和无对白镜头中也不自动抬升音乐。避免强音突入、夸张低频、强鼓点、突然渐强及忽大忽小。
- 补齐中文 H3 最终 AI 复核的声音规则，让 AI 在现有 `non_diegetic_music` 与逐镜音效中写清本段的音乐、适用镜头、进退时机和低背景混音安排，不新增 H3 字段或混音章节。
- 无配乐时仍保留 `N/A`，由 AI 在镜头声音描述中明确“不自动补背景音乐”；这不是整条音轨静音，原对白与必要现场声仍保留。
- 英文翻译与格式修复忠实保留已确认的声音安排，不重新选乐；仅上下段衔接修复不借机重做音乐。
- 仅升级完全未修改的内置规则与转换器；保留编辑、改名、禁用、删除和自定义状态，现有数据结构不变。

## 生效范围

- 用于新版中新生成或主动重新生成的视频提示词，不自动改写历史提示词、已有视频或正式项目，不自动发起收费生成。
- 本次只调整给 AI 的生成及校验要求，不增加本地音频内容拦截、关键字否决、正文改写或固定 API 阶段，也不修改工作流音量、采样器参数或整条成片音轨。
- 规则中的相对音量是模型应遵循的听感目标，不是实际 API 增益控制或实测保证。仍需以生成模型的最终成片效果为准。
- 保持 H3 官方字段、镜数、切点、原对白与说话人；0.6.3 及更早交付文件保留、不覆盖、不删除、不重编号。

便携包：`莲华视频导演台-0.6.4-便携版.exe`。
交付命令：`npm run deliver:0.6.4`，生成同版本恢复源码、更新说明、启动器和 SHA-256 清单。
