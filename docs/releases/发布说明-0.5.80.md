# 莲华视频导演台 0.5.80 发布说明

## 版本定位

- 本轮仅修复 AI 分镜自动修复与自然动作声两项核心行为，不扩展其他功能。
- AI 完整分镜内容校验失败时，使用原配置文本 API 最多自动修复 3 轮（首次生成之后最多再请求 3 次），每轮使用最新候选和最新错误，不再第一次修复仍错就要求用户手动改稿。
- 声音时刻超出本镜范围时，将出错镜头、原时刻、该镜动作及合法相对时间区间交回 API，只重定位该镜的声音时刻；其他内容、声音文本与镜头边界锁定，不用本地夹断时间、删除音效或重规划全片来绕过校验。
- 修复结果继续通过完整校验。网络或鉴权失败停止，取消或请求过期后不再续发；达到自动修复上限不覆盖已有成果，不无限调用收费接口，不重复提交视频任务，不更换模型、密钥、种子或采样参数。
- 动作声按景别距离、动作力度和叙事必要性自然呈现，不强制每次亲吻都有独立音效。中景轻吻可以非常轻、甚至几乎听不见，不突出“啵”或贴麦口部声。
- 保留必要脚步、碰撞等声音，不为每个小动作配声。默认无配乐，有明确要求时保留低配乐；无连续底噪规则和对白原语言保护继续保留。
- 未编辑的内置默认精确升级，自定义规则、禁用/删除状态和存稿保留。视频化整理与扩写补全、参考素材、schema 21、H3 指纹 v4 及原生成参数不变。0.5.79 及更早版本化交付与正式数据不改写。

## 使用方式

完成交付后，保存工作并关闭旧版，通过 `交付\启动莲华视频导演台-0.5.80-便携版.bat` 打开新版。重新执行所需的 AI 分镜后，模型返回的内容校验错误会由程序按上述上限自动调用同一文本 API 修复，无需手动改 JSON 或声音时刻。

自然动作声规则用于新生成的提示词，不自动覆盖旧存稿或处理已有视频。要应用新规则，请重新生成相应提示词和视频；本版本不会自行启动真实视频或生图任务。

对应便携包为 `莲华视频导演台-0.5.80-便携版.exe`。构建便携版后执行 `npm run deliver:0.5.80` 生成版本化交付。

已通过：分镜 API 自动修复 13 项（含 10 种非法补丁子例）、文本服务 117 项、音频策略/声景/英文转换/转换请求/存储迁移的针对性测试，以及测试源码类型检查与生产构建。生产构建仍有既有的大于 500 kB 分块提示，不影响生成产物；本轮不扩展性能改造。

分镜修复验证使用模拟 API，覆盖截图中的 2.2 秒镜头返回第 3.2s、第一次修复仍错后继续修好，以及三轮上限、网络失败和过期保护。未调用真实 DeepSeek 或生成新视频，实际视频音质尚未实测。
