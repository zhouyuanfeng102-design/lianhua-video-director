# 莲华视频导演台 0.5.112 发布说明

发布日期：2026-09-12。

## 版本定位

本版把长剧情从“逐段手动选择提示词、选图、再提交”改造成可审阅的一键批量视频流程。用户仍能控制每一段实际使用的语言与参考图，每段仍是独立视频任务，不会把整部长剧情拼成一个不透明的大请求。

便携包名称为 `莲华视频导演台-0.5.112-便携版.exe`。完成源码与自动化验证后生成新版交付，同时保留 0.5.111 或更早的版本化交付文件。

## 批量选择与中英文稿

- 视频导演台新增“单段生成 / 长剧情批量”切换。批量页读取当前项目已经完成拆分的全片计划，只列出计划真实关联的分段，不把全片母版或孤立历史分镜混入清单。
- 可以自由勾选任意分段，也可以使用“全选中文”或“全选英文”。搜索只改变当前显示，不会悄悄取消其它已选段。
- 同一分段的中文与英文描述是两个可辨认的稿件，但二者互斥：选择英文会取消该段中文，选择中文也会取消该段英文，因此一个分段在同一批次只生成一个视频。
- 英文选项只使用已经存在且仍与当前中文稿匹配的英文描述，不会临时翻译提示词，也不会改变原对白语言。

## 每段参考图

- 每个分段的提示词行后都有“选择参考图”按钮，可从当前项目图片资产库独立选择图片，并调整顺序和人物、场景、首帧、尾帧等用途。
- 可以把上一段的图片顺序与用途复制到当前段，也可以把当前段选图应用到全部已选段，再逐段微调。
- ComfyUI 模式会同时显示工作流图片槽数量和用途冲突；图片缺失、槽位不足或用途不匹配会在提交前阻止该批次。
- 批量参考图仅属于本次生成草稿，不修改原分镜引用、原中英文提示词或单段视频草稿。

## 预检、去重与费用确认

- 点击生成后先展示整批确认清单，逐段列出语言、时长、参考图数量以及“待提交 / 将跳过”，并要求用户明确确认接口可能产生费用。
- 所有选中项会先统一检查视频 API 或 ComfyUI 连接、Workflow、公共参数、提示词和参考图。任意结构错误都会在创建任务和发送视频 POST 前停止，避免半批误提交。
- 请求指纹同时包含稿件语言、提示词正文、按顺序排列的参考图内容与用途、后端连接语义、Workflow 和参数。相同的进行中任务或提交结果未知任务始终不会重投，避免重复扣费。
- 已成功的相同任务默认跳过；只有用户明确选择重新生成时才创建新副本。强制重新生成也不能绕过进行中或未知任务的防重复保护。

## 固定项目、批次汇总、重试与停止

- 每一段仍是独立视频任务，默认按段号逐个完成准备和提交；单项准备或已知提交失败不会阻断后续段。
- 批次在开始时固定所属项目。提交期间切换页面或切换项目，任务状态和最终视频仍写回发起项目，不会串入当前项目。
- 生成任务页把同一批次归组显示，汇总等待、提交中、运行、成功、失败和停止数量，并保留进入各独立任务查看提示词与参考图快照的能力。
- 批次出现普通失败项时，可点击“只重试失败项”把原语言、提示词、时长、参数和冻结参考图带回批量页复核；打开或回填不会自动提交，仍须再次确认费用。已取消、已停止或快照不完整的任务不会混入。
- “停止未提交项”只停止尚未跨过 POST 边界的后续任务。已经提交给服务器的任务继续追踪；不会调用 ComfyUI 全局 `/interrupt` 而误伤其它运行任务。
- 批次状态和每项安全提交断点会持久保存。重启后只恢复具有可信准备记录的待提交项；`submission-unknown` 或已经记录 POST 边界的任务只核对原任务，绝不自动再次 POST。

## 升级与数据

schema 保持 **23**。既有项目、长剧情计划、中英文提示词、参考图、视频任务、API 配置、ComfyUI Workflow、生成参数和历史成片均保留；升级不会自动重跑任何历史任务。

请先保存当前工作并完全关闭旧版，再启动 `交付\启动莲华视频导演台-0.5.112-便携版.bat`。旧版本化交付不会被自动删除或覆盖。

## 验证边界

批量单元与 UI QA 覆盖自由选择、全选中文/英文、同段语言互斥、逐段选图、预检、重复请求跳过、显式重生成功项、有界提交、跨项目写回、重启安全、批次汇总、失败项回填及停止未提交项。

自动化 UI 使用隔离测试项目和 mock 视频队列，**不调用真实收费视频接口，也不代表任何厂商的真实视频已经生成成功、计费兼容或画质得到验证**。正式使用前仍需用户按所选厂商核对账户余额、并发限制、参数合同、参考图能力和计费规则。
