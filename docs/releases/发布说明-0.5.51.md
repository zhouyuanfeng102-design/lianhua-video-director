# 莲华视频导演台 0.5.51

## 版本定位

本版集中改造图像生成链路：补充独立的生图规则集与分类预设，建立规则选择、AI 转换、任务追踪和图片资产追踪所需的数据结构；同时新增 NovelAI 原生请求适配，并加强 AI 分镜结果的自动返修。

0.5.50 新增的应用内更新日志、0.5.49 的持久报错日志，以及更早版本的项目、素材和 API 配置继续保留。

## 生图规则集与分类预设

- 新增独立生图规则模块，内置通用、OpenAI / GPT Image、SD WebUI、ComfyUI、NovelAI / NAI，以及电影写实、二次元、国风、特摄等规则集。
- 按角色、角色设定图、场景、物品、分镜单帧和九宫格区分分类预设；不同后端可使用自然语言、SD tags 或 NAI tags 格式。
- 规则选择状态可随项目保存和迁移；旧项目缺少新字段时补入内置规则，同时保留已有自定义数据。
- 规则中心已加入生图规则集与分类预设管理，可新增、复制、编辑、删除、导入、导出，并配置后端或分类默认项。

## AI 转换与可追踪性

- 生图转换器增加结果检查与一次 AI 自动返修：空结果、照搬原资料或输出格式不合格时，不直接当作最终生图提示词。
- SD / ComfyUI 与 NovelAI 标签结果会按真实目标格式二次验收：拒绝中文自然语言伪装成 tags、无逗号长句、空分段和非法多重分隔；NovelAI 角色类提示词必须形成完整的“基础段 | 角色段”。
- 分镜图片生成边界采用失败关闭策略；转换请求报错、返回空内容、原样返回规则或仍含视频时间轴字段时，不调用图像模型，也不回退到本地拼接的原提示词。
- 图像任务与生成资产可记录实际使用的规则集 ID、规则版本、分类预设 ID、预设版本和提示词格式。
- 分镜图片源指纹纳入上述规则与预设信息；任一选择或版本变化都会使旧图失效，避免继续自动绑定不再匹配的结果。

## NovelAI 与二进制响应

- 新增 NovelAI V4 / V4.5 请求构造、端点校验、鉴权请求头与正负向提示词参数适配。
- 响应解析支持 PNG、JPEG、WebP、JSON / Data URL / Base64，以及 ZIP 中的首张有效图片；错误响应不会伪装成生成成功。
- 桌面 HTTP 桥增加 Base64 响应模式，避免 ZIP 或图片字节被当作 UTF-8 文本而损坏。
- NovelAI 当前没有经过验证的参考图像素协议；当分镜批次包含任意全局、逐镜或实体关联参考图时，会在创建任务及调用文本转换器前一次性明确停止，不会逐镜浪费请求，也不会静默忽略参考图。

## AI 分镜自动返修

- AI 返回完整分镜后会检查镜头主体是否稳定、明确。
- 遇到“我”“他”“主角”“角色”等无法稳定绑定身份的主体时，将原始分镜和精确错误交给同一文本模型返修一次；返修仍无效才返回明确错误。
- 该处理不使用本地假分镜替代 AI 结果。

## 兼容与数据
