# 莲华视频导演台 4.0.9 发布说明

发布日期：2026-11-08（亚洲/上海）。

## 生成时显示网页上的参数

RH 网页生成页列出这次读取到的运行机型、页面预估，以及时长、画面比例、分辨率、调度器、总步数等网页当前值。提示词格和图片槽仍在各自的位置。

绑成时长或画面比例的项，输入框留空就提交网页上的当前值。设成「固定为当前值」的参数照样显示，不再写成「请先绑定节点」。

已保存的提示词和成片保持原样。

## 交付

- Windows：`莲华视频导演台-4.0.9-便携版.exe`。
- Android：`莲华视频导演台-4.0.9-安卓版.apk`，最低 Android 8.0 / API 26。
- 4.0.8 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.0.9`。本版是共享的网页生成界面，EXE 与 APK 一起交付。

## 验证

打包流程自带类型检查和前端构建。网页参数列出测试已通过。未把已有成片重新生成。
