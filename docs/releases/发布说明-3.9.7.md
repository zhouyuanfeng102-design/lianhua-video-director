# 莲华视频导演台 3.9.7 发布说明

发布日期：2026-11-07（亚洲/上海）。

## EXE 与 APK 双端交付

本版同时提供 Windows x64 便携 EXE 和正式签名 Android APK。手机采用单列内容、项目/创作/素材/任务四项底部导航、全部功能菜单、创作步骤及可滚动编辑弹层，窄屏不再整体缩放桌面版面。

Android 原生平台接入私有目录存档、schema 24 分项目保存、Keystore 密钥加密、素材读写、完整 `.lhvd` 项目包、网络请求及原任务状态恢复。大于 4 MiB 的所选视频和项目包以 256 KiB 分块传入原生临时文件，完成或中断后清理，不需要再次选择同一文件。

手机受管图片、音频与视频仅在显示时映射到同源本地路径；存档、任务和帧记录仍保留原有受管地址。桌面显示行为保持原样。Windows 和 Android 通过完整项目包转移资料，API 密钥在各设备单独配置。

## 保留 RH 网页下拉选项修复

本版保留 3.9.6 的 Windows RH 网页读取改动：读取下拉框完整选项，例如 LLM 模型；生成时按用户选中的项目填写。已保存应用可重新点击“读取网页”取得选项。3.9.6 的原发布说明和交付文件保留。

Android 的 RH 网页/rhTV 采用原生 WebView 路线，实际网站、账号、系统 WebView 功能与验证范围见同版能力记录。代码实现或本地假站通过不等于真实账号和付费生成已验收。

## 本地媒体与任务边界

安卓使用原生抽帧与 Media3 合成，覆盖已实现的裁剪、直接拼接、尺寸/帧率及固定音量 BGM。交叉淡化、自动闪避和淡入淡出等暂未支持的特效保留电脑版导出路径。

活跃原生传输使用前台服务。系统强杀后依靠已保存任务号和检查点恢复状态，不承诺本地队列在进程消失后继续执行，不为客户端改造新增模型请求、自动重提、自动重试或内容审核。

## 版本定位与交付

- Windows：`lianhua-video-director-3.9.7-windows-x64-portable.exe`。
- Android：`lianhua-video-director-3.9.7-android.apk`，最低 Android 8.0 / API 26，需兼容现代网页功能的系统 WebView。
- GitHub 附件提供恢复源码 ZIP、更新说明、安卓安装说明、能力与验证记录及 Windows 启动器；签名私钥、口令及本机缓存不进入恢复源码。

常规构建命令 `npm run pack:all`，交付命令 `npm run deliver:3.9.7`；默认要求 EXE 与 APK 齐全。仅某一端独立 UI 调整时才明确使用 `--ui-only=windows` 或 `--ui-only=android`。后续版本继续遵守双端交付与十进位版本规则；历史文件不覆盖、不重编号、不删除。
