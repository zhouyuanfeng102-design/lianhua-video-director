# 莲华视频导演台 0.7.8 发布说明

## 版本定位

0.7.8 修复排队中的生成任务不能取消、不能直接删除的问题，让删除同时撤销对应后台工作，而不只是隐藏任务卡片。

- 图片任务覆盖普通生图、私密生图、分镜批量和重新生图等入口；处于排队状态时可选择“取消排队”或直接“删除”，不必等待生成完成。
- 排队资料补齐任务同样支持取消与删除。取消保留“已取消”记录，不计为生成失败；删除先撤销排队执行资格，其他任务继续处理。
- 队列调度、撤销/重做历史和迟到结果回写识别已撤销的图片或资料任务，避免取消后继续提交、删除后任务复活或旧结果覆盖资料。
- 本地尚未提交的视频排队任务可同一次操作取消并删除。重启恢复中的旧排队快照先核对可信提交断点，不会把已提交的远端任务误当成本地排队任务删除。
- 已经提交或提交结果未知的视频仍保留原任务查询记录和真实占位；仅停止本地追踪不代表云端取消成功，也不保证停止远端生成或扣费。需确认远端结束后再删除记录。

删除的是选中的任务记录与未开始的排队工作，不删除已保存图片、资料、成片或其他任务。不修改 H3 正文、AI 提示词与内容规则，不新增本地剧情语义审核，不自动重跑收费生成。

## 验证与交付

`scripts/queuedGenerationTasks.test.ts` 已通过，覆盖明确“已取消”状态、直接删除、任务与项目隔离、撤销/重做不复活、被撤销的 FIFO 项不调用转换器或生图接口、其他任务继续、重启状态保留及取消批次及时释放队列。

`scripts/queuedTaskActions.test.ts` 的 19 项生产按钮动作回归已通过：直接执行 App 的取消/删除处理函数，覆盖各类图片与资料排队项、历史回放身份隔离、本地视频等待取消完成后再删除，以及已提交/未知/替换任务的记录保护。

视频侧已完成类型检查，以及 `scripts/videoSerialQueueSafety.test.ts` 的 18 组内存回归。新增覆盖：本地排队任务同次取消删除后不再提交、孤立旧断点不复活已删任务、旧 preparing 元数据不能冒认远端取消、重启时核对较新的提交记录，以及结果未知任务仍保留占位。

`scripts/videoGeneration.test.ts`、`scripts/videoPreparationRecovery.test.ts` 与 `scripts/videoGenerationBatch.test.ts` 已通过，包含定向取消、迟到回调、素材准备恢复、批量顺序和防重复提交。上述测试使用模拟接口及内存状态，没有调用真实收费生成 API 或修改正式项目。

最终图片/资料回归、界面检查、生产构建、隔离数据启动烟测及 SHA-256 核验以本轮实际执行记录为准。以下是验证与交付命令，不代表尚未执行的步骤已经通过：
