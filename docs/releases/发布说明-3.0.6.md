# 莲华视频导演台 3.0.6 发布说明

发布日期：2026-10-25（亚洲上海）。

## AI扩写不再插入顺序提示句

点「AI扩写」时，发出去的正文不再自动加入「请按这个顺序写成连贯正文：」。编辑框里的字和已保存原文都不改。画面描述转化、段落重做和生图不加这句话。

不新增按钮、运行时校验、内容审核、生成拦截、自动重试或模型请求。

## 版本定位

本版便携包为 `莲华视频导演台-3.0.6-便携版.exe`，恢复源码包、更新说明和 SHA-256 清单由交付脚本按同一版本生成。交付命令为 `npm run deliver:3.0.6`。3.0.5 及更早交付文件继续保留，0.5.160 及更早历史版本不重编号、覆盖或删除。

## 定向验证

`scripts/storyPreparation.test.ts` 已通过，16 项检查。测试使用模拟请求，不调用真实模型，也不提交视频生成。检查覆盖：扩写发出去的正文与编辑框原文一致，不含「请按这个顺序写成连贯正文：」，仍只发一次请求。

Windows x64 便携包由打包流程执行类型检查、Vite 生产构建和便携版生成。本版不改变用户项目存档。

交付后请核对 `莲华视频导演台-3.0.6-SHA256.txt` 中的 SHA-256 清单。

## 使用与交付

保存项目并退出旧版，打开 3.0.6 便携版，保留 EXE 旁完整的“莲华视频导演台数据”文件夹。原有「AI扩写」按钮不变。
