# 莲华视频导演台 4.4.1 发布说明

发布日期：2026-11-10（亚洲/上海）。

## 同一个人只站一处

生成这一镜时先读剧情：谁对谁做了什么，这个人此刻站在哪一处。同一个人只写这一处。剧情能确定「他」或「她」是谁时，用这个姓名写。

侧脸近景只写被取景的这个人。上一镜他已经在她身后、这一镜只是看她的脸时，仍写这个姓名留在原来的身后，声音从他那里来。程序不再往近景里补一双没名字的脚，也不再把上一镜的全身站位贴进这一镜。

已保存的提示词和成片保持原样。重新生成该段后才会改。

## 交付

- Windows：`莲华视频导演台-4.4.1-便携版.exe`。
- Android：`莲华视频导演台-4.4.1-安卓版.apk`，最低 Android 8.0 / API 26。
- 4.4.0 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.4.1`。这次改的是人物在镜头里怎么写，EXE 与 APK 一起交付。

## 验证

打包流程自带类型检查和前端构建。H3 正文用内存夹具核对：侧脸近景保留剧情原句，不补没名字的脚，也不把上一镜的进入句贴进这一镜。未在真实 RunningHub 页面上再点运行。
