# 莲华视频导演台 2.9.1 发布说明

发布日期：2026-10-21（亚洲上海）。

## 本次调整

画面描述转化采用“时间、地点、人物、场景、剧情”五项场景稿组织剧情，保留细致动作、打斗过程及完整对白。动作的发起、接触、反应和结果继续连贯表达，避免将具体过程压缩为“较量”“打斗”等概述。

人物身份、群体成员与时间关系继续传递到后续分段和导演过程。有原文依据的群体成员、共同反应和旁观反应保留各自身份；不把所有资料库人物强行加入场面，也不编造未知成员。对白保留完整内容及说话人关系，逐处保留“数天后”“随后的日子里”等跳时，使不同阶段的剧情能够安排相应转场。

沿用现有生成流程，不新增按钮、运行时校验、内容审核、生成拦截、自动重试或额外模型请求。

## 验证

`storyVisualScenes`、`storyVisualSceneAnalysis`、`storyVisualScenesPipeline`、`storyGroupTimePipeline` 四个定向脚本已通过。

长稿原文与场景稿的字符位置分别处理，补测确认各场道具不会因坐标混用串场。测试同时覆盖原对白、动作细化、角色身份、存储回读、原稿回溯、单场重做及现有分批请求数。

`pack:win` 内的 TypeScript 检查、Vite 生产构建和 Windows 便携包打包通过。便携包在隔离数据目录中真实启动，首页和视频导演台正常显示，无白屏及渲染错误。报告位于 `output/playwright/packaged-startup-2.9.1-zdLIhL/report.json`。

流程测试使用离线固定响应，未调用真实模型或提交视频生成；这些结果验证数据传递与程序行为，不代表对模型生成质量作保证。

## 使用与交付

旧结果不会自动改写。再次使用现有“AI 画面描述转化”入口时，若当前正文匹配已采用稿，会沿已保存的转化来源回到原始小说；采用新稿后再解析、分段。人工修改过正文时，保留当前输入进行转化。

继续通过现有分段和导演入口生成后续结果。更新时保留 EXE 旁完整的“莲华视频导演台数据”文件夹。

版本按十进位规则从 2.9.0 升至 2.9.1，保留历史版本号与交付文件。
