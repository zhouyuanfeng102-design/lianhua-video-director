# 莲华视频导演台 3.9.0 发布说明

发布日期：2026-11-07（亚洲/上海）。

## RH 网页读取应用名

读取网页时，从应用页标题读取应用名，写进应用库。原来显示成「网页应用」加编号的，读取后改成网页上的名字。读取仍在后台进行，不弹出窗口。

已经添加、还显示编号的应用，再点一次「读取网页」就会换成页面标题。

## 版本定位与交付

Windows x64 便携包：`莲华视频导演台-3.9.0-便携版.exe`。构建命令为 `npm run pack:win`，交付命令为 `npm run deliver:3.9.0`；3.8.9 及更早历史版本文件保留。

## 验证

- 读取结果写回应用名：`npx tsx scripts/runningHubWeb.test.ts`
- Windows x64 便携包：`npm run pack:win`
- 交付文件：`npm run deliver:3.9.0`

已有项目、提示词和成片不作改写。
