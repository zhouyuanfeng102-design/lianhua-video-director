# 莲华视频导演台 3.0.2 发布说明

发布日期：2026-10-24（亚洲上海）。

## 收起尺寸说明

图像工作台里，分辨率和比例下面平时只留「尺寸说明」。原来一直露在外面的估算像素、画幅和云端档位说明，改到点开之后的第一句。比例不一致的提醒和尺寸填错的报错仍留在外面。分镜图的尺寸说明未改。

## 写明剧情原文对私密生成的影响

人物图像设置里的「是否参考剧情补齐资料」改名为「是否附带剧情原文」，按钮仍是「是 / 否」，仍按人物保存。

选「否」：不把章节原文送进文字模型，私密内容大概率能生成。只用当前手工资料、自定义要求和参考图。

选「是」：补资料和生图都会带上当前章节。章节里的私密情节容易让文字接口直接拒绝。

名称、按钮和说明的字号缩小，少占右侧位置。开关本身的行为没有改，不新增运行时校验、内容审核、生成拦截、自动重试或模型请求。

## 版本与交付

本版便携包为 `莲华视频导演台-3.0.2-便携版.exe`，交付命令为 `npm run deliver:3.0.2`。3.0.1 及更早交付文件继续保留，0.5.160 及更早历史版本不重编号、覆盖或删除。

Windows x64 便携包由打包流程执行类型检查、Vite 生产构建和便携版生成；恢复源码包、更新说明、启动器和 SHA-256 清单由交付脚本生成。
