# 莲华视频导演台 1.4.2 发布说明

## 版本定位

1.4.2 修复定向动作在视频分镜、静帧规划和生图提示词之间丢失攻击目标的问题，保留既有项目数据、默认 MiniMax H3 流程和按需 Seedance 2.5 双语格式。

## 修复内容

- 分镜生图转换新增施事者→动作→目标/终点关系约束，要求保留目标是否入画、双方朝向、运动轴和摄影机位置。
- 静帧规划与图片转换明确区分画内目标和画外目标，避免把“向前冲锋”误解为朝摄影机冲锋。
- 视频渲染增加量词主体纠偏和目标方向输出，覆盖“一群敌人冲向夏提雅”等多人物动作表达。
- 历史图片与项目数据不自动重生成；修复后主动重新生成对应分镜图片即可使用新规则。

## 构建与校验

便携版使用 `npm run pack:win` 构建，交付物使用 `npm run deliver:1.4.2` 生成。针对性规则、分镜图片、空间连续性、提示词和 TypeScript 检查结果以本轮实际记录为准。
