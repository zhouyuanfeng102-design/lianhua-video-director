# 莲华视频导演台 2.8.5 发布说明

发布日期：2026-10-20（亚洲上海）。

## 本次修复

修复生成首尾帧时，首帧因 HTTP 502 等普通错误失败后，尾帧也被连带取消的问题。根因是共享首尾帧队列将首帧成功误作为尾帧执行的硬性前提。

- **首帧普通失败**：保留首帧原始失败结果，尾帧使用自身原文和原参考图继续一次原定生成，不借用失败的首帧结果。
- **首帧成功**：继续将真实首帧作为尾帧的连续性参考，保留原有衔接方式。
- **用户主动取消**：仍按用户操作停止队列，不因本次修复继续发起后续生成。

本次不会自动重试失败的首帧，不增加运行时校验、内容审核、生成拦截或额外模型处理步骤。2.8.4 的生成任务页紧凑布局及此前的单段生成、人物参考图关联和提示词修复继续保留。

## 使用方式

保存项目并退出旧版后启动 2.8.5，保留 EXE 旁完整的“莲华视频导演台数据”文件夹。新提交的首尾帧任务使用修正后的队列行为，已有失败或取消记录不自动重跑，项目和素材不自动改写。

旧版已被连带取消的尾帧，可点击该尾帧卡片的“重新生图”单独生成，原任务记录保留。本次修复解决尾帧被连带取消的问题；首帧 HTTP 502 仍保留为图像接口返回的实际错误。

## 验证与交付

两组定向检查通过：`scripts/storyboardBoundaryDependency.test.ts` 与 `scripts/storyboardImageToImageGeneration.test.ts`。覆盖首帧 HTTP 502、保存失败和转换失败后尾帧独立执行，成功首帧继续作连续参考，主动停止不再提交尾帧，以及没有借用旧首帧或自动重试。全部使用本地模拟，没有真实 API 请求。

Windows 打包通过：`npm run pack:win -- --config.directories.output=.pack-release-2.8.5` 已完成 TypeScript 检查、Vite 生产构建和 Windows 64 位便携版生成。构建有已有循环分块及大分块提示，无构建错误。

本版便携包命名为 `莲华视频导演台-2.8.5-便携版.exe`。交付步骤使用 `npm run deliver:2.8.5` 生成版本启动器 `启动莲华视频导演台-2.8.5-便携版.bat`、恢复源码 ZIP、更新说明及 SHA-256 清单。

2.8.4 及更早交付文件继续保留，0.5.160 及更早版本不重编号、覆盖或删除。
