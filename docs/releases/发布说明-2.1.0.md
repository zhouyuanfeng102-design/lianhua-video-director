# 莲华视频导演台 2.1.0 发布说明

发布日期：2026-10-13

## 版本定位

本版修复 RunningHub 图片及视频工作流中手动添加的参考图片槽无法删除的问题。每个图片槽提供明确的删除入口，同时清理仅此槽使用的本地节点目录、请求字段和控件定义。

保存工作流并重新打开后，已删除的图片槽不会被自动同步重新加回。其余图片槽的顺序、映射和生成参数保留。删除在当前工作流草稿中完成，取消编辑不保存本次改动。

## 使用与交付

更新前保存项目并退出旧版，将新 EXE 放在原目录，保留完整的“莲华视频导演台数据”文件夹。

6 组删除专项检查通过，覆盖请求字段精确删除、自定义及失效旧槽、归一化与同步后不恢复、其他用途引用保留，以及无关 JSON 文本和长数字原样保留。

隔离界面检查一次运行通过：图片、视频两种模式均可连续删除新手动槽和旧已保存槽，保存重开不恢复，取消编辑不保存；剩余槽顺序、用途和参数保持一致，请求快照不包含删除的节点。验证没有使用真实项目、上传或生成服务。打包流程中的类型检查、生产构建及 Windows 便携包生成通过，交付附 SHA-256 校验清单。

版本按十进位规则从 `2.0.9 → 2.1.0` 递增。便携包：`莲华视频导演台-2.1.0-便携版.exe`。

打包命令：`npm run pack:win`；交付命令：`npm run deliver:2.1.0`。交付包含便携 EXE、恢复源码 ZIP、更新说明、启动器和 SHA-256 校验清单。2.0.9 及更早历史版本与交付文件保留。
