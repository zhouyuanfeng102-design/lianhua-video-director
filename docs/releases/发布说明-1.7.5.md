# 莲华视频导演台 1.7.5 发布说明

2026-10-10

修复 RunningHub“Minimax-H3 无限长视频自动提示词-小白全能版”未选参考图片槽的默认值，避免旧请求把空字符串传入云端图片合批节点。

## 修复范围

根据该应用的 API 模板，应用 ID `2103012816681041921` 的后五个参考图片字段 `273.image`、`285.image`、`436.image`、`462.image`、`463.image` 在未选图时保留 `example.png`。已选图片仍使用本次上传结果，槽位和图片编号保持原样。第一图片槽的空值没有核实，不作猜测；图片数量、提示词、时长等其他参数也保持原值。

旧版将这些未选字段清空时，云端 `ImageBatchMulti` 节点可能收到空图片，出现 `'NoneType' object has no attribute 'shape'` 和错误码 805。本次修复只覆盖已核实的应用及字段，其他工作流沿用原配置。

## 更新后的使用

新提交和用户明确重试使用修正后的连接副本。历史任务和批次的原始快照保留，已经提交的任务不会自动重发。失败任务可在更新后明确重试；“重新获取成片”仍只查询原云端任务，不会生成新的结果。

## 验证与交付

28 项请求协议检查与 3 个模拟引擎场景已通过，覆盖未选槽恢复模板值、已选槽上传结果、稀疏槽位与原图字节保留、旧快照保留和重试提交边界；未调用真实收费云端生成。`npm run pack:win` 已通过 TypeScript 检查、生产构建与 Windows 便携版打包。

交付包含 V1.7.5 便携版、恢复源码、更新说明、启动脚本和配套 SHA-256 校验文件。1.7.4 及更早发布说明和交付文件保留。
