# 莲华视频导演台 2.3.2

发布日期：2026-10-15。

## 修复停止本地追踪后未知提交批次无法删除

HTTP 524 等错误可能使视频任务停留在“提交结果待确认”。现在停止本地追踪后，可以从生成任务列表删除对应批次，避免已经停止追踪的未知提交记录一直占据列表。

删除只清理列表，保留原任务的未知提交边界、断点和凭据，撤销后仍可恢复原记录。删除与撤销不会重新提交视频生成，也不会取消远端任务。恢复记录不代表能够找回无远端 ID 的普通 API 任务，能否查询仍取决于原任务已有身份及服务提供的查询能力。

## 保留任务与结果保护

正在运行、下载、取消中、尚未停止本地追踪、待取回结果以及续跑关联尚未建立完整的任务继续受删除保护；只有符合现有安全条件的批次才可清理。

HTTP 524 只能表明本次请求没有及时收到有效响应。上游尚无可核对记录时，继续按提交结果待确认处理，不能据此认定服务端已经接收、任务已经失败或费用已经退回。原任务是否受理、运行和扣费，应以上游可核对记录为准。
