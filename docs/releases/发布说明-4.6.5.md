原文是仰躺、压上来或从正面进入，且没有写他在她身后、跪伏、趴着或侧躺时，她仰躺着，背留在身下的垫面上，胸口朝上。双膝弯曲分开，朝向他。他留在她两腿之间，面对她，胸口对着胸口，髋对着髋。进入从她骨盆前面发生。原文只写按回某件家具、没有写按在肩、背或后脑时，写成把她放到这件家具上，背留在垫面上。要看见相接时，同一镜只用一个斜侧面中景，脸和上半身留在这个画面里。

只有原文写了他在她身后、她跪伏或趴着，才用后入。单独的进入、滑入、抵上、抽送或按回不套用。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.6.5`。分段、分镜和视频提示词在两端共用，EXE 与 APK 一起交付。
