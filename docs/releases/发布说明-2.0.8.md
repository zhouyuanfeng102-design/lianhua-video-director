# 莲华视频导演台 2.0.8 发布说明

发布日期：2026-10-13

## 版本定位

本版进一步收紧视频导演台“长剧情批量”的上方批量设置，并修正右侧预览底部按钮被挤压的问题，为分段清单和提示词预览保留更多空间。

批量设置高度约缩至原来一半，提示词格式与连接配置整合排列，生成参数与高级公共参数 JSON 紧凑并排，文字和控件字号随可用空间缩小。

右侧预览底部完整显示“修复人物图片绑定”和“本段图片应用到全部已选”按钮。长提示词及人物图片绑定详情按预览区可用空间显示，保留原有修复绑定、选图和应用到已选片段的操作行为。

## 使用与交付

更新前保存项目并退出旧版，将新 EXE 放在原目录，保留完整的“莲华视频导演台数据”文件夹。

针对性布局检查通过：在 1430×870、100% 字体下，批量设置整框由 294.2px 缩至 147.9px（原来的 50.3%）；在 1280×800、130% 字体下，由 290.1px 缩至 151.6px（原来的 52.2%）。高级 JSON 展开时，设置区没有内部滚动、控件覆盖或越界，参数可编辑，完整范围说明保留在悬停提示中。

右侧修复与应用图片按钮在长正文、展开绑定说明并滚动到底后仍完整可见且可点击。参数组件与实际回调的 48 组针对性检查通过，保留原稿、参数覆盖、映射及冻结重试检查；验证没有调用真实生成服务。打包流程中的类型检查、生产构建及 Windows 便携包生成通过。交付附 SHA-256 校验清单。

便携包：`莲华视频导演台-2.0.8-便携版.exe`。

打包命令：`npm run pack:win`；交付命令：`npm run deliver:2.0.8`。交付包含便携 EXE、恢复源码 ZIP、更新说明、启动器和 SHA-256 校验清单。2.0.7 及更早历史版本与交付文件保留。
