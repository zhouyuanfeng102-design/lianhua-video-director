# 莲华视频导演台 3.6.3 发布说明

发布日期：2026-10-31（亚洲/上海）。

## 一镜一个主运镜

这一镜只写一个主运镜，第二种运镜放到下一镜。固定镜头保持这一格和这一距离。绕拍时脚、髋和肩留在路线朝向，背景从画面滑过。机位用运镜句。举手另写双臂。主观镜头写成 POV。

已有首帧和尾帧、原文没有分成多镜时，用一镜从首帧走到尾帧。

## 接触之后物体才动

要举起的东西从这一镜开头就在那只手里。手先碰到门、兵器或杯子那块已经写出的表面，然后物体停在碰完的状态。一件事写一次，后面只写停住后的状态。

跌倒写成短路径：后脚滑、膝弯、脚掌贴地并停住。尘土和头发在身体停住之后落下。地面留在画面里。

原文要看见全身走路时，镜头按步速拉出，整个人留在画面里。坐下时大腿贴着座位。环抱时手臂留在对方后背外面。原文有疤、印或饰物时，左右和部位用原文的，后面每一镜用同一句。手朝镜头又不是这一镜的主体时，手留在腰侧。

## 回头和台词

视线或机位要过到肩膀后面时，肩膀跟着头转，直到下巴留在肩膀前面，胸口跟着这次转向。视线还在肩线前面时只转头。

这一镜的台词只写一次身体动作，最后一句说完才停。原文写明这个人不能动，才只动眼睛和嘴。画面句里的对白只放在 `<d>` 里。引号只留给原文已经出现在招牌或屏幕上的字。原话逐字保留。

## 身体停留

落地后脚掌贴地，重心留在脚掌上。髋部按实时速度做小幅度起伏，直到这一拍结束。从后面进入时，阴茎仍连在本人腹股沟，前端留在两腿之间的阴道口，臀留在开口后面。阴蒂留在外阴前面。吻没有写伸舌时，嘴唇相贴，舌头各自留在自己嘴里。

这是共用写法。已保存的提示词和成片不改。不新增运行时校验、内容拦截、自动重试、按钮或模型请求。

## 版本定位与交付

Windows x64 便携包：`莲华视频导演台-3.6.3-便携版.exe`。构建命令为 `npm run pack:win`，交付命令为 `npm run deliver:3.6.3`；3.6.2 及更早历史版本文件保留。交付目录同时提供恢复源码、更新说明、启动器与 SHA-256 清单。
