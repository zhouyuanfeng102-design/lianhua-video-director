# 莲华视频导演台 1.7.8 发布说明

2026-10-10

资产库卡片采用更紧凑的文字、按钮、间距和预览高度，常用桌面窗口优先展示两排图片；本地视频按播放进度分段读取，改善反复打开和拖动播放。

## 资产库卡片

卡片名称、选择说明和操作按钮收紧排布，预览框按照窗口可用高度缩小，减少空白区域。常用桌面窗口优先排成两排，单个素材不会撑满整页。超出当前页容量的素材继续分页，跨页选择保留；图片保持完整展示，长名称和详细信息可以按需查看，展开详情不会撑高卡片，原有素材操作入口保留。

## 视频预览

本地媒体读取支持真实的 HTTP 206 分段响应以及正确的 `Content-Range`、`Content-Length` 和 HEAD 响应，播放器可以按播放进度请求文件片段。请求取消后释放文件读取资源。

每次重新打开或重载本地视频使用独立的读取请求，并清理旧播放器错误状态，减少失败加载结果影响后续播放。原资产记录、原视频文件和远程签名 URL 保留。本次修复不改变视频编码，不把播放失败直接判定为原文件损坏。

## 验证与交付

资产库界面专项验证通过：1920×1080、1907×1192、2861×1788 和 1366×768 窗口，在实际应用字体 125%–130% 下均完整显示两排，页面外层无滚动。1907×1192 对应用户截图物理尺寸在 150% 系统 DPI 下的窗口。另验证单素材不撑满、详情不撑高、41 素材分页无遗漏且跨页选择保留。

视频读取专项通过，覆盖字节边界、末尾片段请求、HEAD、416 响应、安全路径、缺失文件与请求取消。真实 Electron 播放专项通过：MP4、扩展名为 `.mov` 的 MP4、WebM 和用户提供的原 `.mov` 各两次打开、正常播放、中段与尾段跳转、关闭。

仅针对新增修正补验失败加载后的恢复，以及本地独立请求对两种 MOV 文件的影响；重复打开、播放与稳定跳转通过，素材元数据更新不会更换正在播放的来源。用户原视频 SHA-256 保持不变。`npx tsx scripts/videoAssetPreview.test.ts` 通过。本轮未自动提交收费视频生成，验证不代表支持所有第三方视频编码。

`npm run pack:win` 通过，完成 TypeScript 检查、Vite 生产构建和 Windows x64 便携版打包。构建保留现有循环分块与较大分块提示，未重复执行整套回归。

本版提供 V1.7.8 便携版、恢复源码、更新说明、启动脚本和配套 SHA-256 校验文件。1.7.7 及更早发布说明、交付文件和交付入口保留。
