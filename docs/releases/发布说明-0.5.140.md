# 莲华视频导演台 0.5.140 发布说明

发布日期：2026-09-19

## 版本定位

为云端工作流增加明确的输出参数绑定，让视频时长与分辨率在单段、批量生成时直接可见，并实际传递到已绑定的节点。

## 本版新增

- RunningHub工作流增加视频时长、分辨率及宽高的明确节点绑定入口，使用当前工作流的真实节点字段，不猜测ID或套用教程节点。
- 视频导演台的单段生成与长剧情批量生成增加直观的时长和画面规格控件，减少在杂项参数中逐项查找的操作。
- 留空沿用工作流原值；只有明确填写且绑定到实际字段的参数才会覆盖对应值。其他节点参数、提示词、参考图及云端运行选项保持不变。
- 各工作流独立保存参数映射。修改设置不影响已提交任务的冻结快照，不会自动重跑历史任务或改写已有成片。

## 使用方式

1. 在“API 设置 → 视频生成 → RunningHub 云端 → 管理云端工作流”中，为视频时长和分辨率参数选择对应的真实节点字段；若工作流使用分别设置的宽、高字段，则分别绑定。
2. 保存工作流，在“视频导演台”的单段或长剧情批量生成中选择该工作流，并填写本次需要覆盖的时长和画面规格。不需覆盖的参数留空。
3. 具体支持的时长、分辨率名称、像素范围以及计费以云端工作流为准。设置页面只配置参数，确认生成时才提交任务。

分辨率名称字段与宽高像素字段由各工作流定义，不能仅凭一个节点标题断定同一套设置通用于所有工作流。未绑定的字段不会被软件猜测或偷偷改写。
