# 莲华视频导演台 2.7.8 发布说明

发布日期：2026-10-20（亚洲上海）。

## 版本定位

修复 RunningHub 云端视频工作流读取节点后仍需逐项手动添加 LoRA 位置的问题。沿用现有“读取云端节点”和“导入节点 JSON”入口，读取成功后自动补齐实际存在的 LoRA 模型及强度位置。

## 自动添加 LoRA，保留已有配置

新发现的模型字段与对应强度自动加入 LoRA 配置。已有参数值、用户手动指定的位置和隐藏选择继续保留，重复读取或导入不会重复添加位置。工作流保存仍使用原有“保存工作流”操作。

强度按照实际连线关联，不再只查找模型所在节点。例如本次工作流的 `343.strength_model` 连接 `366` 的 `GoohaiUniversalSlider` 输出，自动绑定到实际可编辑字段 `366.值`；同节点的普通 LoRA 强度仍按原字段绑定。

## 导入入口与分组开关边界

将 API 节点图粘贴到“导入 cURL / JSON”入口时，提示改用“导入节点 JSON”，避免把节点图当作任务请求配置。

363“忽略多组孤海”仍是前端分组开关，API 中的 `inputs` 为空。本版自动添加的是该分组开启后实际进入 API 的 LoRA 参数，没有新增 363 的开关字段，也不把强度参数描述成原分组旁路开关。

本次修复不新增模型请求、自动重试、运行时内容审核或生成拦截；已有工作流配置与历史任务继续保留。

## 使用方法

1. 在 RunningHub 网页打开需要使用的 LoRA 分组并保存工作流。
2. 在软件中选择对应工作流，点击“读取云端节点”；也可把导出的工作流 API 文件通过“导入节点 JSON”导入。
3. 查看自动补齐的 LoRA 位置与原有参数，然后点击“保存工作流”。
