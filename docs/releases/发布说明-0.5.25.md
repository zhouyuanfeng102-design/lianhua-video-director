# 莲华视频导演台 0.5.25

## 版本定位

- 0.5.25 是基于 0.5.24 的提示词可靠性修复版，不改变现有导演流程、时间线结构和项目数据格式。
- 重点提升 NSFW 场景、连续人物动作和旧项目重建时的细节保真，并保持普通项目与历史项目兼容。

## NSFW 细节与动作保真

- 当剧情正文或额外要求明确包含 NSFW 信号时，最终视频提示词会逐镜详细保留原文中的身体状态、姿势、肢体朝向、接触关系、动作顺序、动作幅度和可见结果，不再含蓄替换、概括省略或自行添加原文没有的动作。
- 修复“人物在地点 + 连续动作”的主体与地点误判；无标点动作链、精确镜数和单镜完整动作序列均按原文顺序保留。
- 静态姿态不再被补入无关移动或战斗动作；多镜头中的人物和动作目标会按实际剧情识别，减少模型自行发挥。
- canonical 时间线及由其派生的英文稿、不同目标模型适配稿会沿用上述细节与动作约束。

## 年龄限定处理

- AI 剧情分析和项目圣经仅在用户原文明示年龄或年龄段时填写年龄；未写年龄时保持空白，不再自动推断“成年、青年”等限定。
- NSFW 细节模式会移除系统自动生成的人物年龄锁，不会自动加入“成年限定”等措辞；用户明确写出的年龄仍保持原样，包括剧情正文或制作要求中的表述。
- 人物名、资产名、场景名及普通非 NSFW 项目不受该清理逻辑改写。

## 旧项目兼容与误触发修复

- 旧项目可根据保存的原始剧情、场景快照和额外要求重新识别 NSFW 细节模式；旧分镜动作过于概括时会从原文恢复动作细节，无需迁移项目数据。
- 修复非性语境误触发：工程中的裸露电线、电极或金属，医学检查描述，以及裸体雕塑、绘画等艺术描述不会进入 NSFW 细节模式。
- 继续兼容 0.5.24 及更早项目，并保留现有 UI 布局和导演工作流。

## 交付内容

- 0.5.25 交付包含 Windows x64 便携版、恢复源码、更新说明、版本启动器、无版本启动器与 SHA-256 完整性清单。
- 0.5.24 及更早历史交付文件继续保留，发布脚本不会覆盖旧版本。
