# 莲华视频导演台 4.4.8 发布说明

发布日期：2026-11-11（亚洲/上海）。

## 她并回无名主角

解析提示改为：通读全文后，一个连续的人只返回一张人物卡。没有姓名时，name 用「无名主角」，「她」只写进别名，不再返回名为「她」的第二张卡。两个已经写出姓名的人仍然各留各的。

模型若仍交回一张「她」，解析结果会把这张代词卡并回唯一的人物卡。已保存的人物卡不自动改，再点一次「解析并补全」才会并。

## 交付

- Windows：`莲华视频导演台-4.4.8-便携版.exe`。
- Android：`莲华视频导演台-4.4.8-安卓版.apk`，最低 Android 8.0 / API 26。
- 4.4.7 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.4.8`。人物解析两端共用，EXE 与 APK 一起交付。

## 验证

代词身份夹具核对：单独的「她」并进「无名主角」；千仞雪和比比东同时在场时不把「她」猜给其中一人。打包流程自带类型检查和前端构建。
