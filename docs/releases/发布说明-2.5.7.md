# 莲华视频导演台 2.5.7

发布日期：2026-10-17。

## 剧情生图保留行动目标与注视对象

针对原分镜明确“冲向对手、视线锁定对手”，转换后的图片提示词却仅剩“向前冲锋、刀尖指向正前方”的情况，调整共享剧情生图规则：先表达当前静帧的具名行动者、动作对象、注视对象及其相对位置，再按已有机位描述实际可见的正面、侧面或背面，最后展开外貌与环境。自然语言、SD 标签与 NAI 角色段保持相同的关系语义。

原镜已有机位、动作阶段、距离与裁切继续生效，保留侧拍、自然回头、头身不同向、目标主观镜头、画外目标及局部特写。不会将所有战斗改成背拍，也不为展示双眼或胸甲而转动人物。共享规则适用于普通分镜、首尾帧、自选静帧和相关剧情生图入口；各张图片使用自己的时刻，完整视频过程不作为同一静帧附加。

## 人物参考图的外观与姿态分开

实际图片提交中，标为人物身份用途的参考图增加一次简短说明：只提供外形、配色、服装与身体结构，不沿用其站姿、头部朝向、视线或正脸展示。该说明不施加到仅有普通构图或同批外观连续首图的请求；构图与首尾状态参考继续按各自明确用途使用。

已经清除或失效的人物绑定不会因旧来源信息重新成为身份参考。实际上传顺序、角色对应与正文保持原有处理方式。

## 更新范围与历史内容

本次集中更新共享转换规则和人物参考用途，不批量重写所有后端、人物设定、无人风景或物品预设。旧版内置规则块只在新请求组合时按完整原文识别并替换，用户编辑的规则保留；项目存档不迁移，历史任务与原图不覆盖。

来源镜头仍存在时，资产卡“重新生成”沿用现有流程，按当前镜头及规则重新转换，新图另存。复用历史最终提示词的重试仍使用其历史正文。已有图片像素不会自动改变；未新增额外 AI 审核、关键词语义拦截或自动重复出图。

## 验证与交付

已通过针对人物朝向的开发测试：具名动作与注视对象、参考图用途和绑定边界、当前镜头重新生成入口、不同提示词格式，以及旧版完整规则块与自定义规则的兼容组合。打包流程中的 TypeScript 类型检查与 Vite 构建通过；未追加全量回归或界面审核。

真实接口出图尚未执行：独立测试环境无法读取系统加密的 API 凭据，文本转换和图片生成请求均为 0 次；因此本版不宣称已经验证该模型的实际出图效果。开发检查没有加入软件生成流程，未新增运行时校验、审核或重试。

本版交付命令为 `npm run deliver:2.5.7`，便携包名为 `莲华视频导演台-2.5.7-便携版.exe`；同时提供恢复源码、更新说明、启动器及 SHA256 文件。
