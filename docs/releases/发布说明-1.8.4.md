# 莲华视频导演台 1.8.4 发布说明

2026-10-11

本版改造“AI画面描述转化”：先理解剧情中的事件、动作对象与因果，再把已有动作转成可拍摄的过程与可见反应，改善只复述原文的问题。

## 剧情理解与动作细化

默认分两阶段请求当前文本模型。第一阶段通读剧情，记录事件、原文证据、行动者、目标、动作过程、结果与未确定信息；第二阶段据此生成自然段形式的画面描述。战斗与复杂动作重点交代起势、运动路径、接触或落空、回应和结束状态，简单动作不强行拉长成固定模板。

人物身份、事件顺序、命中结果、胜负与原有对白继续以原文为依据。原文未明示的步法、朝向或过渡细节列入“编排补充”，不能擅自增加人物、技能、伤势或改变结局。猜测和心理判断保留其不确定性，例如“可能还有同伴”不会被写成同伴已经入场。

转化程度可选择“忠实细化”或“详细动作与编排”。正常短文本两阶段各请求一次，长文本按预算分批处理，携带全局叙事摘要、当前场景动作依据与衔接状态，完整动作计划保存在本地。超过安全预算且无法可靠分批时会明确提示并保留原文。检查结果以核对提示展示，由用户决定采用；不会为了这些提示隐式重复请求。

## 审阅与局部重做

结果审阅增加“动作与依据”：逐段显示原文依据、画面描述、剧情事实与动作因果，以及单独列出的编排补充。可筛选有改动的段落，仍可在“全文对照”中阅读并复制完整原文和结果。

“重新转化”会按当前原文、资料、规则、接口与转化程度重新处理；“只重做这一段”带着完整上下文和相邻段落重写所选段落，保留其它段落。未采用的结果不会覆盖编辑区。原文、资料、设置或当前项目变化后，旧结果不能直接覆盖当前输入，可重新转化。

## 来源保存与后续制作

采用时保存原文、转化正文、逐段依据、动作计划与转化程度。“查看转化来源”可回查采用时的完整记录。后续剧情解析、语义分段与视频提示词继续使用相同动作依据，区分原文事实与转化编排，减少再次误读。

Seedance 成稿同步接收当前段对应的动作证据。已有 Seedance 稿继续保留查看，需主动重新生成才能使用本版证据传递策略。

原项目、旧转化来源、历史提示词、图片与任务继续保留。旧来源没有动作元数据时，仍可查看全文对照；需要应用新转化策略时，请主动重新转化并采用。

## 验证与交付

动作转化引擎 14 项针对性检查通过，覆盖两阶段、长文本预算、单长段跨批次证据定位与局部重做。剧情解析上下文、来源持久化、设置指纹与旧规则迁移检查通过；语义分段计划 34 项、规划请求 47 项及参考资料、Seedance 动作证据传递相关检查通过。打包流程中的 TypeScript 检查、Vite 生产构建和 Electron 便携包构建通过，保留既有循环分块与体积提示。

直接使用 1.8.4 便携 EXE，在新建隔离数据目录中完成审阅与保存流程检查。1120×720、1280×800 下审阅对话框与采用按钮位于窗口内，没有横向溢出。验证两阶段原文传递、逐段事实与编排补充、单段重做保留其它段落、生成期间禁用冲突操作、全文重新转化、采用后实际保存与重载、转化来源回查，以及设置或草稿变化后阻止旧结果覆盖。

检查还覆盖生成期间选择“保留原文”：释放迟到响应后，不进入下一阶段、不复活审阅、不修改编辑区。采用的来源与动作元数据在后续编辑和丢弃待审结果后保持原记录。检查期间没有页面或控制台错误。

成品 UI 检查在最后一处长单段证据边界修复前执行；该修复只调整批次内的证据定位，未改变界面与控制流程。修复后补充针对性单元检查并重新打包，保留已通过的 UI 结论，没有重复运行整套界面检查。

本版只使用隔离数据与本机模拟文本接口验证调用流程、审阅操作和来源保存，未运行全量回归，未调用真实文本、生图或视频服务；模拟结果不代表所配置模型的实际转化质量。

本版按十进位从 1.8.3 升级至 1.8.4，便携包名为 `莲华视频导演台-1.8.4-便携版.exe`，交付命令为 `npm run deliver:1.8.4`。1.8.3 及更早发布说明、交付文件与交付入口继续保留。
