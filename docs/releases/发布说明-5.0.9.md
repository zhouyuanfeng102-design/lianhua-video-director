# 莲华视频导演台 5.0.9 发布说明

2026 年 11 月 24 日 · Windows x64 便携版与 Android 正式签名版

## 版本定位

本版给 AI 剧情分段加上合并和小分段。一段里的剧情太少时，可以把连续的几段收成一段；一段里的剧情太多时，可以把这一段分成两段。每段仍用原来的秒数。Windows 与 Android 共用这一处。

## 合并和小分段

在提示词导演台的 AI 剧情分段里，直接点分段卡片。再点同一张就取消。编辑区写着已选范围。

点「合并」，选中的连续几段交给文本 API 收成 1 段。点「小分段」，当前这一段分成 2 段。每次只发一次请求，只带点中的段，不重跑整章。

返回的段数不对，或原文摘录不在这几段已有摘录里，这一次作废，原来的分段保持不动。已锁定的段要先解锁。

没被替换的段正文不动。新段是待生成，不挂旧提示词。紧接着的下一段标成需更新，等你自己重试。旧提示词和成片留在项目里。全片总秒数按新的段数乘以每段秒数更新。

## RunningHub 计时

本版包含 5.0.8 的计时修复。视频仍在生成时，执行耗时按实际开始时间继续累计。

Windows x64 下载 `lianhua-video-director-5.0.9-windows-x64-portable.exe`，Android 下载 `lianhua-video-director-5.0.9-android.apk`。维护者使用 `npm run deliver:5.0.9` 生成本地交付文件 `莲华视频导演台-5.0.9-便携版.exe`、`莲华视频导演台-5.0.9-安卓版.apk`、恢复源码与 SHA-256 清单。

签名与验证范围见 [5.0.9 能力与验证记录](能力与验证记录-5.0.9.md)。安卓安装与备份见 [安卓安装说明](../android-install.md)。
