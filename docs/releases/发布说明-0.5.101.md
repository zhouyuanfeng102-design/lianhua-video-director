# 莲华视频导演台 0.5.101 发布说明

## 版本定位

本版修复提示词导演台“导演与视觉”卡片中选择按钮不可稳定点击的问题。目标便携包为 `莲华视频导演台-0.5.101-便携版.exe`。

## 导演与视觉

- 导演分类、导演风格、视觉风格改为“输入框 + 选择下拉”组合：左侧仍可手写自定义内容，右侧“选择”是真正可点击的下拉控件。
- 选择导演分类后，会立即刷新可选导演风格；选择导演风格后，会同步回填导演分类、导演风格名称和风格说明。
- 选择视觉风格继续使用提示词工作台同一套视觉风格库，并沿用旧项目兼容兜底。
- 继续去掉导演参数区里重复的“风格预设”控件；规则中心的风格预设管理和内部兼容逻辑保持不变。

## 验证

本轮针对性验证：

```powershell
npm run test:typecheck
npm run test:styles
npm run test:workflow
npm run test:release-review
```

并使用 Playwright 打开开发页面，实际选择“导演分类”“导演风格”“视觉风格”三个下拉，确认均可点击并回填输入框。

交付时使用：

```powershell
npm run pack:win
npm run deliver:0.5.101
```

交付应生成 0.5.101 便携版、恢复源码、更新说明、版本专属启动脚本和 `SHA-256` 清单；现有 0.5.100 及更早版本化产物继续保留。最终校验值以 `交付\莲华视频导演台-0.5.101-SHA256.txt` 为准。
