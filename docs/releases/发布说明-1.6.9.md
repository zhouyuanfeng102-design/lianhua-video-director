# 莲华视频导演台 1.6.9 发布说明

2026-10-09

资产库每张卡片的详细信息改为默认折叠，减少卡片高度，便于浏览更多素材。

## 使用方式

点击卡片中的“详细信息”可独立展开或收起人物参考、章节、标签、时长、尺寸、音频信息、文件大小和 SHA-256 等内容。

名称、图片或视频预览、视频选图及操作按钮保持直接显示；文件缺失和重新生成不可用的提示仍直接可见。

展开状态仅影响当前界面，不写入项目数据；刷新后恢复默认折叠。

## 验证与交付

本次仅调整资产卡片的展示。针对性界面检查通过，覆盖默认折叠、完整元信息展开、逐张独立开关、键盘操作、刷新后恢复折叠，以及操作按钮保持可见；检查中资产数据未变，未提交生成请求，未出现浏览器错误。

`npm run pack:win` 包含的 TypeScript 检查、生产构建和 Windows 便携版打包均通过。`npm run deliver:1.6.9` 用于生成便携 EXE、恢复源码 ZIP、更新说明、启动脚本及 SHA-256 校验文件。历史发布说明和交付文件保留。
