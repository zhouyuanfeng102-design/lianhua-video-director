# 莲华视频导演台 4.2.9 发布说明

发布日期：2026-11-09（亚洲/上海）。

## 没交到网页的任务可以再交一次

网页上的运行按钮没点出去时，这条任务仍记着「已经越过提交边界」。点「继续准备原任务」或「恢复查询原任务」会把同一段再交给网页一次，不再把准备阶段退回去。同一条网页任务如果已经点过运行，桥接不会再点第二次。

已保存的提示词和成片保持原样。

## 交付

- Windows：`莲华视频导演台-4.2.9-便携版.exe`。
- Android：`莲华视频导演台-4.2.9-安卓版.apk`，最低 Android 8.0 / API 26。
- 4.2.8 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.2.9`。这次改的是任务提交记录，EXE 与 APK 一起交付。
