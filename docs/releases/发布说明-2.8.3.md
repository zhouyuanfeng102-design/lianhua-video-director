# 莲华视频导演台 2.8.3 发布说明

发布日期：2026-10-20（亚洲上海）。

## 本次修复

修复 NSFW 剧情在 AI 语义分段阶段被压缩成普通亲密概述，导致后续分镜、视频提示词转换和 H3 只能继续生成普通提示词的问题。

- **语义分段源头**：完整原文明确包含 NSFW 内容时，分段请求保留原剧情已有的动作阶段、人物与部位对应、姿势与支撑、衣物或裸露状态、接触变化、人物反应、声音依据及本段结束状态。跨段连续事件按实际进度分配，不在每段重新开始或提前后续阶段。
- **当前段分镜规划**：除当前段正文外，同时读取该段 `semanticSource` 原始证据。即使正文曾被概括，只要当前段真实证据明确，分镜规划仍获得详细动作规则；只读取当前段证据，不把其他段的 NSFW 内容串入本段。
- **视频提示词与 H3**：首次生成或重新创作新稿时使用动作细化规则；参考更新、连续性修复、格式修复和结构修复使用保真规则，保留已有细节但不擅自增加原文没有的新阶段。
- **AI 画面描述转化**：确认“理解剧情”和“生成画面正文”两个阶段仍会根据实际 NSFW 原文各注入一次完整规则，普通剧情不注入。该链路没有被本次调整移除或覆盖。

本次不增加年龄门禁、运行时内容审核、生成拦截、自动重试或额外模型请求，也不增加本地 NSFW 文案合格性校验。

## 已有项目如何使用

保存项目并退出旧版后启动 2.8.3，保留 EXE 旁完整的“莲华视频导演台数据”文件夹。

已有分段和提示词不会被自动改写。需要应用新规则的长剧情可重新执行 AI 语义分段，再生成对应段的分镜和视频提示词；仅需更新当前提示词时，也可直接重新生成当前段。AI 画面描述转化继续使用原入口。

## 验证与交付

语义分段定向检查 24/24 通过，覆盖 NSFW 与普通剧情的条件注入、单次请求、固定时长与 AI 适配模式、取消和错误处理。NSFW 视频动作定向检查通过，覆盖新稿转换、参考更新、当前段语义证据、H3、翻译和 Seedance。AI 画面描述转化 16 项两阶段检查通过，并确认 NSFW 原文在理解与正文两个实际请求中各注入一次完整规则。全部使用本地合成响应，无付费 API 请求或用户项目写入。

Windows 打包通过：`npm run pack:win -- --config.directories.output=.pack-release-2.8.3` 完成 TypeScript 检查、Vite 生产构建和 Windows 64 位便携版生成。构建仅提示已有循环分块及大分块警告，无构建错误。

本版便携包命名为 `莲华视频导演台-2.8.3-便携版.exe`。交付步骤使用 `npm run deliver:2.8.3` 生成版本启动器 `启动莲华视频导演台-2.8.3-便携版.bat`、恢复源码 ZIP、更新说明及 SHA-256 清单。
