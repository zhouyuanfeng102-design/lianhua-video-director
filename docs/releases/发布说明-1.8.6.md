# 莲华视频导演台 1.8.6 发布说明

2026-10-11

本版按用户要求取消“AI画面描述转化”的本地校验与自动重试，将剧情理解、动作细化和交付要求集中到 AI 源头规则。

## 转化规则与处理方式

取消本功能的动作事实、逐字原文引用、事件与段落元数据格式等本地门禁，以及本地生成的剧情核对提示。引用中的标点、空格或版本字段形式差异，不再成为拒收整批转化结果的条件。

AI 仍先理解剧情与动作因果，再展开复杂动作的过程。源头规则要求 AI 保留实际行动者、目标、命中或落空、结果、原对白与尚未确定的信息；原文未明示的具体动作编排单独说明。格式、段落关联与上下文承接也在原有生成请求中完成，不追加独立审核或返修请求。

取消本功能的自动返修和接口参数兼容重试；画面转化与 AI 扩写均取消服务拒绝输出额度后自动降低额度再请求的行为。服务或传输失败直接显示错误，不自动发送第二遍；正常画面转化保留理解与细化两个阶段，长原文仍按必要批次处理。用户主动点击“重新转化”全文或“只重做这一段”仍是一次新的操作。

原文对照、动作依据、编排补充与采用后的转化来源继续保存，供后续解析和提示词制作使用。原文在采用前保持不变，项目或草稿变化后的迟到响应继续受原有覆盖保护。沿用 1.8.5 恢复的剧情输入布局，历史项目、原文与转化结果保留。

## 验证与交付

引擎针对性检查 16 组、结果展示检查 19 项及转化来源持久化检查通过。`npm run pack:win` 完成 TypeScript 检查、Vite 生产构建和 Electron 便携包构建；保留原有分块体积与循环分块提示。

使用实际 1.8.6 便携 EXE 运行专用 `scripts/storyVisualRulesOnlyUiQa.mjs`，通过本机模拟接口和隔离数据验证：版本字符串、重复事件 ID、非逐字引用及未知段落关联不再阻止结果展示、采用或保存读取，本地核对页与核对计数已移除。采用后的正文、AI 动作元数据及处理前原文经过桌面保存重载后仍可读取，“查看转化来源”正常。

随后主动发起一次新的转化，模拟接口返回 `max_tokens` 输出额度 HTTP 400 错误。该操作只请求一次并直接报告服务错误，没有降低额度或兼容重试，现有草稿和转化来源保留。整个检查共 3 次模拟模型请求，阶段依次为 `understanding`、`visualizing`、`understanding`：前两次属于正常理解与细化，第三次属于独立失败操作。另查看 1280×800 返回正文截图，界面布局正常。

本轮未调用真实模型、未读写正式用户数据，也未运行全量回归；真实模型的理解与动作转化效果尚未实测。交付目录附带各文件的 SHA-256 清单。

本版按十进位从 1.8.5 升级至 1.8.6，便携包名为 `莲华视频导演台-1.8.6-便携版.exe`，交付命令为 `npm run deliver:1.8.6`。1.8.5 及更早发布说明、交付文件与交付入口继续保留。
