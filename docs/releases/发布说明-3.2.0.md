## NSFW 连续动作改成连着的来回

已经进入之后的抽送、跨坐起伏、手指进出、口部来回、揉握和研磨，新稿写成髋、腰或手带动的同一个来回。前半送到当前深度，后半退回一小段，人还留在里面，再进入下一个来回。快和深写在连续几个来回上。完全拔出、分开和换姿势各写一次。

这种身体接触的动作句、运镜句和声音继续用送入、贴着、起伏、研磨，以及低而近的皮肤贴合、湿滑黏连和压低喘息。抽送带动的桌面或床铺晃动只留在画面里。手或物件单独打到桌面、撞门、打斗和兵器相撞仍写闷响、拍击和撞击。

纯格式修复、参考更新和衔接修复保持已写动作与音效。只做英文翻译时，旧稿里的一下插入再整个抽出保持原动作。已经生成的旧提示词要重新走中文转换，或获准重写动作与声音的 H3 转写，来回和声音才会换掉。

不新增校验、重试、按钮或额外模型请求。普通剧情不使用这套来回句。
