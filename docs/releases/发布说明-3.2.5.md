# 莲华视频导演台 3.2.5 发布说明

发布日期：2026-10-27（亚洲/上海）。

## 视频提示词写入已选画风

导演台里选好的画面风格和导演调度，以前只留在本地草稿的风格标签里。正式六字段没有画风这一格，转到 H3 时正文从人物身份和场景光写起，提交给模型的提示词里就没有「精细3D电影CG，古风仙侠写实」这类句子。场景里的天光仍是光线，不是画风。

现在这两句用用户原文各写一次。六字段接在首镜光影的场景光后面。H3 的 full-reference 写在 `[Shot 1]` 之前。三字段写在第一镜正文开头。Seedance 写在视频规格里。后面的镜头不再重复。没有选择画风时不另编一套。参考图仍按身份、场景或通用参考使用。

已经提交的旧提示词不会变。要带上画风，需要重新生成视频提示词。

不新增校验、重试或按钮。

## 版本定位

本版便携包为 `莲华视频导演台-3.2.5-便携版.exe`。交付命令为 `npm run deliver:3.2.5`。3.2.4 及更早交付文件继续保留。

## 定向验证

已选风格进入转换资料、空风格不编造、H3 与 Seedance 说明各测一次。打包中的类型检查和生产构建另计。
