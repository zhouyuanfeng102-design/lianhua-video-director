# 莲华视频导演台 3.6.9 发布说明

发布日期：2026-11-01（亚洲/上海）。

## 上传设置收进工具条

图片资产库的上传设置从标题右侧挪到工具条第一行。角色图、绑定实体、职责和「上传参考素材」同一行，高度 26 像素。下面一排仍是搜索和筛选。

## 尾帧已经在选图里时不再挡住界面

视频导演台整理本段选图时，上一段尾帧若已经在本段参考图中，沿用现有选图，不再插入第二张。原先这一步抛出「该尾帧已在本段选图中，不能重复添加。」，整个界面会被错误页挡住。

已有素材、提示词和成片不改。不新增运行时校验、内容拦截、自动重试、按钮或模型请求。

## 版本定位与交付

Windows x64 便携包：`莲华视频导演台-3.6.9-便携版.exe`。构建命令为 `npm run pack:win`，交付命令为 `npm run deliver:3.6.9`；3.6.8 及更早历史版本文件保留。交付目录同时提供恢复源码、更新说明、启动器与 SHA-256 清单。
