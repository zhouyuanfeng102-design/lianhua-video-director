# 莲华视频导演台 0.5.2

## API 设置单屏改造

- 图片 API 功能仍完整保留，并调整为 API 设置页默认打开的首个面板。
- 图片 API、文本 API、视觉 API、视频任务和密码本统一为顶部五个一级标签，进入页面即可看见并切换。
- 每次只显示当前设置面板；视频任务字段改为紧凑四列布局，密码本独立成页，不再把图片 API 挤到首屏下方。
- 1120×720、1280×720、1280×800 窗口下，五个面板均无需页面滚动即可完整查看，且没有内部纵向滚动、横向溢出或遮挡。

## 功能边界

- 图片 API 继续支持 OpenAI 兼容接口和 Stable Diffusion WebUI 真实出图。
- ComfyUI 与 NovelAI 仍保留提示词资产模式，并会明确提示尚未接入真实出图。
- 本次不改变 API 密钥加密、配置档、密码本填充、数据迁移或视频任务协议。

## 数据位置

- 便携版默认将数据放在 EXE 旁边的 `莲华视频导演台数据`。
- 也可通过 `LIANHUA_DATA_DIR` 指向其他健康磁盘。
- 从 0.5.1 升级不会清除现有项目数据；首次使用新包前仍建议创建恢复点。

## 验证范围

已覆盖图片 API 默认显示、五标签切换、各面板边界、页面纵横向溢出、控制台错误、完整自动化测试、生产构建、Web QA、Electron 桌面 QA，以及最终便携 EXE 的隔离数据目录启动和保存恢复测试。
