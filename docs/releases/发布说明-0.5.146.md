# 莲华视频导演台 0.5.146 发布说明

发布日期：2026-09-22

## 版本定位

本版修复Krea-2私密全身图生成第二个全身人物、重复主体或多视图的问题。问题的主要诱因是私密全身任务沿用了3:2横向输出，虽然提示词已经要求单主体，模型仍可能用额外人物填补左右空间。本版将私密全身的画幅、正向构图锚点和负面布局约束统一收紧；不新增、移动或修改未满18岁门禁。

## 本版变更

- 私密全身图固定为2:3竖向画幅，基础画布由1024×1024调整为1024×1536。用户选择更高输出档位时保持相同纵横比。
- 旧私密全身任务若保存为3072×2048等横向尺寸，点击“重新生图”会按同等边长档位调整为2048×3072等竖向尺寸；原任务和原图片不改写。
- 私密全身的转换规则和最终提示词都明确要求恰好一个完整主体沿中央竖轴出现，从头到脚完整入画，头顶与足底留边，主体两侧延续同一片背景。
- 仅私密全身任务追加布局负面词，抑制第二人物、克隆人物、镜像人物、重复全身、多视图、分屏、双联画、三联画、资料板、角色设定板、转面图、拼贴和额外面板。
- 私密四视图和私密四合一不附加上述单图负面词，避免其必要的多视图或多区域结构被误伤；私密局部特写继续使用独立的单部位规则。
- 新建任务与重新生图使用同一套竖图尺寸归一化、最终提示词锚点和布局负面词，历史横图不会继续把旧尺寸带入新版重生请求。
- Krea-2内置规则升级为1.2.0，角色私密资料预设升级为1.5.0，规则目录升级为10。只迁移未编辑的旧内置项，停用状态、用户编辑和自定义规则保持不变。

## 使用与兼容

1. 请先保存并完全退出旧版，再启动`莲华视频导演台-0.5.146-便携版.exe`；不要同时运行多个版本写入同一数据目录。
2. 旧版中生成成双人、重复全身或多视图的私密全身任务，可直接点击“重新生图”。新版会重新转换提示词并使用2:3竖图，不复用旧横向尺寸。
3. 本版不会自动重跑历史任务，也不会删除或改写已有图片。第三方模型仍有随机性，最终结果以任务中保存的最终提示词、请求尺寸和实际图片为准。
4. 本版未修改年龄门禁链路。相关逻辑不属于本次私密全身构图修复范围。
