# 莲华视频导演台 0.5.4

## MiniMax H3 紧凑执行稿

- 新增 MiniMax H3 官方格式适配稿，把 canonical 时间线整理为可直接执行的紧凑执行稿，同时保留原始中文时间线。
- H3 稿按素材类型与引用职责组织信息，减少重复描述，让关键主体、动作、镜头和声音更集中。

## 软预算与尾段保留

- 使用软预算控制 H3 稿篇幅：优先压缩重复或低优先级内容，不以生硬截断破坏镜头语义。
- 压缩时执行尾段保留，确保收束动作、最终画面与结尾信息仍进入执行稿。

## 物种动作引擎

- 动作生成会结合主体物种、身体结构与运动方式，选择更贴合生物特征的动作链。
- 对怪兽、异形与非人主体保持其形态和运动逻辑，避免怪兽人物化以及不合结构的拟人动作。

## H3 稿操作

- UI 可直接复制、导出、保存 H3 稿，便于粘贴到生成平台或留存为项目交付文本。

## 兼容说明

- 现有 canonical 时间线、其他目标模型适配稿与历史项目数据继续保留；H3 稿作为附加输出，不覆盖原始内容。
