# 莲华视频导演台 3.7.0 发布说明

发布日期：2026-11-01（亚洲/上海）。

## 一次导入多个素材

资产库原来的上传按钮改为「批量导入素材」。点一次可以在文件窗口里选择多张图片、多个视频或多个音频，按选择顺序一起写入资产库。

选了人物、场景或物品时，这一批都绑到同一个实体，先选的排在前面。某一张读取失败时，其余文件仍然导入，并提示失败数量。内容和已有文件相同时，仍复用已有文件。

已有素材、提示词和成片不改。不新增运行时校验、内容拦截、自动重试或模型请求。

## 版本定位与交付

Windows x64 便携包：`莲华视频导演台-3.7.0-便携版.exe`。构建命令为 `npm run pack:win`，交付命令为 `npm run deliver:3.7.0`；3.6.9 及更早历史版本文件保留。交付目录同时提供恢复源码、更新说明、启动器与 SHA-256 清单。

## 验证

- Windows x64 便携包：`npm run pack:win`
- 交付文件：`npm run deliver:3.7.0`

已有素材、提示词和成片不作改写。
