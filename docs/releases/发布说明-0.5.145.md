# 莲华视频导演台 0.5.145 发布说明

发布日期：2026-09-22

## 版本定位

本版集中修复私密生图的版式串扰、局部内容串图、单图误拦截和旧任务重生绕过新规则问题。未增加年龄门禁，不修改正式项目、已有图片、私密档案或用户自定义规则。

## 本版变更

- 修复“未分格单画面”被本地校验中的“分格”子串命中，导致私密全身提示词自动返修后仍失败、图像模型未调用的问题。
- 私密提示词公共协议不再同时列出私密全身、四视图、四合一和局部特写；每次请求只注入当前所选版式的构图合同。
- 私密全身使用一幅连续单画面、一个完整主体和从头到脚构图的正向描述，减少被模型解释为资料板、多视图或附加面板。
- 私密局部特写只保留当前部位、紧邻解剖环境、肤色、肤质、体表纹理和比例锚点；脸型、眼睛、发型、身高、普通服装与道具不再进入局部生图转换源。
- 自动返修只重申当前唯一目标，不复述检测到的多视图、资料板、辅助窗或其它部位等错误词，降低错误概念在第二次转换中被强化的概率。
- 新建私密任务和“重新生图”使用同一套全身、局部与四合一检查；重生时强制按当前私密规则重新转换，旧最终提示词与旧转换器快照不再直接复用。
- 内置私密预设升级为1.4.0；0.5.144的1.3.0内置预设自动迁移并保留启用状态，编辑过的用户自定义预设不被覆盖。

## 使用与兼容

1. 请先保存并完全退出旧版，再启动`莲华视频导演台-0.5.145-便携版.exe`；不要同时运行多个版本写入同一数据目录。
2. 0.5.144中失败的私密全身任务可以直接点击“重新生图”；新版会使用原任务可核验的私密资料与当前规则重新转换，不复用导致失败的旧提示词。
3. 已成功但版式错误的旧私密图点击“重新生图”时也会重新转换。原图片与原任务保留，新结果作为新的任务和资产写入。
4. 本版不会自动重跑历史任务，也不会删除或改写已有图片。实际第三方模型仍可能存在随机构图偏差，最终生成结果应以任务中保存的最终提示词和图片为准。
