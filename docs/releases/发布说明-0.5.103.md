# 莲华视频导演台 0.5.103 发布说明

## 版本定位

本版修复私密资料图任务在生图提示词转换阶段返回拒绝说明后，自动返修仍不合格的问题。目标便携包为 `莲华视频导演台-0.5.103-便携版.exe`。

## 私密生图转换

- 私密资料图生图提示词转换器新增专用正向工作协议，首轮和自动返修都会按墨色江湖私密资料图规则输出可执行提示词。
- 返修请求会清洗本地失败原因和上一次拒绝文本，避免把“不能作为可执行提示词”等本地错误原文再次喂给模型。
- 私密模型请求继续剥离年龄门禁和 negative 控制词；年龄门禁仍由软件其它位置负责，不在私密提示词转换器里重复。
- 私密四合一规则升级为私密全身最大主画面、三个私密局部较小辅助窗；内置生图规则目录升至 4，旧内置私密预设自动迁移，用户自定义预设保留。

## 验证

本轮针对性验证：

```powershell
npm run test:llm
npm run test:image-rules
npm run test:image-rule-app
npm run test:typecheck
npm run test:styles
npm run test:workflow
npm run test:release-review
```

交付时使用：

```powershell
npm run pack:win
npm run deliver:0.5.103
```

交付应生成 0.5.103 便携版、恢复源码、更新说明、版本专属启动脚本和 `SHA-256` 清单；现有 0.5.102 及更早版本化产物继续保留。最终校验值以 `交付\莲华视频导演台-0.5.103-SHA256.txt` 为准。
