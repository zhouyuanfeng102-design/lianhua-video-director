# 莲华视频导演台 1.3.2 发布说明

版本日期：2026-10-05（亚洲上海）。

本版在生成任务的图片卡片显示本次实际使用的生图规则与分类预设，方便核对图片的生成配置。名称和版本以任务保存的记录为准。

## 本版变化

- 图片任务卡片新增“生图规则”和“分类预设”，显示名称与版本；排队、运行、成功和失败状态均可查看。
- 使用规则转换提示词的新任务保存本次实际选定的规则与预设名称、版本快照，生成资产同时保留这些记录。后续更改工作台设置、重命名或删除规则，不会替换已保存的任务名称。
- 旧任务未保存名称时，只按已记录的 ID 和版本匹配规则库；匹配到名称时明确显示“名称按记录匹配”，不把匹配结果冒充原任务的名称快照。
- 无法匹配的旧记录显示已保存的 ID 和版本；完全没有相关记录时显示“未记录”，不从当前工作台设置猜测历史配置。
- 重新生图沿用已有规则快照；需要重新转换提示词并选择规则时，新任务保存本次实际选择。现有历史任务和图片保留，查看配置不会改写历史记录。

## 使用与升级

保存项目并正常退出旧版，在原交付目录打开 `莲华视频导演台-1.3.2-便携版.exe`，或使用 `启动莲华视频导演台-1.3.2-便携版.bat`。

进入“生成任务”，查看图片卡片中的“生图规则”和“分类预设”。旧任务的匹配注记或“未记录”表示历史保存信息的完整程度；调整当前图像工作台设置不会补写旧任务。

便携版默认读取 EXE 同目录下的 `莲华视频导演台数据` 文件夹。本项目交付目录内的正式数据位置为 `交付\莲华视频导演台数据`。升级保留该文件夹，不把它放进恢复源码包；设置了 `LIANHUA_DATA_DIR` 的环境继续使用该指定目录。

## 版本与交付

本轮验证已通过：图片任务四种状态下的规则与预设展示、长名称换行、历史快照及缺失记录兼容、名称保存与重新生图继承、任务提示词复制。类型检查和 Windows 便携版构建通过；实际 EXE 的启动、保存、重新载入、恢复点与内置视频工具检查通过。验证使用隔离的合成数据，没有读取正式项目或调用付费生成接口。

从 `1.3.1` 按用户要求的十进位规则升级到 `1.3.2`，下一版本为 `1.3.3`。小版本位和补丁位限定为 `0–9`，例如 `1.3.9 → 1.4.0`。已交付的 `0.5.160` 及更早历史版本保留原版本号和文件；其他历史交付文件也不覆盖或删除。

构建命令：`npm run pack:win`。

交付命令：`npm run deliver:1.3.2`。交付脚本读取本发布说明，输出便携 EXE、恢复源码 ZIP、更新说明、版本启动器及 SHA-256 校验清单。
