# 莲华视频导演台 3.4.2 发布说明

发布日期：2026-10-28（亚洲/上海）。

## 修复 RunningHub H3 图片编号

- RunningHub 导入完整 API 工作流时，继续按 H3 实际消费顺序编号。
- AI 应用没有完整 graph 时，按已配置图片槽顺序编号；所有具有明确图片槽映射的 RunningHub 工作流通用生效，不再依赖单个云端 ID。
- 图片上传仍写入各自配置的物理槽，未选图片沿用现有空槽处理。

## 版本定位

本版 Windows 便携包为 `莲华视频导演台-3.4.2-便携版.exe`。构建命令为 `npm run pack:win`；已有版本文件保留。
