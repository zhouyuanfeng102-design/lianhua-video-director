# 莲华视频导演台 0.9.7 发布说明

版本日期：2026-09-30

## 版本定位

针对V0.9.6新AI分段出现“响应没有完整可解析的JSON对象”的错误，修复JSON接收和请求控制。截图本身未包含完整AI响应，不能据此断言该次是实际截断；本轮已用合成响应复现软件的解析误拒路径，并修复相关自动恢复缺口。

## 本版修复

- 完整JSON前后的非JSON说明花括号不再让已有计划失效；尾部说明对象不再替换真正的计划。支持最多两层JSON字符串解码及明确的`data/result`透明包装，保持AI正文、台词和证据原字。
- 按协议字段识别完整计划，不从后面的坏计划回退到前面的示例。真正未闭合JSON仍交由AI返回完整结果，软件不补引号、括号或剧情；无明确边界的未闭合JSON示例前言仍按未完成响应处理。
- 语义分段请求选择JSON对象输出，DeepSeek使用既有关闭额外思考选项；源提示词改为合法JSON示例并明确字符串转义、完整数组和根对象要求。普通H3、其他文本任务及Claude协议继续其原请求合同。
- 截断、未闭合JSON、仅返回思考或空正文自动恢复；按原因调整本次请求的输出额度，不改用户保存的配置。预算逐次增长至本流程65,536 tokens的增长边界；用户原额度更高时保留原额度，不再翻倍。只接受接口明确的输出token上限，不把输入或上下文窗口错误当作输出上限。
- 接口明确不支持JSON输出参数时撤除该参数，按同一提示词协议重试。接口适配、输出恢复、JSON格式修复及AI明确不足自修复共享最多三次重试，总计最多四次请求；成功即停止，取消和迟到结果不继续请求或提交。
- 最终错误区分无JSON、JSON语法无效、对象未闭合、输出截断和接口原因，显示已自动重试次数；诊断只含响应长度、JSON位置等数值，不保存AI正文或思考。该分段失败分支接入报错日志并显示中文阶段名称。
- 固定每段时长、AI决定段数及原文语义分段流程继续使用；失败保留旧结果。H3、普通/私密生图及NSFW规则未改，不新增独立AI审核或本地剧情门禁。

## 使用

保存并关闭旧版后运行V0.9.7，在原剧情和每段时长设置下点击“AI 理解剧情并分段”即可。失败会显示实际原因与尝试次数，并可从报错日志查看。
