# 莲华视频导演台 0.5.128 发布说明

发布日期：2026-09-15

## 版本定位

在 API 设置的视频生成中增加独立“RunningHub 云端”入口，用于保存和复用 RunningHub 云端 ComfyUI 视频工作流。原来的“视频 API”和“ComfyUI 视频”继续保留，不互相覆盖连接、密钥或工作流库。

## 云端连接与多工作流

- 独立设置服务地区、API 根地址、API Key 和启用开关。密钥只保存在连接设置，输入框隐藏显示，不从教程命令中自动导入。
- 同时支持 RunningHub v2 AI 应用 `run/ai-app/{ID}` 与云端 ComfyUI 工作流 `run/workflow/{ID}`。云端 ID 按文本保存，避免 19 位 ID 转成浮点数后失真。
- 工作流库支持新建、复制、重命名、删除确认、保存与显式“设为当前”。选择一项编辑不等于启用该工作流；删除只影响本地配置，不删除云端工作流、生成结果或历史任务。
- 支持粘贴 cURL、导入请求 JSON 与导入/导出本软件的无密钥工作流配置。cURL 作为文本读取，绝不执行 shell 命令；导入只新增条目，不覆盖已有工作流或自动提交任务。
- 教程结构样板只保留技术节点和参数，提示词与图片使用占位符，不带入原教程剧情或参考图片，也不自动调用该应用。

## 明确输入映射与运行选项

- 提示词映射明确选择 `nodeInfoList` 内的 `nodeId + fieldName`；参考图按配置槽位顺序上传并注入，可分别标记普通参考、人物、场景、首帧、尾帧等用途。
- 不按节点名称猜测用户意图，不将普通 ComfyUI API 图或画布擅自转换成 RunningHub 请求。真正的首帧约束还取决于云端工作流节点自身支持，普通参考图不保证严格首帧起画。
- 未绑定的常量、音频、LoRA 等字段保留原值。编辑单个节点值或运行选项，只替换目标字段；保存 JSON 与自定义映射相互独立，不重新推断已有映射。
- 可配置实例规格 `default / plus / ultra`、个人队列和可选 Webhook。实例保留 `retainSeconds` 默认不启用；填写 10–180 秒时明确提示额外保留费用。相关会员/企业 API Key 资格、资源可用性和最终费用以 RunningHub 账号为准。
- 可指定最终视频输出节点；查询结果时按视频类型及节点筛选，不误将图片预览识别为生成视频。

## 生成链路与保护

- 视频导演台可选择 RunningHub 云端来源与保存的工作流；批量任务继续使用已选提示词、参考图及原有确认流程。
- 云端链路包含参考图上传、提交、任务查询和视频下载。配置保存或导入本身不产生生成请求；不自动重跑历史任务或猜测失败后重新提交。
- 任务在提交时冻结工作流、输入和运行参数。之后修改当前设置或切换工作流，不改变已经提交的任务快照。
- 未保存编辑离开前提示确认；异步导入与保存读取权威最新配置，防止旧界面覆盖新密钥或并行新增的工作流。损坏草稿可留在编辑区修复，不伪装成可用工作流。
- RunningHub 教程未确认服务端取消接口，本版不伪造取消成功。停止已提交任务只停止本地追踪，云端可能继续运行和计费；请在 RunningHub 控制台确认服务端状态。
