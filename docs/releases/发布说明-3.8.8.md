# 莲华视频导演台 3.8.8 发布说明

发布日期：2026-11-06（亚洲/上海）。

## RH 网页等结果出来再下载

网页任务提交后，软件打开「我的生成」，等到这一条的任务号出现在结果里，再点「下载」并收回成片。任务号还没画出来时，不再立刻当成「还没出现」。

已经在网页里生成完成、软件仍显示生成中的任务，退出旧版后用本版继续查看，会按原任务号下载，不会再点一次运行。

## 版本定位与交付

Windows x64 便携包：`莲华视频导演台-3.8.8-便携版.exe`。构建命令为 `npm run pack:win`，交付命令为 `npm run deliver:3.8.8`；3.8.7 及更早历史版本文件保留。

## 验证

- Windows x64 便携包：`npm run pack:win`
- 交付文件：`npm run deliver:3.8.8`

已有项目、提示词和成片不作改写。
