# 莲华视频导演台 4.1.1 发布说明

发布日期：2026-11-08（亚洲/上海）。

## 换人说话时嘴跟着换

同一镜里换成另一个人说话时，上一句的人嘴先闭上。新的一句开始时，镜头以小幅度、慢速度转到这张嘴，再由这张嘴张开。人在半空或高处时，镜头向上转。听的人和刚才说完的人都不接这句。

嘴还在画面外时，仍按 4.1.0 留在画面外，画面里已有的嘴保持闭合。人本来就在当前这张能看清的嘴里说话时，写法不变。

已保存的提示词和成片保持原样。重新生成该段后，换人的那一句才会改到新的嘴上。

## 交付

- Windows：`莲华视频导演台-4.1.1-便携版.exe`。
- Android：`莲华视频导演台-4.1.1-安卓版.apk`，最低 Android 8.0 / API 26。
- 4.1.0 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.1.1`。本版是共享提示词写法，EXE 与 APK 一起交付。
