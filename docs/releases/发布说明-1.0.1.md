# 莲华视频导演台 1.0.1 发布说明

版本日期：2026-09-30

## 版本定位

V1.0.1集中修复多人物视频的说话人绑定和对白排时同步，并为已有段落提供可恢复的AI修复入口。

## 本版修复

- AI从源头理解完整对白、停顿、换人交接与口部动作，再决定镜头和发话区间。新稿与明确的对白修复同时交付分镜排程及H3正文，避免正文、分镜和后续英文使用不同时间。
- 逐句保留原话和人物原名，使用稳定声源编号；H3正文统一使用本段视频从0秒起的时间。翻译、选图、衔接和格式修复保持已确认排程。
- 参考图按明确的人物或形态归属、实际图片槽位绑定。预览、复制、提交与排队任务使用同一稿，换图不调用文本AI重写剧情；缺失或损坏的可选绑定仅提示。
- 提示词结果新增“修复对白与排时”。由现有AI流程完成当前段修复，保存修复前后版本；恢复时同步恢复中英文稿、镜头、身份绑定、镜数设置及对应生成记录。
- 固定段长和用户指定镜数保持；自动镜数由AI按剧情调整。合镜、拆镜的来源、连续性和资料可见范围由AI明确选择，不在本地取并集或机械复制到新镜头。
- 输出截断、结构修复等技术恢复共用各交付阶段最多三次重试，临时调整本次输出额度，不修改保存的API配置。
- 保留H3三字段/六字段结构、现有NSFW规则和默认不加BGM。不新增独立AI审核或本地剧情门禁；已有视频不会因升级自动重生成。

## 使用方式

新生成的提示词自动使用本版规则。已有段落可在提示词结果中点击“修复对白与排时”，由AI完成修复，无需手动改正文。修复提示词后，如需新的成片，仍需主动提交视频生成。

## 版本与数据

版本按十进位从1.0.0更新为1.0.1。保留原版本号及历史交付文件，保持现有项目、图片、视频和API配置；不自动删除旧包。先保存并关闭旧版，再启动新版。
