# 莲华视频导演台 5.0.4 发布说明

2026 年 11 月 22 日 · Windows x64 便携版与 Android 正式签名版

## 版本定位

本版修复两人同镜时，一个人的发型和发饰被安到另一个人身上的问题。Windows 与 Android 共用这套提示词成稿。

## 每个人留着自己的头

参考图和身份句已经把两个人分开。贴在一起的镜头如果改成另一套英文名，或收成「两张侧脸」，海螺会把最显眼的辫子和发饰画到两个人头上。

现在同一镜有两个以上的人时，分别写出每个人的姓名。身份句里已经写明的发型和发饰留在这个人自己的参考图和身份句里。英译沿用源稿汉字姓名，动作和运镜按人分开写。

已保存的成片和提示词不因升级改写。要换成新画面，先重新生成这一段的提示词，再生成视频。

本版未新增运行时校验、重试、按钮或模型请求。

Windows x64 使用 `莲华视频导演台-5.0.4-便携版.exe`。Android 使用 `莲华视频导演台-5.0.4-安卓版.apk`。维护者使用 `npm run deliver:5.0.4` 整理两端安装包、恢复源码与 SHA-256 交付清单。
