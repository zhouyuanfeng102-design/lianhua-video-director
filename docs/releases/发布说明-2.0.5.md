# 莲华视频导演台 2.0.5 发布说明

发布日期：2026-10-13

## RunningHub 云端图片生成

在“API 设置 → 图片 API → 后端”选择“RunningHub 云端”，填写 API 根地址和密钥。图片连接独立于视频连接，可保存多个图片应用及节点映射。

可导入 RunningHub 的 cURL、包含 nodeInfoList 的请求 JSON，或包含提交示例的完整 Markdown / TXT API 说明。导入仅保存配置。普通 ComfyUI 的 API 节点图仍在 ComfyUI 后端导入，不会被当作 RunningHub 云端调用请求。

用户提供的 Krea2 应用 `2070152175753453569` 自动识别业务提示词 `115.prompt`、宽度 `95.value`、高度 `96.value`。生成时按实际映射替换提示词；尺寸默认沿用云端示例，明确选择尺寸覆盖后才替换宽高。模型、采样与系统指令保留工作流配置。

交付附带 `莲华视频导演台-2.0.5-Krea2云端图片示例.json`，在“导入 API 请求文件”选择即可。示例不含密钥，不会改变云端完整工作流；密钥须在连接设置中填写。

支持已绑定图片输入槽的参考图上传，使用 RunningHub 上传结果的 fileName 填入对应槽。参考图片数量超过真实槽位时明确阻止提交。云端生成按提交、查询、下载顺序接入现有图片任务；只提交一次生成请求，成功结果保存到资产库。

已完成的图片若下载暂时失败，保留原任务和图片地址，交给现有保存流程重试；不会因为下载失败自动再提交收费生成任务。

工作流被删除或原任务连接、参数已变化时，重新生成明确提示需要重新选择，不会自动换用另一应用。图片连接的工作流与选择、任务后端及资产来源随项目保存恢复，视频连接分别保留。

## ComfyUI 提示词入口兼容

识别经预览节点、Llama 文本转换节点进入文本编码器的上游提示词，修复该 Krea2 图的 `115.prompt` 被遗漏的问题。保留 `109.prompt` 系统指令和细化分支的固定提示词，不沿图像或潜变量连线误判正负面文本。

## 使用与交付

本版沿用 2.0.4 的资产编辑归属、音频冲突导入与同源分段计划恢复修复。更新前保存项目并退出旧版，将新 EXE 放在原目录，保留完整的“莲华视频导演台数据”文件夹。

RunningHub 图片接口专项 14 组、尺寸专项 5 组、分镜提交前校验 4 组、下载中断保存恢复及旧四种图片后端任务快照兼容检查通过。ComfyUI 上游提示词专项 7 组及相关现有导入、尺寸和分镜检查通过。实际界面确认文件导入、配置保存恢复、节点映射和参考图校验；便携包确认图片与视频连接分别保存。类型检查与生产构建通过。验证使用隔离数据与模拟 RunningHub 接口，不调用收费生成任务。

便携包：`莲华视频导演台-2.0.5-便携版.exe`。

打包命令：`npm run pack:win`；交付命令：`npm run deliver:2.0.5`。历史版本和交付文件保留。
