# 莲华视频导演台 1.4.7 发布说明

分镜时间线每组长剧情方案右侧新增“删除方案”按钮。标题旁显示段数、总时长和创建时间，便于区分同一章节的多个方案；按钮与分段标签分行排列，避免被标签挤出或遮挡。

点击后显示确认，说明将删除的分段及分镜提示词数量。确认后只删除该方案及其独占分镜提示词；图片、视频、已提交任务、原文和其他方案保持。共享或异常交叉关联的分镜不会被连带删除。需要恢复时可使用顶部“撤销”。

删除当前方案后自动切换到剩余方案，全部删除时显示空状态或剩余独立分镜。相应章节选择和批量草稿同步清理，已有单段视频草稿及其来源证据保留。提示词正在生成或更新时须先完成或停止，以免正在返回的结果与删除冲突；图片、视频任务不因方案删除被取消。

保留 1.4.6 的删图保护：资产库删除自动生成图只解除绑定，不会重写视频提示词或清空英文。

保存退出旧版后运行 1.4.7 便携 EXE，保留旁边的“莲华视频导演台数据”文件夹。此次改造不自动删除真实项目中的任何方案，由用户点击按钮选择。
