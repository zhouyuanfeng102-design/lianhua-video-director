# 莲华视频导演台 2.2.6

发布日期：2026-10-15。

## Seedance 生成失败原因

提示词导演台刷新 Seedance 中文或重试英文时，原先部分失败只显示在生成状态，未进入左侧报错日志，重新打开项目后也无法从日志了解具体原因。本版将这些失败接入现有持久报错日志。

日志包含失败原因、生成阶段、模型、服务地址及可用的 HTTP 请求诊断，方便定位服务返回错误和内容生成失败。已有公共分镜和中文稿继续保留，英文失败可以单独重试英文；主动取消和剧情、参数变化后已过期的请求不会误记为生成错误。

重试当前段时清除上次失败标记，避免接口仍在处理中却继续显示旧的“失败”。本次请求确实失败后，会重新显示本次原因；可从左侧“报错日志”展开查看和复制脱敏后的错误详情。

## 兼容与交付

没有批量数据迁移，不自动重跑旧任务；保留已有项目、提示词和历史交付文件。版本按十进位规则从 2.2.5 递增至 2.2.6。

## 验证结果

针对本次修复的隔离界面检查通过，使用生产构建和本地模拟文本接口，覆盖中文 HTTP 502、英文 HTTP 503 的原始原因、状态码、阶段、模型、地址及日志详情，日志计数和重启恢复均正确。

英文失败后保留中文，续跑仅补英文；中文失败停止英文和后续段，保留公共分镜和已有 H3 稿。重试时旧失败原因消失；主动取消后返回的迟到错误不新增日志、不回写失败原因、不覆盖旧稿，也不启动后段。页面错误和意外外部请求均为零。报告：`output/playwright/seedance-failure-log-2.2.6-verified/report.json`。

打包流程中的 TypeScript 类型检查通过，最终 Vite 生产构建通过；既有分块循环和体积提示仍存在。Windows x64 便携包已生成，包内版本为 2.2.6，65 项 dist/electron 文件与本次构建逐字节一致。

没有执行全量回归，没有调用真实生成 API或改动正式项目数据。交付包含便携 EXE、恢复源码、更新说明、启动器和 SHA-256 清单；最终校验以本版清单为准。旧版未记录的实际失败原因无法追溯，需要在新版主动重试后才能捕获。
