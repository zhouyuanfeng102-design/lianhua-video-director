# 莲华视频导演台 1.1.9 发布说明

日期：2026-10-03。

## 版本定位

修复有效参考图因格式标记错误而报“参考图片格式或文件签名无效”的问题。本次问题图片的文件名后缀是 `.jpg`，实际内容为 PNG。旧版上传时保留了 `image/jpeg` 声明，发送前校验发现声明与文件头不一致，于是在本地中止请求。

新上传的 PNG、JPEG、WebP 按真实文件内容规范格式标记，工作台及资产库保存正确的图片 MIME。项目中已保存的旧参考图无需删除或重新上传：发送时在请求副本中校正格式和上传文件名，原图、原资产及原任务记录保持。浏览器和桌面版传输均使用正确格式，保留参考图顺序、原请求尺寸和参数。

格式校正不重新编码或修改图片字节。原有上传大图缩小策略保持；无法解码的上传图片会提示损坏，不再当作正常参考图保存。桌面传输继续检查 Base64、真实格式、容器完整性、单图与请求大小、托管路径与校验值，不以取消校验的方式兼容错误标记。

## 使用方法

保存并关闭旧版后，启动 `莲华视频导演台-1.1.9-便携版.exe`。之前上传的错标格式参考图可以继续选择使用，不必手动改扩展名或重新上传。

本版仅修复参考图片格式读取和传输，不改变提示词内容、模型返回结果或其他任务规则。

## 版本与验收

从 1.1.8 按十进位更新为 1.1.9，下一版为 1.2.0。历史交付文件保留。

构建 `npm run pack:win` 后运行 `npm run deliver:1.1.9`，生成便携 EXE、恢复源码 ZIP、更新说明、启动器和 SHA-256 校验清单。

验证范围包括图片错标格式、真实图片字节不变、旧参考图兼容、损坏图片拦截、工作台上传及保存重载、桌面与浏览器请求，以及最终便携 EXE 启动。模拟生成验证使用隔离合成图片和模拟服务，不提交真实付费生成请求。

已通过的验证：

- 22 项桌面参考传输/WebP 测试；7 类真实图片的 Electron 验证，包含渐进 JPEG、带元数据 PNG、三类 WebP。声明格式交叉错标均按真实格式处理，截断文件拒绝。
- 9 次模拟请求的服务链路测试，覆盖桌面、浏览器、SD WebUI、ComfyUI，检查原始字节、数量、顺序、尺寸及原资产元数据保留。
- 完整 App 上传错后缀参考图、正确预览、错误文件拒绝、保存重载、旧任务重新生图及两种传输验证通过，无页面错误或外网访问。
- 图像生成、图生图、ComfyUI、图像错误、存储、文本请求、26 项视频传输及54 项 Electron 回归通过。
- 严格类型检查、500 KiB 分包预算和生产冷启动、51 项发布检查通过。
- 最终 1.1.9 便携 EXE 的版本、隔离数据目录、启动、保存、重载、恢复点、内置媒体工具及三个窗口尺寸验收通过，控制台错误为 0。ASAR 内53个 dist/electron 文件与本次构建逐字节一致。
