# 莲华视频导演台 2.2.0

发布日期：2026-10-14。

## 视频模型参数读取与选项展示

通用视频 API 的视频时长、分辨率与画面比例原先只有手工输入，用户无法从界面了解所选上游模型的可用档位与限制。

本版从当前连接的模型资料与可用 OpenAPI 说明读取所选模型参数，API 设置中的自动补齐同时缓存能力资料。单段生成与长剧情批量增加“读取模型参数”，按当前连接和所选模型显示对应资料；完整模型列表继续保留，由用户自行选择。

上游返回明确枚举时，下拉框显示真实可选档位；返回数值范围与步长时，快捷选项限于该范围，并支持范围内自定义。参数为自由字符串时支持常用选项与自定义输入。

网站可能只返回模型名称，或只提供部分参数资料。没有返回限制的参数明确提示上游未提供限制，仍提供常用下拉：时长 `5 / 10 / 15 / 20 / 30` 秒，画面比例 `16:9 / 9:16 / 1:1 / 4:3 / 3:4`，分辨率 `480p / 720p / 1080p`；也可自定义填写。这些是便捷输入，不代表上游保证支持。

读取参数只更新当前连接的能力资料，不自动发起生成，也不修改已填写的生成参数或已有任务的执行快照。参数留空仍保留原值，原有自定义请求、其他服务连接与历史任务继续按已保存配置使用。

提示词导演台的“画面与规则”移除画幅与分辨率选择框；实际视频参数在视频导演台按所选接口调整，旧项目资料保留。

## 使用

1. 在“API 设置 → 视频生成 → 视频 API”选择当前连接，自动获取并补齐模型与接口资料，并选择模型。
2. 在视频导演台的单段生成或长剧情批量中选择该视频 API 配置；需要刷新资料时点击“读取模型参数”。
3. 在时长、画面比例和分辨率下拉框中选择参数。已知枚举按上游选项填写，有范围时按范围填写；未知参数可以选择常用项，也可以自定义。
