## 参考特写与实际比例

参考图占满画面时，视频模型有时会把取景误当成实际尺寸。本版调整两端共用的提示词，让参考图提供形状、颜色和纹理，尺寸由人物自身比例决定。

重新生成时使用新版提示词。Windows x64 下载 `lianhua-video-director-5.0.7-windows-x64-portable.exe`，Android 下载 `lianhua-video-director-5.0.7-android.apk`。

同版提供 Windows 与 Android 软件包、源码恢复包、安装说明、能力与验证记录、Windows 启动器及本说明。

签名与验证范围见 [5.0.7 能力与验证记录](能力与验证记录-5.0.7.md)。安卓安装与备份见 [安卓安装说明](../android-install.md)。
