# 莲华视频导演台 0.5.58 发布说明

## 版本定位

0.5.58 打通角色性别资料从剧情和图片分析、资料编辑与补齐，到生图、视频最终提示词转换的完整链路。性别是可编辑的剧情事实，不限制为固定枚举：人类角色可以填写男或女，动物及非人角色可以填写雄或雌，也可以保留世界观中的任意自定义性别。0.5.57 及更早功能与历史交付文件保持不变。

## 性别资料与 AI 写回

- 图像工作台的 NPC 角色资料新增独立“性别”输入框；新增、保存、重新选择和重载项目时都会保留用户填写的完整文字。
- AI 剧情分析根据原文中的姓名、称谓、代词、身份、物种和明确设定整理角色性别，并把结果写入项目人物资料。
- 项目圣经人物补全继续补齐可用于后续生成的性别信息；同名人物已有的非空用户资料优先保留。
- 图像工作台“AI 补齐资料”可以单独补齐空白性别，不覆盖用户已填写的性别，也不把自定义性别强制改成男、女、雄或雌。
- 角色“AI 识图”会从图片中的可见人物或生物特征返回性别资料，并与其他角色外观字段一起回填当前表单。

## 生图与视频提示词链路

- 角色参考图、头像、半身、全身和四视图的本地资料源都会使用明确的“性别设定”字段，不再把性别隐藏在无标签文本中。
- 生图文本转换请求携带完整性别资料，并从转换器源提示词要求模型把它作为主体身份事实准确保留或转译，不依赖本地性别枚举或内容拦截。
- 最终视频提示词转换会按每镜稳定主体匹配项目人物性别，将对应性别事实随逐镜证据交给转换器。
- 视频转换规则要求在主体身份描述中保留已知性别，避免同一人物跨镜、跨段或图片转视频时出现男女、雌雄混淆。

## 测试覆盖

- 角色表单字段、任意自定义性别的新增与更新、实体与表单双向映射、空白字段 AI 合并均有单元回归。
- 文本模型边界覆盖 AI 剧情分析、项目圣经补全、AI 补齐、AI 识图及生图转换中的性别请求与返回。
- 视频转换回归检查逐镜性别证据、转换器硬契约及应用调用处的人物资料接线。
- 图像工作台 UI 回归覆盖独立性别输入框、保存、重新选择、持久化和紧凑视口布局。
