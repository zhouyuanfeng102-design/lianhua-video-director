# 莲华视频导演台 2.9.6 发布说明

发布日期：2026-10-22（亚洲上海）。

## 文字 API 缓存优化

参考本机“墨色江湖”的固定规则与共享资料前置方式，调整本软件文字模型请求的排列。原先当前段号、分段正文和变化参数出现在完整剧情与人物资料之前，会提前截断可复用的前缀；画面转化还重复追加了同一阶段输出指令。

本版在各业务原有请求中优先排列固定规则与已提供的共享资料，将本次变化的数据放后；保留字段值、数组顺序、完整语义数据结构、消息角色、资料来源和人物图片关联。覆盖剧情转换与扩写、解析、估时分段、资料填写、分镜导演、H3、Seedance、翻译、生图提示词转换及相关视觉文字分析。翻译只使用自身任务已有资料，不为提高比例塞入无关剧情。

DeepSeek 使用服务端自动前缀缓存，不增加 cache_control、预热调用、等待调度或模型请求。固定前缀更稳定有利于命中，实际比例仍受首次调用、服务端保留时间、模型与中转接口返回能力影响，不承诺固定百分比。

## 缓存命中分析

左下角“更新日志及项目地址”上方新增“缓存命中分析”，与更新日志入口同高；当前项目框压缩为紧凑布局。打开后可查看最近 1000 次实际文字 API 请求，按项目、模型、阶段筛选。

每次实际请求记录时间、所属项目/章节/分段、任务阶段、接口类型、模型、输入 Token、命中与未命中 Token、命中率、耗时及完成/失败/取消状态。图像任务中的文字转换和视觉文字识别也纳入，图像渲染与视频生成本身不计入文字缓存统计。请求开始时固定归属，后台完成时不跟随当前选中的项目变化。

单次命中率为缓存命中输入 Token 除以总输入 Token。DeepSeek 原生字段与兼容 cached_tokens 字段不重复相加；Claude 总输入包含普通输入、缓存读取和缓存写入。累计比例按可计算请求的输入 Token 加权。接口没返回缓存字段时显示“未返回”，与真实 0% 区分；失败响应若带有用量则保留。

历史仅在本机独立保存，不进入项目存档、撤销历史或项目导出；只保存统计数字和归属，不保存 API 密钥、接口地址、提示词正文、响应正文或图片。重启前仍在进行的记录显示为已中断，不补发请求。

## 验证与边界

离线定向测试已通过：共享资料及字段值保持、相邻请求公共字符前缀延长、资料权限与禁用剧情设置保留、重复指令移除、DeepSeek/兼容/Claude 用量计算、加权汇总、未知与零值、成功/失败/取消单条记录、项目切换归属、隐私字段不落库、1000 条容量及历史恢复。

这些测试使用合成资料与模拟响应，没有调用真实模型；公共字符长度不等于 Token 数或实测命中率。

打包中的 TypeScript 类型检查、Vite 生产构建和 Windows x64 便携包生成通过。生产页面定向检查通过：1440×1000 浅色与 1120×720 深色窗口中的入口同高、项目框收紧、零命中与未知区分、加权汇总、项目/模型/阶段筛选、空记录、Escape 焦点恢复及重载历史。没有浏览器错误或真实模型请求。构建保留现有循环分块与大文件提示，未改变分块配置。

额外检查的旧 `llm.test.ts` 共 221 项，并非全部通过：与 HEAD `93e52f1f` 隔离基线对照，17 项既有失败在修改前同样存在；本次多出的 2 项由旧测试按原请求顺序截取全文造成，已修正测试边界并仅重跑这 2 项，均通过，仍保留完整原文逐字相等与 51/50 对象数量断言。未扩大修复无关历史行为，也未把旧回归报告为全绿。

本次不新增运行时校验、内容审核、生成拦截或自动重试，不增加模型请求。更新程序不修改用户项目存档。保存项目并退出旧版后，使用 2.9.6 便携版，保留 EXE 旁完整的“莲华视频导演台数据”文件夹；历史版本和交付文件保留。
