# 莲华视频导演台 3.3.2 发布说明

发布日期：2026-10-27（亚洲/上海）。

## 继续批次和强制关闭

继续批次以前会等整段视频查询结束，按钮停在「正在检查」。切到别的项目后，这个锁还留着，回来再点也没有反应。现在继续批次只把已提交的任务重新排进原来的查询，按钮马上恢复。查询仍在后台进行。

有未完成任务时，一点关闭就提示还有多少项。可以选择强制关闭或返回软件。强制关闭不再等这次保存。服务器上的任务不取消，本机留下上次已经写完的保存。没有未完成任务时仍先保存；保存过久时，同样可以选择强制关闭。

不新增任务页按钮，不新增校验或重试。

## 版本定位

本版便携包为 `莲华视频导演台-3.3.2-便携版.exe`。交付命令为 `npm run deliver:3.3.2`。3.3.1 及更早交付文件继续保留。

## 定向验证

未完成任务可强制关闭、返回软件会留下窗口、保存等待过久仍可继续等待。打包中的类型检查和生产构建另计。
