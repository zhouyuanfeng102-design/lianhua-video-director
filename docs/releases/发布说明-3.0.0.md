## 修复原文重复段落误报

画面描述转换稿会为同一事件同时保存“动作过程”概括行和“过程细化”展开行。两行共享大量事实文字，但不是用户把原文复制了两遍。旧检测器只按相似字符和编辑距离判断，因此会在转换后的正文上弹出重复段落确认。

本版在重复检测器的两个候选分支中识别相邻的“动作过程/行动过程”与“过程细化”结构，只跳过这一明确的同事件表达；整篇原文复制、真实长段重复和普通近重复仍继续检测。检测本身仍只读，不会自动删除原文。

本修复直接处理误报根因，不新增运行时校验、内容审核、生成拦截、自动重试、按钮或模型请求。
