# 莲华视频导演台 1.1.8 发布说明

日期：2026-10-02。

## 版本定位

修复“场景 → 风景场景”生成图片混入人物和剧情动作的问题。场景分类预设选择正确，但旧链路把地点连续性锚点中的人物动作直接拼进画面资料，又注入完整剧情和人物身份上下文；部分补充规则还误把场景描述为普通角色图。

风景场景现在明确为单幅无人环境资产，只提取建筑或地貌、布局、固定陈设、材质、天气和光线。地点原文作为资料保留，转换器语义提取环境，不按姓名或关键词修改用户档案。该模式不再注入完整剧情、人物身份或普通角色图补充要求；无人环境规格对旧版和自定义预设同样生效。参考图只用于环境信息，不继承人物。

故事快照、分镜首帧、分镜图、角色和道具继续按各自模式处理。工作台新增无人环境说明，便于选择正确规格。

## 旧图处理

保存并关闭旧版后，启动 `莲华视频导演台-1.1.8-便携版.exe`。

在“生成任务”找到之前错误的风景图，点击“重新生图”。旧任务不再直接复用已保存的错误最终提示词，而是优先从原任务冻结的场景资料重新提取无人环境提示词；没有原资料快照时，以旧提示词作为环境提取资料。新图作为新任务保存，原图、原任务和地点档案保留。

已按本版无人环境规格转换的任务可以复用其有效提示词重试。重新生图仍沿用原任务尺寸、后端选择与参考图记录，按照原有 API 配置规则执行。

## 版本与验收

从 1.1.7 按十进位更新为 1.1.8，下一版为 1.1.9。历史交付包保留，不修改正式项目进行测试。

构建 `npm run pack:win` 后运行 `npm run deliver:1.1.8`，生成便携 EXE、恢复源码 ZIP、更新说明、启动器和 SHA-256 校验清单。

已通过的验证：

- 12 项风景模式规则专项、18 项转换与重生图链路测试通过，覆盖三种输出格式、旧规则与自定义规则、已删除原任务的资产恢复、尺寸与自定义负面词保留。
- 既有图像生成与重生图、68 项图像规则、人物身份及 App 规则集成回归通过；严格类型检查、500 KiB 分包预算及生产冷启动、51 项发布检查通过。
- 完整 App 使用合成数据点击“风景 → 故事快照 → 分镜首帧 → 风景”，各模式上下文及请求正确；旧污染任务重新转换，新规格任务复用有效提示词。
- UI 回归共 5 次模拟文本转换、6 次模拟生图，无重复请求、页面错误或外网访问。原任务、图片、地点、人物、剧情和规则保持，重载正常。
- 1280×800、1600×1000 界面检查通过，无人环境说明及主要按钮可见，无横向溢出。
- 最终 1.1.8 便携 EXE 验收通过：版本、隔离数据目录、启动、保存、重载、恢复点、内置媒体工具及三个窗口尺寸，控制台错误为 0。ASAR 内 53 个 dist/electron 文件与本次构建逐字节一致。

测试使用模拟服务与隔离合成数据，未调用真实付费生成接口。图片生成模型的实际输出仍需人工检查；本次修复验证的是资料、规则、转换和提交链路。
