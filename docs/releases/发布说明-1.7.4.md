# 莲华视频导演台 1.7.4 发布说明

2026-10-10

生成任务的图片卡片在名称旁新增“文生图”或“图生图”标识，直接显示本次生图方式。

## 判定方式

标识依据任务保存的实际输入：使用参考图片的任务显示“图生图”，确认没有参考图片的任务显示“文生图”。之后修改选图或删除资产，不会改变旧任务的生图方式。历史任务缺少足够的输入资料时显示“方式未记录”。

此标识反映原始图像输入，不改变已有提示词转换流程。即使旧任务的转换记录为文生图，只要保存了参考图输入，仍显示“图生图”。

## 验证与交付

针对性真实界面检查已通过：10 类图片输入记录和 5 种任务状态，名称右侧显示对应方式；日间与夜间、桌面与窄窗口下标签可见且不横向溢出。直接预览图片的输入方式经规范化、保存和重载保留；删除当前参考资产不改变旧任务标识。

`npm run pack:win` 已通过 TypeScript 检查、生产构建和 Windows 便携版打包。交付包含 V1.7.4 便携版、恢复源码、更新说明、启动脚本和配套 SHA-256 校验文件。

本轮沿用既有任务与项目存储，不执行真实上传或收费生成。1.7.3 及更早发布说明和交付文件保留。
