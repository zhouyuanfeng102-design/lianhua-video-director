# 莲华视频导演台 3.1.0 发布说明

发布日期：2026-10-25（亚洲/上海）。

## 第一批文字链路前置 MAESTRO

在原有 NSFW 文字框架前面，为第一批文字阶段挂上完整 MAESTRO PROTOCOL v7.0（重建稿）：

- `story-preparation`（AI扩写 / AI画面描述转化）
- `story-visual-understanding` / `story-visual-writing` / `story-visual-rewrite`
- `image-custom-convert`（自定义生图 · 规则转换）

原有 NSFW 前缀、stage 备注和任务协议仍保留在后面。MAESTRO 末尾带固定格式覆写：输出形态以后方任务协议与所选生图规则为准。

分镜、H3、Seedance、估时、解析资料等其它文字阶段本版不挂，后续再优化。

## 命中率：固定进前缀，用户要求最后

- 固定规则（MAESTRO、NSFW Role/世界书、写类创作指导、自定义生图图片 NSFW 规则）一律放系统前缀。
- 普通剧情与成人剧情共用同一套系统前缀，不按内容类分叉前缀首字节。
- 用户要求保持在后方可变区；成人细则靠规则内“SFW 则忽略”生效，不再把创作指导拼到用户正文后面。

这样改是为了保住文字 API 前缀缓存命中率，而不是用成人/普通两套 system 把缓存冲掉。

## 版本定位

本版便携包为 `莲华视频导演台-3.1.0-便携版.exe`，恢复源码包、更新说明和 SHA-256 清单由交付脚本按同一版本生成。交付命令为 `npm run deliver:3.1.0`。3.0.9 及更早交付文件继续保留，0.5.160 及更早历史版本不重编号、覆盖或删除。
