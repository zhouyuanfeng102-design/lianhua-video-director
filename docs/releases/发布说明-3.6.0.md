# 莲华视频导演台 3.6.0 发布说明

发布日期：2026-10-31（亚洲/上海）。

## H3 单图绑定与首尾帧模式

ComfyUI MiniMax H3 `ImageToVideo` 只有一个已选图片槽时，该唯一图片作为 `Picture 1`。即使图片经由不透明变换节点传入，只要没有第二个图片槽竞争编号，就不再因无法追踪中间节点而漏绑。存在多个图片槽、多个消费者或来源不明确时，继续沿用现有明确映射和保守处理，不猜图片编号。

H3 新稿按本次实际素材区分官方模式：无参考素材为 T2VA；单首帧为 I2VA；首帧与尾帧同时存在为 FL2VA；单尾帧为 L2VA；其它图片、视频、音频或中间参考素材为 Ref2VA。I2VA 从 `0.00` 秒首帧状态继续发展；FL2VA 描述两端之间连续且可到达的过程并在末端抵达尾帧；L2VA 从合理前置状态发展并收束到尾帧；Ref2VA 按明确素材映射说明参考职责，不猜编号。

不新增运行时校验、内容审核、生成拦截、自动重试、按钮或模型请求。已保存的提示词和成片不作改写。
