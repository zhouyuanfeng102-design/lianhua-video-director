# 莲华视频导演台 0.9.0 发布说明

发布日期：2026-09-29

## 版本定位

V0.9.0 修正 V0.8.9 中分镜参考图操作过于复杂、原自定义图片数量未进入图生图的问题，恢复“参考图栏选图，提示词结果原按钮生图”的操作方式。

## 本版修复

- 简化上一版操作：参考图栏目只显示和选择本段图片，支持搜索、上传、多选、取消和清空。不再需要另外选镜头、应用绑定或使用参考图栏目内的生成按钮。
- 生图沿用“提示词结果”下方原按钮。选中参考图后，“生成分镜图片”默认按原镜头数生成；自定义填写1–100时，恰好生成要求的总张数，每张都带本段当前选中的原图进行图生图。
- “生成首尾帧图片”同样带所选原图，仍然生成首帧、尾帧两张，不受自定义分镜图片数量影响。图像工作台也继续使用原来的选镜头和生成按钮。
- 默认分镜及首尾帧不调用文本 API。自定义数量只复用已有的剧情/H3静帧规划，选择对应数量的不同剧情瞬间；不把参考图转成文字，不再进行额外提示词转换、人物资料补齐或新增AI审核。
- 各段选择独立，所选原图实际上传至图像接口，不自动加入其它段或历史图。未选参考图时保留原文字生图；选图后如原图不可读或接口不支持，会显示具体原因，不静默退回文生图。
- 图像分辨率继续同步图像工作台。排队、重试固定本次原图、API、尺寸、提示词和静帧信息，不随当前选图变化。
- 结果资产保留不含密钥或图片正文的安全重生快照。即使删除原任务或原参考图卡，从结果图片重新生成仍使用原图和原API；快照确实缺失或损坏时显示原因，不伪装成文生图。原图仍随项目包和外部备份保存。
- 已保存H3、视频槽位、视频镜头数和时长、普通/私密生图及NSFW规则保持不变。历史0.8.9及更早交付、项目和媒体不删除、不覆盖、不重编号。

## 使用方法

1. 打开当前段的“参考图”，选择要使用的图片。
2. 回到“提示词结果”，需要指定图片张数就填写原“分镜图片数量”框。
3. 点击原“生成分镜图片”按钮；生成首尾帧则点击原“生成首尾帧图片”。不需要其它绑定步骤。
