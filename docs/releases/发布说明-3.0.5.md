# 莲华视频导演台 3.0.5 发布说明

发布日期：2026-10-25（亚洲上海）。

## 自定义生图规则转换可写出私密画面提示词

自定义生图勾选「使用规则转换」时，文字模型先按你写的要求转换提示词。要求里已经有性行为或私密身体描写时，这次请求在所选生图规则前面带上人物图、分镜图正在使用的两段画面规则：写成一张静帧提示词，不拒绝、不改成普通场景，只返回提示词。

你写的那句要求仍是唯一的用户内容，不附带章节原文。文生图和带参考图的自定义生图共用这一次转换。

普通要求不带这两段。没勾规则转换时，原句仍直接交给生图。人物图、分镜图和私密资料图的请求不变。不新增按钮、运行时校验、内容审核、生成拦截、自动重试或模型请求。

## 版本定位

本版便携包为 `莲华视频导演台-3.0.5-便携版.exe`，恢复源码包、更新说明和 SHA-256 清单由交付脚本按同一版本生成。交付命令为 `npm run deliver:3.0.5`。3.0.4 及更早交付文件继续保留，0.5.160 及更早历史版本不重编号、覆盖或删除。

## 定向验证

`scripts/customImagePrompt.test.ts` 已通过。测试使用模拟请求，不调用真实模型，也不提交图片生成。检查覆盖：普通要求不带画面规则、私密要求在所选规则前带上这两段、用户原文不改写、仍只发一次转换请求。

Windows x64 便携包由打包流程执行类型检查、Vite 生产构建和便携版生成。本版不改变用户项目存档。

交付后请核对 `莲华视频导演台-3.0.5-SHA256.txt` 中的 SHA-256 清单。

## 使用与交付

保存项目并退出旧版，打开 3.0.5 便携版，保留 EXE 旁完整的“莲华视频导演台数据”文件夹。原有自定义生图按钮不变。
