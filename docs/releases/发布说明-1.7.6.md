# 莲华视频导演台 1.7.6 发布说明

2026-10-10

资产库图片与视频卡片改为按窗口可用空间自适应布局，预览框随窗口缩放，超出当前页容量时通过分页浏览。

## 资产库布局

卡片按资产库剩余可用宽高调整列数、行数和每页容量，预览框使用剩余空间，页面无需上下滚动；素材较多时点击上一页、下一页浏览。图片完整展示，不裁切、不拉伸变形。

详细信息继续默认折叠，展开后在卡片内浮层查看，长内容在浮层内滚动，不撑高页面。选图、预览、绑定、定位、编辑、删除等原有操作入口保留，跨页选择也会保留。本次布局调整覆盖资产库图片和视频区域，音频及其他页面沿用原布局。

## 验证与交付

本轮资产库专项界面检查通过：1480×900、1280×720、1024×768、900×650 窗口下，41/7/1/0 张图片均无页面或网格溢出，全部卡片操作完整可见；窗口高度改变、分页、跨页选图、搜索和章节筛选正常。另检查详情展开、125% 字体的夜间模式和合成视频卡片。测试使用隔离的合成项目，无真实 API 调用或用户数据修改；修复了一处测试夹具本地开发连接问题，仅补查受影响的运行检查。

Windows 便携版打包通过，流程已包含 TypeScript 检查和生产构建，未重复执行全量回归。

交付包含 V1.7.6 便携版、恢复源码、更新说明、启动脚本和配套 SHA-256 校验文件。1.7.5 及更早发布说明和交付文件保留。
