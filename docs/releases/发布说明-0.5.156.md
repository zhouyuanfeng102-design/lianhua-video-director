# 莲华视频导演台 0.5.156 发布说明

发布日期：2026-09-24

## 版本定位

首帧可自由选图，素材分类不再限制本次首帧用途；选中图片直接显示实际占用的首帧、人物1、人物2等槽位。

## 本版变更

- RunningHub和ComfyUI明确映射的首帧、尾帧槽可放任意已选可用图片。分镜图、构图参考或人物图不用先修改素材分类，图片ID、内容、数量与顺序保持原样。
- 单段和长剧情的选图卡片及顺序与用途页显示“首帧（槽1）”“人物1（槽2）”“人物2（槽3）”等标签。取消、重选、排序、换工作流后即时更新；超出映射容量显示未分配，不静默丢图或填图。
- AI尾帧＋参考图模式明确槽1已由AI衔接帧占用，人物图从槽2开始。重新选择人物图后保留组合设置或已经选出的静态尾帧，H3图片编号同步，不自动重做AI选帧或提交视频。若按本段出场人物绑定补入普通主图，保存后明确提示数量，可在预览核对。
- 首段仍由用户选择开场图片，不伪造不存在的上一段视频；后续段沿用准确前段的AI衔接依赖。
- 预览、实际请求与新任务快照统一使用本次槽位用途；多项旧任务重试分别使用自己的冻结映射。复制图片不会把工作流派生用途写回普通选图或原资产。
- 本地图片用途错误完整显示中文原因，不再把composition等用途名称截成未知服务错误。无明确首尾帧槽的接口不猜测第一张图片用途；图片数量、文件、节点、未知提交、继续与防重复收费保护保留。

## 不改动的内容

不新增本地内容语义审核，不改H3原稿、对白、音乐、图像预设、模型/API设置或系统代理，不自动重跑旧任务。0.5.155的预设升级保护、0.5.154的AI尾帧组合以及已有项目、素材与旧交付文件继续保留。
