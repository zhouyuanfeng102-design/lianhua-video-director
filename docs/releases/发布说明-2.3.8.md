# 莲华视频导演台 2.3.8

发布日期：2026-10-16。

## 补全战斗编排与群体场面

源头生成区分持续交战、压倒性持续清剿、瞬杀、追逐和阵列推进。原文明示的招式、次数、能力与结果保持；概述性持续交战允许补足相容的具体动作、迎击衔接和群体调度。前景交点、中景梯队与远景军势共同表现规模，避免以集体腾空、碎片和镜头晃动代替攻击过程。

画面描述转化的详细模式保存可选的战斗场面计划，并经语义分段传到本段分镜。事实锁与导演选择分开记录，保留行动组、空间层、阶段因果、对白并行安排与进出状态。忠实模式仍只展开原文有依据的过程，普通交谈不强套战斗。

分镜与估时先容纳完整自然对白、必要行动和结果辨认，再安排摄影。真实在场人物可在符合剧情时继续画外发话，不能删台词、机械赶话或延长瞬杀填时间。画面转化与估时使用新版本缓存标识，重新生成时应用新规则。

## 按实际参考更新H3

本次视频稿按实际图片与音频识别参考模式。H3三字段稿后来增加人物或多参考时，可点击“更新本次参考”，由一次AI参考更新生成对应结构，保留原动作、对白、声音和镜头切点。更新只保存在本次视频草稿，不覆盖源分镜；不匹配的新H3请求在提交视频前提示更新，原任务快照重试继续保留旧输入。

普通多图槽中的开场和结束图片仅标为构图用途，不声称远端已启用硬首尾帧条件。图片槽映射、用途或模板变化会使旧参考更新失效；已声明的自动尾帧就绪不会额外触发一次参考更新。

## 使用新策略

对已有战斗片段，应从中文源头重新规划；需要更多演绎时间时先重新估时与分段。仅重新翻译英文、更新身份图或修复格式会保留已有动作设计。H3提交时如出现参考更新提示，在确认本次选图后更新并查看本次稿。

版本按十进位规则由2.3.7递增至2.3.8。历史发布文件、项目、确认稿和冻结任务保留，无自动数据迁移或自动视频重跑。
