# 莲华视频导演台 0.5.12

## 长剧情三阶段流程

- 长剧情现在强制按三个阶段执行：① 根据完整剧情和全片时长生成一份可审阅的全片总视频提示词与完整时间轴；② 在界面中检查、编辑并确认总提示词；③ 仅在确认后，按单段时长从总时间轴切出连续视频段。
- 总提示词草稿和确认状态会持久化，编辑总提示词会立即撤销确认；总时长、剧情或总镜头变化也会阻止使用旧确认结果。
- 分段镜头直接裁剪已确认的总镜头，跨段镜头只重设时间头，正文不再从分段剧情重新编写；每段保存来源镜头 ID，局部时间轴从 0 秒开始。
- TXT/JSON 导出同时保留全片总提示词、局部提示词和来源镜头追踪信息。
- 继续保留批量生成真实结果判断、启动时孤儿状态修复、明确失败原因/重试按钮、项目库和项目删除能力。
