# 莲华视频导演台 3.3.1 发布说明

发布日期：2026-10-27（亚洲/上海）。

## 剧情里写明的话补进台词

「一路说着后山几处灵田今年的收成」这类句子以前留在动作里，台词格只有别的引号原话。海螺看见有人在说、又没有这句词，就会凑出听不清的声音。

现在，说、道、问、答、笑说、一路说着、接着说、低声说后面已经写出的内容，会补成可以念的中文，放进 `<d>` 一次。补全只用本段已有的事实、称谓和语气。已有引号的句子原字不动。动作里不再把这句台词再说一遍。没有新句子的「接着说下去」停在已经补上的话。翻译、参考更新和纯格式修复仍跟已写好的稿子，不在那几步重新补词。

已经生成的视频不会变。要听到补上的话，需要重新生成对应片段的视频提示词。

不新增校验、重试或按钮。
