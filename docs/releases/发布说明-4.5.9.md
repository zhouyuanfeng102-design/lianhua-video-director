# 莲华视频导演台 4.5.9 发布说明

发布日期：2026-11-12（亚洲/上海）。

## 清空人物资料时保留视觉风格

图像工作台的清空只清当前选中的人物、场景或物品资料。名称和视觉风格保留，关联图片不解除。

## 交付

- Windows：`莲华视频导演台-4.5.9-便携版.exe`。
- Android：`莲华视频导演台-4.5.9-安卓版.apk`，最低 Android 8.0 / API 26。
- 4.5.8 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.5.9`。图像工作台两端共用，EXE 与 APK 一起交付。

## 验证

打包流程自带类型检查和前端构建。未在界面上再点一次清空。
