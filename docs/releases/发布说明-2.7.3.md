# 莲华视频导演台 2.7.3 发布说明

发布日期：2026-10-19（亚洲上海）。

## 单段结果与长剧情分别选择

修复切到“单段演出”后仍显示长剧情最后选中分段的问题。结果按稿件实际来源和所属方案选择，单段与长剧情分别记住本章结果，切换模式、刷新和切换章节后仍对应各自选择。历史记录中即使保存了“单段模式＋第 6 长段”，也不会把该段冒充独立单段稿。

当前章节没有独立单段稿时显示“尚未生成单段提示词”，已有长剧情分段继续保留。通过“查看原稿”仍可打开明确指定的历史稿件，不删除或重写旧稿。

## 视频草稿自动带入当前提示词

从侧栏进入视频导演台，真正空白的单段草稿会带入当前显示稿件的格式、语言和已有参考图。已填写的正文、名称、选图、来源关联、任务复用以及已进入的批量模式和选择保持原样；连接与参数保留。

“送到视频导演台”继续作为明确指定新稿件的入口，可主动替换本次视频草稿。这里只准备草稿，点击“生成视频”才提交任务；不新增模型请求、内容校验、生成拦截或自动重试。
