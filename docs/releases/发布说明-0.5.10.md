# 莲华视频导演台 0.5.10

## 批量生成与状态修复

- 批量生成现在只把“真实分镜存在且最终提示词 `finalPrompt` 非空”的视频段计为完成。
- 应用启动、桌面状态载入和项目库归档项目载入时，会自动修复孤儿分镜、空提示词结果和上次中断的 `generating` 状态。
- 每个视频段都会保留可读的失败/修复原因；失败段可在分段条、段落编辑区和导演台结果区点击“重试本段”。
- 批量与单段生成统一记录实际错误信息，成功写入真实提示词后自动清除旧失败原因。

## 兼容性

- 保留 0.5.9 的持久化项目库、长剧情拆段、导演台一屏布局、提示词生成和资产管理能力。
- 旧项目数据无需手动迁移；首次启动会在保存时写回修复后的状态。

## 验证

- TypeScript/Vite 生产构建通过。
- 状态迁移、批量队列、完整性诊断和顺序生成 UI 回归通过。
