# 莲华视频导演台 0.7.0 发布说明

## 版本定位

本版修复长剧情估时不足、总提示词失败后的恢复路径，以及 AI 自检/自动修复流程；交付包为 `莲华视频导演台-0.7.0-便携版.exe`。

## 本轮更新

- 修复长剧情估时不足：AI 会根据用户选择的分段时长自动补足全片总时长，并向上调整为该时长的整数倍。每个视频段使用完整的用户分段时长，不再要求手动修改，也不生成最后的短尾段。
- 估时结果异常（包括超过可用上限）会回到同一 AI 流程自检并修复后继续规划；估时、总提示词与分段规划可在一次操作中连续完成。
- 总提示词或 H3 生成失败时保留已完成的 AI 估时和当前上下文，自动返回规划区，用户可直接重新生成新的总提示词，不必重新手动设置估时。
- 失败区域增加可展开的详细原因，保留 H3 `section`、`Shot`、`At` 等定位信息，便于判断具体失败位置并重新生成。
- 放宽本地对同一语义节拍的错误时长判断；剧情拆分、时长补足、检查与修复均由 AI 完成，本地只负责技术结构读取、请求状态和结果归属保护，不新增本地剧情内容门禁。

## 兼容与边界

- 保留 H3 原文格式、中文/英文提示词、镜头边界、既有错误详情与历史项目；不自动重跑收费视频，不改写已有提示词、正式项目或媒体。
- 0.6.9 及更早版本的便携包、恢复源码、更新说明、启动器和 SHA-256 清单均保留，不覆盖、不删除。
- 本轮版本遵守十进位版本规则：`0.6.9 → 0.7.0`，不生成 `0.6.10` 或 `0.10.0`。

## 验证

- `npm run test:typecheck`
- `npm run test:story-pacing`
- `npm run test:ai-segmentation-review`
- `npm run test:user-facing-errors`
- `npm run test:styles`
- 长剧情、分段、请求身份和 H3 相关回归测试
- `npm run build`
- `npm run deliver:0.7.0`（生成 EXE、恢复源码、说明、启动器和 SHA-256 清单）

交付目录中的 `莲华视频导演台-0.7.0-SHA256.txt` 是本版四个版本化产物的 SHA-256 清单，可用于核对下载或复制是否完整。

本说明描述的是程序流程和回归验证；实际视频时长与内容仍取决于外部模型和服务商返回结果。
