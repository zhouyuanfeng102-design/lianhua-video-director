# 莲华视频导演台 2.5.3

发布日期：2026-10-17。

## 图生图任务显示参考图

生成任务中的图生图卡片显示本次携带的参考图数量、编号与名称，覆盖分镜图生图、转换后携带参考图的任务以及自定义生图。

优先读取任务保存的参考图历史快照，沿用当时名称和顺序；图片后来重命名或从资产库删除，不会改变已有快照的显示。没有快照的旧任务按保存的参考图 ID 回查资产名称，必要时回退到已保存的主要参考图记录；图片已删除或记录缺失时明确提示，不从当前分镜、人物绑定或新选图片猜测历史输入。

## 保持卡片高度与紧凑布局

参考图信息放入任务现有元数据区域，图片任务卡片保持原有高度。章节、尺寸、模型、生图规则、分类预设与参考图信息随可用空间和内容量自适应缩小字号；超长内容只在元数据区域内滚动，悬停可查看完整参考图名称。

本次调整任务信息展示与排版，保留已有任务、图片和项目数据，不自动提交新的生成请求。历史版本说明与交付文件继续保留。

## 验证与交付

基于生产构建的针对性界面检查通过：覆盖历史快照优先、旧参考图编号、主要参考图回退、已删除图片、名称未记录与七张长名称参考图；1480px 浅色、1040px 深色以及 125% 字号下，新增参考图信息前后卡片与提示词区域高度一致，字号自适应缩小，超长列表可局部滚动，没有横向溢出。恢复 100% 字号后自适应尺寸正常恢复。

检查使用隔离的合成项目，无页面或控制台错误，未读取用户项目、提交真实生成请求或运行全量回归。首次开发服务器检查在加载合成数据依赖时超时，随后改用生产构建完成验证。

打包流程中的 TypeScript 类型检查与 Vite 生产构建通过，未单独重复类型检查。构建仍提示循环分包与较大代码块，未阻塞构建和本次界面验证。Windows 64 位便携包已生成。
