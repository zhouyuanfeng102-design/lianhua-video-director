# 莲华视频导演台 4.7.0 发布说明

发布日期：2026-11-16（亚洲/上海）。

## 版本定位

修复 ComfyUI 视频工作流的画布导入和选择状态不一致问题。按十进位规则从 4.6.9 升为 4.7.0，同版提供 Windows EXE 和 Android APK。

## ComfyUI 视频画布

- 视频导入接入生图已有的画布转换器，支持画布 JSON 和 API 节点 JSON。画布在导入、保存或字段编辑边界转换成 API 执行图；已有 API 原文及未修改的参数保持原样。
- 按明确的控件名称、命名值、节点连线及旁路状态还原输入，支持附件使用的 Set/Get 连接、Reroute 和相关预览控件处理，不猜测未知自定义控件的位置。
- H3 图片槽按实际 `ref_image_0…5` 连线顺序识别，避免按 LoadImage 节点编号排序而串图。本次反馈附件本地识别为 6 个图片槽、输出节点 364。
- 工作流管理中的既有导入入口、重新识别、保存、字段编辑和导出使用一致的执行图，不增加新按钮。

## 工作流选择与提交

- 普通草稿保存的工作流 ID 已删除或因重新导入变化时，恢复到设置中明确有效的当前工作流。仍有效的本地选择继续保留。
- 下拉框、每段图片槽数、底部连接摘要和实际提交目标保持一致；无法恢复时真实显示缺失或待选，不再假显示首个工作流名称。
- 单段、批量和自定义生视频共用选择规则，分别保留各连接的参数草稿。
- 历史重用任务和失败任务继续使用其原有冻结连接快照，不自动换成设置页的新工作流。
- 将原有的未启用、地址为空和找不到工作流三种原因分开说明，避免已勾选开关仍被笼统提示“请先启用”。

没有新增运行时校验、审核、生成拦截、自动重试、模型请求或按钮，没有进行哈希测试。已保存的提示词、工作流映射、历史任务和成片不自动改写。

## 已完成的定向检查

- 视频工作流选择解析与普通表单恢复检查通过。
- 视频画布导入、H3 物理槽顺序、绑定与字段编辑检查通过。
- 既有共享画布转换、生图画布请求及视频工作流库检查通过。
- 真实组件 7 项检查通过：批量真实 ID、6 槽和底部摘要与模拟提交一致；旧/新连接参数分区保留；缺失工作流真实显示；有效本地选择保留；冻结快照包含空草稿 ID 的兼容；单段和自定义生成提交实际选择的 ID。外部生成请求为 0。
- 既有 `comfyuiVideo.test.ts` 中一处输出消息断言失败，期望包含“原绑定节点 10”，实际为“已保存到视频资产库”。已从 4.6.9 原交付源码隔离确认同样失败，没有改无关业务或调整断言掩盖结果。

本轮打包流程包含一次类型检查和生产构建。EXE、APK 构建、正式签名及最终产物核对结果记录在同版“能力与验证记录”中。

未连接用户的实际 ComfyUI 生成视频，未执行 Android 真机安装或覆盖升级验收；不将本地转换、模拟提交或签名检查写成实际生成及真机运行通过。

## 交付

- Windows x64：`lianhua-video-director-4.7.0-windows-x64-portable.exe`。
- Android：`lianhua-video-director-4.7.0-android.apk`，使用既有正式发布签名，最低 Android 8.0 / API 26。
- GitHub 同版提供 EXE、APK、更新说明、恢复源码 ZIP、安卓安装说明、能力与验证记录和 Windows 启动器，共 7 个附件；本地既有 SHA-256 清单不上传为 GitHub 附件。签名私钥和口令保存在仓库外。
- Mac 版已取消，不属于本版交付范围。
- 4.6.9 及更早版本保留原版本号与文件，不覆盖、不重编号、不删除。

构建：`npm run pack:all`；交付：`npm run deliver:4.7.0`。共享前端由打包流程构建一次，两端复用同一次结果。

本次 GitHub 更新沿用现成双端包，未重新打包、重跑上述测试或进行哈希测试。构建、签名和验证边界见 [4.7.0 能力与验证记录](能力与验证记录-4.7.0.md)，安装与备份见 [安卓安装说明](../android-install.md)。
