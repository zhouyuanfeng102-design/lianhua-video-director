# 莲华视频导演台 1.7.7 发布说明

2026-10-10

视频提示词的源头规划与转换规则改为先理解剧情中的完整事件，再展开视频模型能够辨认的身体动作、受力关系和连续站位。

## 剧情与动作表达

规划先区分行动者、直接受力对象、最终目标和环境地标。例如“甲把物体踢向乙”需要保留甲施力、物体受力、物体飞向乙、乙回应的完整关系；门、墙或走廊方向不能替代具名人物目标。

踢、扔、抓、推、躲、攻击等动作按照剧情展开必要的起始姿态、支撑与发力、使用肢体、接触部位、运动方向、回应及结束姿态。强度和比喻用于补充这些可见事实，心理与意图转为有剧情依据的表情、视线、姿态或行动。合理展开保留原剧情的能力、意图和结果。

物体被接触后才沿受力方向运动，人物在威胁逼近后回应；下一镜继承上一镜的站位、物体方向和动作阶段。机位与景别根据动作选择，关键接触要能辨认，摄影机换角度不会使人物自动换位。

H3 中文、英文翻译和 Seedance 共同保留这些动作关系。保留原段长和固定镜数，在既定时段内安排动作过程。

## 应用方式

更新后主动重新生成视频提示词，应用新规则；Seedance 也需要重新生成提示词才能使用新版规则。旧总稿在显式重新生成时可展开动作，已确认排程继续保留。Seedance 策略版本变化仅使派生成稿需要刷新，不改历史正文或输入。

已保存的提示词、历史任务和成片保留，本次不新增数据迁移、额外模型请求、动作校验门禁或结果重写流程，也不自动提交收费视频生成。

## 验证与交付

本轮 `videoActionChoreography.test.ts` 专项验证通过，共 17 组。覆盖 35 秒 6 镜的踢物到具名目标、抛物到接收者、原剧情证据传入规划与普通转换及 H3、H3 与 Seedance 中英文规则、保留和翻译范围，以及请求次数不增加。另覆盖旧总稿显式重新生成展开动作且保留已确认排程、Seedance 策略更新仅改变派生稿的新鲜度，保存内容和输入不变。验证采用确定性模拟响应，未调用真实收费 API，未对新规则生成的成片效果作验证。

Windows 便携版打包通过，包含最终修正，流程已执行 TypeScript 检查和生产构建；保留原有分块循环与体积提醒，未重复执行整套回归。

本版提供 V1.7.7 便携版、恢复源码、更新说明、启动脚本和配套 SHA-256 校验文件。1.7.6 及更早发布说明、交付文件和交付入口保留。
