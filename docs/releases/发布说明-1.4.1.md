# 莲华视频导演台 1.4.1 发布说明

## 版本定位

1.4.1 是针对图片身份上下文、Seedance 异步保存和章节状态标准化的修复版本，保持既有项目数据和默认 MiniMax H3 流程。

## 修复内容

- 修复图片身份上下文在已有分镜原文时丢失其他剧情文档，以及旧项目仅有场景数据时无法提供场景证据的问题。
- 修复 Seedance 2.5 官方提示词翻译等待期间切换项目或章节造成结果静默丢失、错误提示成功的问题。
- 修复章节工作区状态标准化首次写入 `undefined`、再次标准化又清除导致对象形状变化的问题。

## 交付文件

- `莲华视频导演台-1.4.1-便携版.exe`
- `莲华视频导演台-1.4.1-恢复源码.zip`
- `莲华视频导演台-1.4.1-更新说明.md`
- `莲华视频导演台-1.4.1-SHA256.txt`
- `启动莲华视频导演台-1.4.1-便携版.bat`

## 构建与校验

便携版使用 `npm run pack:win` 构建，交付物使用 `npm run deliver:1.4.1` 生成。交付目录中的 SHA-256 文件记录本版各交付文件的校验值。
