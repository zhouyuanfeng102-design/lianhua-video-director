# 莲华视频导演台 0.5.155 发布说明

发布日期：2026-09-24

## 版本定位

交付GPT2.5微NSFW五视图专用预设，以及旧预设升级保护。原全身图预设、普通GPT2.5与K2五视图不改动；不新增或修改年龄门禁。

## 本版变更

- `GPT2.5 · 微NSFW五视图`升级到1.1.0，参考已有全身角色预设，将统一的湿衣、湿发、水珠、光线与布料状态分别描述到左侧两个头像和右侧三个全身视角。
- 保留单张横向3:2、正面和侧面头像加正面/侧面/背面全身的五区域版式，保持同一身份、衣着基底和光照；衣物仍为主要遮挡层，不改成私密资料图。
- 规则目录升级到13。目录12已经完成首次安装，本次只替换与旧出厂正文完整匹配的目标预设，不补回已删除项目，不覆盖改名、编辑过的预设，停用项升级后仍保持停用。
- 保留当前手选规则与绑定，不修改历史任务的规则快照，不自动重新转换或收费生成。0.5.154的AI衔接帧加人物参考等功能保持不变。

## 使用与兼容

1. 请先保存并完全退出旧版，再启动`莲华视频导演台-0.5.155-便携版.exe`，不要多版本同时写入同一数据目录。
2. 在普通生图中选择五视图及`GPT2.5 · 微NSFW五视图`，未编辑的内置预设会显示1.1.0。用户自定义预设保留原内容与版本。
3. 历史任务与图片不会自动重跑或改写。要使用新版预设，请从图像工作台发起新任务；历史重试仍遵循其已保存的规则快照。
4. 本版不修改外部服务的模型参数或审核设置。验证不调用真实收费生图，提示词效果仍有模型随机性，不承诺具体出图效果。
