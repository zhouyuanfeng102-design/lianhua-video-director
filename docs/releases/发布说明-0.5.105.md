# 莲华视频导演台 0.5.105 发布说明

## 版本定位

本版只修复跨项目撤销/重做后的剧情串写，以及删除无关素材时改写已有提示词两项问题。目标便携包为 `莲华视频导演台-0.5.105-便携版.exe`；0.5.104 的既有功能继续保留，其它已知问题不在本轮修复范围内。

## 本轮修复

- 跨项目撤销/重做时，同步恢复当前项目的剧情原文和工作区控件，避免另一项目的草稿在保存或再次切换项目时覆盖当前项目。普通同项目撤销仍保留未保存输入。
- 删除素材前判定分镜的实际引用，只重建相关分镜。无关分镜保留原对象、中文和英文提示词、对白时间、生成计划，以及已确认的全片母时间轴和分段，不再因删除无关图片而失效。
- 镜头、全局参考、提示词记录、首尾帧、音频等真实引用继续正常清理；删除不存在的素材 ID 不改动项目。人物、场景和道具卡片中的素材关联仍会清理。

## 升级与数据

请先保存当前工作并完全关闭旧版，再启动新版，避免多个版本同时操作同一数据目录。推荐启动 `交付\启动莲华视频导演台-0.5.105-便携版.bat`；无版本启动器在本次交付完成后也会指向 0.5.105。

schema 保持 **23**，不新增数据迁移；既有项目、素材、任务、规则、API/模型配置及生成参数保留，不自动重跑已有任务。本轮不删除旧包和任何正式数据，现有 0.5.104 及更早版本化交付继续保留。修复用于防止问题再次发生，不会自动还原此前已被覆盖的内容；如需恢复旧内容，请使用已有恢复点或备份。

上一轮源码 `npm test`（覆盖 72 个测试文件）、`npm run build` 和 8 项隔离 UI 回归已通过。该结论不替代新包的启动烟测及 SHA-256 校验，也不代表真实外部 API 生成已验收；新包结果以本次实际执行记录和产物为准。

```powershell

```

