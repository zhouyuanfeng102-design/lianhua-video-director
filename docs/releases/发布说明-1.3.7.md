# 莲华视频导演台 1.3.7 发布说明

版本日期：2026-10-05（亚洲/上海）。

## 版本定位

本版把视频工作台从“按片段顺序导出”扩展为可直接编辑、删除和拼接的可视化时间线，适合生成视频后剪掉不满意的几秒，再接入其它素材。

## 本版变化

- 新增按片段时长比例显示的可视化时间线和缩放控制，方便定位当前播放头与选中片段。
- 支持编辑选中片段的源视频起止点，也可用播放头快速设置起点和终点。
- 支持删除选区并自动合拢空档、在播放头处插入素材（必要时拆分原片段），以及替换选区内容。
- 编辑历史支持撤销和重做；删除、插入和替换后会自动校正相邻转场，避免旧转场跨越新接缝。
- 原始素材、项目数据和导出音频设置保持独立保存，编辑操作只更新当前工作台草稿。

## 验证

- `npm run test:video-workbench`：视频工作台及编辑专项测试通过（编辑专项 6 组，以及工作台、选择和单页相关回归通过）。
- `npm run pack:win`：TypeScript 检查、Vite 生产构建和 Windows x64 便携版打包通过；仅保留现有分包循环与大 chunk 提示。
- `npm run deliver:1.3.7`：交付文件生成成功，SHA-256 清单逐项核对通过。

交付文件包括 `莲华视频导演台-1.3.7-便携版.exe`、`莲华视频导演台-1.3.7-恢复源码.zip`、`莲华视频导演台-1.3.7-更新说明.md`、`启动莲华视频导演台-1.3.7-便携版.bat` 和 `莲华视频导演台-1.3.7-SHA256.txt`。其中 SHA-256 清单用于核对便携包与恢复源码。
