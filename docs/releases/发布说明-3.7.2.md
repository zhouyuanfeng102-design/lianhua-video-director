# 莲华视频导演台 3.7.2 发布说明

发布日期：2026-11-05（亚洲/上海）。

## 分段按剧情和总时长切开

自定义总时长时，AI 剧情分段先按原文先后，把动作、原话和反应排成一条用满所填总秒数的连续演出，再按所选的单段秒数切开。切口落在一句说完、一次动作完成，或同一件持续的事做到的进度。

15 秒及更短的一段，放一件这段时间演得完的连续情节：一次主动作、它引起的反应、这期间说得完的原话。后面不同的事进下一段。超过 15 秒的一段，按每 15 秒写下同一条演出的真实进度。一次视频生成只有 4 到 15 秒。一次短进入加一句短话不再独占更长的一段。

AI 适配没有填写总时长时，先按剧情的自然时间排整片，再用同样的密度切开。每段仍是完整的一段。不新增按钮，不新增拒绝薄段或厚段的校验，也不自动重试。

已保存的分段、提示词和成片不改。重新做一次 AI 剧情分段后，新排法才会用上。

## 版本定位与交付

Windows x64 便携包：`莲华视频导演台-3.7.2-便携版.exe`。构建命令为 `npm run pack:win`，交付命令为 `npm run deliver:3.7.2`；3.7.1 及更早历史版本文件保留。交付目录同时提供恢复源码、更新说明、启动器与 SHA-256 清单。
