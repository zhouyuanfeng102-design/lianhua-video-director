# 莲华视频导演台 1.2.8 发布说明

## 版本定位

修复图像工作台“场景”资料缺少视觉风格的问题。便携包为 `莲华视频导演台-1.2.8-便携版.exe`。

## 本次修复

- 场景资料增加与人物页一致的“视觉风格”预设下拉框和自定义输入框。
- 保存场景时一起保存风格；切换场景、重开软件后恢复各自设置，已保存的场景风格不会被导演台默认值覆盖。
- 兼容没有风格字段的旧场景，继续沿用导演台风格；主动清空的“不套用预设”也能保存。
- 风景场景、故事快照和分镜首帧都会把所选风格带入提示词转换和任务快照。AI 补齐保留已有的非空风格。
- 沿用无人风景场景的环境限制、1.2.6 的结果区精简以及 1.2.7 的 H3 交付修复。

## 使用

保存并正常退出旧版，在原交付目录打开新版。进入“图像工作台 → 场景”，选择或填写视觉风格，点击“保存”后按需要生成图片。生成结果从“生成任务”查看。

已完成的图片和任务保留原结果；修改风格后，需从场景工作台新建生图任务才会使用新风格。

## 验证范围

使用虚构环境、模拟接口与隔离测试目录，检查预设和自定义风格、清空风格、场景切换、保存重载、三种场景规格的请求参数及任务快照。完成相关回归、类型检查、生产构建及新包启动、保存和重载验证。

未调用真实生图接口；测试验证软件传入的风格和保存链路，不把模拟图片作为模型出图效果的证明。

构建：`npm run pack:win`。交付：`npm run deliver:1.2.8`。交付包含便携 EXE、恢复源码 ZIP、更新说明、启动器及 SHA-256 清单。
