# 莲华视频导演台 1.7.2 发布说明

2026-10-09

修复提示词导演台横向长剧情分段条在夜间模式下未选中项仍为白底的问题。

## 展示变化

所有夜间主题中的未选中分段使用对应暗色背景，避免在暗色界面中出现整条白底。经典原色的日间外观保持原样，已经显式选择的主题不重置。

本版继续包含“经典原色”：未设置主题及旧配置默认采用原多彩导航按钮和面板风格，显式选择的新配色继续保留。经典原色、莲华粉、湖蓝、青竹、暖砂、紫藤，以及日间、夜间、跟随系统模式仍可独立选择。

紧凑批量分段、图像任务完整提示词滚动框和资产库详细信息默认折叠继续保留。本次仅修正展示，不调整生成、衔接、稿件或项目保存逻辑。

## 验证与交付

针对性分段条验证通过：经典原色与暖砂的夜间模式下，提示词导演台和全片规划中的默认、悬停、选中状态共检查 12 组，均无白底，最低文字对比度为 4.17:1。经典日间分段条的三种状态颜色与原 CSS 一致。检查使用隔离的合成数据，没有调用真实生成接口，没有重复此前已通过的整套主题、批量或任务检查。

`npm run pack:win` 通过，包含 TypeScript 检查、生产构建和 Windows 64 位便携 EXE 打包。`npm run deliver:1.7.2` 用于生成便携 EXE、恢复源码 ZIP、更新说明、启动脚本及 SHA-256 校验文件。1.7.1 及更早发布说明和交付文件保留，不覆盖已交付版本。
