# 莲华视频导演台 2.7.7 发布说明

发布日期：2026-10-19（亚洲上海）。

## AI 语义分段每次点击只请求一次

移除 AI 语义分段内部的自动重试，包括 JSON 格式失败、输出未完整返回、接口参数不兼容和模型自评不足后的自动再请求。沿用现有“AI 理解剧情并分段”和“重新 AI 分段”入口，每次点击只发起一次模型请求；失败时保留已有计划、分镜和成片，不自动修改额度或格式参数继续生成。

## 减少输出协议歧义，补充安全错误定位

场面编排结构改为合法 JSON 示例，不再向分段模型提供含 `string`、`?:` 等类型签名的结构示意。保留现有输出字段和完整剧情、动作、次数、对白、资料及来源关系，只要求理由、摘要等辅助说明简短，避免重复叙述挤占输出。

沿用已有 JSON 解析过程，在解析器提供信息时记录语法类别、错误位置及行列；区分响应正文与解码字符串中的位置，不把模型正文、人物资料或完整原始错误片段拼入诊断。未取得具体位置时不猜测。

此前失败响应的原始正文没有保存，无法据长度记录还原具体坏字符。本版消除已发现的格式歧义并改善后续定位，不宣称已经确定那次失败的精确语法原因。

## 全片动作时间安排优先于原文段落

保留 2.7.6 的跨自然段连续编排规则，并在同一次请求末尾明确：先完成全片自然动作、完整发话和必要停顿的安排，再分配视频窗口。短促颔首、虚晃、后撤不能为了填满一段被分别拉长为数秒；理由中的安排必须落实到实际片段中。

相邻自然段的连续动作可以进入同一窗口，较长行为也可按真实进度跨窗。完整保留招式、次数、整理、喘息、明确局部慢速及对白，不用删动作或增加空转换取较少段数。AI 适配不预设目标段数；固定模式仍保持用户指定的总时长、单段时长和段数。

原文、采用稿及现有场面记录继续保留，已有计划不会在升级时被自动重写。全片重新分配使用原有“重新 AI 分段”；“重新生成本段”仍只处理当前段。

## 验证

五组定向脚本各运行一次并通过：`semanticSequencePlanner.test.ts`（23/23）、`semanticSequenceProgress.test.ts`、`semanticSequenceApp.test.ts`、`semanticActionWindowPlanning.test.ts`（2/2）和 `semanticSequenceJsonDiagnostics.test.ts`。

覆盖实际请求参数、失败时仅一次请求、取消与过期结果处理、已有计划及 H3 保留、用户主动发起第二次请求成功，以及安全 JSON 诊断。动作窗口用例确认多个自然段可以保存到同一窗口，固定模式的时长与段数保持。

打包内 TypeScript 检查、Vite 生产构建和 Windows 64 位便携版打包通过。构建仍提示项目已有的循环分包与部分包体积较大，未出现类型或构建错误。相关 UI 脚本已同步为单次请求预期并通过 JavaScript 语法检查，本次未重复运行整套界面回归或启动用户的项目。

本次未调用真实收费文本或视频模型，不以模拟响应或构建检查证明真实模型的分段质量，也未据此确认实际成片效果。
