# 莲华视频导演台 4.0.5 发布说明

发布日期：2026-11-07（亚洲/上海）。

## 分段不再少演看得见的行动

下次做全片分段时，不超过 15 秒的一段放一条还没演完的连续过程。这条过程里每一次看得见的变化都写进这段正文：谁从哪到哪，身体从什么姿势到什么姿势，手上和门窗变成什么样。短的进入、起身、趴下、拿放，要么留在这段里，要么作为下一段的开头接着演。

下一段的入口就是上一段的出口，不能跳到更后面的结果。对白和这些变化放不进现有窗口，就增加段数。紧凑也不能靠少演原文里的可见行动来完成。

已保存的分段、提示词和成片保持原样。重新做全片分段后，这些行动才会进入某一段。只重写单段提示词，补不回已经被分段跳过的行动。

## 交付

- Windows：`莲华视频导演台-4.0.5-便携版.exe`。
- Android：`莲华视频导演台-4.0.5-安卓版.apk`，最低 Android 8.0 / API 26。
- 4.0.4 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.0.5`。本版是共享分段规则，EXE 与 APK 一起交付。

## 验证

打包流程自带类型检查和前端构建。未把已有分段和成片重新生成。
