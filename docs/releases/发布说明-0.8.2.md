# 莲华视频导演台 0.8.2 发布说明

## 版本定位

修复 AI 选尾帧遇到输出额度耗尽时不会自行重试，以及失败后第一次点击重试可能无效的问题。

根因有两处：视觉 API 既有默认输出额度为3000 tokens，思考模型可能在产出选帧正文前就用完额度，原流程失败后没有追加本轮输出预算的重试；另外失败状态已显示时，上一轮异步收尾可能仍占用执行标记，导致第一次手动重试被吞掉。这不是 H3 格式校验或本地内容审核拦截。

- 对供应商已明确返回的可恢复错误，首次请求后最多自动重试3次；每轮共最多4次潜在收费的视觉 AI 调用，不无限重试。
- 仅返回思考或输出截断时，调整本轮请求副本的输出额度；供应商明确告知输出上限时按该上限调整，不把输入或上下文容量误当输出上限。
- 不改用户保存的视觉 API 配置，不换模型。候选帧和缩略图只准备一次，每次请求仍提供完整前后段提示词和候选图片；只约束选帧结果使用短 JSON，不压缩剧情资料或改写 H3。
- 手动重试等待前一轮失败收尾结束后继续同一任务；已保存的选帧结果优先恢复和绑定，不重复调用 AI 购买同一结果。
- 每次潜在收费请求前都持久记录收费边界和当前次数，检查取消、来源及保存状态；完成结果先记录后绑定，失败恢复复用已经完成的结果。
- 旧任务不会因升级自动追加收费次数；用户明确点击重试后才授权本轮最多4次调用。
- 超时、认证失败、拒绝、内容过滤、取消、换源、保存失败和结果未知时停止，显示具体原因，不自动反复收费。此重试策略仅用于 AI 选尾帧，不开启全局文本模型重试。

## H3、数据与费用

本版不修改 H3 正文、章节、镜号、时间切点、参考标签或对白语法，不增加本地内容审核；0.8.1 的参考图固定槽位与原用途替换继续保留。

不自动重新生成图片或视频，不修改用户正式项目、原素材或已有成片；不覆盖、重编号或删除 0.8.1、0.8.0、0.5.160 及更早交付。测试使用隔离假数据和模拟接口，不调用真实收费 API。

## 验证与交付

已通过双 tsconfig 类型检查、45项选帧回归、17项文本模型协议错误回归、10组选帧界面流程、26项任务卡检查、30项原生提交记录回归、视频任务全链、保存恢复、H3协议、固定槽位和51项发布规则。所有AI与视频API请求均为模拟，没有调用真实收费服务。

真实FFmpeg抽帧、选帧核心、视频引擎与原生提交记录贯通验证通过：模拟前两次输出达到上限，第三次成功，本轮额度依次为2048、4096、8192；仅准备一次6张候选。完成结果先保存、绑定前中断后恢复，不再抽帧或购买AI结果；上段和下段视频各提交一次，源视频校验和不变。

生产构建通过500 KiB分块预算与真实ESM初始化检查，最大JavaScript块501401字节。包内21个JavaScript/原生提交记录文件与生产构建逐字节一致；9个H3、提示词和固定槽位相关关键文件与0.8.1恢复源码保持一致。

便携包在`.qa-data-0.8.2`隔离启动，显示`v0.8.2`，保存、重载、恢复快照与1120×720、1280×720、1280×800三个视口通过，页面错误为0。记录为`.qa-packaged-0.8.2/report.json`。历史0.8.1、0.8.0、0.7.9各4项版本化制品SHA-256核验通过，未被改动。
