# 莲华视频导演台 2.8.0 发布说明

发布日期：2026-10-20（亚洲上海）。

## 版本定位

调整视频工作台的布局密度，减少上方工具区和视频素材卡片占用的高度，让同一窗口能显示更多素材。

## 界面调整

- 压紧视频工作台上方工具区，为下方视频素材列表腾出空间。
- 视频素材卡片高度约减半，字体随可用空间调整；完整名称、章节、时长和尺寸等元信息换行显示，不用省略号截断。
- 列表按名称和实际章节、时长、尺寸文字的完整高度分页，长名称需要换行时仍完整展示。

现有搜索、跨页选择、添加素材、剪辑与导出功能继续保留。本次为界面布局调整，不修改项目、素材、稿件、任务或成片，不新增运行时内容校验、生成拦截、自动重试或模型请求。

## 验证

本次布局定向检查已通过：在 1280×800、130% 字号下，常见视频名称卡片约 29.5 像素高，当前页显示 6 张；素材列表上方工具区约 77 像素高。另覆盖 1120×760 的分页及超长中英文名称，逐页检查名称完整、无文字裁切、按钮无遮挡、无面板溢出。检查使用隔离样例，未操作用户项目或请求视频生成。

Windows 打包已完成（`npm run pack:win -- --config.directories.output=.pack-release-2.8.0`）：TypeScript 检查、Vite 生产构建和 Windows 64 位便携版生成均通过。构建仍有既有循环分块和大分块提示，无构建错误；未追加全量回归。

## 交付文件

本版便携包命名为 `莲华视频导演台-2.8.0-便携版.exe`。交付步骤使用 `npm run deliver:2.8.0` 生成版本启动器 `启动莲华视频导演台-2.8.0-便携版.bat`、恢复源码 ZIP、更新说明及 SHA-256 校验清单。

保存项目并退出旧版后再启动新版本，保留 EXE 旁完整的“莲华视频导演台数据”文件夹。2.7.9 及更早交付文件继续保留，0.5.160 及更早历史版本不重编号、覆盖或删除。
