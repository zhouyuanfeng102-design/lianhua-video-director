# 莲华视频导演台 4.0.8 发布说明

发布日期：2026-11-08（亚洲/上海）。

## 新版积分和老版 RH 币都能提交

RH 网页登录状态按这个窗口里实际写的余额显示。新版显示积分、过渡 RH 币和钱包。老版仍显示 RH 币和钱包。

新版运行区写「费用以实际用量结算」，或写出积分、过渡 RH 币的预估时，会继续点击运行。老版页面仍然要看到 ≈ RH币 才点击运行。应用介绍里的「每秒消耗 RH 币」不算预估，不会因此点击。

已保存的提示词和成片保持原样。

## 交付

- Windows：`lianhua-video-director-4.0.8-windows-x64-portable.exe`。
- Android：`lianhua-video-director-4.0.8-android.apk`，最低 Android 8.0 / API 26。
- 4.0.7 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.0.8`。本版是共享的网页任务提交，EXE 与 APK 一起交付。
