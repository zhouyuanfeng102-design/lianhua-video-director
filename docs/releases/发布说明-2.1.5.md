# 莲华视频导演台 2.1.5 发布说明

发布日期：2026-10-13

## 版本定位

本版修复私密生图从资产库手工选择参考图时，普通图片被筛选排除、选取状态无法保留的问题。

普通可用图片无需预先绑定人物即可显示和选择，所选图片保留在当前生图通道。已有私密标记的图片继续按当前人物与部位匹配；选择普通图作为参考时，源资产的私密标签与人物关联保持原值。

界面中的参考图提示文字按实际可选范围说明，避免将资产库误描述为只支持同人物同部位私密图。已有资产、项目、任务记录与历史交付文件继续保留。

## 使用说明

更新前保存项目并退出旧版，保留完整的“莲华视频导演台数据”文件夹。

在私密生图设置中点击“从资产库选择”，可手工选取当前项目的普通可用图片作为参考。普通图无需先改成私密资产或关联到当前人物；已有私密图仍需匹配当前人物与部位。

选图后确认当前通道出现参考图缩略图、参考复选框已选，再执行生图。切换人物或部位后应重新确认参考图范围；参考图选择本身不会提交生成任务。
