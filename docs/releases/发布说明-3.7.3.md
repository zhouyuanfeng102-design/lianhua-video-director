# 莲华视频导演台 3.7.3 发布说明

发布日期：2026-11-05（亚洲/上海）。

## 提示词末尾不再带上人物记录

H3 正文写到 `non_diegetic_music` 为止。人物和事件记录只放在交付数据的 `identityBindings` 里，不再接在配乐字段后面。

模型如果仍把 `{"version":1,"characters":...}` 写在正文后面，读取时会把这份记录拆进原有的绑定字段。不因此再请求一次，也不新增拒绝或按钮。

已保存的提示词和成片不改。要对有问题的那一段重新生成本段提示词，新正文才不会带上这截记录。

## 版本定位与交付

Windows x64 便携包：`莲华视频导演台-3.7.3-便携版.exe`。构建命令为 `npm run pack:win`，交付命令为 `npm run deliver:3.7.3`；3.7.2 及更早历史版本文件保留。交付目录同时提供恢复源码、更新说明、启动器与 SHA-256 清单。
