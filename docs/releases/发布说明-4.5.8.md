# 莲华视频导演台 4.5.8 发布说明

发布日期：2026-11-12（亚洲/上海）。

## 云端选项改成下拉

RunningHub 的 LIST 字段把提交值放在 index，把看见的名称放在 description。读取云端节点时会记下这些选项。其它参数和节点参数里，凡是带选项的字段都改成下拉，选中的仍是云端要的那个值。

已经保存的工作流要再点一次「读取云端节点」，选项才会出现。没有选项的文本和数字字段仍是输入框。

## 交付

- Windows：`lianhua-video-director-4.5.8-windows-x64-portable.exe`。
- Android：`lianhua-video-director-4.5.8-android.apk`，最低 Android 8.0 / API 26。
- 4.5.7 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.5.8`。工作流配置两端共用，EXE 与 APK 一起交付。

## 验证

节点目录夹具核对 LIST 的 index 和说明能变成下拉选项，16 组通过。打包流程自带类型检查和前端构建。未在真实 RunningHub 页面上再点运行。

本次 GitHub 发布沿用已生成的 EXE 与正式签名 APK，未重新打包、重跑检查或运行哈希测试。版本、签名与检查范围见 [4.5.8 能力与验证记录](能力与验证记录-4.5.8.md)，安装与备份见 [安卓安装说明](../android-install.md)。
