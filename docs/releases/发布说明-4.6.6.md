# 莲华视频导演台 4.6.6 发布说明

发布日期：2026-11-14（亚洲/上海）。

## 龟头指向接触处，茎身留在这一镜

阴茎出现时，根留在这名男性自己的腹股沟。龟头是远离腹股沟的那一端。茎身连着根和龟头。进入时龟头指向她的骨盆里面，尿道口朝向她的体内。含入时茎身从他的腹股沟伸到她的嘴唇，龟头指向她的口腔，这一镜看见这段茎身。只亲到龟头时，嘴唇留在龟头那一截，龟头仍指向她的嘴唇，根仍留在他的腹股沟。

进出仍是这一次缓慢行程：进的时候龟头朝她骨盆里面走，退时龟头仍留在阴道口里面，并且仍朝她骨盆里面，再进到腹股沟贴上骨盆。

原文这一镜有进入、抽插、含入、抵住或已经露出时，同一镜用一个斜侧面固定中景，同时看见脸、他的腹股沟，以及从腹股沟连到接触处的这段茎身。原文这一镜没有阴茎接触、也没有写出露出时，才只拍脸、胸口或腰以上。

已保存的成片、分镜、章节和提示词不改写。下次扩写、画面描述转化、重新生成分镜或提交视频时使用这些句子。

## 交付

- Windows：`莲华视频导演台-4.6.6-便携版.exe`。
- Android：`莲华视频导演台-4.6.6-安卓版.apk`，最低 Android 8.0 / API 26。
- 4.6.5 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.6.6`。分段、分镜和视频提示词在两端共用，EXE 与 APK 一起交付。
