# 莲华视频导演台 0.5.106 发布说明

## 版本定位

本版修复视频导演台“本次参考图片”的资产库选择范围问题。目标便携包为 `莲华视频导演台-0.5.106-便携版.exe`；0.5.105 的数据保护修复及此前功能继续保留，其它已知问题不在本轮修复范围内。

## 本轮修复

- “从图片资产库选择”现在读取资产库全部图片型资产，不再只显示普通/分镜图片。人物、场景、道具、普通参考图、九宫格、首尾帧、Clay Render 和私密资料图都可手动选入本次视频参考图。
- 选择器仍排除视频和音频资产；原文件缺失的图片保持禁用提示，避免提交不存在的本地文件。
- 使用所选图片只影响当前视频生成草稿，会解除旧任务图片快照并改用当前资产库图片；提示词、种子和其它参数保持不变。

## 升级与数据

请先保存当前工作并完全关闭旧版，再启动新版，避免多个版本同时操作同一数据目录。推荐启动 `交付\启动莲华视频导演台-0.5.106-便携版.bat`；无版本启动器在本次交付完成后也会指向 0.5.106。

schema 保持 **23**，不新增数据迁移；既有项目、素材、任务、规则、API/模型配置及生成参数保留，不自动重跑已有任务。本轮不删除旧包和任何正式数据，现有 0.5.105 及更早版本化交付继续保留。

## 验证与交付

本轮针对性验证：

```powershell
npm run test:video-director-draft
npm run test:video-director-references
npm run test:typecheck
npm run test:styles
npm run test:release-review
```

构建与交付步骤：

```powershell
npm run pack:win
npm run deliver:0.5.106
```

交付应生成 0.5.106 便携版、恢复源码、更新说明、版本专属启动脚本和 SHA-256 清单。最终校验值以 `交付\莲华视频导演台-0.5.106-SHA256.txt` 为准；以上命令是执行步骤，不表示尚未运行的新包烟测或校验已经通过。测试必须使用专用隔离 QA 数据目录，不得指向正式数据。
