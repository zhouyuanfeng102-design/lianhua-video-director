# 莲华视频导演台 0.9.6 发布说明

版本日期：2026-09-30

## 版本定位

V0.9.6 将新长剧情改为“原剧情 → AI理解并分段 → 逐段分镜与H3提示词”，不再先生成全片总提示词。历史总稿流程继续兼容，不自动改写旧项目。

## 本版改造

- 新建长剧情直接提交完整原文、所选单段时长D、导演要求和人物事实，无需先解析场景，不生成隐藏总稿或全片H3。AI按事件、对白归属、动作阶段及上下段衔接决定段数N；每段D秒，总时长D×N，不留不足整段的短尾段，不用字数公式硬切。
- AI编排的分段正文与原文证据分别保存，逐段记录事件、对白、入口/出口和衔接状态。后续分镜只使用本段证据和对应上下文，已完成动作继承结果，不靠重复收束、空镜或换运镜填段。
- 用户确认分段后，沿用现有逐段AI分镜和中英文H3生成链路。下一段收到上一段已完成的最终提示词进行承接；衔接约0.5秒、最多0.8秒且计入本段时长，不把上段大段剧情重新演一遍。
- 新模式显示“AI 理解剧情并分段”“重新 AI 分段”，不再显示全片总提示词面板。缺少新模式标记的历史计划继续原总稿流程，用户可以主动选择新的语义分段。
- 新计划冻结剧情、导演要求和人物事实快照，重启、导入导出和重试不串用别的计划来源。手动编辑分段有明确标记，不覆盖原文证据。
- 重新分段追加新计划，旧计划、提示词、参考图、已提交任务和成片保留。请求同步占位防止双击重复提交；取消、迟到响应和失败不会覆盖已有结果。
- 理解与必要修正交给现有AI请求，不新增独立AI审核或本地语义门禁。继续做JSON、字段、ID、来源快照和固定时长等技术检查；AI报告规划不足或结构错误时最多自动修复三次。
- H3三字段/六字段、镜号、对白身份、声音及图片引用协议保持原链路；不改普通/私密生图及NSFW规则。选图、复制参考图和本地末帧按钮仍不重写视频提示词。

## 使用与历史内容

1. 保存并关闭旧版，再运行V0.9.6便携包；若旧版保存失败，先导出当前项目再退出。
2. 在剧情栏准备完整剧情，选择每段时长，点击“AI 理解剧情并分段”。不必先生成总提示词。
3. 查看AI分段结果，确认后按原流程生成每段分镜和H3视频提示词，再选择参考图生成视频。
4. 旧总稿项目继续可用，需使用新方式时主动重新AI分段；升级不自动重生成旧提示词或视频。

本版调整剧情编排与数据传递，不承诺云端模型一定生成完全无误的画面、对白或声音；模拟接口测试不替代真实收费模型成片验收。
