# 莲华视频导演台 1.8.5 发布说明

2026-10-11

本版修复 1.8.4 剧情解析页面在 AI 画面转化期间出现的输入布局错位，恢复原来的章节名称与剧情原文编辑布局。

## 恢复剧情解析输入布局

章节名称保持正常输入框高度，剧情原文继续占据页面剩余的主要编辑空间。AI 转化进度与待审提示按内容高度显示，不再挤乱字段位置或把章节名称拉成大块空白。

原来的输入顺序、保存原文、AI 扩写、AI 画面描述转化、清空、解析并补全及项目圣经预览入口继续保留。

1.8.4 增加的剧情理解、动作细化、动作依据与编排补充、全文重转和单段重做功能继续保留；本版只修复主页面布局。原项目、转化来源、历史提示词与任务保留。

## 验证与交付

最终 `npm run pack:win` 通过 TypeScript 检查、Vite 生产构建和 Electron 便携包构建，保留既有循环分块与体积提示。

直接使用 1.8.5 便携 EXE，在隔离数据目录中检查 1280×800、1120×720 和 1920×1200 三种窗口尺寸，覆盖空闲、图生视频空闲、转化中、待审及待审同时转化五种状态，共 15 组。章节名称输入框高度与空闲状态一致，剧情原文只让出提示条实际需要的高度，底部操作栏保持位置，没有溢出。另查看 1280×800 与 1920×1200 转化中截图，确认恢复原来的输入布局。检查期间没有页面或控制台错误。

首轮检查因便携版解压启动超过 40 秒而超时，尚未发出模拟请求或开始页面检查。将检查脚本的启动等待改为 90 秒并设置独立临时目录后重试通过；未因此修改产品或重新打包。

本轮使用 4 次本机模拟文本接口请求及隔离数据验证动态状态布局，没有访问生产项目数据或调用真实文本、生图、视频服务；未重复运行全量回归，也未重新评估动作转化模型效果。

本版按十进位从 1.8.4 升级至 1.8.5，便携包名为 `莲华视频导演台-1.8.5-便携版.exe`，交付命令为 `npm run deliver:1.8.5`。1.8.4 及更早发布说明、交付文件与交付入口继续保留。
