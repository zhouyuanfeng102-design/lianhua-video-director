# 莲华视频导演台 2.5.0

发布日期：2026-10-16。

## 图片关联与声源编号分开处理

修复图片已经明确绑定同一个人物 ID，却因视觉定位句中没有声源编号而显示“已选·待关联”的问题。人物的外观身份句与其它镜头中的发声描述可以分别书写；图片关联不再审核声源编号是否写在外观句里，也不审核声源编号是否重复。

原有声源编号与声音描述保留，不为关联图片把声音搬入外观句，不修改用户选图或既有项目数据。

## 人物绑定修复只请求一次

已有同 ID、可准确定位的绑定直接返回，不调用 AI。需要修复时，每种语言只发一次请求，不再因本地正文判断失败自动重发三次。

人物绑定修复与保存流程不再审核 H3 字段、镜号、切点、声音或视觉句内容。JSON 可读取、目标 ID 对应、文本位置可准确应用、异步结果仍属当前任务和原稿未被覆盖等技术条件保留。

保留此前版本的分段设置同排布局，以及参考提示不阻止生成的行为。本次不迁移项目数据，不自动重试真实生成任务。
