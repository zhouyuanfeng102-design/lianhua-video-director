# 莲华视频导演台 1.5.0 发布说明

1.5.0 处理人物参与记录、本地格式和排程判断导致整段视频提示词被拒收的问题。每段仍使用现有分阶段生成流程，本次不改为单次调用生成。

## 主要改动

- 取消生成链路中对人物证据逐字匹配、人物覆盖、身份句位置、正文格式及排程一致性的本地否决。现有 AI 复核请求同时接收剧情上下文、人物资料、本段任务和候选正文，由 AI 完成内容自查与修复。
- 人物参与与身份记录随最终正文一起由 AI 返回。记录无法读取或时间轴暂不能同步时保留正文及已有时间轴，显示具体提醒，不因此触发内容返工或判定整段提示词不可用。
- 中文、英文复核请求失败时保留此前已取得的正文并标注复核未完成；从未取得可用正文时如实报错。提醒随项目及历史版本保存，切换英文仍可看到中文交付遗留的提醒。
- 统一人物提醒与实际参考图关联对 `[Shot5]`、`[Shot 5]` 的识别。根据明确的人物归属和用户实际选图建立槽位对应；缺少确定关联时继续显示待关联，不把人物提及当作图片已提交。
- 保留空响应、JSON 读取、接口错误及项目切换保护。仅无法读取返回数据等技术错误保留有限修复，不再因本地内容规则反复调用 AI。
- 旧项目不自动重跑生成；已保存的正文、历史记录与资产保持保留。

## 验证范围

针对性验证覆盖人物证据差异、紧凑镜号、附属记录损坏、时间轴同步失败、中文检查点、英文复核失败、切换项目取消、保存恢复及实际图片槽位关联。测试使用合成数据和模拟响应，不调用真实付费 AI 接口。

构建命令为 `npm run pack:win`，包含 TypeScript 检查及生产构建；交付命令为 `npm run deliver:1.5.0`。打包后使用独立测试资料目录检查启动，避免读取或修改真实项目。
