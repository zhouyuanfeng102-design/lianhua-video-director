# 莲华视频导演台 2.4.4

发布日期：2026-10-16。

## 人物声音年龄与音色设定

修复年轻人物在视频生成中缺少稳定声音身份的问题。现在可在“剧情解析 → 实体资料 → 人物”的声音档案中，或“视频导演台 → 项目声音预设”中，填写声音年龄、基础音色、对白语言、口音、稳定说话习惯及声音一致性补充，并选择已有音频作为样音。

声音年龄与外观年龄、实际年龄分开保存。空白项目不会自动获得模型推造的固定音色，长寿人物也不会因为真实年龄较大就自动使用老年声线。保存后的实际内容变化才增加档案版本，可明确清空。

H3与Seedance的新生成读取人物声音资料，把稳定声线与本句冷淡、愤怒、强硬等表演区分；声音描述位于原有正文、台词之外，不新增格式字段或章节。自然发话时长与必要停顿参与排程，固定已确认时间不擅自调整，也不通过删词和赶话消化不足。

## 参考音频与已有项目

支持音频的RunningHub工作流可按本段真实说话人继承样音，已有项目声音预设和本段单独设置优先。Seedance使用自身的音频引用语法，H3按实际媒体保持对应格式。生成区显示当前连接的音频能力与已选声源；不支持的第三方接口仍使用文字声音要求，不会把样音标成已提交或已锁定。

声音资料变化用于后续主动生成，不改写历史中英文提示词、旧任务和已生成视频。翻译、参考更新及旧任务冻结重试继续保留原确认声音。旧项目无需批量迁移，删除样音时只解除当前引用并保留声音文字。

## 使用方法

先为需要修正的角色保存声音档案，再主动生成新的H3或Seedance提示词，检查逐句声音与对白时间后生成视频。已有视频要改变声音，需要新生成或独立换声处理；本版本没有集成第三方语音合成、自动成片换声，也不会自动调用这些服务。

文字说明和参考样音仍受视频模型能力影响，不能保证每次生成的音色完全一致。

## 验证与交付

声音档案的4组规范化与保存重载测试、2组语义计划冻结与样音删除测试，以及声音事实传输、来源指纹、新生成与保真操作权限、H3和Seedance格式的定向检查通过。音频选择与引用24组测试通过，另验证多处音频插入保存重载可逆、mock上传恢复、稀疏音频槽、H3参考更新和旧任务冻结重放。

使用本次生产构建在1366×1000隔离浏览器中完成声音档案的保存、刷新恢复、相同内容不增加版本、修改音色增加版本、清空后刷新不恢复。历史提示词与旧视频快照保持不变，生成API请求、外部HTTP尝试和页面错误均为0，没有读取真实项目数据。

打包流程中的TypeScript类型检查、Vite生产构建和Windows便携包生成通过，保留已有分包循环与包体大小提示。未追加全量界面与功能回归，也未调用付费视频生成进行音色试听；最终声音效果仍需在所用模型上验证。
