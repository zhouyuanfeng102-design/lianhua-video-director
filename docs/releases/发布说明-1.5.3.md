# 莲华视频导演台 1.5.3 发布说明

修复分镜图片转换时人物朝向、身份展示与镜头取景互相冲突，以及旧生成图自动影响下一张构图的问题。

## 画面规则

- 先理解当前镜头所选时刻的机位、景别和裁切，再描述人物身体朝向、具名视线对象、动作目标与可见外貌。允许自然回头、侧脸、背面和局部特写，不强制身体、头、眼睛和武器保持同一方向。
- 首帧采用第一镜起始机位，尾帧采用最后一镜运镜终点。结尾若落在握柄或战靴特写，就保留该局部，不为了展示人物恢复成双人全景。
- 分镜图不再套用“完整主体优先”的通用构图要求；只使用当前裁切中可见的身份特征。明确看镜头或主观镜头仍可按剧情表达。

## 参考图

- 同一镜头自动生成的分镜图、首帧和尾帧不再跨用途自动回流为构图参考；明确选中的历史图片仍可使用。
- 不把参考资产保存的整段旧提示词、旧构图锚点重新塞进转换资料，避免重复旧的朝向错误。
- OpenAI 兼容接口的自然语言生图提交按实际上传顺序说明每张图片的人物归属及用途；人物图主要保持身份、外貌与服装设计，姿势、视线与裁切服从当前镜头。未绑定图片继续可用。标签格式和工作流接口保留自身输入方式。
- 普通重试若实际参考图发生变化，仅刷新本版程序附加的参考顺序说明，保留 AI 生成的画面正文，不额外调用文本模型。

## 旧图怎么重新生成

直接使用资产库原有的 **重新生成**，或生成任务原有的 **重新生图**，不增加操作按钮。

分镜图、首尾帧仍有当前来源镜头时，读取当前镜头、当前生图规则和图像 API，重新转换一次提示词后生成一张新图，保留原图、原任务与 H3 视频提示词。会产生新的文本和图像生成费用。旧的自定义静帧描述会舍弃，重新按当前来源镜头选择瞬间。

人物等其他图片继续按原有重试方式处理。来源镜头已删除的旧图片也保留原有存稿重试方式。升级不会自动重画历史图片，也不会批量调用接口。

## 验证与交付

针对性验证覆盖取景与视线规则、自动参考图过滤、实际参考顺序映射、当前镜头重新转换及普通重生兼容。使用隔离合成数据和模拟 API 验证按钮与提交行为，不使用真实付费图像接口；实际模型的画面执行仍需要生成后观察。

交付包含 1.5.3 便携版、恢复源码、更新说明、启动器及 SHA-256 文件，历史版本保留。更新前保存并关闭旧版，保留原目录中的“莲华视频导演台数据”文件夹。

构建：`npm run pack:win`；交付：`npm run deliver:1.5.3`。
