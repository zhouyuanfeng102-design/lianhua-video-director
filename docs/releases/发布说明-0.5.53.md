# 莲华视频导演台 0.5.53 发布说明

## 版本定位

0.5.53 在 0.5.52 的最终视频提示词结构自动返修基础上，收紧逐镜时间与主体身份边界，修复宽泛分镜主体导致合格 AI 返修结果被错误拒绝的问题。历史 0.5.52 及更早交付文件保持不变。

## 锁定逐镜时间边界

- 返修输入明确携带每镜精确起止时间；模型必须原样保留时间标签、镜头数量与镜头顺序。
- 禁止返修过程合并、拆分、重排镜头，或用近似时间替换既定边界。
- 返修结果仍通过与首次候选相同的完整时间轴与六字段结构校验，不能因为进入自动修复分支而绕过验证。

## 稳定主体边界

- 每镜 `allowedSubjects` 作为稳定主体白名单进入返修契约，限制模型只能使用该镜已经声明的真实主体。
- `allowedSubjects` 的主体证据优先使用本地六字段草稿主体，再回退原分镜 `shot.subject`；所得稳定名称才进入白名单，避免宽泛主体覆盖明确人物并误拒合格结果。
- 稳定主体继续要求完整的“主体正在 [动作链]”结构，且不得在镜头间发生无证据改名或身份漂移。

## 自动修复与失败边界

- 首次 AI 结果不合格时，仍把精确错误、不合格候选和逐镜证据交回同一文本模型自动返修一次。
- 自动修复只由 AI 完成，本地代码不拼接、不补写最终视频提示词，也不把本地六字段草稿保存为最终成品。
- 返修仍不合格、返回空内容或拒绝说明时保持原有结果不变，并保留可定位的真实错误。

## 发布验证范围

- 交付前运行完整自动化测试、TypeScript 构建、普通与长剧情 UI 回归以及 Windows 便携版打包验证。
- 新便携包须在隔离数据目录核对版本、schema、保存重载、恢复点、加密能力和多个低高度视口。
- 正式交付包含便携 EXE、恢复源码、更新说明、版本启动器和 SHA-256 校验清单；0.5.52 及更早历史文件不得覆盖。

## 交付

- 便携包：`莲华视频导演台-0.5.53-便携版.exe`
- 交付命令：`npm run deliver:0.5.53`
- 正式交付包含便携 EXE、恢复源码、更新说明、版本启动器和 SHA-256 校验清单。
