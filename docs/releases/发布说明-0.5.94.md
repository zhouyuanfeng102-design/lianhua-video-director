# 莲华视频导演台 0.5.94 发布说明

## 版本定位

本版对照墨色江湖的真实实现，重新整理人物私密档案、私密图片提示词与图像工作台流程。重点是让稳定身体资料、剧情中的动态穿脱状态和模型请求边界各自归位，避免默认服装回填、局部资料串用，以及年龄或否定式控制文字被本地模型当成画面内容。目标便携包为 `莲华视频导演台-0.5.94-便携版.exe`。

## 稳定身体锚点与全身/局部分流

- 每个人物只维护一份长期稳定的私密身体档案，作为同一身份、脸部、发型、肤色、体型和辨识特征的身体锚点。
- 私密全身图使用完整身体资料和头到脚构图；部位图只使用当前指定部位的资料和近景/微距构图，不混入其他私密部位。
- 私密资料图不带默认服装、装备或含服装的普通人物锚点，也不把某一镜的姿势、接触、动作阶段和残留写回常态档案。
- 普通人物参考图和私密资料图继续分开保存、按人物与用途精确引用，避免不同人物或不同资料类型串用。

## 纯正向模型输入

- 私密资料补齐请求中的事实正文只保留肯定式身份与外貌资料，不向本地模型拼入年龄限制、审核措辞、禁止类语句或负面提示词。
- 私密全身图和部位图沿用墨色江湖的正向画面组织方式；最终图片请求不发送 `negativePrompt`，规则集、预设、任务恢复和重新生成路径均保持空负面词。
- 局部生图只携带当前选择部位的稳定资料；普通生图仍使用原有正负提示词规则，不受本次调整影响。

## 剧情解析、补齐与动态连续性

- 剧情重新解析不会因后续普通场景而删除人物已经建立的长期私密档案；资料补齐只填空白字段，并将有效结果写回原绑定人物。
- 手工填写的资料继续优先，补齐失败不覆盖已有内容；切换人物或工作台视图后，已经返回的有效档案仍按原人物归属保存。
- 常态身体资料与逐镜状态继续分离。人物带衣入镜后在镜内脱衣时，视频提示词按“入镜衣物 → 穿脱动作 → 镜尾状态”描述；后续镜头继承镜尾状态，只有剧情明确重新穿回时才恢复对应衣物。
- 裸露范围、具体接触、动作阶段、衣物去向和残留属于剧情连续性，不会污染长期身体锚点；多人物状态分别记录。

## 图像工作台一页自适应

- 人物资料区可直接补齐和编辑私密全身、适用部位资料，并选择私密全身图或对应部位图。
- 左侧资料/提示词和右侧说明/预览使用独立状态；切换说明或预览不会清空当前资料、提示词或任务选择。
- 常用资料、规则、预览和生成操作会随窗口高度与全局字号收紧并显示在一页内，不依赖页面滚动查找。

## 单一安全门禁

私密模型调用前只执行一次本地安全门禁。门禁所需判定仅在应用内完成，不写进私密资料提示词或私密生图提示词，也不作为负面提示词发送给本地模型；这样既保留调用边界，又避免重复审核链和控制文字污染画面。

## 兼容性与交付

schema 保持 22。0.5.93 及更早交付文件、既有项目、私密档案、图片与视频素材、生成任务、模型配置和正式数据均保留；升级不会自动重跑历史任务，也不会覆盖旧版交付。

完成代码核验后使用：

```powershell
npm run test
npm run pack:win
npm run deliver:0.5.94
```

交付应生成 0.5.94 便携版、恢复源码、更新说明、版本专属启动脚本和 SHA-256 清单；现有 0.5.93 及更早版本化产物继续保留。
