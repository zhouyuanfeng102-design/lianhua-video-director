# 莲华视频导演台 0.5.64 发布说明

## 版本定位

0.5.64 是图像工作台分镜选择列表的排版修正版，重点整理长描述和多镜头场景下的列表结构与操作区。保留 0.5.63 的分镜图片方案/版本命名、所选生图规则、旧重名兼容和生成过程保护，不改变已有图片、提示词或项目数据。

## 分镜列表排版

- 每个镜头独立占一条列表行，避免多个镜头及长描述挤在同一行。
- 勾选框和镜号保持固定位置，长描述使用剩余宽度，并仅在所属条目内换行。
- 镜头较多时在限高列表内独立滚动，列表不会无限向下撑开。
- 操作区与镜头列表分开，长描述不会把操作按钮挤散。
- 选中条目有清晰状态，便于确认本次要生成的镜头。

## 保留与兼容

- 镜头顺序、勾选生成、规则集与分类预设选择继续沿用现有流程。
- 方案编号、同镜重复生成版本号、旧自动重名修复，以及跨入口互斥和过期结果绑定保护继续保留。
- 本版不迁移或改写镜头正文，也不要求重新生成已有图片。
- 0.5.63 及更早历史包保留，项目数据目录继续使用原有位置。

## 交付

- 便携包：`莲华视频导演台-0.5.64-便携版.exe`
- 交付命令：`npm run deliver:0.5.64`
- 正式交付包含便携 EXE、恢复源码、更新说明、版本启动器和 SHA-256 校验清单。
