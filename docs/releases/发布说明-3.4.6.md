# 莲华视频导演台 3.4.6 发布说明

发布日期：2026-10-30（亚洲/上海）。

## 百万像素分镜图按原值提交

Qwen Image 2.1 等多参图工作流把分辨率绑在百万像素字段、把画面比例绑在比例字段，宽高可以不绑。分镜图选择 1K、2K 或 4K 时，提交保留该百万像素原值，例如 `2.0000000000000004`，不换算成 1024、2048 或 4096。

分镜比例写入已经绑定的比例选项。`16:9` 写成 `16:9 (Widescreen)`，`9:16` 写成 `9:16 (Portrait Widescreen)`。比例选项对不上时，仍提示没有唯一选项。

宽高都没算出时，不再把 `0×0` 报成「短边不足 64 像素」。按分镜比例实际算出的短边小于 64 时，仍提示提高分辨率或改用自定义尺寸。自定义像素仍要求工作流绑定宽高。

不新增校验、重试或按钮。已生成的图片和已保存的工作流原值保持不动。

## 版本定位

本版 Windows 便携包为 `莲华视频导演台-3.4.6-便携版.exe`。构建命令为 `npm run pack:win`，交付命令为 `npm run deliver:3.4.6`；交付同时生成恢复源码、更新说明、专属启动器和 SHA-256 清单，已有版本文件保留。
