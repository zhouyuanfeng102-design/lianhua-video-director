# 莲华视频导演台 3.8.7 发布说明

发布日期：2026-11-06（亚洲/上海）。

## RH 网页按模型选择器填写 LoRA

网页上的 lora_name 是模型选择器，不是文本框。名字和软件里保存的文件名已经一致时，生成时保持页面上的选择。需要更换时，打开模型列表搜索并点「立即使用」。旁边的 strength_model 写入对应的数字框。

3.8.6 里这次失败发生在点击运行之前，任务没有提交。

## 版本定位与交付

Windows x64 便携包：`莲华视频导演台-3.8.7-便携版.exe`。构建命令为 `npm run pack:win`，交付命令为 `npm run deliver:3.8.7`；3.8.6 及更早历史版本文件保留。

## 验证

- Windows x64 便携包：`npm run pack:win`
