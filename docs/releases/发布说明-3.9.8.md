# 莲华视频导演台 3.9.8 发布说明

发布日期：2026-11-07（亚洲/上海）。

## 已安装的门窗抽屉留在原处

下次生成提示词时，已经装在墙、门洞、窗洞或柜体上的活动部件保持原来的安装。门框、窗框、铰链和滑轨留在墙或柜体里。门扇、窗扇、闸门、柜门、抽屉和盖子只绕原来的轴转动，或沿原来的轨道滑动。

杯子、信、武器和其他本来就能拿起来的物件仍按取放写。原文明确写了拆下、卸下或砸离安装位时，部件才离开原来的轴或轨道。

这条规则进入剧情编排、镜头承接、时长安排、H3 正文和英文翻译。已保存的提示词和已经生成的视频保持原样。要看到新写法，需重新生成对应段落。

## 交付

- Windows：`lianhua-video-director-3.9.8-windows-x64-portable.exe`。
- Android：`lianhua-video-director-3.9.8-android.apk`，最低 Android 8.0 / API 26。
- 3.9.7 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:3.9.8`。本版是共享提示词规则，EXE 与 APK 一起交付。
