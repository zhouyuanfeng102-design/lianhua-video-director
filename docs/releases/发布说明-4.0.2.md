# 莲华视频导演台 4.0.2 发布说明

发布日期：2026-11-07（亚洲/上海）。

## 画面风格仍写在第一镜开头

已选的画面风格没有取消。三字段 H3 仍把这一句写在 `[Shot 1]` 正文开头，只写一次，例如「画面风格：3D电影CG写实……」。这句只写色彩、材质、光影和质感，不写成配乐。

没有用户明确要求配乐时，`non_diegetic_music` 仍只写 `N/A`。有首帧图时，先写这一句画面风格，再从画面里已经在的人和物接着写动作。

已保存的提示词和成片保持原样。重新生成该段后，`[Shot 1]` 开头才会出现这句画面风格。

## 交付

- Windows：`莲华视频导演台-4.0.2-便携版.exe`。
- Android：`莲华视频导演台-4.0.2-安卓版.apk`，最低 Android 8.0 / API 26。
- 4.0.1 及更早的交付文件保留，不覆盖、不重编号。

常规构建 `npm run pack:all`，交付 `npm run deliver:4.0.2`。本版是共享提示词规则，EXE 与 APK 一起交付。

## 验证

打包流程自带类型检查和前端构建。未把已有成片重新生成。
