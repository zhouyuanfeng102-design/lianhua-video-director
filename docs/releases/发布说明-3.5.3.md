# 莲华视频导演台 3.5.3 发布说明

发布日期：2026-10-30（亚洲/上海）。

## 同一人一镜只有一个身体

带参考图的新视频稿写明：本镜每个已写姓名的人只有一个身体，只站在这一镜正文写的那一个位置。多视图、开场构图和通用参考里已经出现的同一个人只提供外观或场面，不在画面里再复制一个。摄影机模拟某人的视角时，这个人不再作为第二个身体画进同一镜；机位在他身旁，或他留在画外作为视点。

英文写成 each named person in this shot has one body, standing only where this shot places them。

这是共用规则，不改某一条已经保存的提示词。已生成的视频保持原样。下次重新生成才会用新写法。不新增校验、拦截、重试或按钮。视频模型仍可能偶发重复人物，这条规则用来压低这个概率。

## 版本定位

本版 Windows 便携包为 `莲华视频导演台-3.5.3-便携版.exe`。构建命令为 `npm run pack:win`，交付命令为 `npm run deliver:3.5.3`；交付同时生成恢复源码、更新说明、专属启动器和 SHA-256 清单，已有版本文件保留。
