# 莲华视频导演台 0.8.5 发布说明

## 版本定位

本版从分镜规划、对白动作时序和人物参考绑定的源头改进多人说话错位问题，按十进位从 `0.8.4 → 0.8.5` 更新。沿用现有AI调用阶段，不增加新的审核服务或本地语义门禁。

## 本次修复

- 分镜规划先为完整原话、停顿、换人交接、口部动作及反应安排可执行时间，再按剧情信息选择镜数与镜长；不先把每段固定成一镜后硬塞事件。15秒是分段时长，不是镜头数量，一段可包含多个有叙事理由的镜头，也保留本来合理的连续单镜。
- AI在新生成全片总规划时若判断原估时不足，可以同步返回完整扩时估算；新的总时长必须是用户所选分段秒数的整数倍，不留最后几秒的短尾段。该权限只用于新的全片总规划，不向普通单段、已确认片段或已有成片扩散。
- 逐句明确完整姓名、唯一声源、原语言原话和发话起止区间，不用固定字数/语速公式压缩，也不把长句堆到最后几秒。前句结束后再接下一话轮，原剧情明确抢话、重叠或齐声时仍保留原安排。
- 亲吻、喝水、进食等口部动作与有声口型按剧情安排合理先后；走路或手势等可与讲话并行，不把所有动作一刀切为串行。非说话人物保持自然倾听和表情，不代说、不做对应台词的说话口型。
- H3保持三字段或完整参考六字段的既有章节、顺序、镜号、切点及对白标签。人物定义只承担静态身份说明，同一次剧情动作只在镜内时间执行段写一次，减少先在介绍演一遍、再按时间点重复执行的歧义。
- 每句对白紧邻完整姓名及既有S声源ID；Picture图片槽编号、Subject人物编号和S声源编号互相独立，不根据相同数字、左右位置或换图顺序猜说话人。
- 画面左右、人物自身左右及接触部位按同一机位保持自洽；用稳定身份确定说话人，不反过来按“左边的人”猜身份。只补充必要定位，不重复堆叠矛盾的左右描述，也不声称分析过未提供像素的尾帧。
- 尾帧＋人物参考读取图片实际槽号及明确绑定的人物资料姓名，同图多人关系照原绑定保留；没有明确姓名时不凭文件名发明新角色。身份说明仍属于视觉资料，不得朗读成名单或新增台词。
- 移除曾被裸插到首镜的Picture标签串式修复基准。选中参考标签作为协议元数据传递，AI在原有H3字段中把各图片与姓名、Subject或开场职责自然关联；空槽不压缩、人物和声源不重编号。
- 已确认稿的转换、英文翻译、参考绑定和衔接修复继续服从该阶段边界，保留原镜界、时长、逐字对白与既有声音方案，不借新规则重做旧剧情。仅新增和主动重新生成的结果应用本版规则，不自动改写旧提示词、任务、图片或视频。
- 不新增模型审核轮次，不用本地口型/关键词规则否决AI语义，也不本地重写AI正文；必要的已有结构修复仍由AI返回完整正文。
