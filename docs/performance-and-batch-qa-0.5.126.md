## 实际验收记录

- 完整npm test通过；新增主进程保存/关闭、前端编码/FIFO恢复、视频runtime/合并轮询/缺失任务、图片多提交和尾帧整体替换回归均纳入。
- 73MiB合成状态：原完整saveStateAsync测到renderer最长间隔5462ms；加入前端编码Worker后完整保存3723ms、最长间隔419ms、快照捕获104ms。独立真实Electron/asar纯编码约514ms、最长间隔63ms。主进程worker另测持续心跳，最长约84ms。均是隔离合成数据，不代表所有设备/工作流的固定耗时。
- 视频重复1000条相同事件只解析1次workflow，不再反复更新状态；普通步数/字节变化只在runtime显示，不写整库。6任务同一连接只请求1次queue。长期缺失任务保留unknown防重并暂停本地查询，恢复不POST。
- 实际关闭验证：创建项目后未等180ms自动保存即请求关闭，最新名称写盘；模拟保存失败窗口保留并解锁，恢复真实保存后再次关闭成功。恢复包装等待旧编码/保存完成，锁定恢复期间旧写入，同步采用恢复状态后解锁。
- 生图真实隔离UI：甲3、乙4、同人两个部位3/4共14任务，上一张未结束仍能提交；模拟一张失败，其余13张保存，仅4次转换。8张上限、缩略图选择、排队取消删除、刷新自动重发0均通过。
- 尾帧真实界面：3参考图→Comfy单槽及单图API可直接整体替换；关闭不改、取消恢复3图、批量两后段、中英切换、旧素材不删均通过。
- 1120×720、1280×800及100/130%字号的多图结果与替换确认检查通过。使用静态中性色测试素材，不调用真实收费接口，不修改正式项目。
- 0.5.126便携包启动烟测通过：保存、重载、恢复点、内置媒体工具、要求窗口尺寸和consoleErrors检查通过。包内33个前后端构建文件与本次验证源码/产物逐文件一致，包含独立前端编码worker。
