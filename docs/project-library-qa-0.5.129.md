# 项目库创建时间排序验收

范围：项目库按创建时间从新到旧排列，卡片显示“创建于”；保存/编辑不改变排序，缺失日期不冒用当前时间。不改剧情、素材或删除行为。

检查：创建时间与更新时间相反的项目；同一创建时间稳定排序；切换旧项目后自动保存；重载保持；缺失/非法日期；选择/取消全选不改变项目；1120×720与1280×800、放大字号下时间/项目名/删除按钮无重叠。

使用隔离模拟项目，不读取或写入正式项目数据，不实际删除素材，不调用收费接口。

追加范围：最终视频提示词转换的本地人物名单/内容匹配硬门禁取消，全文由AI同请求自检修正。验证新主体别名、对白与风格变化不触发隐藏返修；真实结构错误最多一次全量AI修复；已确认稿不由本地对白规则重新请求或改写；日志明确本地结构/上游HTTP来源。继续保留取消、过期响应及跨项目写回保护。
