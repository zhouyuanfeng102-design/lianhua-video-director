# 语义分段段数协议修复（2026-10-01）

状态：已纳入 V1.0.6，便携包实际启动、保存及重载验证通过；验收详情见[发布说明-1.0.6.md](releases/发布说明-1.0.6.md)。历史 EXE 和用户数据保持不变。

## 问题

模型原本需要同时填写 `segmentCount` 和 `segments`。两者不一致时，本地结构解析会要求模型修复；错误只说两个字段必须相等，没有给出实际数字。展示层又把这些字段误当成未知英文服务错误，掩盖了原因。

仅凭这类错误不能断言剧情缺失，也不能断言只是计数写错；不应在本地静默修改计数后接受一份可能缺段的计划。

## 修改

- 新模型输出根字段为 `reason`、`fitStatus`、`segments`，不再重复要求 `segmentCount`。
- 内部段数由完整解析后的数组长度得到。模型决定每段剧情和边界；本地仅生成标识、编号和固定时长窗口，不补写、复制、裁切剧情。
- AI 适配模式仍由模型决定实际段数，总时长始终为实际段数乘以用户选择的单段时长。
- 自定义总时长模式核对实际数组数量是否等于总时长除以单段时长，不允许一个正确的旧计数字段掩盖缺段。
- 兼容旧格式的一致计数；矛盾计数交给原有最多三次自动修复，保留完整原文及最近失败回答。规则要求模型先辨明错数还是漏段，再交完整新格式，不能仅删除计数掩盖缺失。
- 数量矛盾显示“AI 声明几段、实际返回几段”；固定预算错误显示所需段数、总秒数、单段秒数和实际段数。
- 展示层只识别明确的本地结构诊断，保留字段原因与重试次数；未知上游英文和敏感内容仍沿用既有处理，不全局放行字段名。
- 不增加独立 AI 审核调用或本地剧情门禁，不改变 H3、图像规则、历史计划或已有媒体。

## 验证

- 解析器：29 组；覆盖无计数、旧格式矛盾、固定预算缺段/多段、完整数组上限、非整数时长倍数、包装 JSON 和截断。
- 分段服务：46 组；覆盖完整原文/最近回答传递、新格式自动修复、连续失败、截断恢复、取消及固定预算。
- 全部分段回归、错误摘要/详情/复制脱敏回归、文本服务回归通过。
- 实际应用回调模拟验证：无计数正常生成、旧计数矛盾自动修复、连续四次失败不覆盖旧结果；同一界面再次点击可重新生成，不遗留忙碌状态或请求锁。
- H3 协议与运行错误日志脱敏、持久化回归通过。
- 严格类型检查、生产构建、分包体积及生产入口冷启动测试通过。

所有模型响应均为隔离模拟；没有调用真实付费 API 或读取、修改用户正式项目。测试验证协议、重试和保存边界，不代表真实模型永远不会漏写剧情。
