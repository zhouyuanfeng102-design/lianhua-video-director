# 安卓安装、更新与备份

当前版本：**4.5.8**，2026-11-12（亚洲/上海）。安装文件：`lianhua-video-director-4.5.8-android.apk`。最低系统为 Android 8.0（API 26）；设备需有可用且兼容现代网页功能的 Android System WebView，系统版本较旧时应先更新厂商提供的 WebView。安装门槛不表示所有出厂旧 WebView 都已通过测试，实际设备兼容范围以同版“能力与验证记录”为准。

## 安装与开始使用

1. 将 APK 保存到手机，在系统文件管理器中打开。如果系统询问，允许本次用于打开 APK 的浏览器或文件管理器安装应用，然后按系统提示安装。
2. 打开“莲华视频导演台”，在 API 设置中填写自己使用的文本、图片、视觉或视频接口。
3. 新建项目或导入已有 `.lhvd` 项目包，选好章节后继续剧情、导演、素材及生成任务流程。

手机使用底部导航切换主要页面，更多页面从菜单进入。编辑长文本时页面可滚动；返回键先关闭当前面板或返回上一页，再执行退出前保存。无需安装 Node.js、Java 或 Android Studio。

## 更新

保存当前项目后，下载新版本 APK 并直接覆盖安装。同一包名和正式签名的更新会保留应用数据。若系统提示签名冲突，先核对 APK 来源和版本；不要为解决冲突直接卸载已有应用。

应用的项目数据保存在手机应用私有目录，不在下载 APK 的文件夹中。卸载、系统“清除数据”、换机或恢复出厂设置会移除这些本地数据，应提前导出备份。

## 备份与电脑互传

在软件中导出包含素材的 `.lhvd` 项目包，通过系统文件选择器保存到自己选定的目录，再复制到电脑、移动存储或备份位置。另一设备导入整个项目包；不要只移动索引 JSON，也不要仅复制某一张参考图。

项目包用于项目和素材转移，不同步设备登录和 API 密钥；在新设备重新配置服务。Windows 密钥由 Windows 系统加密，Android 密钥由 Android Keystore 加密，不能直接复制两端密钥文件代替重新配置。

## 连接与任务

外部服务需要手机能访问配置的服务器。手机里的 `127.0.0.1`、`localhost` 指向手机自身，不能用来访问电脑上的 ComfyUI；访问电脑服务应使用其可达地址，并按软件现有设置开启相应局域网访问。

云端已提交任务的状态和任务号随本地存档保存。系统可能暂停或结束后台应用，持续执行能力受 Android 与厂商系统限制；恢复后按原任务状态继续操作，避免对已在服务端运行的任务重复提交。Android 实现范围和已有检查边界见[Android 能力说明](android-capabilities.md)及[4.5.8 能力与验证记录](releases/能力与验证记录-4.5.8.md)。

## 文件与权限

导入文件、选择素材或导出项目时，使用 Android 系统文件选择器选择目标。仅为当前操作授予系统要求的权限；取消选择不会删除原文件。请保留完整项目包备份，并在重要编辑后确认软件保存状态。
