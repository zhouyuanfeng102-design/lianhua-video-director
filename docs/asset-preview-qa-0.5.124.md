# 0.5.124 验收清单

范围：视频资产库静态缩略图/点击单视频播放；删除图像工作台普通角色“参考图”构图快捷项；修复侧栏自适应闪动。只使用隔离目录与合成媒体，不改正式项目、不调用收费接口。

- 视频库打开/翻页/搜索：卡片仅静态图，页面video数为0；缩略图可见时排队生成且缓存，失败保留图标，不创建播放器兜底。
- 播放A→关闭→播放B：恰好一个播放器；关闭/Escape/离开视频库/切项目后为0，旧播放器暂停、清src并load释放资源。
- 播放或封面异步回调：同id文件替换、缺失及跨项目不错误写元数据或展示旧封面；旧视频内容不改。
- 图像工作台：角色规格只有头像/半身/全身/四视图；上传新图、资产库选择与“作为参考图”功能保留；旧reference快照兼容。
- 侧栏：1120×720、1280×800及边界高度，100/130/150%字体，启动/缩放/报错栏变化后持续采样120帧，稳定后scale与卡片bounds不振荡、自身style不持续写回；底部入口无遮挡。
- 真实浏览器和桌面高DPI分别检查列表、播放弹窗、构图按钮和侧栏；至少探索损坏媒体/工具缺失、快速切项目或翻页两类非正常场景。

## 已执行结果

- 完整npm test通过，包含真实FFmpeg封面、缓存变更/取消/进程超时故障注入、播放资源释放、旧图像规格和侧栏回归。
- 原生225%DPI桌面中，6个视频卡片生成6张真实静态首帧，video元素数为0；点击后1个且实际进入播放，关闭后0个，原元素paused=true/src已移除。
- 切换两个视频、Escape和点击遮罩关闭通过；普通角色只有头像/半身/全身/四视图，“从资产库选择参考图”仍能正常打开。
- 初始1270×765，以及1120×720在100/130/150%字号、1280×800在130%字号，稳定后均连续120帧只有1种卡片尺寸，style变更数0，侧栏底部未越出窗口。
- 测试仅使用隔离数据/合成视频，没有读取或覆盖用户项目、没有真实收费API调用。旧0.5.123 EXE校验未变。
- 独立浏览器无桌面封面服务时仍为0→1→0播放器；增减错误提示后侧栏继续120帧稳定，style写入0。新0.5.124便携包隔离启动、保存重载、恢复点、内置工具和所需窗口尺寸烟测通过，consoleErrors为空。
