# 生图转换器的具名身份输出

本次要求：最终图片提示词正文包含输入已明确的作品／世界观和人物姓名，由现有 AI 转换器在同一次转换中自然组织。禁止在最终输出或图片提交阶段本地拼接姓名、作品前后缀。

## 实现范围

- 通用转换规则及实际转换入口共享身份要求，覆盖普通、GPT 微 NSFW、私密、SD、NovelAI、Krea、ComfyUI和自定义规则；保持原规则库、NSFW条款、可见外貌和目标格式。
- 身份来源作为独立 `conversionIdentityContext` 输入。原画面 `conversionSource` 仍独立决定内容路由，其他场次的资料不会触发本图的 NSFW 分支。
- 资料由人物完整姓名／形态名、项目说明、原文标题及有界原文摘录组成。作品识别交给本次转换 AI；未知归属不本地猜测，项目名不直接当作品。
- 分镜使用该分镜保存的原剧情作为优先证据，不混入编辑器中下一份未提交草稿。工作台尚未保存的新剧情仍可作为新建人物图的来源资料。
- 新任务冻结身份资料，保存、加载及需要重新转换的重试沿用快照。已保存最终提示词的普通旧任务仍原样复现，不自动改写历史结果。
- 仅升级已有 GPT 微 NSFW 分镜转换缓存的版本及身份来源指纹。普通直接图生图仍不增加文字转换请求，H3视频提示词、选图按钮与图片数量机制不变。
- 不增加姓名缺失门禁、语义审核请求或专门返修。原有技术格式返修沿用同一份资料。错误回显只做展示脱敏，保留错误原因和状态码。

## 验证入口

`npm run test:image-named-identity` 包含转换器→图片请求的模拟链路与来源／重试持久化检查。另执行 image-rules、image-rule-app、llm、nsfw-private-assets、image-generation、storyboard-images、storyboard-image-to-image，以及严格类型、生产构建和分块／启动检查。

测试均使用中性合成资料与模拟接口，不读取用户项目或API密钥、不进行付费请求。模拟测试验证规则传递、最终正文传输及没有本地硬拼；不代表真实模型每次都百分之百遵循语义要求。

本改造随 1.0.4 发布；构建、隔离便携包验收和交付校验记录见[发布说明-1.0.4.md](releases/发布说明-1.0.4.md)。

## 1.0.5：具体作品归属的源头修正

用户实际反馈显示，1.0.4 转换正文会写“游戏世界”“她原本的剧情世界观”，或者只有“人类女性蒂法”。原共享合同把作品归属过度限定为输入逐字写明的事实；来源包装再次强调“仅提取已明确”，普通入口又仅要求可见事实。规则没有说明泛题材词不算具体作品名，且此前模拟回复直接预置正确作品名的测试只能验证传输，未覆盖这一规则缺口。

- 同一次转换明确区分具体作品／系列／专有世界名与泛称。可靠识别为蒂法·洛克哈特时，AI 自然组织“《最终幻想7》（Final Fantasy VII）的蒂法·洛克哈特……”；这是一项转换规则，不是本地姓名映射表或结果前后缀。
- 作品未字面写出时允许依据明确姓名、别名、稳定角色特征及可靠已有角色知识识别具体出处；明确原创、自定义与同名不同人的资料优先。不确定时只表达已知事实，不猜作品、不用泛称冒充出处。作品归属不覆盖用户所选场景、服装或形态。
- 请求时精确移除旧 1.0.4 共享合同，再注入当前合同，避免冻结快照继续携带相反限制；不改写已保存的规则、最终提示词、项目或任务。
- 独立身份上下文补入当前所选人物的普通档案原文；不带私密档案、图片资产或未选人物。机械摘录优先保留作品／出处／世界观标记及书名号附近原文，避免前部重复人名、长说明和长标题挤掉后部具体归属。整体仍限 12000 字符，分镜已保存原文优先。
- 既有 GPT 微 NSFW 直接分镜转换缓存升级到 version 3，避免新转换任务复用 version 2 的泛称结果；普通直接图生图的路径与缓存保持原样。历史普通任务已有最终提示词时，“重新生图”仍复用其原文，不偷偷调用 AI 改词；新规则用于新转换任务。
- 不新增本地身份校验、语义审核、重试阶段或 AI 请求；NSFW 内容条款与 H3 视频格式不改。接口返回的 HTTP 400 内容拒绝是独立问题，保留原错误，不以身份规则改造绕过服务端拒绝。

新增请求级回归覆盖明确作品、未明写作品但身份可识别、泛称、原创同名、线索不足、跨作品、全身／五视图／私密及三种格式，并验证旧合同只在请求中替换、历史数据保留及结果不被本地硬补。测试使用模拟接口，只证明规则与资料传递和调用边界，不冒充真实模型语义验收。1.0.5 的发布验证见[发布说明-1.0.5.md](releases/发布说明-1.0.5.md)。
