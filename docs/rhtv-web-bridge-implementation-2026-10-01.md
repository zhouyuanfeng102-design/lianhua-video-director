# rhTV 本机桥接实施记录

初始日期：2026-10-01。更新：2026-10-02，版本 1.1.2。基于 `rhtv-web-bridge-plan-2026-10-01.md`；历史发行文件保留。

## 当前交付边界

已实现独立 Edge 自动上传、提交、查询、下载和导入链路，默认关闭。**本地模拟测试通过，真实账号端到端联调尚未验收。** 不能把代码实现或模拟测试等同于 rhTV 实际生成成功。

- 视频 API 提供独立的 `rhTV 网页桥接（本机）` 连接，保留原 RunningHub/API 设置。稳定路由标识 `http://rhtv.localhost` 仅用于桌面 IPC；worker 使用随机回环端口和认证令牌。
- 使用 `playwright-core` 管理独立 Edge 登录目录，不依赖 ChatGPT/Codex 浏览器扩展，不读取日常浏览器 Cookie。首次登录、验证码和异常确认仍由用户完成。
- “仅零费用自动提交”持久化保存，默认关闭。启用前明确确认素材上传、生成和平台自动化使用权限。关闭后不再自动发起新任务，但不伪造已提交任务的取消。
- 文生、首帧、首尾帧和全能参考分别校验数量及用途。原图通过专用 IPC 暂存，保留 SHA-256、原槽位、资产与人物绑定。网页实际附件数组使用连续 Picture 编号，并对应回原槽位；首尾帧使用明确角色，不混用多人物 Picture 引用。
- 自动流程校验模型、模式、完整提示词、本机上传原文件、附件名称/数量/顺序、首尾帧位置、时长、比例和分辨率。1.1.2 移除未经证实的 10 MB、3600 万像素门槛，允许网页处理图片；预览可能压缩或使用 blob/CDN 地址，不再要求其字节等于原文件。准备后预览被替换仍暂停。提示词只规范化换行符，不重写剧情。
- 在实际 `/canvas/task/run` 请求边界拦截核对 canvas 和附件，用同一请求的账号/团队上下文取得本次 H3 报价；仅有效且为零时放行。先持久化提交边界，再最多发送一次请求，不自动重试 POST 或跳转。
- 持久化本机 clientId、网页任务 ID、提交边界、报价及状态。回执未知、重启或断连不重新生成；有原任务 ID 时只恢复原任务查询/下载。没有原任务 ID 的未知提交需人工核实。
- 从原任务结果提取成片链接，不拿缩略图当视频。下载仅允许公共 HTTPS 地址，各级跳转复查，不向 CDN 转发登录凭据；校验声明/流式大小上限、FFprobe 视频内容及 SHA-256 后交回项目素材库。下载失败最多自动重试三次，之后需显式继续原任务。
- 人工准备网页和导入原任务成片继续作为兜底。已拿到网页任务 ID 的任务不能再标记“未提交”；核实失败/取消与核实未提交分开。

## 使用步骤

1. 保存并关闭旧版后启动 1.1.2，或在源码目录运行 `npm run desktop`。旧 EXE 不会自动更新。
2. 进入“API 设置 → 视频生成 → 视频 API”，选择“rhTV 网页桥接（本机）”，设置默认模式、4–15 秒整数时长、分辨率及比例。
3. 启动桥接，点击“Edge 登录 rhTV”，在独立窗口自行登录并处理平台验证。此窗口与用户日常 Edge 的登录目录不同。
4. 确认平台允许账号自动化和素材上传后，启用“仅零费用自动提交”。费用不明或非零会暂停，会员限免不等于长期免费，报价也不保证平台最终锁价。
5. 在原视频导演台选连接、提示词和参考图创建任务。正常链路由程序准备、核验、提交并取回结果；出现暂停时查看原网页和任务状态，不能以重新生成代替原任务恢复。

浏览器预览只展示设置界面，不能启动桌面 IPC 或本机桥接。不支持仅填写网页 URL 就获得官方 API Key；此桥接也不是官方 API。

## 停止与队列

1.0.3 将本机并发和远端证据分开处理。明确“停止跟踪”的任务不再占软件并发，包含其他项目和重启恢复的旧任务；仍保留原任务编号及提交记录，恢复只查询原任务。未停止的未知提交继续计数，避免自动重复提交。

rhTV worker 内部仍采用单账号串行。尚未解决的实际网页提交保留其原任务恢复边界；释放软件调度名额不代表平台已取消任务，也不绕过 rhTV 自身限制。停止桥接后不会被后台查询自动重启。

## 未验收与限制

- 真实会员账号的上传、附件映射、首尾帧、零报价、生成、计费、原任务恢复及下载全链路尚未验收。当前调试用 Edge 扩展存在 Codex 授权连接阻塞；不要为此扩大扩展权限。这不等于软件独立 Edge 已通过或已失败。
- 验证码交给用户，不绕过风控、平台计费或访问限制；不承诺活动长期有效。
- 未实现多账号切换、参考音视频、无头与锁屏可靠性、云端素材删除和缓存自动清理。
- 本机缓存上限为原图合计 1 GB、1000 条任务、成片 2 GB；达到上限明确拒绝，不自动删除。1.1.2 取消专用桌面通道单图 20 MB 限制；可选 HTTP JSON 接口仍有 28 MB 缓冲保护，桌面图片使用 worker RPC 不走此信封。上述本地保护不代表网站规则。独立浏览器配置和任务原文保存在当前用户应用数据目录，不宣称全部加密；Cookie 不进入项目 JSON。

## 验证记录

所有生成测试均为隔离合成数据或模拟接口，未上传用户素材、未真实提交生成、未修改正式项目。

- `test:rhtv`：3 个 TypeScript 专项及 38 个 Node 测试，涵盖模式/原图/引用、大图上传和网页预览处理、自动授权、报价和请求边界、单账号串行、原任务恢复、失败下载和人工兜底。
- `test:rhtv-electron`：Electron 41.10.7 的 ASAR 运行库加载、23 MB 合成原文件经 worker 上传后字节一致、worker 启停及原任务恢复；不打开真实浏览器。
- `test:video-execution`、`test:video-generation`、`queuedTaskActions.test.ts`：跨项目旧停止记录不占位、两条运行后第三条启动、第四条继续排队、重启与恢复不重投、批量和前驱尾帧依赖、删除保护。
- 严格类型检查、桌面下载安全与大小限制回归通过。当前大图修复的构建和交付验证以[发布说明-1.1.2.md](releases/发布说明-1.1.2.md)为准，历史队列专项记录见[发布说明-1.0.3.md](releases/发布说明-1.0.3.md)，不复用旧版 EXE 烟测结论。

完整实站验收仍须在用户授权的账号与素材范围内逐项核对当前零费用、附件身份、实际生成记录和成片，再测试重启不重复提交。没有完成这一步之前，功能保持“实站联调待验收”标识。
