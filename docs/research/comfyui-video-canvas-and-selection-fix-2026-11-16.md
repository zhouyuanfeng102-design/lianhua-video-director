# ComfyUI 视频工作流：画布支持与选择状态修复

日期：2026-11-16。基线：4.6.9。本文记录源码修改，不表示已生成新版本安装包。

## 用户反馈与结论

用户反馈 ComfyUI 生图可用，视频连接也已启用，但长剧情批量页仍显示“请先启用 ComfyUI 并选择视频工作流”。截图中，设置页当前工作流为 `H3-NSFW-3`，识别出 6 个图片槽和输出 364；批量下拉显示 `H3-NSFW`，各段却是 0 个槽，底部为“未选择工作流”。

确认存在两个独立的代码问题：

1. 普通视频草稿保留已经删除或重新导入前的工作流 ID；浏览器下拉框可能显示现有首项，但内部没有对应工作流对象。
2. 生图已经使用共享画布转换器，视频解析入口却直接拒绝包含 `nodes/links` 的画布文档。因此，“必须让用户自行改成 API 格式”并不是完整修复。

用户电脑上的实际旧 ID 没有读取；工作流 ID 失配是从代码确认、且能解释截图三处矛盾的机制，不宣称已经取得该用户的原始存档。

## 1. 普通草稿与实际执行目标一致

新增轻量的 `src/videoWorkflowSelection.ts`，区分执行解析和普通编辑草稿恢复：

- 有效的显式 ID 保留，优先于设置页当前项。
- 执行端遇到明确但缺失的 ID，仍返回未找到，不偷偷换到别的工作流。
- 普通表单的空 ID 或失效 ID，可以恢复到设置页明确有效的当前工作流。
- `activeWorkflowId === undefined` 的历史配置沿用原有首项兼容；明确的 `null` 不被当成首项。
- 没有可恢复目标时，显示“原工作流已删除，请重新选择”或真实待选项，避免下拉框假显示首项。
- 已有失败任务、历史重用任务的冻结连接快照不自动换成全局当前工作流。

单段、批量、自定义视频表单复用这一规则。连接恢复走原有参数分区切换函数，旧连接参数先保存在原分区，再恢复目标连接参数。槽数、摘要、下拉值和提交稿使用同一实际目标。

`src/videoBatch.ts` 和 `src/videoGeneration.ts` 统一使用严格执行解析；普通新任务记录真实工作流 ID。将已有的开关、地址和工作流三个失败原因分别说明，没有新增生成检查步骤。

## 2. 视频接入已有画布转换器

`src/comfyuiVideo.ts` 现在复用 `convertComfyUICanvasWorkflow()`：

- API 节点文档继续保持原文，包括未修改的格式和大整数种子字面量。
- 画布根据明确的输入声明、命名控件值、连线和运行模式转成 API 执行图。
- 导入、保存、字段编辑、重新识别和导出在适当边界统一使用规范化执行图，不把原画布当成 API 字段路径直接编辑。
- 管理面板现有导入入口及帮助文案同步说明画布/API 支持，没有新增按钮。

共享转换器补齐附件实际使用的能力：

- `SetNode/GetNode` 按明确保存的常量名称连接到来源，移除前端虚拟连线节点。
- 保留现有 Reroute、旁路和禁用语义。
- `AUDIO_UI`、分辨率预览、上传按钮等界面控件不作为后端输入。
- 自定义节点使用明确的 `input.widget` 与命名值，不按未知位置猜测参数。
- 附件的 Goohai 分组控制节点有真实后端实现，应保留空输入节点；其不序列化的界面控件不发送到后端。

Goohai 后端定义依据其源码中的 `IgnoreGroupsGuHai`、空 `INPUT_TYPES`、`OUTPUT_NODE=True` 和空返回值；不是按中文名称猜测前端/后端类型。来源：

`https://raw.githubusercontent.com/goohai/Goohaitools-comfyui/master/nodes/%E5%BF%BD%E7%95%A5%E5%A4%9A%E7%BB%84.py`

## 3. H3 图片槽顺序

附件启用的图片来源节点为 19、23、43、49、50、51，但 H3 实际 `ref_image_0` 到 `ref_image_5` 的连线顺序是：

```text
51 → 49 → 50 → 43 → 19 → 23
```

新导入时复用 `readH3ReferenceImageOrders()`，按真实的 H3 动态输入连线确定图片槽，避免按 LoadImage 节点编号排序而串图。不重写已保存的工作流映射、提示词或历史任务。

附件纯本地转换结果：

- 100 个画布节点转换为 36 个执行节点。
- 6 个图片槽，顺序如上。
- 提示词入口 `263.text`。
- 视频输出 `364`。
- 执行图不包含 Set/Get、Reroute 或音频预览界面字段。
- 未连接用户的 ComfyUI，未调用模型，未声称实际视频已生成。
