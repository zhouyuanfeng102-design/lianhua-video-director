# 视频设置与工作流管理验收

范围：整理API设置的“视频生成”界面，参考图像ComfyUI的工作流库形式；保留现有视频协议、工作流与运行任务快照。只用隔离配置和合成API JSON，不发起真实生成。

| 功能/状态 | 功能检查与视觉检查 |
| --- | --- |
| 主页面 | 视频API/ComfyUI分卡片；常用连接和当前工作流明确；小窗口无横向滚动或底部操作遮挡 |
| 工作流库 | 导入新增不覆盖、复制不同ID、保存/重命名、设为当前、删除确认、重启仍保留多份 |
| 编辑状态 | 列表选中编辑不等于启用；未保存切换/关闭可取消；空草稿不冒充可生成工作流 |
| 节点和参数 | 提示词/图片槽顺序及用途/输出/参数映射保存；数字、文本、布尔原类型；连线不误覆盖 |
| JSON | 普通保存不重识别手工映射，重识别单独确认；未改的64位seed/音频/图结构原文保留；密钥不导入导出 |
| API高级设置 | 请求体、认证与结果映射、上传取消分栏；模板脏稿确认/冲突保护；Generic/MiniMax/RunningHub字段不丢 |
| 已有任务 | 修改库不会改变已提交任务的冻结工作流/参数；不因切换配置自动生成 |
| 多窗口布局 | 1120×720、1280×800，100/130%字号；真实桌面高DPI；主面及管理器所有分页/确认栏 |

探索：外部配置变化时保存冲突、不完整导入、删除最后可用工作流、JSON无效/连线字段/不同协议切换与未保存退出。
