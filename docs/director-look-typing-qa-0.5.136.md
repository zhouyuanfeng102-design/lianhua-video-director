# 导演自定义要求点击和输入修复（0.5.136）

## 根因与修复

0.5.135 的专用要求框使用 `disabled={busy}`。busy是多个功能共享的前台任务状态，剧情解析、分镜批量生图、AI识图等任务可跨页保持此状态，导致一个仅保存草稿、不直接改变生成参数的输入框也被禁用。

修复前在真实应用中复现：普通空闲状态鼠标和键盘正常；保持剧情解析运行后切回导演台，输入框disabled=true、点击无法获得焦点、键入内容没有进入字段。

移除草稿输入框与全局busy的禁用绑定；分析按钮和分析方法仍等待前台任务结束，并有说明提示。按钮可访问名称仍为“AI 分析填写”，不会被说明文本替代。保持要求按项目保存、空白原行为及过期分析取消逻辑。

## 验收

使用Playwright Interactive，不使用fill作为本次输入签收：真实鼠标坐标点击、逐字键盘输入、中文提交、中途插入/删除及换行。

- 空闲与剧情解析运行中均可获得焦点并输入。
- 解析运行期间AI分析按钮仍禁用，编辑不产生额外模型请求，不改变正在执行的剧情分析请求。
- 解析成功和模拟HTTP503失败后，最新要求均保留，分析按钮恢复；后续分析收到最新要求并回填四项风格。
- 本项风格分析进行中编辑要求仍能输入，旧响应不覆盖新编辑。
- 原生Electron使用独立data目录与本机模拟HTTP服务，确认数据路径后才注入合成项目。在225%缩放、内容区1270×765下，运行剧情解析时实际键入英文、中文和两行要求：disabled=false、焦点保持，AI按钮仍disabled=true。解析结束后要求不丢失，再点击分析完成回填；全链路仅2次本地模拟请求。
- 目检实际成功界面和忙碌时浏览器截图，无新控件遮挡。未改变其他任务的锁定、保存关闭或恢复期间的全局保护。

脚本：`scripts/directorLookTypingUiQa.mjs`。证据：`output/playwright/director-input-136/`。只使用合成项目和本地模拟接口，未触碰正式项目或付费API。
