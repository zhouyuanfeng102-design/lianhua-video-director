仅修改软件设置与调用适配，不执行真实收费请求。用户教程是v2 AI应用；官方工作流页面同时确认工作流v2入口。

| 用户可见能力 | 检查与证据 |
| --- | --- |
| 第三个独立设置入口 | 视频API/ComfyUI/RunningHub分开；各自密钥、开关、当前选择不互改 |
| 多工作流库 | 新建/复制/保存/改名/切换/删除确认/重载，旧条目与运行快照保留 |
| 教程导入 | cURL只解析不执行，长ID不失真、密钥不进模板/导出，AI应用与工作流端点分开 |
| 明确节点映射 | 提示词节点、顺序图片槽、角色、固定参数及输出节点；只改显式映射 |
| 云端运行选项 | 实例/个人队列/可空保留秒数/可选Webhook；费用功能默认关闭且有提示 |

探索边界：未选择工作流、坏JSON、同名重复导入、导入期间其它配置变化、只返回图片/失败夹带URL、缺图片槽、参数含长整数、跨项目迟到回调。
