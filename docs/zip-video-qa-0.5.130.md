| 功能与状态 | 验证 |
| --- | --- |
| 输出识别 | 同节点直接视频优先、其次ZIP；不拿PNG/TXT当视频；失败/运行中不能被URL误判成功 |

| 多视频 | 全部保存到资产库；要求明确选择本任务成片，选择持久化前尾帧后继不能发起 |

| 异常与取消 | 下载/解压/校验/磁盘/项目保存失败保留云端成功含义；只清本次temp；取消/晚到不得复活任务 |
