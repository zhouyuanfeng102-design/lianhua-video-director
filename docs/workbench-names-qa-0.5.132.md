# 视频素材完整名称显示验证（0.5.132）

## 范围与实现

用户圈选视频工作台左侧视频素材卡片，要求名称不省略，可缩字换行。原实现以单行省略名称，并以固定55px行高计算分页。现在素材单独使用实测名称行高分页，不改变时间线、帧列表和历史任务的分页语义。

名称按实际宽度换行，无空格文件名也可折行。常规字号10.5px并跟随全局字体设置；仅当单条过高时适度缩字。200/300字极长样本可采用全宽名称、独立底部操作行。只改变显示，不截短保存的名称，不改视频文件或生成参数。

## QA清单

- 截图同款中文标题、段序号和English后缀；长中文、无空格英文、emoji、短名称混排。
- 逐页检查每条名称的文字Range全部位于卡片与列表内，标题不压元信息，checkbox、封面、加号的尺寸和命中位置有效。
- 全列表遍历不重、不漏、不改变顺序；跨页选择后按顺序追加并保留原时间线。
- 搜索、清空、无结果、筛选选择保留；不改变条数的长短改名重新计算布局。
- 1120×720、1280×800，100%/130%字体；预留真实侧栏与顶栏占用。反复跨断点缩放后检查连续绘制帧无高度/页数振荡。
- 1120×720、130%下额外测试200/300字中文名及底部操作行。
- 原生Electron窗口：启动内容区1270×765，Windows缩放225%；启动时未先调整窗口。通过真实“界面与字体设置”切到130%，再验证1120×720；逐页检查共12页，无卡片或工作台控件遮挡。
