# 可见的全片总提示词三阶段流程设计

## 目标

长剧情规划必须在界面和数据上严格表现为三个不可跳过的阶段：

1. 根据完整剧情和全片时长生成全片总视频提示词/总时间轴。
2. 展示总提示词，允许用户检查、编辑并确认。
3. 只在确认后，按照单段时长从总时间轴切出视频段。

“生成总提示词”和“切段”不能再由一次“分析并拆段”点击暗中连续完成。

## 状态模型

`VideoSequencePlan` 增加持久化阶段字段：

- `planningStage: 'master-draft' | 'master-confirmed' | 'segmented'`
- `masterPromptConfirmedFingerprint?: string`
- `masterPromptConfirmedAt?: number`

`master-draft` 和 `master-confirmed` 阶段允许 `segments` 为空。旧项目中已有视频段的计划在加载时归一化为 `segmented`；没有总分镜的旧计划继续提示重新生成总提示词。

总提示词草稿使用现有 `Storyboard` 持久化，通过 `masterStoryboardId` 与计划关联。这样关闭应用、切换项目或重新打开后，仍可继续检查未切段的总提示词。

## 三阶段交互

### 阶段一：生成全片总提示词

用户先选择全片时长来源并确认总秒数。主按钮显示：

- 未完成 AI 估时时：`估算全片时长`
- 时长已确定时：`① 生成全片总提示词`
- 生成中：`正在生成全片总提示词…`

此操作只创建/替换总分镜和空分段计划，不执行剧情归段，不显示视频段卡片。

### 阶段二：检查并确认

生成后在同一页面显示“全片总提示词”审阅卡，包括：

- 总时长、总镜头数、生成状态。
- 可编辑的结构化总提示词文本框。
- `复制总提示词`、`重新生成`、`确认总提示词`。
- 明确的校验错误；格式或时间轴无效时禁止确认。

编辑时只允许保留原镜头数量；可以修改每镜正文和时间边界。确认时把文本重新解析回总镜头的时间与 `prompt`，校验必须从 0 秒连续覆盖到全片结束。

确认指纹覆盖计划 ID、剧情快照、总时长、总分镜 ID、最终提示词以及每镜 ID/起止时间/提示词。总提示词或相关输入变化后自动退回待确认状态。

### 阶段三：按总提示词切段

确认后显示独立按钮 `② 按总提示词切段`。点击后才执行本地或 AI 剧情节拍归段，并按每段全局时间裁剪总镜头。每段保存 `sourceShotIds`，提示词时间重置为本段 0 秒。

切段完成后显示现有视频段编辑器；用户确认分段计划后进入 `③ 单段导演`。批量生成仍只能复用总分镜，不能从分段剧情重新编稿。

## 总提示词编辑与切片

新增纯逻辑模块负责：

- 从结构化总提示词解析 `【起始s-结束s】` 条目。
- 在镜头数量不变时，把编辑后的时间和完整逐镜文本同步回 `VideoShot`。
- 裁剪跨段镜头并把总提示词时间头转换为本段局部时间。
- 生成稳定的总提示词确认指纹。

分段 `Storyboard.finalPrompt` 直接由裁剪后的总镜头提示词组成。现有镜头字段仍保留用于连续性和资产关联，但不得重新渲染覆盖用户确认过的总提示词正文。

## 失效与恢复

- 剧情、总时长或总提示词变化：清除总提示词确认，禁止切段。
- 单段上限或切分方式变化：保留已确认总提示词，但要求重新切段。
- 总分镜缺失、为空、时间不连续或未覆盖全片：显示具体原因并返回阶段一/二。
- 旧版已切段计划保持可读；旧版没有总分镜时必须重新走三阶段流程。
- 重新生成总提示词会替换旧总分镜，但不删除历史分段分镜，避免误删用户结果。

## 验证标准

- 首屏不再出现“分析并拆段”。
- 生成总提示词后视频段数量仍为 0，页面必须出现总提示词全文。
- 未确认时，切段按钮不可用或不存在。
- 编辑总提示词后，确认状态立即失效。
- 确认并切段后，每段 `sourceShotIds` 来自同一总分镜，局部提示词从 0 秒开始。
- 刷新或重启后可恢复到总提示词审阅阶段。
- 24 秒/8 秒用例产生一个 0—24 秒总分镜和三个局部 0—8 秒分段。
- 完整测试、浏览器流程、打包成品冒烟和 SHA-256 交付校验通过。
