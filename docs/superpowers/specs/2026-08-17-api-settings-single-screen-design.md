# API 设置单屏布局设计

日期：2026-08-17  
目标版本：0.5.2

## 背景与问题

图片 API 功能、配置档、密码本填充和真实出图调用均仍然存在。当前问题来自页面结构：完整的视频任务卡和密码本始终排在模型 API 标签之前，模型标签默认打开文本 API；同时 `.settings-view` 使用自然高度，最终由 `.workspace` 产生整页纵向滚动。用户因此在首屏找不到图片 API，并且必须滚动才能查看后续设置。

## 已确认方案

API 设置页改为一个固定单屏工作区，标题与安全提示下方直接显示五个一级标签：

1. 图片 API
2. 文本 API
3. 视觉 API
4. 视频任务
5. 密码本

首次进入默认打开“图片 API”。每次只渲染当前标签对应的一组详细设置，所有标签始终位于首屏内，不再把视频任务和密码本固定堆叠在其他 API 之前。

## 组件与状态

- 在 `SettingsView` 中引入独立的 `SettingsPanel` 类型：`image | text | vision | video | credentials`。
- 原有 `ApiTarget` 继续只负责文本、视觉、图片三类模型配置档、模型列表和密码本快速填充，不改变数据结构。
- `SettingsPanel` 默认值为 `image`，标签点击仅切换本地展示状态，不修改或迁移用户设置。
- 现有图片、文本、视觉、视频任务、密码本表单及保存处理逻辑继续复用，只调整它们的条件渲染位置。
- 清空密钥、自动保存和底部数据目录说明保持原有行为。

## 布局

设置页使用固定高度网格：标题、安全提示、一级标签占自动高度，活动面板占剩余高度，底部数据目录说明占自动高度。页面本身不得产生纵向滚动。

- 图片、文本、视觉面板沿用紧凑双列表单。
- 视频任务的八个字段在桌面窗口使用四列两行，以缩短高度；较窄窗口仍保持可读字段宽度。
- 密码本保持一行紧凑管理表单。
- 活动面板必须完整落在工作区可视边界内；不通过缩小到不可读字号或裁剪字段实现单屏。

## 数据与错误处理

本次不改变 API 配置的持久化、加密、迁移、出图请求和错误提示逻辑。图片 API 仍支持 OpenAI 兼容与 Stable Diffusion WebUI 真实出图；ComfyUI 和 NovelAI 保持现有“仅保留提示词资产/未接入”提示。

## 验收标准

- 1120×720、1280×720、1280×800 三种窗口下，进入 API 设置后 `.workspace` 无纵向滚动。
- 五个一级标签均无需滚动即可看见并点击。
- 默认首屏显示“图片 API”，且后端、模型/工作流、API 地址、API 密钥、启用开关和配置档操作全部可见。
- 切换文本、视觉、视频任务、密码本后，当前面板完整显示且工作区仍保持 `scrollTop = 0`。
- 不出现横向溢出、遮挡、裁切、控制台错误或框架错误覆盖层。
- 原有设置读写、密码本填充、配置档管理和图片 API 数据不回归。

## 测试策略

1. 先新增失败回归测试，锁定五标签结构、默认图片面板及固定单屏 CSS。
2. 在真实浏览器中验证标签切换、图片表单字段可见性和纵向/横向溢出指标。
3. 在 Electron 桌面环境复测 API 设置页面。
4. 运行完整单元测试和生产构建。
5. 升级到 0.5.2，生成便携 EXE，并对最终交付包执行成品冒烟、版本显示和 SHA256 校验。

## 非目标

- 不新增 API 厂商协议或后端适配。
- 不改变密钥加密机制。
- 不重做全局导航或其他工作区布局。
- 不把五组详细表单同时压缩展示在一个屏幕内。
