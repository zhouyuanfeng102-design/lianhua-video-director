# 0.5.123 自动尾帧衔接验收清单

范围：从零成片启动长剧情批量任务；首段保留用户选图，后段等上一段生成、保存并抽取一张真实末帧后才提交。不使用真实收费接口，不读写正式项目。

| 功能与状态 | 功能检查 | 可见证据 |
| --- | --- | --- |
| 零成片配置 | 第2段“用上段尾帧”默认自动模式，不依赖已有视频；首段禁用 | 自动模式截图及可用确认按钮 |
| 批量配置 | 全选中文/英文、后续段自动衔接、费用确认；中英同段只生成一次 | 清单和最终确认截图、提交输入 |
| 参考图用途 | 单槽替换确认、多槽追加保留原图；普通参考不承诺严格首帧 | 替换确认及用途文案 |
| 顺序执行 | 3段真实本地视频，仅前段落盘后抽1张末帧，再提交后段 | 请求、落盘、抽帧顺序和末帧颜色断言 |
| 任务反馈 | 等待上段/抽取尾帧/衔接待处理/已保存区分，未落盘不计成功 | 任务卡和分组状态、状态单测 |
| 停止与恢复 | 等待/抽帧/上传时取消；失败不循环重试；可明确重试准备 | 取消后无新POST，恢复原链回归 |
| 身份安全 | 当前选择语言、相邻段号、项目、冻结来源；不自动增选收费段 | 选段空档报错、跨项目/损坏数据回归 |
| 重启安全 | 主文件旧、journal新；复用已抽帧，不重复POST；取消不复活 | 持久化/恢复回归 |
| 布局 | 1120×720和1280×800，100%/130%字体；桌面原生高DPI启动 | 弹窗/清单/任务状态截图与控件边界 |
| 视频素材多选 | 逐项勾选、跨页全选筛选结果、清空、批量追加；不覆盖已有剪辑 | 数量/顺序、失败保留选择、项目切换清理 |
| 时间线下方输出声音 | 同页修改尺寸/fps/BGM音量/淡入淡出，仍能剪辑片段 | 大小窗口中字段与导出按钮无遮挡，分页列表有完整行 |

探索场景至少覆盖：1. 只选择第1和第3段，不擅自用第1代替第2；2. 设置衔接后切换语言、撤销设置、切换工作流；3. 下载或抽帧失败后重试/取消。

真实远端模型的生成质量、计费及服务可用性不在无付费验收范围内。

## 实际验收结果

- 完整 `npm test` 通过，生产构建与分包体积检查通过。构建有 Vite 500 kB 提示；项目500 KiB体积预算通过。
- 真实FFmpeg：三段视频、两张真实末帧；第一条末帧为蓝色、第二条末帧为绿色，原视频校验值不变，下一段请求绑定准确帧字节；切换项目后仍只写原项目。
- 自动衔接真实按钮回归通过：零视频、替换确认、批量设置、中英切换、取消/恢复配置、缺段不提交及费用确认；旧的手动抽帧十二组交互回归通过。
- 视频工作台真实交互通过：跨页全选八个有效视频，保留原有片段并依次追加；搜索/取消选择；同页修改输出名/尺寸/fps/BGM音量/剪辑入点与转场；部分失败仅保留失败项、重试不重复追加成功项。
- 1120×720与1280×800，100%/130%字体下工作台所有相关控件无遮挡、无面板或整页滚动。额外预留184px侧栏与66px顶栏后仍通过。自动尾帧弹窗额外检查150%字体通过；桌面原生225%DPI确认控件完整。
- 0.5.123便携包隔离烟测通过，保存/重载、恢复点、内置媒体工具、要求窗口尺寸与控制台异常检查通过。旧0.5.122交付EXE校验保持不变。
- 所有数据均为隔离测试素材；无真实收费接口调用，无正式项目改写。
