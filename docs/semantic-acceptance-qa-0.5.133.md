# 去除本地语义拦截：0.5.133验收

## 已确认的根因

原来的本地形态分类器把“标准人形躯干、双臂双腿”等普通人类结构归入anthropomorphic。剧情解析的年龄检查移除AI提供的human-like标记后重新推断，再把anthropomorphic当作非人，碰到“约二十岁”便触发返修及拒收。并非修仙者天然被AI判断为非人。

本轮取消AI结果的本地语义判错、对应强制返修和词面删改。保留AI给出的普通资料、年龄、形态与不确定性。明确选择的形态可作为提示词输入，unknown/auto不等于非人。仍保留JSON、字段类型、ID、时间轴、真实接口/媒体文件错误和跨项目取消保护。

## 界面验收清单与结果

主代理使用Playwright Interactive、真实应用组件及同源模拟接口，在全新浏览器上下文中执行，没有访问正式项目数据或收费API。

- 实际点击“解析并补全”：3名人族修仙者、human-like、标准人形躯干/双臂双腿、外观约二十岁、实际约三百岁。
- 每名人物全部15个返回字段逐项与持久化数据一致；1个地点和1个场景正常保存。
- 每轮仅分析、人物补齐、地点补齐3次正常请求，0次年龄/物种语义返修。
- 切到图像工作台逐一选择3名人物，检查类人形态、身体结构、种族和两种年龄。
- 优化分别返回Markdown排版和英文自然段：原结果展示，0条本地语义警告；采用只放入编辑区，不自动覆盖保存原文；还原有效。
- 模拟HTTP503、损坏JSON：真实技术错误可见，不再被包装成“无法识别原因”；原有场景、人物和已保存剧情保持不变，无语义重试。
- 两轮分别在1280×800/100%和1120×720/130%字体、225%像素缩放执行，每轮7次模拟请求、无非预期控制台错误。
- 截图独立目检：原文页、人物年龄表单、对照审阅、语义校验关闭提示与技术错误弹窗；关键按钮和年龄字段无重叠遮挡。

报告与截图：`output/playwright/semantic-acceptance-133/`、`output/playwright/semantic-acceptance-133-small/`。

## 回归与限制

重点回归涉及llm、imageGeneration、imagePromptRules、storyboardImages、promptEngine、promptTranslation、appEffects以及分段计划。既有纯分析辅助函数可供历史测试/手动工具使用，但不再作为AI生成结果的语义门禁。

未验证真实外部模型的创作质量；不承诺AI永不判断错误。本轮验证的是本地不再因这些语义规则拒收或删改AI结果，同时技术错误仍明确显示且不覆盖已有数据。未批量修正历史人物、剧情或提示词，未重跑历史生成任务。
